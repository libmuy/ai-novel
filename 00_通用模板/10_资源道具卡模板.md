# 资源/道具分级卡模板

## 使用范围
所有主角获得或使用的法宝、丹药、功法、材料必须登记，防止战力崩坏。

## 资源卡片字段

### 基础信息

| 字段 | 类型 | 说明 |
|------|------|------|
| `名称` | 文本 (必填) | |
| `类型` | 枚举 (必填) | 法宝/丹药/功法/材料/秘境/情报/其他 |
| `等级` | 文本 (必填) | 对应玄道境界，如“筑基期可用，金丹期才发挥全力” |

### 来源与背景

| 字段 | 类型 | 说明 |
|------|------|------|
| `制造者/出处` | 文本 (必填) | 谁造的？从哪来？决定背景故事与隐患 |
| `当前持有者` | 文本 (必填) | |
| `获取章节` | 文本 (必填) | |

### 功能与限制

| 字段 | 类型 | 说明 |
|------|------|------|
| `核心能力` | 列表 (必填) | 最多2个，忌全能 |
| `使用代价` | 文本 (必填) | 每次消耗什么？次数限制？副作用？ |
| `使用限制` | 文本 (选填) | 需特定条件/血脉/环境？ |

### 隐患与关联

| 字段 | 类型 | 说明 |
|------|------|------|
| `追踪印记` | 文本 (选填) | 是否被做了手脚？能否被定位？ |
| `因果牵连` | 文本 (选填) | 持有它会引来谁？ |
| `伏笔功能` | 文本 (选填) | 关联哪个伏笔ID？ |

### 状态追踪

| 字段 | 类型 | 说明 |
|------|------|------|
| `当前状态` | 枚举 (必填) | 完好/受损/损毁/已消耗/已转让 |
| `历次使用记录` | 列表 (选填) | 章节号 + 使用效果 + 副作用 |
