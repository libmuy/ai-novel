# 版权安全与原创性规范模板

## 使用范围
定义全书的版权红线、禁词清单、古籍使用规则与原创改写标准。AI生成每一章后，必须自动检索并替换违禁内容。

---

## 一、禁词清单

### 1.1 严禁出现的真实古籍名句

包括但不限于：
- "天行健，君子以自强不息"
- "道可道，非常道"
- "知行合一"（原句，但可作为理念改写）
- "己所不欲，勿施于人"
- "大道至简"
- "上善若水"
- 任何《道德经》《论语》《易经》《庄子》等真实古籍的原句

**例外**：可以作为"理念"被主角用自己的话重新表达，但**禁止直接引用原句**。

### 1.2 严禁出现的知名仙侠作品原词

包括但不限于：

- "剑来"
- "我有一剑"
- "一剑光寒十九洲"
- "天地不仁，以万物为刍狗"（真实古籍+知名作品双重禁用）

- 任何《凡人修仙传》《剑来》《大奉打更人》《一念永恒》《完美世界》《斗破苍穹》等头部作品的高频台词或设定名

### 1.3 严禁出现的现实宗教原教义表述

- 儒家、兵家、佛家、道家等现实宗教思想的原教义表述
- 如："仁义礼智信"原句、"因果轮回"原句、"空性"原句等
- **例外**：可以作为"理念"被改写，但禁止直接使用宗教术语作为体系名称或台词

### 1.4 严禁出现的现实历史典故直接引用

- "荆轲刺秦"
- "卧薪尝胆"

- 任何现实历史事件的直接引用

## 二、虚构古籍使用规则

### 2.1 专属古籍库（全书固定）

**只使用以下六本虚构典籍，永不使用真实古籍**：

1. 《尘心杂记》
2. 《俗世儒章》
3. 《清虚残篇》
4. 《云山道录》
5. 《人间风物志》
6. 《乡野古训》

### 2.2 古籍引用规则

- 每句引用控制在**30字以内**
- 引用后**立刻回到剧情**，不做翻译或解释
- 只在**关键节点**使用，不是每章必用
- 使用前先铺垫"主角读过这本书"或"偶然想起某句话"
- 提前为每本古籍准备**3-5句核心短句+适用场景**

### 2.3 古籍弹药库格式

```markdown
### 古籍弹药库 · [书名]

风格：
主题：

核心短句：
- "……"（适用：面对抉择时）
- "……"（适用：失去重要之物时）
- "……"（适用：坚守底线时）
- "……"（适用：发现黑暗时）
- "……"（适用：底层人物高光时）
```

## 三、原创改写规则



### 2.4 古籍弹药库管理规则（简化版）

**种子库（固定）**：每本古籍预置 **5句** 核心短句，覆盖最通用场景（抉择/失去/坚守/离别/善恶）。全书不变。

**生长区（追加）**：写作中若种子库无贴切句子，允许创作新句，**但必须同时满足**：
1. 符合该古籍风格（见各书籍"风格"与"主题"字段）
2. 30字以内
3. 创作后立即登记到该古籍弹药库中，标注【追加】和首次使用章节

**AI决策优先级**：
1. 优先检索种子库
2. 若无，再检索生长区
3. 若仍无，则新创作并登记
4. **严禁硬凑旧句**——宁可留白，不贴错句

**清理规则**：每本古籍总句数不设硬上限。每卷结束后由人工审查一次，移除"只使用过一次且语境过于特殊"的句子。AI不执行删除操作。

### 3.1 哲理改写标准

当你想表达一个常见哲理时（如"修心重于修力"），**禁止直接写这个句子**。

**改写方法**：
1. 用主角的**底层视角**重新表达（如："境界是壳，心性是根，壳破根存，尚可再长；根烂壳在，终成空壳"）
2. 用**具体比喻**替代抽象概念（如：用"灯下有鬼"替代"人心险恶"）
3. 用**反讽或悖论**增加深度（如："人守一善，天予一难"替代"善有善报"）

### 3.2 体系名称原创标准

- 修行体系名称：必须自创，禁止与现实宗教或知名作品撞名
- 境界名称：必须自创，禁止与现实修炼术语或知名作品撞名
- 势力名称：必须自创，禁止与知名作品中的宗门/家族撞名
- 地理名称：必须自创，禁止与知名作品中的地名撞名

### 3.3 角色名称原创标准

- 主角及重要配角姓名：必须自创，禁止与知名作品主角撞名
- 外号/代号：必须体现角色特征，禁止直接借用知名作品外号

### 3.4 禁词改写示例对照表（供AI检索与替换参考）

| 禁词/禁句 | 允许的安全改写方式 |
|----------|------------------|
| 天行健，君子以自强不息 | 改写为："天不自健，人自健；天不自强，人自强。" |
| 道可道，非常道 | 改写为："说得清的道，不是真道；能命名的大道，早已偏离。" |
| 知行合一 | 改写为："知而不行，只是半知；行而不知，只是莽行。" |
| 上善若水 | 改写为："最大的善，像枯井里那点水——不争，却救了人命。" |
| 天地不仁，以万物为刍狗 | 改写为："天不偏人，地不怜命——凡人在这里，和杂草一样。" |
| 大道至简 | 改写为："真道理不复杂，复杂的是人心。" |
| 己所不欲，勿施于人 | 改写为："自己不想走的路，别推别人去踩。" |
| 三十年河东，三十年河西 | 改写为："河会改道，人会换命——但改道的水，还是那滩水。" |
| 莫欺少年穷 | 改写为："别因人穷就踩一脚——穷巷里的骨头，比朱门的肉硬。" |
| 我有一剑 | 改写为："我手里这柄短剑，崩了尖，钝了刃，但还能杀人。" |
| 剑来 | 改写为："剑在鞘里，鞘在腰上——拔不拔，看值不值。" |
| 浩然气 | 改写为："胸中那口气，不是天地给的，是自己一口一口攒的。" |
| 武夫境 | 改写为："武道修士不称境界，称背了几条魂。" |
| 香火神道 | 改写为："众生念力凝成神，神散了，念还在——只是没人记得了。" |

> **规则**：改写后的句子必须满足——① 融入具体意象（天/水/井/路/山等），② 30字以内，③ 自然嵌入主角的内心总结，而非强行加塞。

## 四、主角人设红线

### 4.1 固定人设（不可偏离）

| 要素 | 要求 | 禁止 |
|------|------|------|
| 出身 | 底层出身 | 禁止宗门天骄、转世大能、系统加身 |
| 心性 | 坚韧，守底线，懂取舍 | 禁止圣母、禁止冷血无情、禁止无脑爽 |
| 行事 | 遇事先明理再动手 | 禁止一言不合就开打、禁止以德报怨 |
| 主修 | 玄道 | 禁止开局即巅峰 |
| 兼修 | 文道感悟 | 禁止文道直接用于战斗（仅限明心见性、稳固道心） |
| 升级 | 必须有资源+心境+代价三重门槛 | 禁止闭关三月直接升级、禁止天降机缘无代价 |

### 4.2 "不吃无脑爽"的具体红线

- 禁止主角越阶秒杀（越阶必须有至少2个外部条件支撑）
- 禁止主角在绝境中"爆种"反杀（必须有提前铺垫的后手或外部援助）
- 禁止主角的敌人突然降智（敌人必须按"利益最大化"行动）
- 禁止主角的盟友无条件帮助（帮助必须有利益交换或情感铺垫）
- 禁止"杀人夺宝后无人追查"（必须结算消息传播和后续报复）

## 五、AI生成后的自动检索流程

每章生成后，必须执行以下检索：

1. **禁词检索**：扫描全文，匹配禁词清单。若出现，立即替换或删除。
2. **古籍检索**：确认所有古籍引用均来自六本虚构典籍。若出现真实古籍，立即替换。
3. **金句检索**：扫描是否有"常见网文金句"或"现实名人名言"的影子。若有，用主角自己的语言改写。
4. **人设检索**：确认主角行为符合"谨慎+守底线+懂取舍"。若出现无脑爽行为，重写。
5. **比例检索**：确认感悟段落不超过30%，打斗段落不超过70%。
