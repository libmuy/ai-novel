# 修炼体系模板

## 使用范围
定义小说中所有修行体系的本源、境界、能力、代价与互克关系。

## 体系卡片字段

### 基础定义

| 字段 | 类型 | 说明 |
|------|------|------|
| `体系名称` | 文本 (必填) | 体系唯一标识名 |
| `体系代号` | 文本 (选填) | 简称或内部代号 |
| `本源描述` | 文本 (必填) | 该体系的力量来源，如“天地灵气”“杀伐因果” |
| `修行方式` | 文本 (必填) | 如何获得与提升力量 |
| `代表人群` | 文本 (必填) | 典型修行者身份 |
| `破境考验` | 文本 (必填) | 每突破一个大境界必须面对的考验名称与形式 |

### 境界体系

| 字段 | 类型 | 说明 |
|------|------|------|
| `境界列表` | 表格 (必填) | 九级或自定义级境界，每级包含：境界名、对应基准境界、核心特征、战力标志、破境考验内容 |
| `基准对照系` | 文本 (必填) | 以哪一体系为通用参照（通常选玄道九境：练气→渡劫） |

### 能力边界

| 字段 | 类型 | 说明 |
|------|------|------|
| `核心能力` | 列表 (必填) | 该体系标志性能力，每项需注明上限与限制 |
| `能力细则` | 文本 (条件必填) | 对易崩坏的能力（如文道批注、言出法随）必须逐项划定红线 |
| `使用代价` | 文本 (必填) | 使用力量必须付出的普遍代价 |
| `致命弱点` | 列表 (选填) | 该体系在实战中的结构性弱点 |

### 互克关系

| 字段 | 类型 | 说明 |
|------|------|------|
| `克制体系` | 列表 (必填) | 该体系在规则上克制的其他体系 |
| `被克体系` | 列表 (必填) | 该体系在规则上被克制的其他体系 |
| `互克备注` | 文本 (选填) | 强调“互克非绝对”，说明取决于境界、环境、功法配合 |

### 兼修机制

| 字段 | 类型 | 说明 |
|------|------|------|
| `可兼修体系` | 列表 (选填) | 与本体系可兼容的其他体系 |
| `兼修桥梁` | 文本 (条件必填) | 两者兼容的核心逻辑 |
| `兼修代价` | 文本 (条件必填) | 兼修带来的额外风险或代价 |

```markdown
|-----------|---------|---------|---------|---------|
| ... | ... | ... | ... | ... |

【能力边界】
核心能力：
- 能力A：上限...，限制...
- 能力B：上限...，限制...

- 细则1：...
- 细则2：...

使用代价：

【互克关系】
克制体系：
被克体系：

【兼修机制】
可兼修体系：
兼修桥梁：（如适用）
兼修代价：（如适用）
```
