# 两难抉择设计卡模板

## 使用范围
每5-10章安排一次。主角必须选“吃亏”的选项，且代价不能立刻化解。

## 抉择卡片字段

### 情境构建

| 字段 | 类型 | 说明 |
|------|------|------|
| `触发事件` | 文本 (必填) | 发生了什么，迫使主角必须选？ |
| `时间压力` | 文本 (选填) | 是否必须在极短时间内决定？ |
| `旁观者` | 文本 (选填) | 有谁看着？这会影响主角的抉择吗？ |

### 选项设计

| 字段 | 类型 | 说明 |
|------|------|------|
| `选项A_内容` | 文本 (必填) | 利益选项 |
| `选项A_即时收益` | 文本 (必填) | |
| `选项A_长期收益` | 文本 (选填) | |
| `选项A_人设冲击` | 文本 (必填) | 是否违背“谨慎”或“底线”？ |
| `选项B_内容` | 文本 (必填) | 底线选项 |
| `选项B_即时代价` | 文本 (必填) | 必须具体且无法立刻化解 |
| `选项B_长期代价` | 文本 (选填) | |
| `选项B_人设强化` | 文本 (必填) | |

### 选择与后果

| 字段 | 类型 | 说明 |
|------|------|------|
| `最终选择` | 枚举 (必填) | 必须是B |
| `选择动作细节` | 文本 (必填) | 忌心理描写，用动作体现纠结 |
| `即时后果` | 文本 (必填) | 立刻发生的坏事 |
| `延迟回报` | 文本 (选填) | 预计多少章后以什么形式回报？ |
| `关联配角反应` | 文本 (选填) | 谁因此事改变了对主角的看法？ |

### 感悟闭环

| 字段 | 类型 | 说明 |
|------|------|------|
| `事件结果` | 文本 (必填) | |
| `古籍点题` | 文本 (必填) | |
| `内心总结` | 文本 (必填) | 大白话 |
| `转化为行动准则` | 文本 (必填) | |

### 代价追踪

| 字段 | 类型 | 说明 |
|------|------|------|
| `连锁反应列表` | 列表 (必填) | 至少列出3个后续章节的影响 |
