# 状态台账模板

> 类型：卡片模板 · 定义字段与填写示例，用于生成/维护 `03_状态/` 下的动态状态台账。

## 定位：与事件卡的分工

> **事件卡管"事"，台账管"态"。**
> - `08_战斗结算`、`09_主角突破卡`、`10_事件与感悟卡` = 事件的设计与叙事（为什么打、怎么打、消息怎么传、心理影响）——记录"发生了什么"；资源物品条目登记在 `04_资源` 类别文件【物品卡】。
> - 状态台账 = 状态的投影与连续性（某人什么境界、某物在谁手里、势力什么关系）——记录"现在是什么"。
> - **单向引用**：台账条目引用事件卡 ID（`BT-`/`BP-`/`RES-`），事件卡不回指台账，避免双向维护。
> - **身份与状态分离**：身份/设定（性格、立场、欲望）以 `02_数据库/` 对应卡片为正典；台账只记动态量（境界、伤势、所在地、持有、关系、隐患、财务）。冲突时身份以设定卡为准、状态以台账为准。

## 触发规则（建台账条件）

| 类型 | 建台账条件 | 说明 |
|------|-----------|------|
| **人物** | 出场≥3章，或有持续状态变化（境界/伤势/关系/位置/持有） | 主角必建 |
| **物品** | 具备**独立叙事身份**：世界唯一、有生命周期、状态变化牵动剧情 | 可流通商品/消耗品（丹药、灵石、普通法器）不建，数量记入持有者台账的"装备持有" |
| **势力** | 有敌友/实力/领地变化，且与主角互动持续 | 一次性背景势力不建 |
| **财务** | 主角必建；重要人情债/债务往来的角色视需要建 | 对应 `04_资源` 主角经济曲线 |
| **世界** | 出现疑似违反/揭示世界基本法则的异常现象，或未知规则（WR-未知）进入揭示流程 | 数据文件 `03_状态/世界_当前状态.md`；只记动态世界状态，身份/公理以 `01_设定/00_小说概念.md`【世界基本法则】为正典，冲突时**不得修改世界基本法则** |

## 通用结构（两段式）

每份台账固定两段：**顶部是当前状态快照（写作会话只读这一段），下方是变更历史（维护会话追加，对账用）**：

```markdown
# 状态台账 · [类型] · [对象名]
> 追踪对象：@引用
> 正典来源：02_数据库/[对应设定卡]（身份/设定以此为准，本文件只记动态量）
> 触发规则：[建台账原因]
> 更新职责：维护会话（任务9）每章后追加变更并刷新快照；写作会话只读【当前状态快照】段。

## 当前状态快照（更新至 第N章）
[五类字段，见下]

## 变更历史（薄索引 · 追加式）
| 章节 | 事件卡ID | 维度 | 变更 from → to | 备注 |
|------|---------|------|---------------|------|
| [N] | [事件卡ID] | [维度] | [变更前] → [变更后] | [事件简述] |
```

## 五类字段定义

### 1. 人物台账（`人物_姓名.md`）
| 字段 | 说明 |
|------|------|
| 境界 / 身体状况 / 所在地 / 装备持有 / 关键关系 / 财务 / 隐患·未解代价 / 当前目标 | 快照逐项填写 |

### 2. 物品台账（`物品_名称.md`）
| 字段 | 说明 |
|------|------|
| 持有者 / 状态（完好·受损·损毁·封印·易主）/ 数量·耐久 / 等级·类别 / 关联伏笔 / 附加说明 | 快照逐项填写 |

### 3. 势力台账（`势力_名称.md`）
| 字段 | 说明 |
|------|------|
| 综合实力 / 领地·据点 / 主要关系 / 与主角互动状态 / 当前动向 | 快照逐项填写 |

### 4. 财务台账（`财务_主角.md`）
| 字段 | 说明 |
|------|------|
| 对应经济阶段 / 灵石结余 / 主要资产 / 人情债 / 固定支出 / 近期收支变动 | 快照逐项填写 |

### 5. 世界台账（`世界_当前状态.md`）
| 字段 | 说明 |
|------|------|
| 当前世界状态 | 世界层面当前可公开/可感知的状态（不涉及未揭示真相） |
| 未知规则揭示进度 | WR-未知 规则清单：规则ID / 是否进入揭示流程 / 当前揭示阶段 / 关联伏笔（@伏笔.ID） |
| 疑似异常现象 | 疑似违反/揭示世界法则的现象：现象描述 / 涉及规则（WR ID） / 是否已解释 / 结论（正常/待揭示/留待后文） |
| 关联事件卡 | 引用 `BT-`/`BP-`/`C` 事件卡 ID，登记现象首次出现的章节 |

> 身份/公理以 `01_设定/00_小说概念.md`【世界基本法则】为正典；本台账只记动态世界状态。异常现象登记后**不得修改**世界基本法则；未知规则经用户确认揭示后，才由维护会话更新概念卡规则状态，并在此台账记录揭示进度。

## 对账规则（防漂移核心）

1. **每章结束后**，维护会话执行：读本章正文 + 本章新建事件卡（`BT-`/`BP-`/`RES-`），逐卡提取状态变更。
2. **对账语句**：本章所有新建事件卡的状态变更，必须在对应台账【变更历史】中能查到条目。查不到 = 漏记，立即补。
3. **追加式维护**：历史只追加不修改；快照随最新变更刷新。若历史与快照冲突，以历史最新条目为准并核对事件卡。
4. **索引同步**：新增/停用台账对象时，更新 `03_状态/00_索引.md`。
5. **正文为准**：若变更清单与正文冲突，以正文为准（读者看到的真相），并回头修正事件卡与台账。

## 首次建台账

- 按触发规则确定首批对象（主角、出场≥3章配角、独立叙事身份物品、主角财务、持续互动势力；世界台账在出现疑似违反/揭示世界法则的异常现象或未知规则进入揭示流程时建立）。
- 初始快照 = 各对象在"正文开写前"的起始状态（从 `02_数据库/` 定稿数据提取；正文卷大纲未写前即为第0章起点）。
- 变更历史初始为空，等待第一张事件卡触发。
