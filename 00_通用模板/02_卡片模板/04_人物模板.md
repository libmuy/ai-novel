# 人物模板

> 类型：卡片模板 · 定义字段与填写示例，用于生成/维护 `02_数据库/07_人物/07_人物.md`。
>
> 适用：所有出场超过3章、对主线有推动、有独立选择的角色。

## 字段与示例

`(必)`=必填，其余选填；示例值为格式参考，勿照抄。

### 人物卡 · [角色姓名]

【基础档案】
| 字段 | 必填 | 说明与示例 |
|------|------|-----------|
| 姓名 | (必) | 本名 |
| 代号/外号 | | 江湖称呼，体现特征或他人评价 |
| 性别 | | |
| 年龄/寿元 | | 凡人写年龄；修士写"外表年龄/实际寿元" |
| 出身地 | | 具体到村镇或势力 |

【修行档案】
| 修行体系 | (必) | 关联修炼体系卡 |
| 当前境界 | (必) | 对照基准体系，如"[体系]·[境界名]（对应[基准境界]）" |
| 功法/神通特色 | | 2-3个核心能力，忌多忌杂 |
| 本命法宝/武器 | | 名称+特征，无则写"无" |
| 战斗风格 | | 近战/远程/伏击/阵法/辅助，及标志性战术 |

【角色内核】（三要素）
| 立场 | (必) | 站在哪一边，具体到势力或理念 |
| 欲望 | (必) | 最想要什么，越具体越好 |
| 底线 | (必) | 何时翻脸、牺牲、背叛或赴死 |

【与主角关系】
| 初遇地点 | | |
| 初遇关系定位 | | 恩人/仇敌/交易对象/路人 |
| 关系演变轨迹 | | 如"利用→猜忌→合作→诀别" |
| 对主角的影响 | | 教会主角什么？或触发主角哪次道义选择？ |
| 主角对其的影响 | | 因主角改变了什么选择？ |

【独立故事线】
| 人生目标 | | 与主角无关时，他自己想做什么？ |
| 当前进度 | | 目标完成多少？遇到什么阻碍？ |
| 高光时刻设计 | | 预计在哪段剧情做出独立于主角的关键选择？ |
| 预计退场方式 | | 死亡/离开/背叛/飞升/被遗忘/化为战鬼等 |
| 退场情感基调 | | 壮烈/苍凉/释然/讽刺/温暖 |

【创作标签】
| 情绪功能 | | 温暖担当/黑暗揭示/利益镜子/道义对照/喜剧调剂/悲剧预警 |
| 说话风格 | | 寡言/机锋/市井粗口/文言腔/阴阳怪气/沉默行动派 |
| 标志性细节 | | 一个动作、物品或习惯，用于替代"他很悲伤" |

## 动态字段清单

> 声明本角色的哪些属性随剧情变化、需要进入状态追踪。字段名与类型以 `00_通用模板/03_字段词表.md`【角色类对象】为准；`build_baseline.py` 按本小节生成基线候选，`audit` 的 `state_field_undeclared` 按本小节校验履历字段。
> **关系类不在此声明**：角色与角色/势力的关系走 `06_关系` 一等对象或从属方单指针字段（师承/持有者等），见字段词表【关系类对象】。
