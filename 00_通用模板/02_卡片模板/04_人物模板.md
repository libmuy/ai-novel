# 人物模板

> 类型：卡片模板 · 定义字段与填写示例，用于生成/维护 `02_数据库/07_人物/07_人物.md`。
>
> 适用：所有出场超过3章、对主线有推动、有独立选择的角色。
>
> **数据库章节边界**（`00_系统架构规范.md` §七、§二·A）：人物卡记录身份、内核、能力、关系弧线与长期状态，**不记章节号**。"某人第几章登场/退场、第几章与主角关系变化、第几章做出某选择"——唯一权威是所属卷 `规划_卷NN.md`【章节节拍表】对应行摘要的 `@引用`。关联伏笔/道义写 `@伏笔.<ID>` / `@道义.<ID>`。`audit_consistency.py` 的 `DBCHAP001` 会拦卡片正文里的 `第N章` / `卷N第` / `场景N`。

## 设定层边界（人物卡不写剧情）

> 人物卡属**设定层**，回答「他是谁、要什么、能做什么、大致会走向哪里」，**不提供剧本**（`00_系统架构规范.md` §二「核心判定原则」、§七）。历史上云端会把「谁对谁做了什么、发生了几次、给了多少」写进卡里——这些是规划层（卷纲【章节节拍表】【关系变化】【本卷退场配角】）与状态层（`05_工作区/02_状态/`）的事实，写进卡里就成了第二份、会漂移，还会剧透并被当成硬约束（曾出现人物卡写死某次事件的具体经过，与后来的细纲冲突，只能回头改卡）。
>
> **写法判据**：一句话换一章、换一种写法仍成立 → 可写；必须依赖「某次发生了某事」才成立 → 不写，去它的权威位置。
>
> | 不写（事件 / 状态） | 写（定性） |
> |---|---|
> | 「主角用异宝帮他续了三年命」「被主角一击击杀」 | 「因被主角信任而做出违背自保的选择」 |
> | 「攒了七年，有二十三枚，还差七十七枚」「据点被砸了两次」 | 「长期攒钱只为一个具体的翻身指望」 |
> | 「引爆火硝矿囊与敌同归于尽」（具体手段与经过） | 「以自身为代价换他人生路的牺牲」（方式类别 + 情感基调） |
>
> - **可以写**：性格、能力与限制、立场 / 欲望 / 底线、关系**形态**（如「利用→猜忌→合作→诀别」）、弧线**定性**、关键信物 / 遗物的**名称**（供卷纲对账，不写其流转经过）。
> - **不写**：具体事件经过、次数、数量与金额、「主角……了」式动作链、章节号；动态状态（当前进度 / 伤势 / 心境 / 所在地）一律走状态层，不进卡。
> - 情节里用到而卡上没有的**长期事实**，按 `00_系统架构规范.md`「设定缺口的补录」补进卡，不要写进细纲 / 正文就算了。
> - `audit_consistency.py` 的 `CARDPLOT001/002` 会拦本节禁写内容；确需保留某行时加 `<!-- CARDPLOT-ok: 理由 -->`。

## 字段与示例

`(必)`=必填，其余选填；示例值为格式参考，勿照抄。

### 人物卡 · [角色姓名]

【基础档案】
| 字段 | 必填 | 说明与示例 |
|------|------|-----------|
| 姓名 | (必) | 本名 |
| 代号/外号 | | 江湖称呼，体现特征或他人评价 |
| 性别 | | |
| 年龄/寿元 | | 凡人写年龄；修士写"外表年龄/实际寿元" |
| 出身地 | | 具体到村镇或势力 |

【修行档案】
| 修行体系 | (必) | 关联修炼体系卡 |
| 当前境界 | (必) | 对照基准体系，如"[体系]·[境界名]（对应[基准境界]）" |
| 功法/神通特色 | | 2-3个核心能力，忌多忌杂 |
| 本命法宝/武器 | | 名称+特征，无则写"无" |
| 战斗风格 | | 近战/远程/伏击/阵法/辅助，及标志性战术 |

【角色内核】（三要素）
| 立场 | (必) | 站在哪一边，具体到势力或理念 |
| 欲望 | (必) | 最想要什么，越具体越好 |
| 底线 | (必) | 何时翻脸、牺牲、背叛或赴死 |

【与主角关系】
| 初遇地点 | | 关联 `@区域.[名称]` / `@地名.[名称]`，不写"第几章初遇" |
| 初遇关系定位 | | 恩人/仇敌/交易对象/路人 |
| 关系演变轨迹 | | 关系**弧线形态**，如"利用→猜忌→合作→诀别"；只写形态，不写具体事件与"第几章变化"（哪一章发生去卷大纲节拍表查） |
| 对主角的影响 | | 教会主角什么认知 / 触发主角哪类道义选择（**定性**，如「教会主角：规则可以被利用也可以被改变」）；关联道义用 `@道义.<ID>`、伏笔用 `@伏笔.<ID>`，不写章节号与具体事件 |

> 「主角对其的影响」字段已取消：那是「主角对他做了什么」的事件描述，归卷纲【关系变化】与状态层，不进人物卡。

【独立故事线】
| 人生目标 | | 与主角无关时，他自己想做什么？（长期愿望，不写进度；「当前进度 / 阻碍」属动态状态，走状态层，本字段已取消） |
| 高光时刻设计 | | 预计做出哪一类独立于主角的关键选择（**弧线定性**，写"是什么"，一两句）；不写具体手段与经过、不写章节号、不复述节拍表剧情。见上「设定层边界」对照表 |
| 预计退场方式 | | 死亡/离开/背叛/飞升/被遗忘/化为战鬼等**类别** + 一句话影响；不写具体经过与"第几章退场"（退场章与经过归卷大纲【章节节拍表】【本卷退场配角】）。卷纲验收要与本字段对账，故类别须明确 |
| 退场情感基调 | | 壮烈/苍凉/释然/讽刺/温暖 |

【创作标签】
| 情绪功能 | | 温暖担当/黑暗揭示/利益镜子/道义对照/喜剧调剂/悲剧预警 |
| 说话风格 | | 寡言/机锋/市井粗口/文言腔/阴阳怪气/沉默行动派 |
| 标志性细节 | | 一个动作、物品或习惯，用于替代"他很悲伤" |

## 动态字段清单

> 声明本角色的哪些属性随剧情变化、需要进入状态追踪。字段名与类型以 `00_通用模板/03_字段词表.md`【角色类对象】为准；`build_baseline.py` 按本小节生成基线候选，`audit` 的 `state_field_undeclared` 按本小节校验履历字段。
> **关系类不在此声明**：角色与角色/势力的关系走 `06_关系` 一等对象或从属方单指针字段（师承/持有者等），见字段词表【关系类对象】。
