# 修炼体系模板

> 类型：卡片模板 · 定义字段与填写示例，用于生成/维护 `02_设定/01_修炼体系/01_修炼体系.md`。

## 字段与示例

`(必)`=必填、`(条)`=条件必填，其余选填；示例值为格式参考，勿照抄。

### 体系卡 · [体系名称]

【基础定义】
| 字段 | 必填 | 说明与示例 |
|------|------|-----------|
| 体系名称 | (必) | 体系唯一标识名 |
| 体系代号 | | 简称或内部代号 |
| 本源描述 | (必) | 力量来源，如"天地灵气""杀伐因果" |
| 修行方式 | (必) | 如何获得与提升力量 |
| 代表人群 | (必) | 典型修行者身份 |
| 破境考验 | (必) | 每突破一个大境界必须面对的考验名称与形式 |

【境界体系】
| 境界列表 | (必) | 表格每行：本体系境界 \| 对应基准 \| 核心特征 \| 战力标志 \| 破境考验 |
| 基准对照系 | (必) | 以哪一体系为通用参照（各书自定，通常选主修体系） |

【能力边界】
| 核心能力 | (必) | 体系标志性能力，每项注明上限与限制 |
| 能力细则 | (条) | 易崩坏能力（言出法随、因果干预等）必须逐项划定红线 |
| 使用代价 | (必) | 使用力量必须付出的普遍代价 |
| 致命弱点 | | 体系在实战中的结构性弱点 |

【互克关系】
| 克制体系 | (必) | 规则上克制哪些体系 |
| 被克体系 | (必) | 规则上被哪些体系克制 |
| 互克备注 | | 强调"互克非绝对"，取决于境界、环境、功法配合 |

【兼修机制】
| 可兼修体系 | | 可兼容的其他体系 |
| 兼修桥梁 | (条) | 两者兼容的核心逻辑 |
| 兼修代价 | (条) | 兼修带来的额外风险或代价 |
