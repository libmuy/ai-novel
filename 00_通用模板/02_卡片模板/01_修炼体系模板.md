# 修炼体系模板

> 类型：卡片模板 · 定义字段与填写示例，用于生成/维护 `02_数据库/01_修炼体系/` 文件夹及下属层级文件。

## 层级结构与文件拆分

本分类为多实体查表型数据，采用「总索引 + 子文件」多文件结构，**产出合计 >1KB 时按每体系一文件拆分**（≤1KB 保持单文件、全部写入总索引）。全部文件置于分类文件夹 `02_数据库/01_修炼体系/` 内。

| 文件 | 内容 |
|------|------|
| `02_数据库/01_修炼体系/01_修炼体系.md` | 总索引：【体系索引】表格（体系名｜一句话概况｜体系文件链接）+【大境界一览】表（9 大境界跨体系对照 + 破境考验，供 agent 低 token 定位突破节点）+【待创建条目】；≤1KB 时承载全部体系卡 |
| `02_数据库/01_修炼体系/01_修炼体系_<体系名>.md` | 体系文件：单个体系卡全文（含基准对照系/境界表/能力边界/互克关系/兼修机制）；辅助职业卡（如 `[辅助职业名]`）同样以独立文件落位，不走境界体系/互克/兼修结构，索引中标注"辅助职业" |

**文件命名规则**：文件名 = 前缀 `01_修炼体系` + `_<体系名>`，名称与体系卡名称完全一致。

**父子关系规则**：总索引放「体系索引 + 文件链接」，子文件放「体系卡全文」；多体系并存时每体系一个文件，互克/兼修跨文件用体系名称（`体系名` 文本）引用，引用对象未成卡时登记「待创建条目」。增量追加新体系时，须同步在总索引【体系索引】表追加该体系行（体系名｜一句话概况｜体系文件链接），不得只新增体系文件而遗漏父索引更新。

**按需取分支示例**：某章需主角所在体系设定，只加载 `02_数据库/01_修炼体系/01_修炼体系.md`（总索引）+ `02_数据库/01_修炼体系/01_修炼体系_<主修体系名>.md`；涉及互克/兼修体系时再追加对应体系文件，禁止整目录全量灌入。

## 字段与示例

`(必)`=必填、`(条)`=条件必填，其余选填；示例值仅为**格式示范、非预设设定**，禁止照抄示例名称，实际名称须按小说题材定位自主原创。

### 体系卡 · [体系名称]

【基础定义】
| 字段 | 必填 | 说明与示例 |
|------|------|-----------|
| 体系名称 | (必) | 体系唯一标识名 |
| 体系代号 | | 简称或内部代号 |
| 本源描述 | (必) | 力量来源，如"天地灵气""杀伐因果" |
| 修行方式 | (必) | 如何获得与提升力量 |
| 代表人群 | (必) | 典型修行者身份 |
| 破境考验 | (必) | 每突破一个大境界必须面对的考验名称与形式 |

【境界体系】
| 境界列表 | (必) | 表格每行：本体系境界 \| 对应基准 \| 核心特征 \| 战力标志 \| 破境考验。**两种可接受结构**：① 主修体系用完整境界表（大境界×小境界×四阶，逐小境界列核心特征/战力标志）；② 辅助/次级体系可用 9 级简表（等级｜对应主修境界｜核心能力｜战力标志），一级对应主修一个大境界 |
| 基准对照系 | (必) | 以哪一体系为通用参照（各书自定，通常选主修体系） |

【能力边界】
| 核心能力 | (必) | 体系标志性能力，每项注明上限与限制 |
| 能力细则 | (条) | 易崩坏能力（言出法随、因果干预等）必须逐项划定红线 |
| 使用代价 | (必) | 使用力量必须付出的普遍代价 |
| 致命弱点 | | 体系在实战中的结构性弱点 |

【预留接口】(选)
| 未命名段位 | 境界表顶端之上是否保留"传说中更高层次"的模糊表述 |
| 未分类功法 | 是否预留"不属于任何已知体系"的功法归类位 |
| 非常规突破 | 是否预留正常突破路径之外的破例通道（不写死具体触发条件） |

【互克关系】
| 克制体系 | (必) | 规则上克制哪些体系 |
| 被克体系 | (必) | 规则上被哪些体系克制 |
| 互克备注 | | 强调"互克非绝对"，取决于境界、环境、功法配合 |

【兼修机制】
| 可兼修体系 | | 可兼容的其他体系 |
| 兼修桥梁 | (条) | 两者兼容的核心逻辑 |
| 兼修代价 | (条) | 兼修带来的额外风险或代价 |

【体系规则】（独立区域 · 体系内部规则）

> 本区块定义该修炼体系**内部**的规则，是「世界基本法则（上位规则）→ 修炼体系规则 → 具体能力规则 → 剧情行为」优先级链的体系层。上位规则见 `01_设定/00_小说概念.md`【世界基本法则】（WR 规则，硬/软/未知三态）。体系规则不得违反上位硬规则；若与本体系其他区块字段重复，本区块只做汇总引用、不重复填写细节。

| 字段 | 必填 | 说明与示例 |
|------|------|-----------|
| 力量来源 | (必) | 体系力量从何而来（汇总【基础定义】本源描述；须与世界「力量法则」一致：力量必须有来源、不得凭空产生） |
| 修炼原理 | (必) | 如何获得与提升力量（汇总【基础定义】修行方式） |
| 消耗机制 | (必) | 使用力量必须付出的消耗与代价（汇总【能力边界】使用代价；不得存在"无代价能力"，除非上位软规则允许且已铺垫） |
| 突破条件 | (必) | 晋升所需条件（汇总【基础定义】破境考验 + `09_主角突破卡` 三重门槛：资源/心境/外部） |
| 突破风险 | (必) | 突破失败或强行突破的后果（境界跌落/经脉受损/寿元削减等） |
| 能力限制 | (必) | 能力上限与红线（汇总【能力边界】核心能力上限/能力细则/致命弱点；能力必须存在上限） |
| 克制关系 | (必) | 体系互克（汇总【互克关系】；互克非绝对） |
| 体系边界 | | 该体系做不到什么、是否触及上位规则边界（汇总【预留接口】：未命名段位/未分类功法/非常规突破） |
| 特殊例外 | | 体系内允许的破例情形：例外内容 + 触发前提（必须明确铺垫，不得违反世界硬规则） |
| 上位规则合规声明 | (必) | 本体系遵守哪些世界硬规则（引用 WR 编号）；与哪些世界软/未知规则相关；是否触碰「规则级力量/复活/因果干预/信息垄断」等敏感边界及处理方式；确认无冲突 |

## 体系规则与世界基本法则的一致性检查

生成或修改本体系时，逐项检查（与 `01_设定/00_小说概念.md`【世界基本法则】对照）：

1. 是否违反世界硬规则？
2. 是否与世界力量法则一致（来源/消耗/上限/克制/副作用）？
3. 是否与生命与死亡法则冲突（不得设计无条件复活、无代价永生）？
4. 是否与因果法则冲突（誓言/契约/命运/时间相关能力是否有上位依据）？
5. 是否产生无法解释的力量来源？
6. 是否存在无代价能力？
7. 是否存在能力上限？

任一检查不通过：修改本体系设计，不得修改世界基本法则；确实触及未知规则时，登记伏笔并保持规则「未知」。
