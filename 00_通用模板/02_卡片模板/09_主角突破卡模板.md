# 主角突破卡模板

> 类型：卡片模板 · 定义字段与填写示例，用于生成/维护突破数据。数据落位：`03_规划/《部编号》_《部名》/《卷编号》_《卷名》/00_事件卡/<BP-卷号-序号>_突破卡.md`。
>
> 主角每次突破大境界或关键小境界时必须填写；日常修炼进度无需填写。突破不是"升级"，而是力量、代价、感悟三者的交汇点。

## 字段与示例

`(必)`=必填，其余选填；示例值为格式参考，勿照抄。

### 突破卡 · [BP-卷号-序号]

【基础信息】
| 字段 | 必填 | 说明与示例 |
|------|------|-----------|
| 突破ID | (必) | 格式：`BP-卷号-序号`，如 `BP-V1-001` |
| 突破章节 | (必) | 发生在第几章，如 `第23章` |
| 当前境界 | (必) | 突破前的境界 |
| 目标境界 | (必) | 突破后的境界 |
| 突破类型 | (必) | 正常晋升/强行突破/破而后立/外力催化/双修共鸣 |

【前置条件】（必填，缺一不可）
| 修为积累 | (必) | 突破前积累了多少章？具体做了什么？（如：历经7章，完成3次任务，积累[资源]若干） |
| 资源消耗 | (必) | 使用哪些资源？引用 `@资源.名称` + 数量。必须与 `04_资源` 等级匹配 |
| 外部契机 | (必) | 什么外部事件触发突破契机？（战斗重伤、古籍启发、生死危机、他人点化） |
| 心境铺垫 | (必) | 突破前经历了什么心理变化？（如：第一次杀人后的自我怀疑、目睹弱者被欺后的愤怒与无力） |

> 四字段对应 `00_通用写作规则` §7「突破门槛」三重门槛：资源消耗→资源条件、心境铺垫→心境条件、外部契机→外部条件、修为积累=前置积累量。

【突破过程设计】
| 突破场景 | (必) | 在哪里突破？环境特征？（忌"洞府闭关"，要有具体环境压力：瘴气沼泽、敌营腹地、雷暴山巅） |
| 冲突原型 | (必) | 本次突破的戏剧引擎：**谁在此刻入场？给出什么交易/诱惑/设局？**突破必须在具体人物与具体局面中发生，禁止抽象"战胜心魔"。须与修炼体系【大境界破境考验】对应（如"道灵择"→某势力此刻抛出改修诱惑） |
| 过程描写 | (必) | 突破不是"轰的一声"，要写身体具体感受（经脉撕裂、灵气倒灌、识海震荡、旧伤复发） |
| 干扰因素 | | 是否有外部干扰？（敌人追杀、环境恶化、心魔侵扰、资源不足） |
| 失败风险 | (必) | 失败代价是什么？（境界跌落、经脉受损、寿元削减、被敌人发现） |

【突破结果】
| 新能力 | (必) | 核心能力变化，2-3项，忌多忌杂。必须具体（如：灵气储量翻倍→持续战斗时间从半时辰延至一个时辰） |
| 新限制 | (必) | 新增的限制或代价（如：需定期服用[巩固丹药]，否则境界不稳；新功法与旧功法冲突需重新磨合） |
| 战力评估 | (必) | 突破后能打什么水平？与同境界普通修士相比如何？（必须诚实，禁止"同阶无敌"） |

【后续影响】
| 势力反应 | | 哪些势力会注意到这次突破？他们会怎么做？ |
| 敌人反应 | | 敌人得知后会如何调整策略？ |
| 新目标 | | 突破后主角的下一个目标？ |

## 突破后联动

- 突破/资源类红线（禁无代价、禁顿悟、禁越阶秒杀、禁连续突破等）定义见 `00_通用写作规则` §7，逐项自检见其第八章【事件设计层】。
- 突破卡负责"过程与结果"。突破完成感悟闭环 → 必须在正文生成后，单独填一张 `10_事件与感悟卡` 扩展为完整"事件→古籍→感悟"三段式；突破卡的`古籍引用`字段与事件与感悟卡必须一致。
