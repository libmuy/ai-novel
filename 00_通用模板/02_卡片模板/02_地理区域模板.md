# 地理区域模板

> 类型：卡片模板 · 定义字段与填写示例，用于生成/维护 `02_数据库/02_地理区域/` 文件夹及下属层级文件。

## 层级结构与文件拆分

地图数据采用「世界 → 区域 → 地名」三级层级，按层级拆分为多文件，**传给 AI 时自上而下按需取分支，禁止全量加载**。全部文件置于分类文件夹 `02_数据库/02_地理区域/` 内。

| 文件 | 内容 |
|------|------|
| `02_数据库/02_地理区域/02_地理区域.md` | 总索引：世界索引（世界名｜一句话概况｜世界文件链接） |
| `02_数据库/02_地理区域/02_地理区域_<世界名>.md` | 世界文件：世界卡全文 + 该世界全部区域卡 |
| `02_数据库/02_地理区域/02_地理区域_<世界名>_<区域名>.md` | 区域文件：区域卡全文 + 该区域地名索引（地名｜一句话｜文件链接） |
| `02_数据库/02_地理区域/02_地理区域_<世界名>_<区域名>_<地名>.md` | 地名文件：单个地名卡全文 |

**文件命名规则**：文件名 = 前缀 `02_地理区域` + 按「世界/区域/地名」逐级追加 `_<名称>`，名称与卡片名称、`@引用` 标识完全一致；文件均位于 `02_数据库/02_地理区域/` 文件夹内。

**父子关系规则**：父文件放「下一级的索引/卡片清单」，子文件放「本级卡片全文」；区域卡在世界文件（完整列出该世界所有区域）与区域文件（自包含头部）各出现一次，地名卡全文只在地名文件（区域文件仅索引，不重复）。增量追加新世界/区域/地名时，须自顶向下逐级同步更新父文件索引（总索引【世界索引】/区域文件【地名索引】），新增条目行与子文件一一对应。

**按需取分支示例**：某章发生在「世界A/区域B」的地名C，只加载 `02_数据库/02_地理区域/02_地理区域.md`（总索引）+ `02_数据库/02_地理区域/02_地理区域_世界A.md` + `02_数据库/02_地理区域/02_地理区域_世界A_区域B.md` + `02_数据库/02_地理区域/02_地理区域_世界A_区域B_地名C.md`，自上而下逐级下钻，禁止整文件全量灌入。

## 字段与示例

`(必)`=必填，其余选填；示例值为格式参考，勿照抄。

### 总索引 · `02_数据库/02_地理区域/02_地理区域.md`

【世界索引】表格，每行：世界名 | 一句话概况 | 世界文件（`02_数据库/02_地理区域/02_地理区域_<世界名>.md`）

### 世界卡 · [世界名称]（世界文件头部）

【基础信息】
| 字段 | 必填 | 说明与示例 |
|------|------|-----------|
| 世界名称 | (必) | 唯一标识名，与文件名 `_<世界名>` 一致 |
| 世界概况 | (必) | 一句话总览世界格局 |
| 天地灵气 | (必) | 灵气总量与分布大格局，与修炼体系境界挂钩 |

【区域构成】
| 区域列表 | (必) | 该世界下辖的全部区域卡，逐区填写（见下「区域卡」），区域名与区域文件名一致 |

【宏观格局】
| 支配势力 | (必) | 世界级支配性势力，引用 `@势力.[名称]` |
| 世界级冲突 | (必) | 决定世界走向的核心矛盾 |
| 世界观秘密 | | 最高层真相、禁地、禁忌 |

### 区域卡 · [区域名称]（世界文件内逐区填写）

【基础信息】
| 字段 | 必填 | 说明与示例 |
|------|------|-----------|
| 区域名称 | (必) | 唯一标识名，与文件名 `_<区域名>` 一致 |
| 所属世界 | (必) | 所在世界名称（与上一级世界卡一致，文本即可） |
| 区域层级 | (必) | 凡域/坊市带/天域/禁地/其他自定义层级 |
| 地理位置 | (必) | 在世界中的相对位置与接壤区域，引用 `@区域.[名称]` |
| 灵气浓度 | (必) | 对修行的影响，如"稀薄""中等""浓郁如液"，与可支持的最高境界匹配 |

【历史成因】(条·仅区域层级=禁地时必填)
| 起源事件 | 何时、因何事导致此地变为禁地 |
| 遗留威胁 | 至今仍存在的危险源头 |
| 关联伏笔 | 引用 @伏笔.[ID]（若已有，若无则留空） |

【生态与资源】
| 主导体系 | (必) | 该区域哪种修行体系占主流 |
| 特产资源 | (必) | 该区域产出的关键资源 |
| 危险等级 | | 进入所需的最低实力或生存难度 |
| 区域特色 | (必) | 用于叙事的世界观氛围描述 |

【势力分布】
| 势力列表 | (必) | 区域内所有重要势力，引用 `@势力.[名称]` |
| 势力关系简述 | | 区域内势力间的局部冲突或合作 |

【地名构成】
| 地名列表 | (必) | 该区域下辖全部地名，引用 `@地名.[名称]`，并与地名文件名一致 |

【与主角关系】
| 主角活动阶段 | | 主角在哪一境界阶段主要在此活动 |
| 核心冲突类型 | | 主角在此区域经历的主要冲突类型 |
| 世界观展开层级 | | 该区域揭示世界的哪一层真相 |

### 区域文件 · `02_数据库/02_地理区域/02_地理区域_<世界名>_<区域名>.md`

- 区域卡（同世界文件内该区域卡，作文件头部，保证单取一域时自包含）
- 【地名索引】表格，每行：地名 | 一句话概况 | 地名文件（`02_数据库/02_地理区域/02_地理区域_<世界名>_<区域名>_<地名>.md`）

### 地名卡 · [地名]（地名文件头部）

【基础信息】
| 字段 | 必填 | 说明与示例 |
|------|------|-----------|
| 地名 | (必) | 唯一标识名，与文件名 `_<地名>` 一致 |
| 所属区域 | (必) | 所在区域，引用 `@区域.[名称]` |
| 位置描述 | (必) | 在区域内的相对方位与周边地标 |
| 类别 | (必) | 坊市/宗门驻地/城镇村庄/秘境入口/遗迹/险地/关隘/其他 |

【环境与驻留】
| 灵气/危险 | | 该处灵气浓度或危险程度 |
| 地标建筑 | | 标志性建筑或景观 |
| 常驻人物与势力 | | 引用 `@配角.[姓名]`、`@势力.[名称]` |

【叙事用途】
| 叙事用途 | (必) | 适合安排哪些剧情场景（居住/交易/冒险/冲突战场等） |
| 相关事件/伏笔 | | 引用 `@伏笔.[ID]` |
