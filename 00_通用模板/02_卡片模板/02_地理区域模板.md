# 地理区域模板

> 类型：卡片模板 · 定义字段与填写示例，用于生成/维护 `02_设定/02_地理区域`。

## 字段与示例

`(必)`=必填，其余选填；示例值为格式参考，勿照抄。

### 区域卡 · [区域名称]

【基础信息】
| 字段 | 必填 | 说明与示例 |
|------|------|-----------|
| 区域名称 | (必) | 唯一标识名 |
| 区域层级 | (必) | 凡域/坊市带/天域/禁地/其他自定义层级 |
| 地理位置 | (必) | 在世界中的相对位置与接壤区域 |
| 灵气浓度 | (必) | 对修行的影响，如"稀薄""中等""浓郁如液" |

【生态与资源】
| 主导体系 | (必) | 该区域哪种修行体系占主流 |
| 特产资源 | (必) | 该区域产出的关键资源 |
| 危险等级 | | 进入所需的最低实力或生存难度 |
| 区域特色 | (必) | 用于叙事的世界观氛围描述 |

【势力分布】
| 势力列表 | (必) | 区域内所有重要势力，每项关联势力卡 |
| 势力关系简述 | | 区域内势力间的局部冲突或合作 |

【与主角关系】
| 主角活动阶段 | | 主角在哪一境界阶段主要在此活动 |
| 核心冲突类型 | | 主角在此区域经历的主要冲突类型 |
| 世界观展开层级 | | 该区域揭示世界的哪一层真相 |
