# 单章细纲模板

> 类型：卡片模板 · 定义字段与填写示例，用于生成/维护 `正文卷N/00_规划/07_单章细纲`。
>
> 写单章正文前的必读模板（见 `00_使用说明` 任务路由表）。没有细纲，禁止直接生成正文。本模板将一章拆为 2-5 个**场景**，各定义字数、功能、内容要点与钩子，保证节奏可控、不跑偏。

## 字段与示例

`(必)`=必填，其余选填；示例值为格式参考，勿照抄。

### 单章细纲 · [章节号]

【基础信息】
| 字段 | 必填 | 说明与示例 |
|------|------|-----------|
| 章节号 | (必) | 如：第1章、第1卷第3章 |
| 本章类型 | (必) | 推进章/冲突章/转折章/情感章/信息章/压抑章/爽感章 |
| 预计总字数 | (必) | 建议范围：2000-4000字 |
| 关联卷大纲节点 | (必) | 对应 06_卷大纲 中的哪个章节节拍？ |

【场景列表】（核心，每章 2-5 个场景）
| 场景序号 | (必) | 第1场景、第2场景…… |
| 场景地点 | (必) | 具体地点，关联地理区域/地名（`@区域.名称` / `@地名.名称`） |
| 场景字数 | (必) | 该场景预计字数，所有场景之和=本章总字数 |
| 场景功能 | (必) | 推进/揭示/转折/情感/铺垫（定义与占比见下） |
| 场景内容简述 | (必) | 100字以内，谁做了什么，结果是什么 |
| 出场角色 | (必) | 使用 `@人物.姓名` 或 `@主角` 格式 |
| 涉及资源 | | 使用 `@资源.名称` 格式 |
| 涉及伏笔 | | 使用 `@伏笔.ID` 格式 |
| 场景钩子 | (必) | 场景结束时留下的悬念，驱动进入下一场景 |

**场景功能说明**：推进（主角向目标前进一步：获线索/到新地/完成交易，占比40-50%）、揭示（释放新信息：世界观/背景/势力关系，15-20%）、转折（局势突变：被发现/被背叛/意外收获，10-15%）、情感（塑造关系或内心变化，10-15%）、铺垫（埋伏笔或造悬念，5-10%）。规则：每章至少 1 个推进 + 1 个情感或转折；连续两场景不得同为"推进"；"揭示"后必须紧跟"推进"或"转折"。

**场景间钩子设计**（禁止硬切）：
- 悬念钩子：A场景末留未解答问题，B场景回答或深化（"他打开盒子，里面不是丹药，而是一封信"）
- 动作钩子：A场景末主角做一个动作，B场景展示结果（"他拔出剑，向黑影刺去"）
- 情绪钩子：A场景末主角产生情绪，B场景展示其如何影响决策
- 信息钩子：A场景末释放一条信息，B场景展示谁对此做出反应

【章级钩子】
| 章末钩子类型 | (必) | 重钩（危机/变故/悬念激化）/ 轻钩（疑惑/反常/未说破） |
| 章末钩子内容 | (必) | 50字以内，具体写了什么让读者翻页？ |
| 与下章衔接点 | (必) | 下一章第一句必须承接什么？ |

【道义与感悟】
| 本章落地道义 | (必) | 对应 03_核心道义体系 中的哪条？（允许写"0.5条——仅埋设"） |
| 古籍引用 | | 若用古籍点题，写清书名和短句 |
| 感悟触发场景 | | 在哪个场景中触发感悟？ |

【自检预检】
| 预估事件:感悟比例 | (必) | 如 "7.5:2.5"，必须在 7:3 ±15% 范围内 |
| 预估压抑/爽感 | (必) | 本章整体是压抑章还是爽感章？（连续压抑不得超过3章） |
| 新设定数量 | (必) | 本章计划引入的新设定数量（不得超过3个） |
