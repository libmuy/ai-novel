# 卷大纲模板

> 类型：卡片模板 · 定义字段与填写示例，用于生成/维护对应数据文件。

## 使用范围
生成任意一卷大纲时，必须按此结构输出。禁止跳跃章节或省略字段。

## 输出字段

### 基础定位

| 字段 | 类型 | 说明 |
|------|------|------|
| `卷号` | 文本 (必填) | 如：第一卷 |
| `卷名` | 文本 (必填) | 如：[区域名] |
| `主角起始境界` | 文本 (必填) | 本卷开始时主角的境界 |
| `主角结束境界` | 文本 (必填) | 本卷结束时主角的境界 |
| `本卷核心矛盾` | 文本 (必填) | 一句话概括本卷要解决的核心问题 |
| `本卷必须落地的道义ID` | 列表 (必填) | 从 `03_核心道义体系` 中选至少1条，本卷必须通过具体事件让其自然浮现 |
| `战力/经济崩坏预警` | 文本 (必填) | 本卷结束时，主角获得的资源是否会导致其"过富"？战力是否超出了 `04_资源分级体系` 的控制范围？若有，必须在下一卷安排具体的"资源损耗"或"降维打击"事件；若安全，写明"无风险"及判断依据 |

### 章节节拍表

| 字段 | 类型 | 说明 |
|------|------|------|
| `章节总数` | 数值 (必填) | 通常10-15章 |
| `章节列表` | 表格 (必填) | 每行包含：章节号、一句话剧情摘要、必用模板、核心事件类型、钩子类型 |

章节列表格式：

```markdown
| 章节 | 一句话剧情摘要 | 必用模板 | 核心事件类型 | 钩子类型 |
|------|---------------|---------|------------|---------|
| 第1章 | ... | 05_开篇三章指南 | 入戏/危机 | 重钩 |
| 第2章 | ... | 05_开篇三章指南 | 冲突/吃亏 | 轻钩 |
| ... | ... | ... | ... | ... |
```

核心事件类型枚举：
- 入戏/危机：开篇300字规则
- 冲突/战斗：涉及战斗结算
- 冲突/谈判：涉及跨体系冲突区块或势力博弈
- 抉择/道义：涉及事件与感悟卡
- 突破/晋升：涉及主角突破卡
- 感悟/闭环：涉及事件与感悟卡
- 日常/铺垫：信息释放、关系建立、伏笔埋设
- 收束/回收：伏笔回收、情感释放、阶段性结算

钩子类型枚举：
- 重钩：未解决的危机、突发变故、隐秘伏笔显现、两难困境激化
- 轻钩：伏笔暗现、自我疑惑、未说破的一句话、反常细节
- 无钩：仅用于卷末重大情感释放后的"喘息章"，极其罕见

### 资源与伏笔规划

| 字段 | 类型 | 说明 |
|------|------|------|
| `本卷埋设伏笔列表` | 列表 (必填) | 每个伏笔包含：伏笔名称、类型（短/中/长）、埋设章节、预计回收章节/卷 |
| `本卷回收伏笔列表` | 列表 (必填) | 本卷计划回收的前文伏笔 |
| `本卷新增资源/道具` | 列表 (选填) | 本卷主角获得的重要物品，关联 `12_资源道具卡` |
| `本卷损毁/失去资源` | 列表 (选填) | 本卷主角失去的重要物品或能力 |

### 角色与关系

| 字段 | 类型 | 说明 |
|------|------|------|
| `本卷新出场配角` | 列表 (必填) | 每个配角关联 `04_配角卡` |
| `本卷退场配角` | 列表 (选填) | 死亡/离开/背叛/被遗忘 |
| `本卷关系变化` | 列表 (选填) | 主角与某势力/配角的关系变化 |

### 卷末状态

| 字段 | 类型 | 说明 |
|------|------|------|
| `本卷结束时主角状态` | 文本 (必填) | 资源/关系/隐患/道心/身体五维状态简述 |
| `卷末钩子` | 文本 (必填) | 引出下一卷的核心悬念 |
| `下一卷预告方向` | 文本 (必填) | 下一卷主角将去哪里、面对什么、解决什么问题 |
