# 卷大纲模板

> 类型：卡片模板 · 定义字段与填写示例。当前项目约定：分卷细纲统一存放于 `01_设定/06_全书卷大纲_V<N>.md`（总索引 `01_设定/06_全书卷大纲.md`），`正文卷N/00_规划/06_卷大纲.md` 路径已弃用，不再使用。
>
> 生成任意一卷大纲必须按此结构输出，禁止跳跃章节或省略字段。

## 字段与示例

`(必)`=必填，其余选填；示例值为格式参考，勿照抄。

### 卷大纲 · 第[N]卷 · [卷名]

【基础定位】
| 字段 | 必填 | 说明与示例 |
|------|------|-----------|
| 所属部 | (必) | 如：第一部；对应 `00_主角档案.md`【全书弧线】中的部划分 |
| 卷号 | (必) | 全书维度**连续递增**编号，禁止按"部"重新从1开始计数（如第一部为卷1-4，第二部从卷5起接续编号）。所有下游ID（`V卷号-C章节号-序号`、`BP-V卷号-序号`、`BT-V卷号-序号`）均依赖此编号连续性，一旦跳号或重置将导致跨部引用冲突。 |
| 卷名 | (必) | 如：[区域名] |
| 主角起始境界 | (必) | 本卷开始时主角的境界 |
| 主角结束境界 | (必) | 本卷结束时主角的境界 |
| 本卷核心矛盾 | (必) | 一句话概括本卷要解决的核心问题 |
| 本卷必须落地的道义ID | (必) | 从 `03_核心道义体系` 选至少1条，本卷必须通过具体事件让其自然浮现 |
| 战力/经济崩坏预警 | (必) | 卷末资源是否导致主角"过富"？战力是否超出 `04_资源` 控制范围？若有，下一卷必须安排"资源损耗"或"降维打击"；若安全，写明"无风险"及依据 |

【章节节拍表】
| 章节总数 | (必) | 通常10-15章 |
| 章节列表 | (必) | 每行：章节号、一句话剧情摘要、必用模板、核心事件类型、钩子类型。格式见下 |

```markdown
| 章节 | 一句话剧情摘要 | 必用模板 | 核心事件类型 | 钩子类型 |
|------|---------------|---------|------------|---------|
| 第1章 | ... | 05_开篇三章指南 | 入戏/危机 | 重钩 |
| ... | ... | ... | ... | ... |
```

**核心事件类型枚举**：入戏/危机（开篇300字规则）、冲突/战斗（战斗结算）、冲突/谈判（跨体系冲突或势力博弈）、抉择/道义（事件与感悟卡）、突破/晋升（主角突破卡）、感悟/闭环（事件与感悟卡）、日常/铺垫（信息释放、关系建立、伏笔埋设）、收束/回收（伏笔回收、情感释放、阶段性结算）

**钩子类型枚举**：重钩（未解决的危机、突发变故、隐秘伏笔显现、两难困境激化）；轻钩（伏笔暗现、自我疑惑、未说破的一句话、反常细节）；无钩（仅用于卷末重大情感释放后的"喘息章"，极其罕见）

【资源与伏笔规划】
| 本卷埋设伏笔列表 | (必) | 每个伏笔含：名称、类型（短/中/长）、埋设章节、预计回收章节/卷 |
| 本卷回收伏笔列表 | (必) | 本卷计划回收的前文伏笔 |
| 本卷新增资源/道具 | | 主角获得的重要物品，关联 `04_资源`（物品卡，登记入对应类别文件） |
| 本卷损毁/失去资源 | | 主角失去的重要物品或能力 |
| 本卷财务危机安排 | | 本卷是否安排"缺钱"困境？发生在哪几章？对照 `04_资源_经济.md`【财富分级基准表】核对主角当前境界应有身家，判断危机是否合理（如：金丹期主角却身无分文，需交代具体原因，不得无来由） |

【角色与关系】
| 本卷新出场配角 | (必) | 每个配角关联 `07_人物` |
| 本卷退场配角 | | 死亡/离开/背叛/被遗忘 |
| 本卷关系变化 | | 主角与某势力/配角的关系变化 |

【卷末状态】
| 本卷结束时主角状态 | (必) | 资源/关系/隐患/道心/身体五维状态简述 |
| 卷末钩子 | (必) | 引出下一卷的核心悬念 |
| 下一卷预告方向 | (必) | 主角将去哪里、面对什么、解决什么问题 |
