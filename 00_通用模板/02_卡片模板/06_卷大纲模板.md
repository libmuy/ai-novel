# 卷大纲模板

## 层级职责说明

- 任务 09（全书卷大纲） 只生成以下字段：【基础定位】（所属部/卷号/卷名/起止境界/核心矛盾/主要道义主题/战力预警）。禁止输出【章节节拍表】【资源与伏笔规划】【角色与关系】【卷末状态】——这些属于单卷级职责。
- 任务 10+（单卷大纲生成） 基于任务 09 产出的该卷【基础定位】，生成完整单卷大纲，含全部字段。
- 第一卷 的单卷大纲任务必须额外加载 05_开篇三章设计指南，其他卷不加载。

> 类型：卡片模板 · 定义字段与填写示例。全书卷大纲总索引存放在 `03_规划/规划.md`，各部规划存放在 `03_规划/《部编号》_《部名》/规划_《部名》.md`；单卷完整大纲（含【章节节拍表】【资源与伏笔规划】【角色与关系】【卷末状态】）由任务 10 产出，存放在对应 `03_规划/《部编号》_《部名》/《卷编号》_《卷名》/规划_《卷名》.md`。
>
> 生成任意一卷大纲必须按此结构输出，禁止跳跃章节或省略字段。
>
> **章节归属单一权威（见 `00_系统架构规范.md` §二·A）**：本卷「某事在第几章」的唯一权威
> 是【章节节拍表】的「一句话剧情摘要」（须用 `@引用` 点名该章关键对象/伏笔/资源）。
> 【角色与关系】【资源与伏笔规划】各表**不带「章节」列**，只描述「是什么」。**禁止**输出
> 【出场对象ID清单】等按章节的对象索引表——任务11 直接读节拍表对应行摘要的 `@引用`。

## 字段与示例

`(必)`=必填，其余选填；示例值为格式参考，勿照抄。

### 卷大纲 · 第[N]卷 · [卷名]

【基础定位】
| 字段 | 必填 | 说明与示例 |
|------|------|-----------|
| 所属部 | (必) | 如：第一部；对应 `00_主角档案.md`【全书弧线】中的部划分 |
| 卷号 | (必) | 全书维度**连续递增**编号，禁止按"部"重新从1开始计数（如第一部为卷1-4，第二部从卷5起接续编号）。所有下游ID（`V卷号-C章节号-序号`、`BP-V卷号-序号`、`BT-V卷号-序号`）均依赖此编号连续性，一旦跳号或重置将导致跨部引用冲突。 |
| 卷名 | (必) | 如：[区域名] |
| 主角起始境界 | (必) | 本卷开始时主角的境界 |
| 主角结束境界 | (必) | 本卷结束时主角的境界 |
| 本卷核心矛盾 | (必) | 一句话概括本卷要解决的核心问题 |
| 本卷必须落地的道义ID | (必) | 从 `03_核心道义体系` 选至少1条，本卷必须通过具体事件让其自然浮现 |
| 战力/经济崩坏预警 | (必) | 卷末资源是否导致主角"过富"？战力是否超出 `04_资源` 控制范围？若有，下一卷必须安排"资源损耗"或"降维打击"；若安全，写明"无风险"及依据 |

【章节节拍表】
| 章节总数 | (必) | 按 `00_小说概念.md`【全书规模目标】的总章节数 ÷ 本部规划卷数 推算，取整后按本卷叙事节奏可上下浮动，不预设固定区间（不同项目规模不同，禁止套用其他项目的经验值） |
| 章节列表 | (必) | 每行：章节号、一句话剧情摘要、必用模板、核心事件类型、钩子类型。格式见下 |

```markdown
| 章节 | 一句话剧情摘要 | 必用模板 | 核心事件类型 | 钩子类型 |
|------|---------------|---------|------------|---------|
| 第1章 | ... | 05_开篇三章指南 | 入戏/危机 | 重钩 |
| ... | ... | ... | ... | ... |
```

> **「一句话剧情摘要」是本卷所有事件章节归属的唯一权威（见 `00_系统架构规范.md` §二·A）。**
> - 摘要须用 `@引用` 点名**这一章的关键对象/伏笔/资源**：配角登场/退场、伏笔埋设/推进/回收、
>   重要资源获得/失去、关系发生变化的双方——凡后文其它区块会提到「第 N 章」的东西，
>   第 N 章摘要里必须有对应 `@引用`。
> - 其它区块（【角色与关系】【资源与伏笔规划】）**不再带「章节」列**，只描述「是什么」。
> - **禁止**另建【出场对象ID清单】之类的按章节索引表——任务11 直接读本表对应行摘要的 `@引用`。
> - `audit_consistency.py` 的 `plan_beat` 规则会逐条比对：其它区块点名的对象/伏笔/资源，
>   是否都能在某章摘要的 `@引用` 里找到；埋设伏笔的「埋设章节」那行摘要是否 `@引用` 了该 FH。

**核心事件类型枚举**：入戏/危机（开篇300字规则）、冲突/战斗（战斗结算）、冲突/谈判（跨体系冲突或势力博弈）、抉择/道义（事件与感悟卡）、突破/晋升（主角突破卡）、感悟/闭环（事件与感悟卡）、日常/铺垫（信息释放、关系建立、伏笔埋设）、收束/回收（伏笔回收、情感释放、阶段性结算）

**钩子类型枚举**：重钩（未解决的危机、突发变故、隐秘伏笔显现、两难困境激化）；轻钩（伏笔暗现、自我疑惑、未说破的一句话、反常细节）；无钩（仅用于卷末重大情感释放后的"喘息章"，极其罕见）

【资源与伏笔规划】
| 本卷埋设伏笔列表 | (必) | 每个伏笔含：名称、类型（短/中/长）、**埋设章节**、预计回收章节/卷。埋设章节须精确到章；audit 强制该章节拍表摘要 `@引用` 了此 FH |
| 本卷回收伏笔列表 | (必) | 本卷计划回收的前文伏笔（回收章节同样须在节拍表摘要 `@引用`） |
| 本卷新增资源/道具 | | 主角获得的重要物品，关联 `04_资源`（物品卡，登记入对应类别文件）；须交代**获取来源**（任务报酬/交易/遗迹探索/猎妖/炼制/某人相赠等）。**不带「章节」列**——获取发生在哪一章，去节拍表查（该章摘要须 `@引用` 此资源或赠予人） |
| 本卷损毁/失去资源 | | 主角失去的重要物品或能力，须交代**原因**。**不带「章节」列** |
| 本卷资源变化轨迹 | (必) | 按叙事阶段（初期/中期/后期，或按境界段）规划：资源获得（来源+数量/品级）、资源消耗（用途+代价）、资源损失/损毁（原因+影响）；对照 `04_资源_经济.md`【财富分级基准表】核对主角当前境界应有身家，避免财富长期脱离对应境界正常区间。阶段用境界/叙事段划分，可标章节范围，但**具体某笔收支落在哪一章以节拍表摘要为准** |
| 本卷财务危机安排 | | 本卷是否安排"缺钱"困境？（危机发生在哪几章去节拍表查）对照 `04_资源_经济.md`【财富分级基准表】判断危机是否合理（如：金丹期主角却身无分文，需交代具体原因，不得无来由） |
| 高阶资源规划 | | 本卷涉及五品以上资源时须注明：获取门槛（境界/实力/势力要求）、交易方式（以物易物/因果契约）、稀缺性（是否引发势力争夺）、后续剧情影响 |

【角色与关系】
| 本卷新出场配角 | (必) | 每个配角：关联 `07_人物` 卡、**职能/定位**（压迫者/同伴/师父/交易对象…）、本卷内的身份或状态演变（如「凡人矿工→随主角入道」）。**不带「出场章节」列**——首次登场在哪一章，去节拍表查（该章摘要须 `@引用` 此人） |
| 本卷退场配角 | | 死亡/离开/背叛/被遗忘：退场**方式**与**影响**。**不带「退场章节」列**——退场章的节拍表摘要须 `@引用` 此人并写明退场 |
| 本卷关系变化 | | 主角与某势力/配角的关系**弧线**（如「敌对→博弈→决裂」）及每一段的**触发事件**。**不带「关键章节」列**——每次关系变化发生的章，其节拍表摘要须 `@引用` 关系双方并体现该变化 |

【卷末状态】
| 本卷结束时主角状态 | (必) | 资源/关系/隐患/道心/身体五维状态简述 |
| 卷末钩子 | (必) | 引出下一卷的核心悬念 |
| 下一卷预告方向 | (必) | 主角将去哪里、面对什么、解决什么问题 |
