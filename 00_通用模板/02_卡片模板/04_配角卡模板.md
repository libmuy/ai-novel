# 配角卡模板

> 类型：卡片模板 · 定义字段与填写示例，用于生成/维护对应数据文件。

## 使用范围
所有出场超过3章、对主线有推动、有独立选择的角色。

## 配角卡片字段

### 基础档案

| 字段 | 类型 | 说明 |
|------|------|------|
| `姓名` | 文本 (必填) | 本名 |
| `代号/外号` | 文本 (选填) | 江湖称呼，体现特征或他人评价 |
| `性别` | 文本 (选填) | |
| `年龄/寿元` | 文本 (选填) | 凡人写年龄，修士写“外表年龄/实际寿元” |
| `出身地` | 文本 (选填) | 具体到村镇或势力 |

### 修行档案

| 字段 | 类型 | 说明 |
|------|------|------|
| `修行体系` | 文本 (必填) | 关联修炼体系卡 |
| `当前境界` | 文本 (必填) | 对照基准体系，如“武道·铭骨境（对应筑基）” |
| `功法/神通特色` | 列表 (选填) | 2-3个核心能力，忌多忌杂 |
| `本命法宝/武器` | 文本 (选填) | 名称+特征，无则写“无” |
| `战斗风格` | 文本 (选填) | 近战/远程/伏击/阵法/辅助，及标志性战术 |

### 角色内核（三要素）

| 字段 | 类型 | 说明 |
|------|------|------|
| `立场` | 文本 (必填) | 站在哪一边？具体到势力或理念 |
| `欲望` | 文本 (必填) | 最想要什么？越具体越好 |
| `底线` | 文本 (必填) | 什么情况下会翻脸、牺牲、背叛或赴死？ |

### 与主角关系

| 字段 | 类型 | 说明 |
|------|------|------|
| `初遇地点` | 文本 (选填) | |
| `初遇关系定位` | 文本 (选填) | 恩人/仇敌/交易对象/路人 |
| `关系演变轨迹` | 文本 (选填) | 如：利用→猜忌→合作→诀别 |
| `对主角的影响` | 文本 (选填) | 教会主角什么？或触发主角哪次道义选择？ |
| `主角对其的影响` | 文本 (选填) | 因主角改变了什么选择？ |

### 独立故事线

| 字段 | 类型 | 说明 |
|------|------|------|
| `人生目标` | 文本 (选填) | 与主角无关时，他自己想做什么？ |
| `当前进度` | 文本 (选填) | 这个目标完成了多少？遇到什么阻碍？ |
| `高光时刻设计` | 文本 (选填) | 预计在哪段剧情中，做出独立于主角的关键选择？ |
| `预计退场方式` | 文本 (选填) | 死亡/离开/背叛/飞升/被遗忘/化为战鬼等 |
| `退场情感基调` | 文本 (选填) | 壮烈/苍凉/释然/讽刺/温暖 |

### 创作标签

| 字段 | 类型 | 说明 |
|------|------|------|
| `情绪功能` | 文本 (选填) | 温暖担当/黑暗揭示/利益镜子/道义对照/喜剧调剂/悲剧预警 |
| `说话风格` | 文本 (选填) | 寡言/机锋/市井粗口/文言腔/阴阳怪气/沉默行动派 |
| `标志性细节` | 文本 (选填) | 一个动作、一个物品、一个习惯，用于替代“他很悲伤” |
