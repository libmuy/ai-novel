# 主角人设卡模板

> 类型：卡片模板 · 定义字段与填写示例，用于生成/维护对应数据文件。

## 使用范围

本模板适用于**主角自身**的档案设计。主角虽然也是"角色"，但与配角有本质区别：配角服务于主角的故事线，主角服务于全书的核心道义与读者共鸣。因此，主角档案需要额外字段来承载"全书成长弧线""核心特殊性""与各卷核心矛盾的映射"等顶层设计。

> **注意**：配角使用 `04_配角卡模板`；主角使用本模板。两者字段有重叠，但本模板包含主角专属扩展字段。

---

## 主角卡片字段

### 基础档案

| 字段 | 类型 | 说明 |
|------|------|------|
| `姓名` | 文本 (必填) | 本名 |
| `代号/外号` | 文本 (选填) | 江湖称呼，前期可无，后期因事迹获得 |
| `性别` | 文本 (选填) | |
| `年龄/寿元` | 文本 (必填) | 出场时年龄/寿元状态 |
| `出身地` | 文本 (必填) | 具体到村镇或势力，必须是"底层" |

### 生存压力与底层视角（主角专属）

| 字段 | 类型 | 说明 |
|------|------|------|
| `生存成本动态表` | 表格 (必填) | 当前境界下，每日维持巅峰战力所需的灵石、食水、药物消耗。境界每提升一次必须更新（体现"越强越烧钱"的底层焦虑） |
| `底层认知偏差` | 文本 (必填) | 主角目前对修仙界最严重的"凡人式误解"是什么？（如：以为境界高者必是德高望重、以为宗门内讲公平）。随境界提升逐步修正，作为成长的关键指标 |

### 核心特殊性（主角专属）

| 字段 | 类型 | 说明 |
|------|------|------|
| `核心特殊性` | 文本 (必填) | 主角与芸芸众生的根本区别是什么？忌"天赋异禀""系统加身"，必须是**心性或视角层面的独特**（如：底层视角、兼修双体系的认知分裂、对"善"的偏执） |
| `核心矛盾` | 文本 (必填) | 全书围绕什么根本矛盾展开？（如：修术 vs 修心、力量 vs 底线、个体生存 vs 群体道义） |
| `不可替代性` | 文本 (必填) | 为什么这个故事**只能**由这个人来讲？换一个人，故事的逻辑和情感内核是否崩塌？ |

### 修行档案

| 字段 | 类型 | 说明 |
|------|------|------|
| `修行体系` | 文本 (必填) | 主修体系 + 兼修体系（如有） |
| `当前境界` | 文本 (必填) | 对照基准体系 |
| `功法/神通特色` | 列表 (选填) | 2-3个核心能力，忌多忌杂 |
| `本命法宝/武器` | 文本 (选填) | 名称+特征，无则写"无" |
| `战斗风格` | 文本 (选填) | 近战/远程/伏击/阵法/辅助，及标志性战术 |

### 角色内核（三要素）

| 字段 | 类型 | 说明 |
|------|------|------|
| `立场` | 文本 (必填) | 站在哪一边？具体到势力或理念。主角的立场可以随成长变化，但必须**有迹可循** |
| `欲望` | 文本 (必填) | 分阶段写：最初想要什么？中期想要什么？后期想要什么？欲望必须**具体**（如：治好母亲的病 → 在修仙界活下去并守住底线 → 探寻世界真相） |
| `底线` | 列表 (必填) | 什么情况下会翻脸、牺牲、背叛或赴死？列出**3-5条**，且必须在全书至少被打破/质疑一次 |

### 全书成长弧线（主角专属）

| 字段 | 类型 | 说明 |
|------|------|------|
| `出场状态` | 文本 (必填) | 底层少年，对修仙界一无所知，带着什么执念入场？ |
| `第一阶段` | 文本 (必填) | 学会什么？第一次明白什么？ |
| `第二阶段` | 文本 (必填) | 学会什么？第一次为什么付出代价？ |
| `第三阶段` | 文本 (必填) | 学会什么？第一次用自己的力量保护他人？ |
| `第四阶段` | 文本 (必填) | 学会什么？第一次质疑自己坚守的道理？ |
| `第五阶段` | 文本 (必填) | 学会什么？在力量与道理之间找到什么答案？ |
| `最终状态` | 文本 (选填) | 全书结束时，主角变成了什么样的人？（可留白，由写作过程自然决定） |

> **通用化说明**：成长弧线的阶段划分**不绑定任何具体修炼体系**。填写时按本小说的境界路径命名各阶段，阶段数量可按实际境界数量增减，但必须保留"→学会→质疑→答案"的递进逻辑。

### 与各卷核心矛盾的映射（主角专属）

| 字段 | 类型 | 说明 |
|------|------|------|
| `卷矛盾映射` | 表格 (必填) | 每卷一行：卷号、该卷核心矛盾、主角在该卷的成长任务、该卷结束时主角的认知变化 |

### 创作标签

| 字段 | 类型 | 说明 |
|------|------|------|
| `情绪功能` | 文本 (必填) | 全书核心视角，所有道义的承载者 |
| `说话风格` | 文本 (必填) | 寡言/机锋/市井粗口/文言腔/底层口音 |
| `标志性细节` | 列表 (必填) | 1-3个动作、物品或习惯，用于替代"他很悲伤" |

### 人设红线（不可偏离）

| 字段 | 类型 | 说明 |
|------|------|------|
| `绝对禁止` | 列表 (必填) | 列出主角永远不能做/不能成为的事（如：禁止宗门天骄、禁止圣母、禁止冷血无情、禁止越阶秒杀无外部条件） |
| `弹性空间` | 列表 (选填) | 列出主角在极端情况下可以突破的底线（但必须付出极大代价，且事后有心理创伤） |

## 与04_配角卡模板的区别

| 维度 | 00_主角人设卡（本模板） | 04_配角卡 |
|------|----------------------|----------|
| 核心特殊性 | 必填，定义全书灵魂 | 无此字段 |
| 全书成长弧线 | 必填，分五阶段 | 无此字段 |
| 卷矛盾映射 | 必填，顶层设计 | 无此字段 |
| 人设红线 | 必填，含"绝对禁止"和"弹性空间" | 无此字段 |
| 独立故事线 | 无此字段（主角故事线=全书主线） | 必填 |
| 退场方式 | 无此字段（主角不退场） | 必填 |
| 与主角关系 | 无此字段 | 必填 |
