# 主角人设卡模板

> 类型：卡片模板 · 定义字段与填写示例，用于生成/维护 `02_设定/00_主角档案`。
>
> 主角与配角本质区别：配角服务主角故事线，主角服务全书核心道义与读者共鸣，故有专属顶层字段。配角用 `04_配角卡模板`。

## 字段与示例

每张卡按以下区块与字段输出，`(必)`=必填、`(条)`=条件必填，其余选填；示例值为格式参考，勿照抄。

### 主角卡 · [角色姓名]

【基础档案】
| 字段 | 必填 | 说明与示例 |
|------|------|-----------|
| 姓名 | (必) | 本名 |
| 代号/外号 | | 江湖称呼，前期可无，后期因事迹获得 |
| 性别 | | |
| 年龄/寿元 | (必) | 出场时年龄/寿元状态 |
| 出身地 | (必) | 具体到村镇或势力，必须"底层" |

【生存压力与底层视角】（主角专属）
| 生存成本动态表 | (必) | 当前境界每日维持巅峰战力所需灵石/食水/药物；境界每提升一次必须更新（体现"越强越烧钱"） |
| 底层认知偏差 | (必) | 主角对修仙界最严重的"凡人式误解"（如：以为境界高者必德高望重）；随境界提升逐步修正，作成长关键指标 |

【核心特殊性】（主角专属）
| 核心特殊性 | (必) | 与芸芸众生的根本区别，忌"天赋异禀/系统加身"，须为心性或视角层面的独特（如：底层视角、兼修双体系的认知分裂、对"善"的偏执） |
| 核心矛盾 | (必) | 全书根本矛盾（如：修术 vs 修心、力量 vs 底线、个体生存 vs 群体道义） |
| 不可替代性 | (必) | 为什么这故事只能由他来讲？换人则逻辑与情感内核崩塌 |

【修行档案】
| 修行体系 | (必) | 主修体系 + 兼修体系（如有） |
| 当前境界 | (必) | 对照基准体系 |
| 功法/神通特色 | | 2-3个核心能力，忌多忌杂 |
| 本命法宝/武器 | | 名称+特征，无则写"无" |
| 战斗风格 | | 近战/远程/伏击/阵法/辅助，及标志性战术 |

【角色内核】（三要素）
| 立场 | (必) | 站在哪一边，具体到势力或理念；可随成长变化但必须有迹可循 |
| 欲望 | (必) | 分阶段写（最初/中期/后期想要什么），必须具体（如：治好母亲病 → 活下去并守住底线 → 探寻世界真相） |
| 底线 | (必) | 何时翻脸、牺牲、背叛或赴死，列3-5条，且全书至少被打破/质疑一次 |

【全书成长弧线】（主角专属）
| 出场状态 | (必) | 底层少年，对修仙界一无所知，带着什么执念入场 |
| 第一阶段 | (必) | 学会什么？第一次明白什么？ |
| 第二阶段 | (必) | 学会什么？第一次为什么付出代价？ |
| 第三阶段 | (必) | 学会什么？第一次用自己的力量保护他人？ |
| 第四阶段 | (必) | 学会什么？第一次质疑自己坚守的道理？ |
| 第五阶段 | (必) | 学会什么？在力量与道理之间找到什么答案？ |
| 最终状态 | | 全书结束时变成什么样的人（可留白） |

> 阶段划分不绑定具体修炼体系，按本小说境界路径命名、数量可增减，但必须保留"→学会→质疑→答案"递进逻辑。

【与各卷核心矛盾的映射】（主角专属）
| 卷矛盾映射 | (必) | 每卷一行：卷号 / 该卷核心矛盾 / 主角成长任务 / 卷末认知变化 |

【创作标签】
| 情绪功能 | (必) | 全书核心视角，所有道义的承载者 |
| 说话风格 | (必) | 寡言/机锋/市井粗口/文言腔/底层口音 |
| 标志性细节 | (必) | 1-3个动作、物品或习惯，用于替代"他很悲伤" |

【人设红线】（不可偏离）
| 绝对禁止 | (必) | 主角永远不能做/成为的事（如：禁止宗门天骄、禁止圣母、禁止冷血无情、禁止越阶秒杀无外部条件） |
| 弹性空间 | | 极端情况下可突破的底线（须付出极大代价，事后有心理创伤） |

## 与 04_配角卡模板 的区别

| 维度 | 00_主角人设卡（本模板） | 04_配角卡 |
|------|----------------------|----------|
| 核心特殊性 / 全书成长弧线 / 卷矛盾映射 / 人设红线 | 必填，顶层设计 | 无此字段 |
| 独立故事线 / 退场方式 / 与主角关系 | 无此字段 | 必填 |
