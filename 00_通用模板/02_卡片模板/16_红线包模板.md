# 常驻红线包模板

> 类型：卡片模板 · 定义结构与填写规范，用于生成/维护每本小说的 `01_设定/00_红线包.md`。
>
> **定位**：设定层 · **卷级蒸馏视图**。把「逐章不变的那半份约束」（主角人设红线、金手指档位、
> 经济锚点、文风与情绪引擎、视角纪律、禁用词高频项、结构与节奏通则）从各上游权威文件里
> 摘出来，打成一包。正文阶段与冷读修订轮的云端提示词【必读规则】/【必读红线】段**整段内联**
> ——云端在零上下文新对话里除提示词外看不到任何模板，本包替它一次性备好逐章不变的约束，
> 免去每轮临场判断「这次该蒸馏哪几条」。
>
> **本包不是任何一条规则的权威出处。** 与上游冲突时以上游为准，并回头修本包（走 §八 流程），
> 不得就地改本包了事。`audit_consistency.py` 的 `redline` 规则守护本包（`REDLINE001`~`004`）。

## 何时建、何时刷新

- **建**：卷 1 正文开写前。前置＝`01_设定/00_主角档案_当前阶段.md`、`01_设定/00_文风.md`、
  `01_设定/00_禁用词表.md`、`02_数据库/04_资源/` 相关卡、本卷 `规划_卷NN.md` 均已定稿。
- **刷新**：§八 表列出的任一上游文件变更后重核对应小节；每卷开写前全表重核（重点金手指的卷级档位）。
- 刷新后必须跑 `python3 02_工具/01_小说通用工具/redline_stamp.py <小说目录> --write` 重新落指纹戳，
  否则 `REDLINE001` 会一直报「上游变过、本包未重核」。

## 结构（八节固定）

文件标题：`# <小说名> · 常驻红线包`。抬头 4 行：类型/用途/刷新周期/冲突处理（照抄本模板定位段的要点）。

### 零、本文件的边界

一张两列表：「进本包 / 不进本包（留给单章提示词）」。判据写死一句：
**一条约束如果换一章就要改数字或改对象名，它就不属于本包。**

| 进本包 | 不进本包 |
|---|---|
| 逐章不变的人设 / 能力 / 经济 / 文风 / 视角 / 结构约束 | 章号、本章要落地的 DY 编号、本章伏笔号 |
| 卷级常量（如金手指在本卷的能力档位） | 本章场景数与各场功能、字数分配 |
| 全书单一基准（经济换算、计量口径） | 本章有名角色**名单**（来自本章细纲【出场对象】） |
| 禁用词高频项 + 权威清单指针 | 本章节拍表行、钩子类型、滑动窗口 |

### 一、主角人设红线

行首标 `> ← <上游文件>【区块】`。写「绝对禁止」清单 + 人格结构 + 弹性空间（可写但带代价）。
**只写逐章不变的定性**，不写「第 X 章他会……」。

### 二、金手指（异宝 / 系统 / 血脉…）能力边界 · 本卷常量

行首标 `> ← <资源卡 ID> ＋ 卷大纲裁决`。写本卷各阶段功能的**开/关档位**与全程禁止项。
**档位切换点用叙述性表述**（「主角入道后」「卷末器灵初醒」），不写章节号——章节归属的
唯一权威是节拍表 `@引用`（`00_系统架构规范.md` §七、§二·A）。触发 `REDLINE004`。

### 三、经济锚点 · 全书单一基准

行首标 `> ← <经济卡> ＋ 用户裁决`。货币单位、兑换率、关键物价、主角财务纪律。
数字必须与经济卡逐条一致（上游改了就 `REDLINE001`）。

### 四、文风与情绪引擎

行首标 `> ← <文风文件>【区块】 ＋ <文风模板>`。加一句：
**凡本轮有「改写 / 新写句子」的修改项，本节即必须遵守的约束**——改稿模型看不到文风模板。

### 五、视角与叙述纪律

人称与限知范围、禁上帝旁白、禁作者评判、禁角色朗读价值观、有名角色不得超出本章细纲清单。

### 六、禁用词（高频项摘录）

行首标 `> **权威清单在 \`01_设定/00_禁用词表.md\`**`，并写明「只列高频踩雷项，冲突以禁用词表为准」。
**`- ` 列表行里用反引号列的每个词，必须已在 `00_禁用词表.md` 的启用区**（`## 包含` / `## 子串` /
`## 正则`）。写进「待确认」区、或压根不在词表里的词，都会触发 `REDLINE002`——两处口径必须一致。

### 七、结构与节奏通则

开篇 300 字、场景数与功能、同质内容上限、事件感悟比、新设定上限、对话句数、章末钩子、禁脑补。
数值与 `00_通用写作规则_生成版.md` 一致（上游改了就 `REDLINE001`）。

### 八、刷新触发（守护落点）

**三列表**，格式如下。第三列由 `redline_stamp.py --write` 回写，**禁止手填**：

| 权威来源变更 | 重核本包 | 上次核对指纹 |
|---|---|---|
| `01_设定/00_主角档案_当前阶段.md` | 第一节 | (脚本回写) |
| `02_数据库/04_资源/…`（资源卡 ID）／卷大纲对金手指阶段的裁决 | 第二节 | (脚本回写) |
| `02_数据库/04_资源/04_资源_经济.md`／用户对经济锚点的新裁决 | 第三节 | (脚本回写) |
| `01_设定/00_文风.md` | 第四节 | (脚本回写) |
| `01_设定/00_禁用词表.md` | 第六节 | (脚本回写) |
| `00_通用模板/01_写作规则/00_通用写作规则_生成版.md` | 第七节 | (脚本回写) |
| **进卷**（每卷开写前） | 全部，重点第二节的卷级档位 | — |

- 第一列每行的 `` `<路径>.md` `` 引用会被 `redline_stamp.py` 逐个解析；解析不到（软链断/改名）→ `REDLINE001`。
- 无 `.md` 引用的行（「进卷」）指纹列写 `—`，脚本跳过。
- 逐行豁免章节号误报（如 §四 引压抑周期通则里的「第 3 章」＝周期内序数）：该行加 `<!-- REDLINE-ok: 理由 -->`。
