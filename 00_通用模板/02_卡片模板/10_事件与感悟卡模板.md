# 事件与感悟卡模板

> 类型：卡片模板 · 定义字段与填写示例，用于生成/维护事件与感悟数据。数据落位：`03_规划/《部编号》_《部名》/《卷编号》_《卷名》/00_事件卡/<章节号>_事件与感悟.md`。
>
> 每章或每几章必须完成一次闭环，禁止主角突然悟道。本卡是"事件设计 + 感悟落地"通用卡：可用于**两难抉择**事件（每5-10章一次），也可用于**普通感悟闭环**；有战斗/突破专属事件时配合 `08_战斗结算` / `09_主角突破卡` 使用。
>
> **两难抉择**：主角必须选"吃亏"的选项，且代价不能立刻化解；设计抉择时填「选择设计」区块，普通感悟闭环可跳过。
>
> **顺序红线**：先事件 → 再古籍 → 最后感悟，禁止调换（见 `00_通用写作规则` §二 与 `03_核心道义体系`）。

## 字段与示例

`(必)`=必填，其余选填；示例值为格式参考，勿照抄。

### 事件与感悟 · [章节号] [事件主题]

【事件锚定】
| 字段 | 必填 | 说明与示例 |
|------|------|-----------|
| 触发事件 | (必) | 具体发生了什么事？必须在前文有铺垫 |
| 主角行动 | (必) | 主角做了什么具体选择/行为？ |
| 事件结果 | (必) | 结果好坏？谁受益谁受损？ |

【选择设计】（两难抉择时必填）
| 时间压力 | | 是否必须在极短时间内决定？ |
| 旁观者 | | 有谁看着？会影响主角的抉择吗？ |
| 选项A（利益） | (必) | 内容 + 即时收益 + 人设冲击（是否违背"谨慎"或"底线"） |
| 选项B（底线） | (必) | 内容 + 即时代价（必须具体且无法立刻化解） |
| 最终选择 | (必) | 必须是B |
| 选择动作细节 | (必) | 忌心理描写，用动作体现纠结 |
| 即时后果 | (必) | 立刻发生的坏事 |
| 关联配角反应 | | 谁因此改变了对主角的看法？（强化"这个世界不鼓励善良"） |
| 连锁反应 | (必) | 至少列出3个后续章节的影响 |

【感悟三层】（必须按顺序）
| 内心总结 | (必) | 大白话，忌文言，忌金句 |
| 古籍点题 | (必) | 虚构典籍，30字以内，引用后立刻回剧情 |
| 行动转化 | (必) | 变成后续章节的具体行为准则 |

【情感落地】
| 情绪类型 | | 内部标注 |
| 替代动作 | (必) | 具体动作或环境细节传递情绪 |

【读者共鸣】
| 现实映射 | | 对应现实中什么普遍困境？ |
