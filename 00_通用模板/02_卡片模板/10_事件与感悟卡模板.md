# 事件与感悟卡模板

> 类型：卡片模板 · 定义字段与填写示例，用于生成/维护对应数据文件。

## 使用范围

每章或每几章必须完成一次闭环。禁止主角突然悟道。本卡是"事件设计 + 感悟落地"的通用卡：既可用于**两难抉择**事件（每5-10章一次），也可用于**普通感悟闭环**事件。有战斗/突破专属事件时，配合 `08_战斗结算` / `09_主角突破卡` 使用。

> **两难抉择**：主角必须选"吃亏"的选项，且代价不能立刻化解。设计抉择时填写「选择设计」区块；普通感悟闭环可跳过该区块。
>
> **顺序红线**：先事件 → 再古籍 → 最后感悟，禁止调换（见 `00_文风与节奏规范` §2 与 `03_核心道义体系` §3.1）。

## 事件与感悟卡字段

### 事件锚定

| 字段 | 类型 | 说明 |
|------|------|------|
| `触发事件` | 文本 (必填) | 具体发生了什么事？必须在前文有铺垫 |
| `主角行动` | 文本 (必填) | 主角做了什么具体选择/行为？ |
| `事件结果` | 文本 (必填) | 结果是好是坏？谁受益谁受损？ |

### 选择设计（两难抉择时必填）

| 字段 | 类型 | 说明 |
|------|------|------|
| `时间压力` | 文本 (选填) | 是否必须在极短时间内决定？ |
| `旁观者` | 文本 (选填) | 有谁看着？这会影响主角的抉择吗？ |
| `选项A（利益）` | 文本 (必填) | 内容 + 即时收益 + 人设冲击（是否违背"谨慎"或"底线"） |
| `选项B（底线）` | 文本 (必填) | 内容 + 即时代价（必须具体且无法立刻化解） |
| `最终选择` | 枚举 (必填) | 必须是B |
| `选择动作细节` | 文本 (必填) | 忌心理描写，用动作体现纠结 |
| `即时后果` | 文本 (必填) | 立刻发生的坏事 |
| `关联配角反应` | 文本 (选填) | 谁因此事改变了对主角的看法？（强化"这个世界不鼓励善良"） |
| `连锁反应` | 列表 (必填) | 至少列出3个后续章节的影响 |

### 感悟三层（必须按顺序）

| 字段 | 类型 | 说明 |
|------|------|------|
| `内心总结` | 文本 (必填) | 大白话，忌文言，忌金句 |
| `古籍点题` | 文本 (必填) | 虚构典籍，30字以内，引用后立刻回剧情 |
| `行动转化` | 文本 (必填) | 变成后续章节的具体行为准则 |

### 情感落地

| 字段 | 类型 | 说明 |
|------|------|------|
| `情绪类型` | 文本 (选填) | 内部标注 |
| `替代动作` | 文本 (必填) | 具体动作或环境细节传递情绪 |

### 读者共鸣

| 字段 | 类型 | 说明 |
|------|------|------|
| `现实映射` | 文本 (选填) | 对应现实中什么普遍困境？ |
