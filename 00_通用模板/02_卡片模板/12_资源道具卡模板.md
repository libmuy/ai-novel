# 资源道具卡模板

> 类型：卡片模板 · 定义字段与填写示例，用于生成/维护对应数据文件。

## 使用范围

用于登记小说世界中所有可获取、消耗、交易的资源与道具。资源是修仙世界的"经济血液"，必须分级明确、来源清晰、流通合理。

> **触发条件**：新资源首次出场时必须填写。已有资源的数量变化在`08_战斗结算`或`09_主角突破卡`中记录，无需重复建卡。
>
> **关联模板**：`04_资源分级体系`（确定等级）、`08_战斗结算`（战利品/消耗）。

## 资源卡字段

### 基础信息

| 字段 | 类型 | 说明 |
|------|------|------|
| `资源名称` | 文本 (必填) | 标准名称，全小说统一使用 |
| `资源ID` | 文本 (必填) | 格式：`RES-类别-序号`，如 `RES-DAN-003` |
| `资源类别` | 文本 (必填) | 丹药 / 法宝 / 材料 / 灵石 / 功法 / 符箓 / 灵兽 / 古籍 / 其他 |
| `等级` | 文本 (必填) | 对照 `04_资源分级体系`，如 `黄阶中品` / `练气级` / `二阶` |

### 属性定义

| 字段 | 类型 | 说明 |
|------|------|------|
| `功能描述` | 文本 (必填) | 具体作用，忌模糊（如："提升修为"→改为"练气期服用后，三日修炼效率提升约三成"） |
| `使用条件` | 文本 (必填) | 什么境界能用？有什么前置条件？（如：筑基期以下有效 / 需配合火系功法 / 每月限服一粒） |
| `使用限制` | 文本 (选填) | 次数限制？副作用？成瘾性？（如：连续服用超过三粒会产生抗药性） |
| `耐久/数量` | 文本 (选填) | 法宝类填耐久度，消耗品类填单次获取的典型数量 |

### 经济属性

| 字段 | 类型 | 说明 |
|------|------|------|
| `获取方式` | 列表 (必填) | 怎么获得？（采集/炼制/购买/任务奖励/杀人夺宝/遗迹探索），至少写两种 |
| `常见产地` | 文本 (选填) | 引用 `@区域.名称` |
| `参考价格` | 文本 (必填) | 以低阶灵石为单位，给出一个价格区间。必须与 `04_资源分级体系` 的兑换比例一致 |
| `稀缺程度` | 文本 (必填) | 常见 / 普通 / 稀缺 / 罕见 / 传说。影响获取难度和消息传播范围 |

### 叙事功能

| 字段 | 类型 | 说明 |
|------|------|------|
| `剧情关联` | 文本 (选填) | 该资源与哪些剧情线相关？（如：是某势力的垄断资源 / 是某个任务的目标物品） |
| `隐藏信息` | 文本 (选填) | 该资源是否有不为人知的特性？（如：看似普通的草药，实为上古丹方的主材） |
| `首次出场章节` | 文本 (必填) | 第几章首次出现 |

## 填写示例

```markdown
### 资源卡 · 引气玉

【基础信息】
资源名称：引气玉
资源ID：RES-CLI-001
资源类别：材料
等级：黄阶上品（练气级）

【属性定义】
功能描述：内含温和灵气，练气期修士握持修炼时，灵气吸纳效率提升约两成；也可用于突破时稳定经脉
使用条件：练气期有效，筑基期效果微乎其微
使用限制：每日使用不超过两个时辰，过度依赖会导致自身吸纳能力下降
耐久/数量：单块可持续使用约三个月，灵气耗尽后变为普通玉石

【经济属性】
获取方式：
  1. 购买：坊市常见，但品质参差
  2. 采集：@区域.翳岭 深处矿脉可采，但有妖兽守护
  3. 任务奖励：散修联盟低级任务常见奖励
常见产地：@区域.翳岭 东麓矿脉
参考价格：3-5块低阶灵石（品质好的可达8块）
稀缺程度：普通

【叙事功能】
剧情关联：@势力.虻巢 控制翳岭矿脉，垄断高品质引气玉，低品质流入黑市
隐藏信息：翳岭矿脉深处偶有变异引气玉（淡青色），内含一丝木系生机，是炼制"定基丹"的隐藏辅料
首次出场章节：第3章（主角在坊市购买）
```

## 与04_资源分级体系的联动

`等级` 和 `参考价格` 字段必须严格对照 `04_资源分级体系`：

- 若 `04_资源分级体系` 中无该资源类别，需先在 `04_资源分级体系` 中补充定义
- 若资源等级与价格不匹配，以 `04_资源分级体系` 为准调整本卡
- 跨体系资源（如古裔体系物品）需在等级后标注体系来源，如 `古裔·二阶（相当于人族筑基期）`
