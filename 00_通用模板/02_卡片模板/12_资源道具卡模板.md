# 资源道具卡模板

> 类型：卡片模板 · 定义字段与填写示例，用于生成/维护资源道具数据。
>
> 新资源首次出场时必须填写；已有资源的数量变化在 `08_战斗结算` 或 `09_主角突破卡` 中记录，无需重复建卡。资源是修仙世界的"经济血液"，必须分级明确、来源清晰、流通合理。

## 字段与示例

`(必)`=必填，其余选填；示例值为格式参考，勿照抄。

### 资源卡 · [资源名称]

【基础信息】
| 字段 | 必填 | 说明与示例 |
|------|------|-----------|
| 资源名称 | (必) | 标准名称，全小说统一使用 |
| 资源ID | (必) | 格式：`RES-类别-序号`，如 `RES-DAN-003` |
| 资源类别 | (必) | 丹药/法宝/材料/灵石/功法/符箓/灵兽/古籍/其他 |
| 等级 | (必) | 对照 `04_资源分级体系`，如 `黄阶中品`/`二阶` |

【属性定义】
| 功能描述 | (必) | 具体作用，忌模糊（如："提升修为"→"服用后数日内修炼效率提升约三成"） |
| 使用条件 | (必) | 什么境界能用？有什么前置条件？（如：[境界]以下有效/需配合[某系]功法/每月限服一粒） |
| 使用限制 | | 次数限制？副作用？成瘾性？（如：连续服用超过三粒产生抗药性） |
| 耐久/数量 | | 法宝类填耐久度，消耗品类填单次获取的典型数量 |

【经济属性】
| 获取方式 | (必) | 怎么获得？（采集/炼制/购买/任务奖励/杀人夺宝/遗迹探索），至少写两种 |
| 常见产地 | | 引用 `@区域.名称` / `@地名.名称` |
| 参考价格 | (必) | 以低阶灵石为单位给出价格区间。必须与 `04_资源分级体系` 兑换比例一致 |
| 稀缺程度 | (必) | 常见/普通/稀缺/罕见/传说。影响获取难度和消息传播范围 |

【叙事功能】
| 剧情关联 | | 与哪些剧情线相关？（某势力的垄断资源/某个任务的目标物品） |
| 隐藏信息 | | 是否有不为人知的特性？（看似普通的草药，实为上古丹方主材） |
| 首次出场章节 | (必) | 第几章首次出现 |

## 与 04_资源分级体系 的联动

`等级` 和 `参考价格` 必须严格对照 `04_资源分级体系`：
- 若无该资源类别，先在该体系中补充定义
- 若等级与价格不匹配，以该体系为准调整本卡
- 跨体系资源在等级后标注体系来源，如 `[体系]·[等级]（相当于[基准境界]）`

> 资源类红线（禁无来源、禁无限制神物、禁随意定价、禁低境高持等）定义与自检统一见 `00_文风与节奏规范` 第八章【事件设计层】资源区。
