# 卷级伏笔跟踪册模板

> 类型：卡片模板 · 定义字段与填写示例，用于生成/维护 `03_规划/《部编号》/《卷编号》/00_伏笔册_《卷编号》.md`。
>
> 伏笔归属于规划层，按“卷”离散化存储。每埋设或回收一个伏笔必须在本卷伏笔册中登记，不登记=不存在，禁止临时现编回收。

## 字段与示例

`(必)`=必填、`(条)`=条件必填，其余选填；示例值为格式参考，勿照抄。

### 卷级伏笔跟踪册 · 示例结构

```markdown
# 《部名称》·《卷名称》· 伏笔跟踪册

## 1. 本卷新埋伏笔
| 伏笔ID | 伏笔名称 | 跨度 | 埋设位置 | 拟回收卷/章 | 伏笔内容描述 | 关联对象 | 状态 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| FH-001 | 示例伏笔名 | 章内/卷内/部内/整书 | 卷01章0003 | 卷01章0025 | 50字以内简述伏笔细节 | @人物.[姓名], @势力.[名称] | 活跃(已埋设) |

## 2. 本卷拟回收/触发伏笔
| 伏笔ID | 伏笔名称 | 来源埋设位置 | 本卷回收章节 | 回收触发事件 | 回收冲击类型 | 执行状态 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| FH-001 | 示例伏笔名 | 卷01章0003 | 卷01章0025 | 触发事件简述 | 逻辑冲击/情感冲击/战力冲击/世界观冲击 | 待执行/已回收 |
```

## 字段规范与属性说明

### 1. 本卷新埋伏笔表

| 字段 | 必填 | 说明与示例 |
|:---|:---|:---|
| 伏笔ID | (必) | 格式：`FH-序号`，如 `FH-001`（全书唯一编号） |
| 伏笔名称 | (必) | 一句话概括，方便检索 |
| 跨度 | (必) | 枚举：`章内`/`卷内`/`部内`/`整书` |
| 埋设位置 | (必) | 具体章节，如 `卷01章0003` |
| 拟回收卷/章 | (必) | 预测回收位置，如 `卷01章0025` 或 `卷02中段` |
| 伏笔内容描述 | (必) | 50字以内，具体写了什么？ |
| 关联对象 | (选) | 使用标准的 `@引用` 语法（如 `@人物.[姓名]`、`@势力.[名称]`） |
| 状态 | (必) | 枚举：`活跃(已埋设)`/`已暗示`/`已废弃` |

### 2. 本卷拟回收/触发伏笔表

| 字段 | 必填 | 说明与示例 |
|:---|:---|:---|
| 伏笔ID | (必) | 引用既有伏笔 ID，如 `FH-001` |
| 伏笔名称 | (必) | 对应伏笔名称 |
| 来源埋设位置 | (必) | 历史埋设章节，如 `卷01章0003` |
| 本卷回收章节 | (必) | 本卷实际回收章节，如 `卷01章0025` |
| 回收触发事件 | (必) | 触发回收的具体剧情事件简述 |
| 回收冲击类型 | (必) | 枚举：`逻辑冲击`/`情感冲击`/`战力冲击`/`世界观冲击` |
| 执行状态 | (必) | 枚举：`待执行`/`已回收`/`待调整` |

## 离散存储与跨卷流转规则

1. **按卷独立存储**：每个卷目录（如 `03_规划/01_第01部/01_卷01/`）下保存一份 `00_伏笔册_卷XX.md`，只包含该卷新埋设及该卷需回收的伏笔；
2. **跨卷自动拉取**：在生成新卷大纲与伏笔册时，Agent 检索历史卷中拟在本卷回收的活跃伏笔，拉入本卷的【本卷拟回收/触发伏笔】表中；
3. **上下文隔离**：未在本卷回收的历史伏笔不进入本卷伏笔册，写作时无需加载全书伏笔总表，大幅节省 Context Token。
