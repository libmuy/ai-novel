# 伏笔登记表模板

> 类型：卡片模板 · 定义字段与填写示例，用于生成/维护 `02_数据库/08_伏笔登记/08_伏笔登记.md`。
>
> 每埋设一个伏笔必须登记，不登记=不存在，禁止临时现编回收。

## 字段与示例

`(必)`=必填、`(条)`=条件必填，其余选填；示例值为格式参考，勿照抄。

### 伏笔登记 · [伏笔ID]

【基础信息】
| 字段 | 必填 | 说明与示例 |
|------|------|-----------|
| 伏笔ID | (必) | 格式：`FH-序号`，如 `FH-001`、`FH-002`（全书唯一） |
| 伏笔名称 | (必) | 一句话概括，方便检索 |
| 跨度 | (必) | 章内/卷内/部内/整书 |
| 埋设卷号 | (选) | 如"卷1"、"卷2"，未确定可留空 |
| 埋设章节 | (选) | 如"第3章"，未确定可留空 |
| 计划回收位置 | (必) | 如"第10章"，未确定可用模糊描述（如"卷2中段"） |

【埋设设计】
| 埋设内容简述 | (必) | 50字以内，具体写了什么？ |
| 埋设方式 | (必) | 对话提及/环境描写/物品出现/主角内心闪念/配角反常行为 |
| 读者可见度 | (必) | 明显/隐约/极隐 |

【回收设计】
| 回收章节 | (条) | 实际回收时填写 |
| 回收方式 | (必) | 直接揭示/角色口述/主角推理/战斗触发/环境变化 |
| 前置暗示 | (必) | 回收前1-3章安排了什么细节让读者似曾相识？ |
| 回收冲击类型 | (必) | 逻辑冲击/情感冲击/战力冲击/世界观冲击 |

【关联网络】
| 关联角色 | | 使用 `@人物.姓名` 格式 |
| 关联势力 | | 使用 `@势力.名称` 格式 |
| 关联主线/支线 | | 主线推进/支线展开/世界观揭秘/人物塑造 |

【状态追踪】
| 当前状态 | (必) | 已埋设/已暗示/已回收/已废弃/待调整 |
| 备注 | | 回收时的具体台词或场景草稿，或废弃原因 |

## 拆分规则

> **拆分规则**：`08_伏笔登记.md` 单文件条目数 **>50条** 或 **累计 >5KB** 时，拆分为「总索引（`08_伏笔登记.md`，仅保留 伏笔ID/名称/类型/状态/所属卷 五列摘要表）+ 按"卷"或"部"分文件（`08_伏笔登记_V1-V4.md` 等，视实际拆分粒度定）」。加载时只读总索引 + 涉及卷/部的分文件，禁止整目录全量灌入。新增伏笔时先查总索引判断归属文件，若未拆分则直接追加，超阈值后再执行拆分并回填父索引。
