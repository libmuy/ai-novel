# 本章状态履历模板

> 文件规范位置：`05_工作区/《部》/《卷》/《章》/04_本章状态履历.md`
> 维护规范：正文生成/定稿时同步产出，仅记录本章新产生的增量状态变化。
> 语法约束：
> - 运算-数值：使用 `+N` 或 `-N` (如 `-30`)
> - 运算-枚举：直接写目标枚举 (如 `炼气二层`)
> - 运算-列表：使用 `+X,-Y` 格式 (如 `+培元丹,-破草鞋`)
> - 描述：直接写 Markdown 自由文本描述
> - 终态标记：`活跃` / `死亡` / `退场` / `暂离`

## 表格列说明

本表共 7 列。前 4 列为**权威计算列**（参与 `merge_chapter_state.py` 合并）；
后 3 列为**元数据列**，仅供人工检索、审计与级联排查，**不参与任何类型合并计算**：

| 列 | 含义 | 取值 |
|---|---|---|
| 章节号 | 产生该变更的章节编号 | 如 `0001` |
| 变更时间 | 该变更被记录/定稿的时间 | 如 `2026-08-30`；未知可写 `-` |
| 变更类型 | 该对象-字段在本章的变更性质 | `新建` / `修改` / `移除` |

字段名与类型的权威定义见 `00_通用模板/03_字段词表.md`。
