# 卷级伏笔跟踪册模板

> 类型：卡片模板 · 定义字段与填写示例，用于生成/维护 `03_规划/《部编号》/《卷编号》/00_伏笔册_《卷编号》.md`。
>
> 伏笔归属于规划层，按“卷”离散化存储。每埋设、推进/暗示或回收一个伏笔必须在本卷伏笔册中登记，不登记=不存在，禁止临时现编回收。
>
> **追加式、不可覆盖**：本册只增不改他卷/上游已登记条目。`FH-序号` 全书唯一、全局分配：新伏笔从"全书已用最大号 +1"起（已用号含其他卷伏笔册 + 设定层/地理卡「相关事件·伏笔」字段里 `@伏笔.FH-xxx` 引用的号）。某号若已被设定层引用，其含义以该引用描述为准，本册只补埋设/回收/关联对象细节，不得改写含义。详见 `00_使用说明.md`【伏笔册维护规则】。

## 字段与示例

`(必)`=必填、`(条)`=条件必填，其余选填；示例值为格式参考，勿照抄。

### 卷级伏笔跟踪册 · 示例结构

```markdown

| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| FH-001 | 示例伏笔名 | 章内/卷内/部内/整书 | 卷01章0003 | 卷05章0012 | 50字以内简述伏笔细节 | @人物.[姓名], @势力.[名称] | 活跃(已埋设) |

| 伏笔ID | 伏笔名称 | 来源埋设位置 | 本卷暗示/推进章节 | 阶段性发展与暗示细节 | 状态更新 |

| FH-001 | 示例伏笔名 | 卷01章0003 | 卷02章0008 | 异宝再次微微鸣响，主角察觉灵脉异动 | 已暗示/推进中 |

| 伏笔ID | 伏笔名称 | 来源埋设位置 | 本卷回收章节 | 回收触发事件 | 回收冲击类型 | 执行状态 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| FH-001 | 示例伏笔名 | 卷01章0003 | 卷01章0025 | 触发事件简述 | 逻辑冲击/情感冲击/战力冲击/世界观冲击 | 待执行/已回收 |
```

## 字段规范与属性说明

### 1. 本卷新埋伏笔表

| 字段 | 必填 | 说明与示例 |
|:---|:---|:---|
| 伏笔ID | (必) | 格式：`FH-序号`，如 `FH-001`（全书唯一、全局分配、永不复用；新号 = 全书已用最大号 +1） |
| 伏笔名称 | (必) | 一句话概括，方便检索 |
| 跨度 | (必) | 枚举：`章内`/`卷内`/`部内`/`整书` |
| 埋设位置 | (必) | 具体章节，如 `卷01章0003` |
| 拟回收卷/章 | (必) | 预测回收位置，如 `卷01章0025` 或 `卷05章0012` |
| 伏笔内容描述 | (必) | 50字以内，具体写了什么？ |
| 关联对象 | (选) | 使用标准的 `@引用` 语法（如 `@人物.[姓名]`、`@势力.[名称]`） |
| 状态 | (必) | 枚举：`活跃(已埋设)`/`已暗示`/`已废弃` |

### 2. 本卷暗示/推进伏笔表（跨卷中间过渡记录）

| 字段 | 必填 | 说明与示例 |
|:---|:---|:---|
| 伏笔ID | (必) | 引用既有伏笔 ID，如 `FH-001` |
| 伏笔名称 | (必) | 对应伏笔名称 |
| 来源埋设位置 | (必) | 历史埋设章节，如 `卷01章0003` |
| 本卷暗示/推进章节 | (必) | 本卷提供新线索或细节暗示的章节，如 `卷02章0008` |
| 阶段性发展与暗示细节 | (必) | 简述本卷对该伏笔做出了什么阶段性暗示、状态改变或新线索释放 |
| 状态更新 | (必) | 枚举：`已暗示`/`推进中`/`待回收` |

### 3. 本卷拟回收/触发伏笔表

| 字段 | 必填 | 说明与示例 |
|:---|:---|:---|
| 伏笔ID | (必) | 引用既有伏笔 ID，如 `FH-001` |
| 伏笔名称 | (必) | 对应伏笔名称 |
| 来源埋设位置 | (必) | 历史埋设章节，如 `卷01章0003` |
| 本卷回收章节 | (必) | 本卷实际回收章节，如 `卷01章0025` |
| 回收触发事件 | (必) | 触发回收的具体剧情事件简述 |
| 回收冲击类型 | (必) | 枚举：`逻辑冲击`/`情感冲击`/`战力冲击`/`世界观冲击` |
| 执行状态 | (必) | 枚举：`待执行`/`已回收`/`待调整` |

## 离散存储与跨卷流转规则

1. **按卷独立存储**：每个卷目录（如 `03_规划/01_第01部/01_卷01/`）下保存一份 `00_伏笔册_卷XX.md`，包含该卷新埋设、该卷暗示/推进以及该卷需回收的伏笔；
2. **跨卷动态跟踪**：
   - 当跨卷伏笔在中间卷产生剧情推进或侧面暗示时，在对应中间卷伏笔册的【本卷暗示/推进伏笔】表中登记；
   - 生成新卷大纲与伏笔册时，Agent 检索历史卷中拟在本卷回收的活跃伏笔，拉入本卷【本卷拟回收/触发伏笔】表；
3. **上下文隔离**：未在本卷出现（无新埋设、无新暗示、非本卷回收）的历史伏笔不进入本卷伏笔册，写作时无需加载全书伏笔总表，大幅节省 Context Token。
