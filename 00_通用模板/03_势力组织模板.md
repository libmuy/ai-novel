# 势力组织模板

## 使用范围
定义小说中所有组织、宗门、家族、军团等集体势力的档案。

## 势力卡片字段

### 基础档案

| 字段 | 类型 | 说明 |
|------|------|------|
| `势力名称` | 文本 (必填) | 唯一标识名 |
| `体系/境界上限` | 文本 (必填) | 该势力主流修行体系与最高战力境界 |
| `地理位置` | 文本 (必填) | 总部或主要活动区域，关联地理区域卡 |
| `核心思想` | 文本 (必填) | 一句话概括行事逻辑 |

### 三要素（缺一不可）

| 字段 | 类型 | 说明 |
|------|------|------|
| `立场` | 文本 (必填) | 站在哪一边？具体到利益集团，忌写“中立” |
| `欲望` | 文本 (必填) | 最想要什么？越具体越好，忌“变强”“扩张” |
| `底线` | 文本 (必填) | 什么情况下会掀桌子、翻脸或不惜一战？ |

### 生存逻辑

| 字段 | 类型 | 说明 |
|------|------|------|
| `经济来源` | 文本 (必填) | 钱/资源从哪来？决定其行为动机 |
| `武力构成` | 文本 (必填) | 靠高手坐镇？靠人数？靠阵法？靠互克关系？ |
| `信息渠道` | 文本 (选填) | 怎么知道外界消息？决定其反应速度 |

### 关系网络

| 字段 | 类型 | 说明 |
|------|------|------|
| `敌对势力` | 列表 (选填) | 与谁有不可调和的矛盾？根源是什么？ |
| `潜在盟友` | 列表 (选填) | 可与谁暂时合作？利益交汇点在哪？ |
| `内部裂缝` | 文本 (选填) | 内部派系斗争或历史遗留问题，主角可利用的切入点 |

### 与主角关系

| 字段 | 类型 | 说明 |
|------|------|------|
| `当前状态` | 枚举 (选填) | 友好/中立/敌对/利用/未知 |
| `关系演变轨迹` | 文本 (选填) | 预计如何变化？ |
| `主角价值` | 文本 (选填) | 该势力看中主角什么？或忌惮主角什么？ |

### 叙事功能

| 字段 | 类型 | 说明 |
|------|------|------|
| `故事作用` | 文本 (选填) | 提供资源/制造阻碍/映照主角/埋设伏笔/展示世界观 |
| `高光/崩塌章节` | 文本 (选填) | 该势力在什么情节中达到影响力顶点或灭亡？ |
