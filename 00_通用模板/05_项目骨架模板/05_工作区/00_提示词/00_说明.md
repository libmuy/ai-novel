# 提示词说明（全书级 00_提示词/）

> 本目录存放全书级规划任务（00~09 及占位符清理 CH/FC/DN/BK/FH）可重新生成的执行 Prompt 缓存。
> 原则：Prompt 可以重新生成；当前数据发生变化时旧 Prompt 必须视为缓存失效。Prompt 不是正式小说数据，不参与设定引用。

## 命名与配对

- 文件名 `NN_<任务名>.md`（不带"提示"后缀），编号见 `00_进度.md` 规划阶段表。
- 云端产出回填文件与提示词**同名**，落在同级 `01_模型输出/`（一致性审查按同名配对 `WS006`）。

## 递归三目录

工作区每一级（全书 / 部 / 卷 / 章）都是 `00_提示词`（提示词存档）、`01_模型输出`（云端原始产出）、`02_状态`（状态数据）。
卷级/章级提示词分别存于 `05_工作区/《部》/《卷》/00_提示词/`（如 `00_单卷大纲生成_卷1.md`）与
`.../《章》/00_提示词/`（`00_单章细纲.md`、`01_正文生成.md`、`02_<事件>卡.md`）。
