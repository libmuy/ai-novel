# 战斗结算清单模板

## 使用范围
每场战斗结束后逐项填写。禁止战斗结束直接换场景。

## 结算清单字段

### 参战信息

| 字段 | 类型 | 说明 |
|------|------|------|
| `参战方` | 文本 (必填) | 主角 vs 谁？有无第三方？ |
| `胜负结果` | 枚举 (必填) | 胜/负/逃/和 |
| `战斗时长` | 文本 (选填) | |

### 外部条件核查

| 字段 | 类型 | 说明 |
|------|------|------|
| `外部条件列表` | 列表 (必填) | 至少2个：地形/阵法/法宝克制/对手受伤/有人相助 |

### 战后代价（主角方）

| 字段 | 类型 | 说明 |
|------|------|------|
| `肉身伤势` | 文本 (必填) | 具体部位与程度 |
| `灵气/血气消耗` | 文本 (必填) | 是否见底？恢复需多久？ |
| `法宝/武器状态` | 文本 (必填) | 完好/受损/损毁 |
| `道心波动` | 文本 (选填) | 无/轻微/剧烈 |

### 敌方状态

| 字段 | 类型 | 说明 |
|------|------|------|
| `死亡名单` | 列表 (选填) | |
| `逃脱名单` | 列表 (选填) | 逃走的会泄露多少信息？ |
| `被俘名单` | 列表 (选填) | 如何处理？ |

### 资源与消息

| 字段 | 类型 | 说明 |
|------|------|------|
| `直接获取` | 列表 (选填) | 战利品 |
| `间接获取` | 列表 (选填) | 如从尸体上发现某势力标记、信件 |
| `目击者` | 文本 (选填) | |
| `消息传播路径` | 文本 (选填) | 谁会知道？对主角后续有什么影响？ |

### 行为逻辑核查

| 字段 | 类型 | 说明 |
|------|------|------|
| `战前评估退路` | 布尔 (必填) | 是/否 |
| `战中保留后手` | 布尔 (必填) | 是/否 |
| `战后更换藏身地` | 布尔 (必填) | 是/否 |
| `检查追踪印记` | 布尔 (必填) | 是/否 |

### 情感表达

| 字段 | 类型 | 说明 |
|------|------|------|
| `主角情绪` | 文本 (选填) | 内部标注，不直接写入正文 |
| `替代动作` | 文本 (必填) | 具体动作或环境细节传递情绪 |
