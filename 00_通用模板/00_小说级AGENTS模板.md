# {{小说名}} · 小说工作区说明

> 本文档是 OpenCode 在本小说工作区的行为指南。**任务开始前，必须先读取 `00_通用模板/00_使用说明.md`**——路由表、@引用/ID 规范、Token 控制、一站式自检等核心规则全部集中在该文件，本文档仅作总览与范围界定。

- **工作区根目录**：本书文件夹（`01_小说数据/{{小说名}}/`），所有路径均相对此目录。
- **`00_通用模板`**：是指向根目录通用模板的符号链接（`-> ../../00_通用模板`），**只读**，禁止写入任何本书数据；其下文件仅定义字段、规则与说明。

## 范围隔离（最重要）

1. 本工作区只操作「{{小说名}}」一书的数据；禁止读取或修改其他小说文件夹（`01_小说数据/` 下的兄弟目录）的数据。
2. 只引用 `00_进度.md` 标记为「定稿」的数据；草稿/待校验数据不得作为写作依据。

## 数据位置（相对本书根目录）

| 目录 | 内容 |
|------|------|
| `00_进度.md` | 各文件成熟度状态（草稿/待校验/定稿），任务前必读 |
| `01_规划/` | 全书级蓝图（小说概念、爽感释放规划、全书卷大纲等） |
| `02_设定/` | 设定卡（主角档案、修炼体系、地理、势力、配角、伏笔、版权安全等） |
| `03_状态/` | 动态状态台账（出场对象、财务等） |
| `03_提示词/` | 云端提示词存档 |
| `正文卷N/` | 卷规划与正文（卷大纲/单章细纲在 `正文卷N/00_规划/`） |

## 任务执行约定

1. 任务路由表、@引用语法、ID 编号规范、Token 控制（单次 ≤4 个模板）——一律以 `00_通用模板/00_使用说明.md` 为准，本文件不重复定义，避免规则多源、口径不一。
2. 通用模板只读：`00_通用模板/` 下文件不得写入任何本书数据。
