# 通用写作规则

> 类型：写作规则 · 行为约束/规范（通用技艺层），生成与续写时遵循。兼作 `01_设定/00_文风.md`【爽感规则】区块的字段定义源（通用部分，见 `99_速查手册` S1）。
>
> **定位**：全书**通用写作规范（技艺层）的唯一权威来源**。开篇300字、中段松紧搭配、结尾钩子、比例基准、写作结构、节奏禁忌、情感表达、爽感释放机制的规则均以此为准；**风格层**（情绪引擎、爽感循环、主角人设红线）由各书所选文风模板定义，本文件与文风模板**叠加生效**。文风模板清单与选择规则见 `00_文风索引`。`05_开篇三章设计指南` 仅保留前三章专属规则（三章功能定位、人设落地、世界观展开节奏），通用规则直接引用本文件。

## 使用范围

定义全书文风比例基准、写作结构、节奏控制与情感表达规则。每章生成后必须逐项校验（第八章）。本章生效的"事件:感悟"比例、情绪引擎、爽感循环、主角人设红线以所选文风模板为准。

---

## 一、固定文风比例（基准）

| 比例 | 内容 | 说明 |
|------|------|------|
| **七分** | 修仙事件、打斗、冒险、资源争夺、秘境探索 | 保证剧情推进、追读粘性 |
| **三分** | 人心取舍、道义感悟、古籍点题、内心成长 | 保证内核深度、情感共鸣 |

**校验**：单章感悟/说教≤**30%**；单章打斗/冲突≤**70%**；连续两章"事件:感悟"比例波动≤**±15%**。

> 7:3 为**基准比例**；各文风模板可在此基准上微调（如天骄崛起流 8:2、沉重宿命流 6:4），本书生效比例以所选文风模板为准。

---

## 二、固定写作结构

全书每章（或每连续两章）必须完成闭环：

```
剧情事件 → 古籍短句点题 → 主角心境道理感悟
```

**禁止变体**：纯说教（无事件直接讲道理）；纯打斗流水账（无感悟只堆战斗）；空洞讲道理（感悟不依托事件）。

## 三、每章黄金结构

### 3.1 开篇300字规则

| 要素 | 要求 |
|------|------|
| 第一句 | 必须是**动作**或**异常**，禁止天气/环境/心情铺垫 |
| 前100字 | 必须出现**主角** + **冲突/危机/异常** |
| 前300字 | 必须让读者产生"然后呢？"的冲动 |

**可选入戏方式**（四选一）：① 危机入戏（主角处于生命危险）；② 悬念入戏（反常现象迫使主角反应）；③ 两难入戏（必须在两个坏选项里选一个）；④ 伏笔入戏（看似平常但读者知道不寻常的细节）。

**禁止入戏方式**：环境描写、心情铺垫、背景介绍（"这个世界分为……"）、回忆入戏（"三年前……"）。

### 3.2 中段结构规则

**松紧搭配**：前段打斗/冲突 → 中段必须插对话或内心评估；前段日常/对话 → 中段必须安排小冲突或危机。同一性质内容连续不得超过**1000字**（开篇三章**800字**）。

**信息释放**：每章新信息（新角色/新设定/新悬念）≤**3个**；每个必须同章或下一章产生叙事效果。

### 3.3 结尾钩子规则

- **重钩**（关键章节、卷末）：未解决的危机、突发变故、隐秘伏笔显现、两难困境激化 → 读者立刻问"然后呢？"
- **轻钩**（情绪收束章）：伏笔暗现、自我疑惑、未说破的一句话、反常细节 → 读者"有点不对劲"
- **频率**：每3章至少2重1轻；重大情感释放后必须用轻钩让读者"喘口气"
- **禁止结尾**：圆满收尾、纯说明收尾、时间跳跃收尾、感悟收尾无钩子

## 六、情感表达规则

### 6.1 禁止直接写情绪

**删除**："他感到悲伤/愤怒/失落/喜悦"、"他心里很难过"、"他不禁有些感慨"。
**替换为**：具体动作（他坐在崖边看着云海，一句话没说，直到天边泛白）、环境细节（他把米袋往地上一放，用刀割开袋口，倒出三分之二，拎着剩下的三分之一重新往前走）、物品互动（他反复掰断又接好一根枯枝，直到手指被木刺扎出血）。

### 6.2 情感戏的对话控制

每段对话**3-5句**内；必须穿插动作/环境描写；禁止超过100字的无打断独白。

### 6.3 代价术语统一简化

> 设定层（`02_数据库/01_修炼体系/`）保留各体系专有代价名词（命灵痕/契痕/铸纹痕、灵斑/铸斑/丹毒纹等）供生成系统查表；读者可见正文统一简化：

- **通用表达默认**：正文承接代价描写默认用"代价""损耗""反噬""折寿"等通用词，读者无需记忆六套平行名词。
- **专名点名规则**：仅两处点名专有术语——① 该体系首次登场的设定点题处；② 该代价成为本章剧情转折核心处。其余出现一律用通用表达。
- **单章上限**：同一章内点名专有代价术语 **≤1个**；禁止堆叠不同体系的专有名词。

## 七、爽感释放机制（防止过度压抑）

> 警告：本文件其他章节极度强调"代价""谨慎""吃亏选择"，若无此机制极易全文压抑、读者流失。爽感与压抑必须交替，如呼吸。

> **无脑爽禁令（全书唯一权威定义）**：爽感必须来自"提前布局、合理前置、兑现代价"，禁止五类——① 越阶秒杀（越阶须至少 **2个** 外部条件支撑）；② 绝境"爆种"反杀（须有提前铺垫的后手或外部援助）；③ 敌人突然降智（敌人必须按"利益最大化"行动）；④ 盟友无条件帮助（须有利益交换或情感铺垫）；⑤ 杀人夺宝后无人追查（必须结算消息传播和后续报复）。逐章执行见第八章【结构层】与【事件设计层】；主角人设红线见所选文风模板。

> **突破门槛（全书唯一权威定义）**：突破必须同时满足**资源条件 + 心境条件 + 外部条件**三重门槛，缺一不可；"代价"是突破的结果（新限制/伤势），不属于门槛。对应 `09_主角突破卡` 前置条件四字段：资源消耗→资源条件、心境铺垫→心境条件、外部契机→外部条件、修为积累=前置积累量。

### 7.1 压抑周期控制

> **边界说明**：本节定义的短/中/长周期为全书通用的**抽象节奏范式**。任何文风模板及小说文风数据文件（`01_设定/00_文风.md`）仅定义周期长度基准、压抑要素推荐与触发门槛，**严禁写死具体章节号、卷号或具体剧情**（属设定层跨界侵入规划层）。具体章节的周期分配与剧情绑定由《卷大纲》【章节节拍表】与《单章细纲》在规划/创作阶段动态编排匹配。

| 周期 | 连续压抑上限 | 必须释放 | 说明 |
|------|------------|---------|------|
| 短 | **3章** | 小爽感 | 成功脱险、获得关键信息、结识可靠盟友 |
| 中 | **8章** | 中爽感 | 布局反杀、以弱胜强智斗、隐忍后资源获取 |
| 长 | **15章** | 大爽感 | 绝地反击、长期伏笔华丽回收、境界突破后首次碾压 |

**压抑定义**：资源持续流失（灵石耗尽、法宝损毁、受伤未愈）；关系持续恶化（被追杀、被背叛、被误解）；道义选择持续吃亏（选了底线，代价不断发酵）；信息持续匮乏（被蒙在鼓里、被动挨打）。
**爽感释放定义**：主角通过自身能力（非天降机缘）获得正向反馈。

### 7.2 爽感来源清单（禁止"无脑爽"）

| 爽感类型 | 前置条件（缺一不可） | 禁用方式 |
|---------|-------------------|---------|
| **精心布局后的反杀** | ① 提前至少 **2章** 布置后手（阵法/陷阱/信息差）② 反杀中明确写出布局回收（让读者"原来那一步是为了这个"）③ 反杀后付出至少一个代价（受伤/暴露/资源耗尽） | 禁"临时想出来的妙计"、禁"对手降智" |
| **以弱胜强的智斗** | ① 明确实力差距，选择"不硬拼"② 利用环境/规则/对手弱点而非"爆种"③ 胜利后状态比战前更差（惨胜） | 禁"靠嘴炮说服敌人"、禁"敌人自杀" |
| **隐忍后的资源获取** | ① 为此资源此前至少忍耐 **3章** 克制/等待/吃亏 ② 获取过程有明确风险评估和退路 ③ 到手后立刻有新的隐患（被盯上/资源有缺陷/需配套资源） | 禁"路边捡到"、禁"对手白送"、禁"无风险获取" |
| **信息差反制** | ① 通过前期观察/情报掌握对手不知道的信息 ② 反制中信息优势被明确展示（"他知道，对手不知道"）③ 信息优势来源后续可追溯 | 禁"全知视角"、禁"对手突然说出关键信息" |
| **盟友的意外支援** | ① 帮助在 **3章前** 有铺垫（欠人情/共同利益/情感纽带）② 帮助有明确代价（盟友受伤/暴露/欠新人情）③ 主角受援后必须在未来章节回报 | 禁"天降救兵"、禁"无条件帮助" |
| **绝境中的极限操作** | ① 绝境是真实的（确实无路可退）② 操作基于已有能力/道具/知识，非新获得力量 ③ 成功后陷入更长的虚弱期（至少 **2章** 无法恢复全力） | 禁"爆种"、禁"突然觉醒新能力"、禁"绝境中升级" |

### 7.3 爽感循环

> 爽感循环的具体范式（如《凡人修仙传》式"谨慎布局 → 绝境/压抑 → 反杀/收获 → 代价结算 → 新的隐患"）由各文风模板【爽感循环】区块定义，本书生效循环以所选文风模板为准。

## 八、单章一站式自检清单（唯一校验入口）

> 生成任意一章正文后，**必须逐项勾选以下所有项目方可存档**。本清单是全书的**唯一章节校验入口**，整合了所有模板的校验要求。**用法**：每章生成后逐项自检；数据层与版权层涉及"登记/填写卡片"的项，须在对应数据文件中实际操作；风格层校验项（情绪引擎、爽感循环、主角人设红线）以所选文风模板为准。

### 【结构层】

- [ ] 本章是否自然体现了道义？（允许"埋设"或"揭示"，不强制固定结构）
- [ ] 道义密度是否合理？（软约束，无硬性配额；过度使用同一道义会削弱叙事张力）
- [ ] 事件:感悟比例是否符合本书所选文风的比例设定（默认 **7:3 ±15%**）？（感悟/说教≤30%，打斗/冲突≤70%，按所选文风微调）
- [ ] 结尾是否有钩子？（重钩或轻钩，禁止圆满收尾）
- [ ] 开篇300字是否满足"动作或异常入戏"？（禁止天气/环境/心情/背景/回忆入戏）
- [ ] 是否有"无脑爽"行为？（越阶秒杀/爆种/敌人降智/白给资源/无条件帮助）
- [ ] 同一性质内容（纯打斗/纯对话/纯感悟）是否连续超过 **1000字**？（开篇三章800字）
- [ ] 新设定是否超过 **3个**？（每个须同章或下章产生叙事效果）
- [ ] 感悟段落是否超过 **300字**？（开篇三章200字）
- [ ] 对话是否控制在 **3-5句** 内并穿插动作/环境描写？
- [ ] 是否连续两章用同一种钩子（重钩/轻钩）？
- [ ] 是否出现连续两个以上的华丽形容词？
- [ ] 专有代价术语是否堆叠？（单章点名≤1个，其余用"代价/损耗/反噬"等通用表达，见 §6.3）

### 【爽感与压抑层】

- [ ] 本章是压抑章还是爽感章？
- [ ] 若为压抑章：已连续压抑多少章？是否超过3章未释放？
- [ ] 若为爽感章：爽感来源是否来自第七章"允许清单"？是否满足前置条件？爽感循环是否符合所选文风模板？
- [ ] 爽感释放后，是否立刻跟进代价结算或新的隐患？
- [ ] 读者预期情绪是否为"爽但担心"或"憋屈但期待"？（禁止"纯憋屈"或"纯爽"）

### 【数据层】

- [ ] 所有**新出场角色**（有姓名）是否已登记到人物卡数据？（`@人物.姓名`）
- [ ] 所有**新埋设伏笔**是否已登记到伏笔登记表？（ID 格式见 `00_使用说明`）
- [ ] 所有**新获取/消耗/损毁资源**是否已登记到 04_资源 对应类别文件的物品清单？（`@资源.名称`）
- [ ] 若有**战斗**，是否填写了战斗结算卡？（08_战斗结算模板）
- [ ] 若有**跨体系战斗**，是否填写了战斗卡「跨体系冲突」区块？
- [ ] 若有**突破**，是否填写了突破卡？（09_主角突破卡模板）
- [ ] 若有**两难抉择或感悟闭环**，是否填写了事件与感悟卡？（10_事件与感悟卡模板）
- [ ] 涉及对象的**状态变更**是否已登记到章级状态履历？（`05_工作区/《部》/《卷》/《章》/02_状态/01_状态履历.md`，按 `00_通用模板/03_字段词表.md` 语法要求填写）

### 【版权层】

- [ ] 是否出现禁词清单中的内容？（知名作品原词、现实宗教原教义——法律/监管红线；真实古籍原句仅正文禁，卷首题记例外，见 `02_版权安全` §1.1）
- [ ] **正文**所有古籍引用是否来自该小说自定的虚构典籍？（卷首题记/章末铭文可引公有领域古籍原句并注明出处）
- [ ] 古籍引用是否控制在 **30字以内**？引用后是否立刻回到剧情、不做解释？
- [ ] 是否有"常见网文金句"或"现实名人名言"的影子？（若有，用主角自己的语言改写，或按 `02_版权安全` §3.1「仿古体化用」再造）
- [ ] 所有角色/势力/地名是否与知名作品撞名？

### 【主角人设层】

- [ ] 主角行为是否符合本书所选文风模板的「主角人设红线」？
- [ ] 若做道义选择，是否承担了**具体且无法立刻化解**的代价？
- [ ] 若获收益，是否伴随**至少一个隐患或代价**？
- [ ] 若与人结盟，对方帮助是否有**利益交换或情感铺垫**？（禁止无条件帮助）
- [ ] 若杀人夺宝，是否结算了**消息传播路径**和**后续追查**？
- [ ] 情感表达是否用**动作/环境细节**替代直接写情绪？（禁止"他感到悲伤"）

### 【资源与经济层】

- [ ] 出现的资源等级是否与主角当前境界匹配？（禁止低境界持高阶资源无代价）
- [ ] 经济交易是否符合已设定的兑换比例？（禁止随意更改灵石兑换率）
- [ ] 主角财务状态是否与 `04_资源_经济.md`【财富分级基准表】对应境界的典型持有量一致？

### 【事件设计层】（战斗/突破/资源三类事件红线的唯一自检执行入口）

**战斗**（08_战斗结算）：
- [ ] 禁止越阶秒杀？（弱于对方时必须靠策略、环境、代价取胜/逃脱，禁"爆种反杀"）
- [ ] 禁止敌人降智？（乙方必须有合理战术）
- [ ] 禁止无伤胜利？（即使赢，甲方也要付出代价：伤势、消耗、暴露底牌）
- [ ] 禁止战斗后无传播？（结果必须有人知道、有传播路径）
- [ ] 禁止杀人无后果？（只要有人死亡，必须有后续追查）
- [ ] 禁止连续战斗无恢复？（两场战斗间必须有恢复/准备时间）

**突破**（09_主角突破卡）：
