# 通用写作规则（校验版）

> 类型：写作规则 · 后置校验排查规范。
> 专用于正文生成后的自检与审校任务，包含全量一站式自检清单与规则核对。

## 一、单章一站式自检清单（唯一校验入口）

> 生成任意一章正文后，**必须逐项勾选以下所有项目方可存档**。

### 【结构层】

- [ ] 本章是否自然体现了道义？（允许"埋设"或"揭示"，不强制固定结构）
- [ ] 道义密度是否合理？（软约束，无硬性配额；过度使用同一道义会削弱叙事张力）
- [ ] 事件:感悟比例是否符合本书所选文风的比例设定（默认 **7:3 ±15%**）？（感悟/说教≤30%，打斗/冲突≤70%，按所选文风微调）
- [ ] 结尾是否有钩子？（重钩或轻钩，禁止圆满收尾）
- [ ] 开篇300字是否满足"动作或异常入戏"？（禁止天气/环境/心情/背景/回忆入戏）
- [ ] 是否有"无脑爽"行为？（越阶秒杀/爆种/敌人降智/白给资源/无条件帮助）
- [ ] 同一性质内容（纯打斗/纯对话/纯感悟）是否连续超过 **1000字**？（开篇三章800字）
- [ ] 新设定是否超过 **3个**？（每个须同章或下章产生叙事效果）
- [ ] 感悟段落是否超过 **300字**？（开篇三章200字）
- [ ] 对话是否控制在 **3-5句** 内并穿插动作/环境描写？
- [ ] 是否连续两章用同一种钩子（重钩/轻钩）？
- [ ] 是否出现连续两个以上的华丽形容词？
- [ ] 专有代价术语是否堆叠？（单章点名≤1个，其余用"代价/损耗/反噬"等通用表达）

### 【爽感与压抑层】

- [ ] 本章是压抑章还是爽感章？
- [ ] 若为压抑章：已连续压抑多少章？是否超过3章未释放？
- [ ] 若为爽感章：爽感来源是否来自准许清单？是否满足前置条件？爽感循环是否符合所选文风模板？
- [ ] 爽感释放后，是否立刻跟进代价结算或新的隐患？
- [ ] 读者预期情绪是否为"爽但担心"或"憋屈但期待"？（禁止"纯憋屈"或"纯爽"）

### 【数据层】

- [ ] 所有**新出场角色**（有姓名）是否已登记到人物卡数据？（`@人物.姓名`）
- [ ] 所有**新埋设伏笔**是否已登记到伏笔跟踪册？
- [ ] 所有**新获取/消耗/损毁资源**是否已登记到 04_资源 对应类别文件的物品清单？（`@资源.名称`）
- [ ] 若有**战斗**，是否填写了战斗结算卡？
- [ ] 若有**跨体系战斗**，是否填写了战斗卡「跨体系冲突」区块？
- [ ] 若有**突破**，是否填写了突破卡？
- [ ] 若有**两难抉择或感悟闭环**，是否填写了事件与感悟卡？
- [ ] 涉及对象的**状态变更**是否已登记到章级状态履历？（`05_工作区/《部》/《卷》/《章》/04_本章状态履历.md`，按 `00_通用模板/03_字段词表.md` 语法要求填写）

### 【版权层】

- [ ] 是否出现禁词清单中的内容？（知名作品原词、现实宗教原教义——法律/监管红线）
- [ ] **正文**所有古籍引用是否来自该小说自定的虚构典籍？
- [ ] 古籍引用是否控制在 **30字以内**？引用后是否立刻回到剧情、不做解释？
- [ ] 是否有"常见网文金句"或"现实名人名言"的影子？
- [ ] 所有角色/势力/地名是否与知名作品撞名？

### 【主角人设层】

- [ ] 主角行为是否符合本书所选文风模板的「主角人设红线」？
- [ ] 若做道义选择，是否承担了**具体且无法立刻化解**的代价？
- [ ] 若获收益，是否伴随**至少一个隐患或代价**？
- [ ] 若与人结盟，对方帮助是否有**利益交换或情感铺垫**？
- [ ] 若杀人夺宝，是否结算了**消息传播路径**和**后续追查**？
- [ ] 情感表达是否用**动作/环境细节**替代直接写情绪？

### 【资源与经济层】

- [ ] 出现的资源等级是否与主角当前境界匹配？
- [ ] 经济交易是否符合已设定的兑换比例？
- [ ] 主角财务状态是否与 `04_资源_经济.md`【财富分级基准表】对应境界的典型持有量一致？

### 【事件设计层】

- [ ] 战斗：禁止越阶秒杀、敌人降智、无伤胜利、无传播、杀人无后果、连续战斗无恢复
- [ ] 突破：禁止无代价突破、顿悟突破、同阶秒杀、突破即满血、连续突破、无感悟突破
- [ ] 资源：禁止无来源资源、无限制神物、随意定价、低境高持、资源通胀、消耗品/法宝损毁无交代

### 【世界规则层】

- [ ] 是否违反世界硬规则？
- [ ] 角色的认知是否符合其身份和时代？
- [ ] 本章新引入设定是否与世界基本法则冲突？
- [ ] 涉及死亡/灵魂/复活/夺舍是否符合生命与死亡法则？
- [ ] 涉及誓言/契约/时间能力是否符合因果与时空法则？
