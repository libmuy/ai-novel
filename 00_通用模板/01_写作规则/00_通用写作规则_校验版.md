## 八、单章一站式自检清单（唯一校验入口）

> 生成任意一章正文后，**必须逐项勾选以下所有项目方可存档**。本清单是全书的**唯一章节校验入口**，整合了所有模板的校验要求。**用法**：每章生成后逐项自检；数据层与版权层涉及"登记/填写卡片"的项，须在对应数据文件中实际操作；风格层校验项（情绪引擎、爽感循环、主角人设红线）以所选文风模板为准。

### 【结构层】

- [ ] 本章是否自然体现了道义？（允许"埋设"或"揭示"，不强制固定结构）
- [ ] 道义密度是否合理？（软约束，无硬性配额；过度使用同一道义会削弱叙事张力）
- [ ] 事件:感悟比例是否符合本书所选文风的比例设定（默认 **7:3 ±15%**）？（感悟/说教≤30%，打斗/冲突≤70%，按所选文风微调）
- [ ] 结尾是否有钩子？（重钩或轻钩，禁止圆满收尾）
- [ ] 开篇300字是否满足"动作或异常入戏"？（禁止天气/环境/心情/背景/回忆入戏）
- [ ] 是否有"无脑爽"行为？（越阶秒杀/爆种/敌人降智/白给资源/无条件帮助）
- [ ] 同一性质内容（纯打斗/纯对话/纯感悟）是否连续超过 **1000字**？（开篇三章800字）
- [ ] 新设定是否超过 **3个**？（每个须同章或下章产生叙事效果）
- [ ] 感悟段落是否超过 **300字**？（开篇三章200字）
- [ ] 对话是否控制在 **3-5句** 内并穿插动作/环境描写？
- [ ] 是否连续两章用同一种钩子（重钩/轻钩）？
- [ ] 是否出现连续两个以上的华丽形容词？
- [ ] 专有代价术语是否堆叠？（单章点名≤1个，其余用"代价/损耗/反噬"等通用表达，见 §6.3）

### 【爽感与压抑层】

- [ ] 本章是压抑章还是爽感章？
- [ ] 若为压抑章：已连续压抑多少章？是否超过3章未释放？
- [ ] 若为爽感章：爽感来源是否来自第七章"允许清单"？是否满足前置条件？爽感循环是否符合所选文风模板？
- [ ] 爽感释放后，是否立刻跟进代价结算或新的隐患？
- [ ] 读者预期情绪是否为"爽但担心"或"憋屈但期待"？（禁止"纯憋屈"或"纯爽"）

### 【数据层】

- [ ] 所有**新出场角色**（有姓名）是否已登记到人物卡数据？（`@人物.姓名`）
- [ ] 所有**新埋设伏笔**是否已登记？新号 = `03_规划/00_伏笔总纲.md`（FH 总账，**唯一权威**）已用最大号 +1，并同步登记进总纲；本卷伏笔册 `00_伏笔册_《卷》.md` 补埋设位置与拟回收卷/章（`audit_consistency.py` 的 `FS001`/`FS005` 据此校验）
- [ ] 所有**新获取/消耗/损毁资源**是否已登记到 04_资源 对应类别文件的物品清单？（`@资源.名称`）
- [ ] 若有**战斗**，是否填写了战斗结算卡？（08_战斗结算模板）
- [ ] 若有**跨体系战斗**，是否填写了战斗卡「跨体系冲突」区块？
- [ ] 若有**突破**，是否填写了突破卡？（09_主角突破卡模板）
- [ ] 若有**两难抉择或感悟闭环**，是否填写了事件与感悟卡？（10_事件与感悟卡模板）
- [ ] 涉及对象的**状态变更**是否已登记到章级状态履历？（`05_工作区/《部》/《卷》/《章》/02_状态/01_状态履历.md`，按 `00_通用模板/03_字段词表.md` 语法要求填写）

### 【版权层】

- [ ] 是否出现禁词清单中的内容？（知名作品原词、现实宗教原教义——法律/监管红线；真实古籍原句仅正文禁，卷首题记例外，见 `02_版权安全` §1.1）
- [ ] **正文**所有古籍引用是否来自该小说自定的虚构典籍？（卷首题记/章末铭文可引公有领域古籍原句并注明出处）
- [ ] 古籍引用是否控制在 **30字以内**？引用后是否立刻回到剧情、不做解释？
- [ ] 是否有"常见网文金句"或"现实名人名言"的影子？（若有，用主角自己的语言改写，或按 `02_版权安全` §3.1「仿古体化用」再造）
- [ ] 所有角色/势力/地名是否与知名作品撞名？

### 【主角人设层】

- [ ] 主角行为是否符合本书所选文风模板的「主角人设红线」？
- [ ] 若做道义选择，是否承担了**具体且无法立刻化解**的代价？
- [ ] 若获收益，是否伴随**至少一个隐患或代价**？
- [ ] 若与人结盟，对方帮助是否有**利益交换或情感铺垫**？（禁止无条件帮助）
- [ ] 若杀人夺宝，是否结算了**消息传播路径**和**后续追查**？
- [ ] 情感表达是否用**动作/环境细节**替代直接写情绪？（禁止"他感到悲伤"）

### 【资源与经济层】

- [ ] 出现的资源等级是否与主角当前境界匹配？（禁止低境界持高阶资源无代价）
- [ ] 经济交易是否符合已设定的兑换比例？（禁止随意更改灵石兑换率）
- [ ] 主角财务状态是否与 `04_资源_经济.md`【财富分级基准表】对应境界的典型持有量一致？

### 【事件设计层】（战斗/突破/资源三类事件红线的唯一自检执行入口）

**战斗**（08_战斗结算）：
- [ ] 禁止越阶秒杀？（弱于对方时必须靠策略、环境、代价取胜/逃脱，禁"爆种反杀"）
- [ ] 禁止敌人降智？（乙方必须有合理战术）
- [ ] 禁止无伤胜利？（即使赢，甲方也要付出代价：伤势、消耗、暴露底牌）
- [ ] 禁止战斗后无传播？（结果必须有人知道、有传播路径）
- [ ] 禁止杀人无后果？（只要有人死亡，必须有后续追查）
- [ ] 禁止连续战斗无恢复？（两场战斗间必须有恢复/准备时间）

**突破**（09_主角突破卡）：
- [ ] 禁止无代价突破？（三重门槛见 §7：资源+心境+外部，至少一项代价）
- [ ] 禁止"顿悟突破"？（必须有具体积累）
- [ ] 突破后战力评估是否诚实？（禁"同阶无敌""越阶秒杀"）
- [ ] 禁止"突破即满血"？（突破中受的伤、耗的精力必须保留）
- [ ] 禁止连续突破？（两次间隔至少 10 章或一个完整事件）
- [ ] 禁止突破后无感悟？（每次突破必须伴随感悟闭环）

**资源**（04_资源·物品卡）：
- [ ] 禁止无来源资源？（任何资源必须有获取方式）
- [ ] 禁止无限制神物？（高阶资源必须有使用条件或副作用）
- [ ] 禁止随意定价？（价格必须与 `04_资源` 一致）
- [ ] 禁止低境高持？（低境界持高阶资源必须有合理来源和"怀璧其罪"隐患）
- [ ] 禁止资源通胀？（同一资源同期价格波动≤±30%，除非有剧情解释）
- [ ] 禁止一次性道具无交代？（消耗品使用后须交代是否补充，法宝损毁后须交代是否修复）

**全部勾选通过，本章方可存档。**

### 【世界规则层】（正文级世界基本法则一致性自检）

> 对照 `01_设定/00_小说概念.md`【世界基本法则】（WR 规则，硬/软/未知三态）逐项检查。未知规则保持未知，禁止自行补全。冲突时报告并修改剧情/下层设定，**禁止修改世界基本法则**。

- [ ] 本章是否违反世界硬规则？（如：随意复活已死亡角色、无来源/无代价力量、角色全知知晓世界全部设定）
- [ ] 角色的认知是否只包含符合其身份、经历、时代和认知能力的信息？（信息与认知法则；禁止默认角色知道世界全部设定）
- [ ] 本章新引入的设定/能力/事件/资源是否与已定稿世界基本法则冲突？（有冲突时：指出冲突位置 → 修改剧情或下层设定；确为剧情异常现象时登记 `05_工作区/《部》/《卷》/《章》/02_状态/01_状态履历.md` 世界对象状态，不得改动世界基本法则）
- [ ] 涉及死亡/灵魂/复活/夺舍/轮回的内容是否符合生命与死亡法则？
- [ ] 涉及誓言/契约/命运/时间的能力是否符合因果法则与空间与时间法则？
