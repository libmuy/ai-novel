# 文风索引

> 类型：写作规则 · 索引/路由（风格专属层）。列出全部文风模板，每本书在 `01_设定/00_小说概念.md`【基础定位】『文风』字段选择**一个**；所选文风模板与 `00_通用写作规则` **叠加生效**。

## 文风模板清单

| 模板 | 适用定位/基调 | 一句话特征 | 比例（事件:感悟） |
|------|--------------|-----------|------------------|
| `00_文风_底层成长流` | 热血坚韧 · 修仙-底层成长（凡人流） | 谨慎布局、以弱胜强、隐忍积累、守底线 | 7:3 |
| `00_文风_天骄崛起流` | 明快热血 · 修仙-天才成长 | 天赋兑现、越级打脸、快节奏爽感 | 8:2 |
| `00_文风_轻松诙谐流` | 市井幽默 · 欢乐向/日常向 | 诙谐化解紧张、笑点服务剧情 | 7:3 |
| `00_文风_沉重宿命流` | 苍凉厚重 · 宿命/史诗向 | 长压抑换深刻爆发、代价沉重 | 6:4 |

## 选择规则

1. 每本书**必须**在 `01_设定/00_小说概念.md`【基础定位】『文风』字段选择**一个**文风模板，填写模板文件名（如 `00_文风_底层成长流`）。
2. 每本书**必须**建立本书文风数据文件 `01_设定/00_文风.md`：在文件头声明继承所选模板，只写本书专属落地内容（含【爽感规则】区块），不复制模板全文；字段定义源见下方「本书文风数据文件结构」。
3. 所选文风模板 + `00_通用写作规则` **叠加生效**：技艺层（结构/节奏/情感表达/自检框架）以 `00_通用写作规则` 为唯一权威；风格层（情绪引擎/爽感循环/主角人设红线/比例微调）以所选文风模板为准；本书爽感落地（压抑周期表/事件库/专属禁忌）以 `01_设定/00_文风.md`【爽感规则】为准。
4. 各文风模板共用 `00_通用写作规则` 的黄金结构与自检框架，互不排斥；本书一经选定，写作与校验均按该模板执行。

## 本书文风数据文件结构

`01_设定/00_文风.md` 的区块骨架与字段定义源：

| 区块 | 内容 | 字段定义源 |
|------|------|-----------|
| 文件头 | 继承声明（继承所选文风模板）+ 分层说明 | 本小节 |
| 【本书文风差异】 | 对继承模板风格层字段的本书级覆盖/补充（无则写"无"） | 所选文风模板字段 |
| 【爽感规则】压抑周期表 | 本书落地：卷/章区间、压抑内容、压抑长度、释放章节、释放类型、释放内容 | `00_通用写作规则` §7.1 |
| 【爽感规则】爽感事件库 | 按类型A-F的本书专属可用场景与前置 | `00_通用写作规则` §7.2 |
| 【爽感规则】爽感禁忌 | 本书专属落地细则（不得与 §7 无脑爽禁令冲突） | `00_通用写作规则` §7 |
| 【爽感规则】双重校验 | 爽感校验 + 道义校验 | §7 + `01_设定/05_核心道义.md` |

## 新增文风模板

新增文风模板时：在本索引登记，并按统一结构（【适用定位】/【主角人设红线】/【情绪引擎】/【爽感循环】/【比例微调】/【自检补充项】）补齐文件，文件命名 `00_文风_<风格名>.md`。
