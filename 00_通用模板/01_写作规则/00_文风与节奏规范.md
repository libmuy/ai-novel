# 文风与节奏规范

> 类型：写作规则 · 行为约束/规范，生成与续写时遵循。本规则兼作 `01_规划/00_爽感释放规划` 的字段定义源（配套产生数据文件，见 `00_使用说明` S1 例外说明）。`02_设定/00_开篇三章适配` 的字段定义源为 `05_开篇三章设计指南` §七，本规则不覆盖。

> **定位**：本模板是全书**通用写作规范的唯一权威来源**。所有关于开篇300字、中段松紧搭配、结尾钩子、情绪锁死、节奏禁忌、情感表达、爽感释放的规则，均以此文件为准。
>
> `05_开篇三章设计指南` 仅保留"前三章专属规则"（如三章功能定位、主角人设落地规则、世界观展开节奏），通用规则部分直接引用本模板。

## 使用范围

定义全书的文风比例、写作结构、节奏控制与情感表达规则。AI生成每一章后，必须逐项校验。

---

## 一、固定文风比例

| 比例 | 内容 | 说明 |
|------|------|------|
| **七分** | 修仙事件、打斗、冒险、资源争夺、秘境探索 | 保证剧情推进、追读粘性 |
| **三分** | 人心取舍、道义感悟、古籍点题、内心成长 | 保证内核深度、情感共鸣 |

**校验规则**：
- 单章内，感悟/说教段落不得超过**30%**
- 单章内，打斗/冲突段落不得超过**70%**
- 连续两章的"事件:感悟"比例波动不得超过**±15%**

---

## 二、固定写作结构

全书每一章（或每连续两章）必须完成以下结构闭环：

```
剧情事件 → 古籍短句点题 → 主角心境道理感悟
```

**禁止的变体**：
- 禁止纯说教（无事件直接讲道理）
- 禁止纯打斗流水账（无感悟只堆战斗过程）
- 禁止空洞讲道理（感悟不依托事件）

---

## 三、每章黄金结构

### 3.1 开篇300字规则

| 要素 | 要求 |
|------|------|
| 第一句 | 必须是**动作**或**异常**，禁止天气/环境/心情铺垫 |
| 前100字 | 必须出现**主角** + **冲突/危机/异常** |
| 前300字 | 必须让读者产生**"然后呢？"**的冲动 |

**可选入戏方式**（四选一）：
1. **危机入戏**：主角正处于生命危险中
2. **悬念入戏**：反常现象迫使主角做出反应
3. **两难入戏**：必须在两个坏选项中选一个
4. **伏笔入戏**：看似平常但读者知道不寻常的细节

**禁止的入戏方式**：
- 环境描写入戏（"清晨的山谷雾气很重"）
- 心情铺垫入戏（"他今天心情很好"）
- 背景介绍入戏（"这个世界分为……"）
- 回忆入戏（"三年前，他还是一个普通人……"）

### 3.2 中段结构规则

**松紧搭配**：
- 若前段是**打斗/冲突**，中段必须插入**对话或内心评估**
- 若前段是**日常/对话**，中段必须安排**一个小冲突或危机**
- 禁止同一性质内容连续超过**1000字**（开篇三章为800字，不得超过）

**信息释放节奏**：
- 每章释放的"新信息"（新角色、新设定、新悬念）不得超过**3个**
- 每个新信息必须在**同章或下一章**产生叙事效果

### 3.3 结尾钩子规则

**重钩**（用于关键章节、卷末）：
- 未解决的危机、突发变故、隐秘伏笔显现、两难困境激化
- 读者看完会立刻问"然后呢？"

**轻钩**（用于情绪收束章）：
- 伏笔暗现、自我疑惑、未说破的一句话、反常细节
- 读者产生"有点不对劲"的感觉

**使用频率**：
- 每3章中，至少2章用重钩，1章用轻钩
- 重大情感释放后，必须用轻钩让读者"喘口气"

**禁止的结尾**：
- 圆满收尾（"他终于安全了，睡了个好觉"）
- 纯说明收尾（"这就是这个世界的规则"）
- 时间跳跃收尾（"三个月后……"）
- 感悟收尾无钩子（"他明白了，然后走了"）

## 四、情绪锁死技巧

### 4.1 反差共情
- 展示一个强大的修士做了一件极其冷漠的事
- 同时展示一个弱小的凡人做了一件极其温热的事
- 让读者自己判断"谁更像人"
- **禁止**：作者旁白直接评判

### 4.2 付出回报不对等
- 主角付出了A，得到的回报远小于A，甚至为负
- 这是底层视角的核心情绪引擎
- **禁止**：付出后立即获得超额回报（爽文逻辑）

### 4.3 道理靠事件落地
- 任何感悟必须依附于具体事件
- 事件结束后主角总结一句人话，再用古籍点题
- **禁止**：主角突然"悟道"，没有事件支撑

## 六、情感表达规则

### 6.1 禁止直接写情绪

**删除以下句式**：
- "他感到悲伤/愤怒/失落/喜悦"
- "他心里很难过"
- "他不禁有些感慨"

**替换为**：
- 具体动作：他坐在崖边，看着云海，一句话没说，直到天边泛白
- 环境细节：他把米袋往地上一放，用刀割开袋口，倒出三分之二，然后拎着剩下的三分之一重新往前走。全程一句话没说。
- 物品互动：他反复掰断又接好一根枯枝，直到手指被木刺扎出血

### 6.2 情感戏的对话控制

- 每段对话控制在**3-5句**内
- 必须穿插**动作描写**或**环境描写**
- 禁止大段独白（超过100字的无打断独白必须拆分）

## 七、爽感释放机制（防止过度压抑）

> 警告：本模板其他章节极度强调"代价""谨慎""吃亏选择"，若不加此机制，极易导致全文压抑、读者流失。爽感与压抑必须交替，如呼吸。

> **无脑爽禁令（全书唯一权威定义）**：爽感必须来自"提前布局、合理前置、兑现代价"，禁止以下五类——
> 1. 越阶秒杀（越阶必须有至少 **2个** 外部条件支撑）
> 2. 绝境"爆种"反杀（必须有提前铺垫的后手或外部援助）
> 3. 敌人突然降智（敌人必须按"利益最大化"行动）
> 4. 盟友无条件帮助（帮助必须有利益交换或情感铺垫）
> 5. "杀人夺宝后无人追查"（必须结算消息传播和后续报复）
>
> 逐章执行见第八章【结构层】通用项与【事件设计层】分域项；主角人设红线见 九「主角人设红线」。

> **突破门槛（全书唯一权威定义）**：突破必须同时满足**资源条件 + 心境条件 + 外部条件**三重门槛，缺一不可；"代价"是突破的结果（新限制/伤势），不属于门槛之一。对应 `09_主角突破卡` 前置条件四字段：资源消耗→资源条件、心境铺垫→心境条件、外部契机→外部条件、修为积累=前置积累量。

### 7.1 压抑周期控制

| 周期类型 | 最大压抑长度 | 必须释放的爽感类型 | 说明 |
|---------|------------|------------------|------|
| 短周期 | 连续 **3章** 压抑后 | 小爽感 | 如：成功脱险、获得关键信息、结识可靠盟友 |
| 中周期 | 连续 **8章** 压抑后 | 中爽感 | 如：精心布局后的反杀、以弱胜强的智斗、隐忍后的资源获取 |
| 长周期 | 连续 **15章** 压抑后 | 大爽感 | 如：绝境中的绝地反击、长期伏笔的华丽回收、境界突破后的首次碾压 |

**压抑的定义**：主角连续处于以下状态
- 资源持续流失（灵石耗尽、法宝损毁、受伤未愈）
- 关系持续恶化（被追杀、被背叛、被误解）
- 道义选择持续吃亏（选了底线，代价不断发酵）
- 信息持续匮乏（始终被蒙在鼓里，被动挨打）

**爽感释放的定义**：主角通过自身能力（非天降机缘）获得正向反馈

### 7.2 爽感来源清单（禁止"无脑爽"）

以下爽感来源**全部允许**，但每种都必须满足右侧的"前置条件"：

| 爽感类型 | 前置条件（缺一不可） | 禁用方式 |
|---------|-------------------|---------|
| **精心布局后的反杀** | ① 主角提前至少 **2章** 布置后手（阵法、陷阱、信息差）<br>② 反杀过程中明确写出布局的回收（让读者"啊，原来那一步是为了这个"）<br>③ 反杀后主角必须付出至少一个代价（受伤、暴露、资源耗尽） | 禁止"临时想出来的妙计"、禁止"对手突然降智" |
| **以弱胜强的智斗** | ① 主角明确知道双方实力差距，选择"不硬拼"<br>② 利用环境/规则/对手弱点，而非自身"爆种"<br>③ 胜利后主角状态比战前更差（惨胜） | 禁止"靠嘴炮说服敌人"、禁止"敌人莫名其妙自杀" |
| **隐忍后的资源获取** | ① 主角为获取此资源，此前至少忍耐了 **3章** 的克制/等待/吃亏<br>② 获取过程有明确的风险评估和退路设计<br>③ 资源到手后，立刻有新的隐患出现（被人盯上、资源有缺陷、需要配套资源才能使用） | 禁止"路边捡到"、禁止"对手白送"、禁止"无风险获取" |
| **信息差反制** | ① 主角通过前期观察/情报收集，掌握了对手不知道的信息<br>② 反制过程中，信息优势被明确展示（让读者看到"他知道，对手不知道"）<br>③ 信息优势的来源在后续章节可被追溯（不是凭空知道） | 禁止"全知视角"、禁止"对手突然说出关键信息" |
| **盟友的意外支援** | ① 盟友的帮助在 **3章前** 有铺垫（欠人情、共同利益、情感纽带）<br>② 盟友的帮助有明确代价（盟友因此受伤/暴露/欠下新的人情）<br>③ 主角在受援后，必须在未来章节回报（不能白拿） | 禁止"天降救兵"、禁止"无条件帮助" |
| **绝境中的极限操作** | ① 绝境是真实的（主角确实无路可退，非假绝境）<br>② 极限操作基于主角已有的能力/道具/知识，非新获得的力量<br>③ 操作成功后，主角陷入更长的虚弱期（至少 **2章** 无法恢复全力） | 禁止"爆种"、禁止"突然觉醒新能力"、禁止"绝境中升级" |

### 7.3 《凡人修仙传》式爽感公式

核心循环：**谨慎布局 → 绝境/压抑 → 反杀/收获 → 代价结算 → 新的隐患**

- **布局期（3-5章）**：主角收集信息、准备后手、评估风险，读者知道"他在准备什么，但不知道能不能成"
- **压抑期（1-2章）**：局势恶化，主角陷入绝境，读者担心"布局够不够"
- **释放期（1章）**：布局回收，反杀成功，读者获得"果然如此"的满足感
- **结算期（1章）**：代价显现，收获盘点，新的隐患埋下，读者期待"接下来怎么办"

**关键**：爽感不是来自"赢"，而是来自"**赢的方式被提前证明是合理的**"。

### 7.4 爽感与压抑的交替节奏（示例）

```
压抑 → 压抑 → 小爽感（脱险） → 压抑 → 压抑 → 压抑 → 中爽感（布局反杀） → 压抑 → 压抑 → 大爽感（绝境收获）
  第1-2章      第3章              第4-6章                  第7章                  第8-9章           第10章
```

- [ ] 主角若做了道义选择，是否承担了**具体且无法立刻化解**的代价？
- [ ] 主角若获得收益，是否伴随**至少一个隐患或代价**？
- [ ] 主角若与人结盟，对方帮助是否有**利益交换或情感铺垫**？（禁止无条件帮助）
- [ ] 主角若杀人夺宝，是否结算了**消息传播路径**和**后续追查**？
- [ ] 情感表达是否用了**动作/环境细节**替代直接写情绪？（禁止"他感到悲伤"）

### 【资源与经济层】（对应 04_资源分级）

- [ ] 本章出现的资源等级是否与主角当前境界匹配？（禁止低境界持有高阶资源无代价）
- [ ] 本章的经济交易是否符合已设定的兑换比例？（禁止随意更改灵石兑换率）
- [ ] 主角的财务状态是否与"主角经济曲线"一致？

### 【事件设计层】（对应 08_战斗结算 + 09_主角突破卡 + 12_资源道具卡）

> 本层为战斗/突破/资源三类事件红线的**唯一自检执行入口**，三个卡片模板不再单独列红线，统一在此逐项勾选。红线定义以本文件 §7「无脑爽禁令」为唯一权威源，本层条目是其在战斗/突破/资源三域的操作化展开，不另行定义。

**战斗**（08_战斗结算）：
- [ ] 是否禁止越阶秒杀？（甲方弱于乙方时，必须通过策略、环境、代价换取胜利/逃脱，禁止"爆种反杀"）
- [ ] 是否禁止敌人降智？（乙方必须有合理战术，不能站着等主角放大招）
- [ ] 是否禁止无伤胜利？（即使赢了，甲方也必须付出代价：伤势、资源消耗、暴露底牌）
- [ ] 是否禁止战斗后无传播？（战斗结果必须有人知道、有传播路径，禁止"无人知晓的秒杀"）
- [ ] 是否禁止杀人无后果？（只要有人死亡，必须有后续追查，禁止"杀完没人管"）
- [ ] 是否禁止连续战斗无恢复？（两场战斗之间必须有恢复/准备时间，禁止"打完一场立刻打第二场满血复活"）

**突破**（09_主角突破卡）：
- [ ] 是否禁止无代价突破？（三重门槛定义见 §7，必须满足"资源条件+心境条件+外部条件"，至少有资源/身体/心理代价一项）
- [ ] 是否禁止"顿悟突破"？（必须有具体积累，禁止因"突然想通了"而突破）
- [ ] 突破后战力评估是否诚实？（禁止"同阶无敌""越阶秒杀"）
- [ ] 是否禁止"突破即满血"？（突破过程受的伤、消耗的精力，突破后必须保留）
- [ ] 是否禁止连续突破？（两次突破之间至少间隔 10 章或一个完整事件）
- [ ] 是否禁止突破后无感悟？（每次突破必须伴随感悟闭环，否则视为无效突破）

**资源**（12_资源道具卡）：
- [ ] 是否禁止无来源资源？（任何资源必须有获取方式，禁止"凭空获得"）
- [ ] 是否禁止无限制神物？（高阶资源必须有使用条件或副作用，禁止"吃了就无敌"）
- [ ] 是否禁止随意定价？（价格必须与 `04_资源分级体系` 一致，禁止同一资源前后价格矛盾）
- [ ] 是否禁止低境高持？（低境界主角持有高阶资源，必须有合理来源和"怀璧其罪"的隐患）
- [ ] 是否禁止资源通胀？（同一资源同期价格波动不得超过 ±30%，除非有剧情解释）
- [ ] 是否禁止一次性道具无交代？（消耗品使用后必须交代是否补充，法宝损毁后必须交代是否修复）

**全部勾选通过，本章方可存档。**
