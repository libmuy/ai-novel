# 禁用词表说明

> 类型：写作规则 · 说明文件。定义每本小说 `01_设定/00_禁用词表.md` 的分区与写法，本文件本身不产生数据、不参与匹配。
>
> **用途**：`02_工具/01_小说通用工具/audit_consistency.py` 的 `manuscript_lexicon` 规则读取各小说
> `01_设定/00_禁用词表.md`，对 `10_正文/**/*.md` 逐行匹配，命中即 `LEXICON001`（warning）。
> 拦截的是「确定性可判」的穿帮——现代科技/计量/材料词、口语网络词、与知名作品撞名词——
> 语义类逻辑问题（前后矛盾、脑补、人物反应失真）不在此列，走多模型冷读循环。

## 一、文件位置与生成

- 路径：`01_小说数据/<NN>_<小说名>/01_设定/00_禁用词表.md`
- 不存在时 `manuscript_lexicon` 只发一条 `LEXICON000`（info）并跳过，不阻断。
- 新建小说时按本说明起一版初稿；世界观定稿后随「设定层」一并复核。

## 二、格式约定（不使用竖线等 Markdown 特殊字符做分隔）

```markdown
# <小说名> · 禁用词表

> 一句话说明 + 指向本文件。

## 包含
手电筒        // 现代照明器具
塑料          // 现代高分子材料

## 正则
\d+\s*公里     // 现代距离单位

## 待确认
分钟          // 本世界是否有精确到「分」的时间概念？待用户定
```

- **分区标题**（`## ` 起）：
  - `## 包含`（或无标题的开头部分）：纯子串匹配，命中即报。
  - `## 正则`：每行一个 Python 正则。
  - `## 待确认`：**只登记、不启用**——拿不准是否真穿帮的词（时间/距离/重量单位等）先放这里，等用户拍板再挪进 `## 包含`。
- **行内注释**：词后接 `　//　` 或 `　——　`（前置至少一个空格）之后的内容是「为什么禁」，写进告警信息，不参与匹配。
- `#` 或 `>` 开头的整行为普通注释。

## 三、建议分区（按世界观逐条筛，不是照抄）

1. **现代科技**：手电/电筒/电池/电线/引擎/马达/雷达/摄像头/塑料/玻璃钢/合金钢/激光/信号……
2. **现代计量单位**：公里/千米/米/厘米/毫米/吨/千克/克/分钟/秒/摄氏度/百分之……
   （多为「待确认」——古典修真世界通常用里/丈/尺/寸、斤/两/钱、一炷香/一盏茶/时辰；
   但个别项目可能自定义了精确单位，须对照 `01_修炼体系`/`00_小说概念` 确认。）
3. **现代材料**：水泥/沥青/混凝土/不锈钢/橡胶/尼龙/化纤……
4. **口语与网络词**：OK/拜拜/搞定/给力/内卷/破防/yyds……以及与本书语域不符的现代俚语。
5. **撞名词**：与知名作品的专有名词（功法/势力/地名/人名）撞车的——查重后逐条列入。

## 四、与其它校验的关系

- `manuscript_lexicon` 只做「词面命中」，不判语境。某词确属本世界合法表达时，
  从词表删除或移入注释，不要靠调低严重度绕过。
- 现阶段 `LEXICON001` = warning：存量正文里的历史穿帮（细纲重出后统一重写）不阻断定稿；
  待某章正文重出、词表复核完成后，可在规则里把该级别升为 error 并补回归测试。
