# 新建小说清单

> 类型：写作规则 · 流程性任务定义（Agent 执行），不产生数据文件本体。
>
> **用途**：新建一部小说时，Agent 按本清单搭建 `01_小说数据/<NN>_<小说名>/` 目录骨架。本任务在 `00_通用模板/00_使用说明.md`「Agent 任务路由表」中登记为「新建小说」。
>
> **前置**：小说名已确定；通用模板已就绪（含 `00_通用模板/05_项目骨架模板/`）。

---

## 执行步骤

1. **确定目录编号**：在 `01_小说数据/` 下以 `<NN>_<小说名>/` 命名子目录，其中 `NN` 为两位数字前缀，**从小到大自动编号**：取现有目录中最大数字前缀 +1，从 `00` 起（例如已有 `00_苍玄`，则新书为 `01_…`）。
2. **从项目骨架模板复制**：
   ```bash
   cp -r 00_通用模板/05_项目骨架模板/ 01_小说数据/<NN>_<小说名>/
   ```
   骨架模板包含完整目录结构和必要的初始化文件。
3. **建通用模板链接**：优先创建相对符号链接 `ln -s ../../00_通用模板 01_小说数据/<NN>_<小说名>/00_通用模板`；Windows 无创建符号链接权限时，改用指向根目录 `00_通用模板` 的目录联接（Junction）。
   - 链接目标只读；在小说目录作为工作区根目录打开时，统一通过 `00_通用模板/...` 访问。
4. **生成 AGENTS.md**：复制 `00_通用模板/00_小说级AGENTS模板.md` 为 `01_小说数据/<NN>_<小说名>/AGENTS.md`，将全文 `{{小说名}}`、`{{NN}}` 占位符替换为实际小说名与目录编号，并按实际目录位置微调路径说明。
5. **生成初始 `00_进度.md`**：从骨架模板复制，按下方「初始进度骨架」确认内容正确，规划阶段 12 项提示词任务全部标记「待生成」，设定卡/正文卷/状态台账留空表。成熟度只允许使用「草稿 / 待校验 / 定稿」三态；"已存档"仅描述文件是否保留，不是成熟度状态。
6. **初始化技能配置**：确认 `05_任务/00_技能/index.md` 和 `05_任务/00_技能/本书技能配置.md` 已从骨架模板复制。
7. **汇报并交接**：完成后向用户汇报骨架结构（目录树 + 软链校验结果），并说明下一步进入云端提示词管线：00 概念 → 01 修炼体系 → 04 资源 → 02 地理区域 → 03 势力组织 → 05 主角配角 → 06 道义 → 07 文风爽感 → 08 书籍库 → 09 全书卷大纲 → 10 第一卷+开篇三章 → 11 单章细纲。

从 `00_通用模板/05_项目骨架模板/` 复制的结构：

```

├── 00_进度.md                   # 初始进度骨架
```
