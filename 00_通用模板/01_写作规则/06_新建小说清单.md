## 执行步骤（由 `new_novel.py` 自动完成）

```bash
python3 02_工具/00_系统级/new_novel.py <小说名>          # 先 --dry-run 看编号与计划
python3 02_工具/00_系统级/new_novel.py <小说名>
```

脚本依次：

1. **确定目录编号**：扫 `01_小说数据/` 下 `^\d{2}_` 目录，`NN = 最大 + 1`（两位，从 `00` 起）。
2. **复制骨架**：`00_通用模板/05_项目骨架模板/` → `01_小说数据/<NN>_<小说名>/`。
3. **建通用模板链接**：相对符号链接 `00_通用模板 -> ../../00_通用模板`（只读）。
4. **生成 AGENTS.md**：由 `00_通用模板/00_小说级AGENTS模板.md` 去掉用法说明段、替换
   `{{小说名}}`/`{{NN}}`。
5. **改 `00_进度.md`**：标题换成实际小说名。
6. **打印**目录树与自检结果。

后续（Agent 交接）：进入云端提示词管线
（00 概念 → 01 修炼体系 → 04 资源 → 02 地理区域 → 03 势力组织 → 05 主角配角 →
06 道义 → 07 文风爽感 → 08 书籍库 → 09 全书卷大纲 → 10 第一卷+开篇三章 → 11 单章细纲）；
`01_设定/`+`02_数据库/` 定稿后执行技能 `08_基线状态初始化.md` 生成冻结基线。
