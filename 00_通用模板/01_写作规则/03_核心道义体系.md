# 核心道义体系

> 类型：写作规则 · 行为约束/规范，生成与续写时遵循。兼作 `01_设定/05_核心道义.md` 的字段定义源（见 `99_速查手册` S1）。

## 使用范围

定义贯穿全书的原创道义准则——这是**创作约束**而非"主题思想"。每章生成后可对照校验：本章是否自然体现了道义？是否避免道义空洞化？

---

## 一、道义条目设计字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `道义ID` | 编号 (必填) | 如：DY-001 |
| `道义表述` | 文本 (必填) | 一句话概括，忌用现实名人名言或网文金句 |
| `核心含义` | 文本 (必填) | 这条道义探讨的价值矛盾是什么 |
| `表现范式` | 列表 (必填) | 冲突类型、选择结构、代价结构、人物关系变化、价值矛盾 |
| `禁忌写法` | 文本 (必填) | 什么写法会让这条道义变成空洞说教？ |
| `校验问题` | 文本 (必填) | 生成章节后自检：本章是否自然体现这条道义？ |
| `深化方向` | 列表 (选填) | 可以在哪些阶段产生不同解释？ |

**数据文件格式**：

```markdown
### 道义条目 · [道义ID]
道义表述：
核心含义：
表现范式：
- 冲突类型：...
- 选择结构：...
- 代价结构：...
- 人物关系变化：...
- 价值矛盾：...
禁忌写法：
校验问题：
深化方向：
```

## 二、道义表现规则

### 2.1 表现范式

表现范式只描述抽象的冲突结构，禁止出现固定人物、地点和章节。

合法示例：
- 冲突类型：资源有限时的分配困境
- 选择结构：保全多数 vs 保全少数
- 代价结构：选择者的心理负担与被放弃者的具体损失

不合法示例：
- 卷4·紫极天域·某事件必须发生
- 第38章主角必须面临取舍

### 2.2 道义与事件的关联规则

| 道义类型 | 适宜的事件类型 | 禁止的依附方式 |
|---------|--------------|--------------|
| 取舍类 | 资源争夺、两难抉择、救谁不救谁 | 禁止主角旁白突然"悟了" |
| 善恶类 | 目睹伪善/真恶、自身被迫作恶、发现反派苦衷 | 禁止脸谱化反派、禁止"他忽然明白善恶" |
| 力量类 | 越阶战斗后的代价、失去重要之物后的空虚、发现强者也有软肋 | 禁止"力量就是正义"的爽文逻辑 |
| 人性类 | 聚散无常、配角独立选择、底层人物高光时刻 | 禁止主角全知视角评判他人 |

### 2.3 古籍点题规则

> **权威声明**：正文古籍引用只使用该小说虚构典籍清单（唯一权威见 `02_版权安全与原创性规范` §2.1，存放于该小说 `02_数据库/06_书籍/06_书籍.md` 总索引 + `06_书籍_<书名>.md` 书籍库）。各书"职能分工"映射存放于该小说 `01_设定/05_核心道义.md`，本模板只定义规则、不存放书单与映射。

- 每本古籍主攻一类场景职能（人心诡谲、修仙界潜规则、力量代价、强者傲慢、底层烟火、出身地智慧等），写作时按场景选对应职能的书，禁止一本古籍跨主题乱用。
- 引用红线（30字以内、引后即回剧情、关键节点才用、使用前铺垫、书籍库每书种子≥5句上限12句）详见 `02_版权安全与原创性规范` §2。

## 三、道义密度控制（软约束）

道义应自然产生，不强制量化配额：

- 重大价值冲突时，优先检查道义是否自然体现
- 普通章节无需强制出现显性道义
- 不得为了满足指标制造主题剧情
- 道义可以通过行动、沉默、代价和关系变化表达
- 不要求角色主动总结道理
- 允许人物暂时不理解某件事
- 允许读者先理解、人物后理解
- 允许同一道义在不同阶段产生不同解释
- 允许人物过去坚持的道理最终被自己修正

## 四、与事件与感悟卡的联动

本模板定义"道义顶层设计"，`10_事件与感悟卡模板` 定义"单章执行流程"。执行方式灵活：

1. 从本模板选**本条要落地的道义**
2. 从 `02_数据库/06_书籍/06_书籍.md`（总索引）选书，按需加载对应 `06_书籍_<书名>.md` 选**适用古籍短句**
3. 用 `10_事件与感悟卡模板`（选择设计）或 `08_战斗结算模板` 设计**触发事件**
4. 事件后的道义表达允许灵活路径（事件→行动/沉默/错误/关系变化/延迟认知/后续长期回响），不强制固定结构
5. 用本模板的**校验问题**自检
