# 核心道义体系

> 类型：写作规则 · 行为约束/规范，生成与续写时遵循。兼作 `02_设定/03_核心道义` 的字段定义源（见 `99_速查手册` S1）。

## 使用范围

定义贯穿全书的原创道义准则——这是**硬性创作约束**而非"主题思想"。每章生成后必须对照校验：是否落地了至少一条道义？是否避免道义空洞化？

---

## 一、道义条目设计字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `道义ID` | 编号 (必填) | 如：DY-001 |
| `道义表述` | 文本 (必填) | 一句话概括，忌用现实名人名言或网文金句 |
| `落地场景` | 列表 (必填) | 通常在什么情境下触发？（面对抉择/失去/坚守/背叛） |
| `禁忌写法` | 文本 (必填) | 什么写法会让这条道义变成空洞说教？ |
| `校验问题` | 文本 (必填) | 生成章节后自检：本章是否通过具体事件让这条道义自然浮现？ |

**数据文件格式**：

```markdown
### 道义条目 · [道义ID]
道义表述：
落地场景：
- 场景A：...
- 场景B：...
禁忌写法：
校验问题：
```

## 二、道义落地规则

### 2.1 事件→古籍→感悟 的固定结构

> 步骤定义与禁止变体以 `00_文风与节奏规范` §二「固定写作结构」为唯一权威来源。本模板只强调一条顺序红线：**先事件 → 再古籍 → 最后感悟**，禁止调换。

### 2.2 道义与事件的绑定规则

| 道义类型 | 必须依附的事件类型 | 禁止的依附方式 |
|---------|------------------|--------------|
| 取舍类 | 资源争夺、两难抉择、救谁不救谁 | 禁止主角旁白突然"悟了" |
| 善恶类 | 目睹伪善/真恶、自身被迫作恶、发现反派苦衷 | 禁止脸谱化反派、禁止"他忽然明白善恶" |
| 力量类 | 越阶战斗后的代价、失去重要之物后的空虚、发现强者也有软肋 | 禁止"力量就是正义"的爽文逻辑 |
| 人性类 | 聚散无常、配角独立选择、底层人物高光时刻 | 禁止主角全知视角评判他人 |

### 2.3 古籍点题规则

> **权威声明**：正文古籍引用只使用该小说虚构典籍清单（唯一权威见 `02_版权安全与原创性规范` §2.1，存放于该小说 `02_设定/02_版权安全` 古籍弹药库）。各书"职能分工"映射存放于该小说 `02_设定/03_核心道义`，本模板只定义规则、不存放书单与映射。

- 每本古籍主攻一类场景职能（人心诡谲、修仙界潜规则、力量代价、强者傲慢、底层烟火、出身地智慧等），写作时按场景选对应职能的书，禁止一本古籍跨主题乱用。
- 引用红线（30字以内、引后即回剧情、关键节点才用、使用前铺垫、弹药库种子≥5句上限12句）详见 `02_版权安全与原创性规范` §2。

## 三、道义密度控制

> 感悟太多会稀释冲击力，以下是经过验证的频率标准：

- **每章**：至少落地 **0.5 条**（允许"埋设"而不"揭示"——本章只埋道义线索，不揭示答案）
- **每3-5章**：必须完成一次**完整闭环**（事件→古籍→感悟→行动，四步缺一不可）
- **每卷**：六条道义至少各落地 **1-2次**
- **全书**：同一道义在不同境界、不同情境下反复出现、每次深度不同（螺旋上升）

**"0.5条"解释**：1.0条 = 有事件、古籍、感悟、行动转化（完整闭环）；0.5条 = 有事件与道义线索埋设但未揭示；0条 = 完全无道义元素（仅允许纯打斗/纯信息释放章，但连续两章0条禁止）。

## 四、与事件与感悟卡的联动

本模板定义"道义顶层设计"，`10_事件与感悟卡模板` 定义"单章执行流程"。执行顺序：

1. 从本模板选**本条要落地的道义**
2. 从 `02_设定/02_版权安全`（古籍弹药库）选**适用古籍短句**
3. 用 `10_事件与感悟卡模板`（选择设计）或 `08_战斗结算模板` 设计**触发事件**
4. 用 `10_事件与感悟卡模板` 完成**事件→古籍→感悟→行动**闭环
5. 用本模板的**校验问题**自检
