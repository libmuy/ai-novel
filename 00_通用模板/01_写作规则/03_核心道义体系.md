# 核心道义体系

> 类型：写作规则 · 行为约束/规范，生成与续写时遵循。本规则兼作 `02_设定/03_核心道义` 的字段定义源（配套产生数据文件，见 `00_使用说明` S1 例外说明）。

## 使用范围
定义长篇小说的"灵魂"——贯穿全书的原创道义准则。所有章节生成、校验、续写都必须以此为基础。

**定位**：这不是"主题思想"，而是**硬性创作约束**。AI生成每一章后，必须对照此模板校验：本章是否落地了至少一条道义？是否避免了道义空洞化？

---

## 一、道义条目设计字段

每条道义必须包含以下要素：

| 字段 | 类型 | 说明 |
|------|------|------|
| `道义ID` | 编号 (必填) | 如：DY-001 |
| `道义表述` | 文本 (必填) | 一句话概括，忌用现实名人名言或网文金句 |
| `落地场景` | 列表 (必填) | 这条道义通常在什么情境下被触发？（如：面对抉择/失去/坚守/背叛） |
| `禁忌写法` | 文本 (必填) | 什么写法会让这条道义变成空洞说教？ |
| `校验问题` | 文本 (必填) | 生成章节后，用这个问题自检：本章是否通过具体事件让这条道义自然浮现？ |

## 二、全书道义总纲（示例结构）

```markdown
### 道义条目 · [道义ID]

道义表述：

- 场景B：...
禁忌写法：
校验问题：
```

## 三、道义落地规则

### 3.1 事件→古籍→感悟 的固定结构

**步骤定义**与**禁止变体清单**以 `00_文风与节奏规范` §2「固定写作结构」为唯一权威来源。本模板只强调一条顺序红线：**先事件 → 再古籍 → 最后感悟**，禁止调换。

### 3.2 道义与事件的绑定规则

| 道义类型 | 必须依附的事件类型 | 禁止的依附方式 |
|---------|------------------|--------------|
| 取舍类道义 | 资源争夺、两难抉择、救谁不救谁 | 禁止主角旁白突然"悟了" |
| 善恶类道义 | 目睹伪善/真恶、自身被迫作恶、发现反派的苦衷 | 禁止脸谱化反派，禁止"他忽然明白善恶" |
| 力量类道义 | 越阶战斗后的代价、失去重要之物后的空虚、发现强者也有软肋 | 禁止"力量就是正义"的爽文逻辑 |
| 人性类道义 | 聚散无常、配角独立选择、底层人物的高光时刻 | 禁止主角全知视角评判他人 |

### 3.3 古籍点题规则

> **权威声明**：六本虚构典籍的"职能分工"以此处为唯一权威来源；`02_版权安全与原创性规范` §2.1 只维护清单本身。调整古籍职能时只改本处，并在 `02_设定/02_版权安全` 各书头部同步。

**虚构古籍库**（正文只使用这六本，永不使用真实古籍；卷首题记例外见 `02_版权安全与原创性规范` §1.1。每本有明确的"职能分工"，避免审美疲劳，写作时按场景选书）：
1. 《尘心杂记》——主攻**人心诡谲、尔虞我诈**（揭示伪善、背叛、人心难测时用）
2. 《俗世儒章》——主攻**修仙界的潜规则与层级秩序**（宗门规矩、人际礼法、资源分配潜规则时用）
3. 《清虚残篇》——主攻**修行力量的本质与沉重代价**（突破、代价、力量反噬时用）
4. 《云山道录》——主攻**高阶修士的傲慢与天地法则的冷漠**（强者压迫、天地无情、大能视角时用）
5. 《人间风物志》——主攻**底层凡域的温暖、烟火气与众生相**（凡人温情、市井烟火、人间百态时用）
6. 《乡野古训》——主攻**主角出身地的生存智慧与接地气的比喻**（用农活/杀猪/种地等底层意象打比方时用）

**使用规则**（每句引用30字以内、引用后立刻回剧情不做解释等红线，详见 `02_版权安全与原创性规范` §2）：
- 只在**关键节点**使用，不是每章必用
- 使用前先铺垫"主角读过这本书"或"偶然想起某句话"
- 提前为每本古籍准备短句弹药库（种子库至少5句，最终上限12句），写作时根据场景选用（详见 `02_版权安全与原创性规范` 2.4节）

## 四、道义密度控制

> **注意**：感悟太多会稀释冲击力。以下是经过验证的频率标准：

- **每章**：至少落地 **0.5 条**道义（允许"埋设"而不"揭示"——即本章只埋下道义线索，不揭示答案）
- **每3-5章**：必须完成一次**完整闭环**（事件→古籍→感悟→行动，四步缺一不可）
- **每卷**：六条道义至少各落地 **1-2次**
- **全书**：道义呈现螺旋上升——同一道义在不同境界、不同情境下反复出现，但每次深度不同

**"0.5条"的解释**：
- 1.0条 = 本章有事件，有古籍，有感悟，有行动转化（完整闭环）
- 0.5条 = 本章有事件，有道义线索的埋设或暗示，但没有完整揭示（为后续章节铺垫）
- 0条 = 本章完全没有道义元素（仅允许纯打斗/纯信息释放章，但连续两章0条禁止）

## 五、与事件与感悟卡的联动

本模板定义"道义的顶层设计"，`10_事件与感悟卡模板`定义"单章的执行流程"。

执行顺序：
1. 从本模板中选择**本条要落地的道义**
2. 从本模板中选择**适用的古籍短句**
3. 用`10_事件与感悟卡模板`（选择设计）或`08_战斗结算模板`设计**触发事件**
4. 用`10_事件与感悟卡模板`完成**事件→古籍→感悟→行动**的闭环
5. 用本模板的**校验问题**自检
