# 云端回填分割规则（本地 Agent 用）

> 类型：写作规则 · 行为约束/工作流，供 OpenCode（本地 Agent）执行"云端回填分割"任务，不产生数据文件。
>
> **用途**：任务 01~04、08 采用「合并单文件输出模式」（见 `00_通用模板/04_提示词/00_云端提示词生成器.md`）时，云端大模型把一次任务的全部产出合并为一个 Markdown 文件。用户将该文件保存到 `01_小说数据/<NN>_<小说名>/05_云端回填/` 后，本规则指导本地 Agent 把它分割回填到路由表「输出路径」对应的数据文件，并校验、更新进度。

## 前置条件

1. 对应任务的云端提示词使用「合并单文件输出模式」拼装（存档文件头有注明）。
2. 云端产出文件已保存到 `01_小说数据/<NN>_<小说名>/05_云端回填/`，命名 `<NN>_<任务名>_云端输出.md`（如 `03_势力组织_云端输出.md`）。该空文件在提示词拼装时已预建（0 字节），用户把云端下载的合并文件直接保存/覆盖到此路径即可。
3. 目标输出文件已按路由表「输出路径」预建空文件（0 字节）；若为增量追加任务，目标文件已有定稿内容。路由表中的总索引路径固定，子文件路径按对应模板的合法命名模式校验，不要求预先知道每个动态子文件名。

**合并任务（01+04、02+03）**：产出文件仍按原任务名、按簇独立处理——簇1 产出保存在 `<NN>_<原任务1>_云端输出.md`（如 `01_修炼体系_云端输出.md`），簇2 产出保存在 `<NN>_<原任务2>_云端输出.md`（如 `04_资源体系_云端输出.md`）。各簇各自按本规则独立分割回填，**分割逻辑零改动**；仅需在两簇都分割完成后追加「合并任务跨簇闭合校验」（见下）。

## 区块标记规范（云端产出必须遵守）

- 区块开头：独占一行 `<!-- FILE: <相对小说数据目录的输出路径> -->`
- 区块内容：该目标文件的完整内容（含文件内标题与区块标题）
- 区块结束：独占一行 `<!-- /FILE -->`
- 区块外只允许文件头说明段；出现其他内容视为格式违规。

## 分割步骤

1. 读入合并文件全文。
2. 按 `<!-- FILE: <路径> -->` … `<!-- /FILE -->` 切分为区块，提取每个区块的路径与内容。
3. **路径白名单校验**：总索引路径必须命中对应任务路由表；子文件路径必须命中对应模板的合法命名模式（如 `02_数据库/03_势力组织/03_势力组织_<势力名>.md`），且不得越出该任务的输出目录。未命中、拼写不符、重复路径或区块未闭合 → **中止，不落盘**，向用户报告违规区块，待云端重出或人工修正。
4. **落位**：
   - 总索引区块：仅覆盖该任务预建的空文件（0 字节）；目标非空且非本任务预建 → 中止并人工确认。
   - 子文件区块：按各模板「文件命名规则」新建文件写入。
   - **禁止覆盖任何非空既有文件**；增量追加任务按「增量追加语义」处理。
5. 区块外文件头说明段忽略，不落盘。

## 校验（分割后、更新进度前）

逐项核对，全部通过方可将本任务标记为「定稿」：
- [ ] 字段齐全性：对照对应卡片模板字段逐一核对，无缺失字段、无占位文本
- [ ] @引用 可解析：跨文件引用对象已成卡；未成卡对象归集到对应文件末尾「待创建条目」清单
- [ ] ID 连续性：同类卡片序号连续递增，无跳号/复用
- [ ] 父索引同步：总索引含全部子文件链接且与文件逐一对应（地理区域逐级补链：世界索引/区域索引/地名索引）
- [ ] 增量追加语义：仅追加，未破坏既有内容
- [ ] 任务特定红线（版权/道义/数值分级等）按该任务存档提示词【验收自检】执行

> 任一校验项失败，目标数据保持「待校验」，不得部分标记为「定稿」；应先输出失败项与修复建议，修复后从头重验。

## 合并任务跨簇闭合校验（01+04、02+03 专用）

合并任务两簇独立分割回填、各自校验通过后，追加核对跨簇引用是否闭合：

- [ ] 簇1 数据文件末尾「待创建条目」中被簇2 产出成卡的对象（`@资源`/`@法宝`/`@势力` 等）已移除待创建登记，引用可解析；
- [ ] 地理区域卡「势力列表」中的势力名与簇2 势力卡标题逐一匹配，无拼写偏差；
- [ ] 簇1 中登记的 `@区域`/`@地名` 待创建条目（如资源体系「常见产地」）未在本次两簇内成卡的，保留待创建登记，待后续任务定稿后补链。

任一跨簇校验项失败，涉及数据保持「待校验」，报告问题清单，修复后重验。

## 回填后处理

- 更新 `00_进度.md`：云端文件首次落位标记「草稿」；开始校验后标记「待校验」；全部校验通过后才标记「定稿」，并登记新增文件清单与回填日期
- 合并文件**保留**在 `05_云端回填/` 存档，不删除
- 校验失败：保持「待校验」，向用户报告问题清单，修复后重新校验；保留合并文件作为原始输入，不将其本身视为定稿数据

## 增量追加语义

合并文件若来自增量追加任务（新增体系/世界/区域/地名/势力/类别/物品卡），分割语义为**追加**：
- 子文件区块内容**追加**到既有子文件末尾（文件不存在则新建）；禁止整体重写既有内容
- 总索引区块仅同步父索引（追加行/逐级补链），不覆盖既有索引
- 完成后按「校验」的"父索引同步 + 增量追加语义"检查

## 与路由表的关系

任务路由见 `00_通用模板/00_使用说明.md`「Agent 任务路由表」；执行本任务时必读模板 = 本规则 + 对应任务的存档提示词（含内联模板与验收自检），必读数据 = 合并文件 + `00_进度.md` + 该任务「输出路径」的预建/既有目标文件。
