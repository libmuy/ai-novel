# 资源

> 类型：写作规则 · 行为约束/规范，生成与续写时遵循。兼作 `02_数据库/04_资源/` 文件夹（含各类别文件【分级表】与【物品卡】两区块）的字段定义源（见 `99_速查手册` S1）。

## 使用范围

定义小说中所有可获取、交易、消耗的资源的分级标准，防止后期战力崩坏与经济体系混乱。每类资源既有「分级表」（品级体系/对应境界），也有「物品卡」（具体物品条目），两者同存于对应类别文件。

## 层级结构与文件拆分

本分类为多类别查表型数据，采用「总索引 + 子文件」多文件结构，**产出合计 >1KB 时按每类别一文件拆分**（≤1KB 保持单文件、全部写入总索引）。全部文件置于分类文件夹 `02_数据库/04_资源/` 内。

| 文件 | 内容 |
|------|------|
| `02_数据库/04_资源/04_资源.md` | 总索引：【分类索引】表格（类别｜一句话概况｜文件链接）；还需包含【物品速查】区块——按类别分组，一次性列出该类别文件【物品卡】区块下已登记的全部具体物品名称（只写名称，不写字段细节），用于防止后续新增物品时出现重复或矛盾设定；≤1KB 时承载全部区块 |
| `02_数据库/04_资源/04_资源_<类别>.md` | 类别文件：单个类别区块全文，含【分级表】+【物品卡】两区块 |

**拆分粒度**：货币 / 丹药 / 法宝 / 功法 / 材料 / 妖兽 / 符箓 / 秘境 / 经济（经济体系 + 财富分级基准表合一），共 9 个类别文件。

**文件命名规则**：文件名 = 前缀 `04_资源` + `_<类别>`，标准类别名固定为上述 9 项之一；确实无法归入任何标准类别的原创资源类型，登记至 `04_资源_原创.md`（登记流程见 §五），不得擅自增设新的标准类别文件。

**父子关系规则**：总索引放「分类索引 + 文件链接」，子文件放「类别区块全文」（区块标题见 §三）。增量追加新的**具体物品卡**时，须同步在总索引【分类索引】表对应类别行更新概况说明；新增**原创类别**须按 §五 流程登记到 `04_资源_原创.md` 并同步总索引，不适用本条"9类固定"限制，也不得跳过 §五 判定流程直接建标准类别文件。新增/删除具体物品卡时，须同步在总索引【物品速查】对应类别下增删该物品名。

**按需取分支示例**：某章主角炼丹，只加载 `02_数据库/04_资源/04_资源.md`（总索引）+ `02_数据库/04_资源/04_资源_丹药.md`；需配平经济时再加载 `04_资源_经济.md`，禁止整目录全量灌入。

## 设计原则

1. **分级必须对应境界**：每一级资源都有明确的"最低使用境界"与"最佳使用境界"。
2. **兑换比例固定**：货币或等价物的兑换比例一旦设定，全书不得随意更改。
3. **越级使用有代价**：低境界强行使用高阶资源，必须有明确的副作用或浪费率。
4. **稀缺度与获取难度挂钩**：高阶资源的获取途径必须与等级匹配，禁止"路边捡到仙器"。

## 一、通用资源总表

以下各表即 `02_数据库/04_资源/` 下各类别文件的数据格式，字段均须按表填写。

### 1.1 货币/能量单位分级

| 字段 | 说明 |
|------|------|
| `货币名称` | 通用交易媒介的名称 |
| `分级列表` | 各级名称、对应基准价值、兑换比例 |
| `灵气纯度` | 每一级蕴含的灵气量或能量密度 |
| `外观特征` | 便于在叙事中描述 |
| `主要用途` | 交易/修炼/布阵/驱动法宝 |
| `获取途径` | 矿脉开采/任务报酬/战利品/兑换 |

### 1.2 丹药分级

| 字段 | 说明 |
|------|------|
| `品级体系` | 几品制？每品是否分阶？ |
| `品级名称` | 一品至X品的具体名称 |
| `对应境界` | 每一品建议的使用境界 |
| `炼制难度` | 对应炼丹师境界要求 |
| `主材等级` | 炼制所需材料的最低等级 |
| `药效上限` | 对同阶修士的效果；对高阶修士的衰减率 |
| `丹毒/副作用` | 越级服用或过量服用的后果 |
| `保存期限` | 丹药是否随时间失效？ |

### 1.3 法宝/武器分级

| 字段 | 说明 |
|------|------|
| `等级名称` | 如：法器→灵器→法宝→灵宝→通天灵宝 |
| `对应境界` | 每一级建议的持有境界 |
| `灵性程度` | 是否有器灵？器灵智能等级？ |
| `祭炼要求` | 需要多少时间与灵气才能初步祭炼？ |
| `进阶可能` | 是否可通过温养/吞噬材料升级？ |
| `损毁修复` | 受损后如何修复？修复成本？ |
| `认主机制` | 滴血/神识烙印/因果绑定/其他？ |

### 1.4 功法/典籍分级

| 字段 | 说明 |
|------|------|
| `等级名称` | 如：基础→进阶→核心→秘传→禁术 |
| `对应境界` | 每一级建议的修习境界 |
| `修习难度` | 入门时间/悟性要求/前置功法要求 |
| `威力上限` | 同阶发挥几成威力？跨阶衰减率？ |
| `隐患/代价` | 修习或施展的副作用 |
| `传承限制` | 是否可抄录？是否可外传？是否有传承禁制？ |

### 1.5 材料/天材地宝分级

| 字段 | 说明 |
|------|------|
| `等级名称` | 如：凡品→灵品→地品→天品→仙品 |
| `对应用途` | 每一级通常用于炼制什么等级的丹药/法宝/阵法？ |
| `生长环境` | 生长/产出地点的特征 |
| `采集难度` | 是否有守护妖兽？是否有采集手法要求？ |
| `保存条件` | 离开原生环境后多久失效？需要什么容器保存？ |

### 1.6 妖兽/异族材料分级

| 字段 | 说明 |
|------|------|
| `等级对应` | 妖兽/异族等级与修士境界的对照 |
| `材料部位` | 哪些部位有价值？（皮/骨/血/丹/角/魂） |
| `价值差异` | 同一妖兽不同部位的价值比例 |
| `处理要求` | 击杀后多久内必须处理？处理不当的后果？ |

### 1.7 符箓分级

| 字段 | 说明 |
|------|------|
| `等级名称` | 如：凡箓→灵箓→法箓→宝箓→禁箓 |
| `对应境界` | 每一级建议的使用境界 |
| `触发条件` | 灵力注入即用/遇险自动触发/需特定手势咒诀？ |
| `威力上限` | 对同阶目标的效果；跨阶衰减率 |
| `制作要求` | 制符师境界要求、材料等级、成功率 |
| `保存期限` | 灵气流失速度？是否随时间失效？ |

### 1.8 秘境/遗迹/洞天分级

| 字段 | 说明 |
|------|------|
| `危险等级` | 各等级名称与建议进入的最低境界 |
| `收益等级` | 通常可获得的资源等级 |
| `开启条件` | 时间限制/血脉限制/钥匙/修为门槛 |
| `存活率` | 各境界进入后的历史存活率（用于叙事参考） |
| `特殊规则` | 内部是否有禁法/禁空/时间流速差异等？ |

## 二、经济体系设计字段

### 2.1 通货膨胀/稀缺度控制

| 字段 | 说明 |
|------|------|
| `高阶资源流通方式` | 高阶资源是否允许用低阶货币直接购买？还是必须以物易物？ |
| `大宗门垄断项` | 哪些资源被大宗门垄断？散修如何获取？ |
| `黑市定价规则` | 黑市价格与官方/坊市价格的差异比例？ |
| `资源再生速度` | 灵脉/妖兽/草药的再生周期？是否可持续开采？ |

### 2.2 财富分级基准表

> 通用查表基准，不限主角——个人（按境界）与势力（按规模）均可查此表估算合理身家，防止"境界不高却坐拥巨富"或"大宗门却穷得叮当响"等失真描写。财务危机、缺钱剧情等叙事节奏安排不在本表范围，见 `06_卷大纲模板.md`【资源与伏笔规划】。

| 字段 | 说明 |
|------|------|
| `对象类型` | 个人（按境界）/ 势力（按规模等级，如：散修/小门派/大宗门/王朝级） |
| `等级/规模` | 对应境界名称，或势力规模分级名称 |
| `典型资源持有量` | 该等级/规模通常持有的资源总值区间（以低阶灵石为单位） |
| `主要收入渠道` | 该等级/规模的典型收入方式 |
| `主要支出渠道` | 该等级/规模的典型支出方向 |

## 三、数据文件格式

拆分后每个类别文件以对应区块为标题，字段即 §一、§二 各表字段全集。类别文件与区块标题对应如下：

| 类别文件 | 区块标题 |

| `04_资源_法宝.md` | `### 资源 · 法宝` + 【法宝分级】 |
| `04_资源_功法.md` | `### 资源 · 功法` + 【功法分级】 |
| `04_资源_材料.md` | `### 资源 · 材料` + 【材料分级】 |
| `04_资源_妖兽.md` | `### 资源 · 妖兽` + 【妖兽材料】 |
| `04_资源_符箓.md` | `### 资源 · 符箓` + 【符箓分级】 |

```markdown
【货币/能量单位】名称：/ 分级：(等级|名称|灵气纯度|兑换比例|外观|用途|获取途径)

【符箓分级】(等级|对应境界|触发条件|威力上限|制作要求|保存期限)
【秘境分级】(危险等级|建议境界|收益等级|开启条件|存活率|特殊规则)
【经济体系】高阶流通方式：/ 大宗门垄断项：/ 黑市定价规则：/ 资源再生速度：
【财富分级基准表】(对象类型|等级/规模|典型资源持有量|主要收入渠道|主要支出渠道)
```

## 四、物品卡（具体物品条目）

每个类别文件除【分级表】外，还包含【物品卡】区块，登记该类别下所有具体物品条目。**新资源首次出场时必须登记**；已有资源的数量变化在 `08_战斗结算` 或 `09_主角突破卡` 中记录，无需重复登记。物品是修仙世界的"经济血液"，必须分级明确、来源清晰、流通合理。

### 4.1 物品卡字段定义

`(必)`=必填，其余选填；示例值为格式参考，勿照抄。

```markdown
【物品卡】名称：/ ID：`RES-类别-序号`（类别枚举见 `00_使用说明` ID 规范）/ 类别：/
【基础信息】
| 资源名称 | (必) | 标准名称，全小说统一使用 |
| 资源ID | (必) | 格式：`RES-类别-序号`，如 `RES-DAN-003` |
| 资源类别 | (必) | 丹药/法宝/材料/货币/功法/符箓/妖兽/其他 |
| 等级 | (必) | 对照本文件【分级表】，如 `黄阶中品`/`二阶` |
【属性定义】
| 功能描述 | (必) | 具体作用，忌模糊（如："提升修为"→"服用后数日内修炼效率提升约三成"） |
| 使用条件 | (必) | 什么境界能用？有什么前置条件？（如：[境界]以下有效/需配合[某系]功法/每月限服一粒） |
| 使用限制 | | 次数限制？副作用？成瘾性？（如：连续服用超过三粒产生抗药性） |
| 耐久/数量 | | 法宝类填耐久度，消耗品类填单次获取的典型数量 |
【经济属性】
| 获取方式 | (必) | 怎么获得？（采集/炼制/购买/任务奖励/杀人夺宝/遗迹探索），至少写两种 |
| 常见产地 | | 引用 `@区域.名称` / `@地名.名称` |
| 参考价格 | (必) | 以低阶灵石为单位给出价格区间。必须与本文件【分级表】兑换比例一致 |
| 稀缺程度 | (必) | 常见/普通/稀缺/罕见/传说。影响获取难度和消息传播范围 |
【叙事功能】
| 剧情关联 | | 与哪些剧情线相关？（某势力的垄断资源/某个任务的目标物品） |
| 隐藏信息 | | 是否有不为人知的特性？（看似普通的草药，实为上古丹方主材） |
| 首次出场章节 | (必) | 第几章首次出现 |
```

### 4.2 物品卡与分级表联动

- `等级` 和 `参考价格` 必须严格对照本类别文件的【分级表】：
  - 若无该资源类别，先在本体系中补充定义
  - 若等级与价格不匹配，以分级表为准调整本卡
  - 跨体系资源在等级后标注体系来源，如 `[体系]·[等级]（相当于[基准境界]）`
- 资源类红线（禁无来源、禁无限制神物、禁随意定价、禁低境高持等）定义与自检统一见 `00_通用写作规则` 第八章【事件设计层】资源区。

## 五、原创资源登记流程（超出9类标准类别时使用）

当设计中出现无法归入货币/丹药/法宝/功法/材料/妖兽/符箓/秘境/经济任一标准类别的资源
（如"记录大道因果的残缺书页"这类叙事驱动型特殊物件）时，按以下顺序判定：

1. **优先尝试归入现有类别并标注特殊性**：若该资源的核心机制与某一标准类别接近（如
   "本质是一件法宝，只是功能特殊"），归入该类别文件，在【等级】字段后追加"（特殊）"
   标注，不新增类别。
2. **确实无法归类时，登记为原创类型**：在 `02_数据库/04_资源/04_资源_原创.md` 中登记，
   每个原创类型自建一张简化分级表（至少包含：对应境界/稀缺度/获取途径/越级代价 四项，
   与 §一 标准类别分级表字段对齐），并说明"判定理由"（为何不属于9个标准类别）。
3. **物品卡字段与 §四 4.1 一致**，资源类别字段填写自定义原创类型名称。
4. 登记后须同步在总索引 `04_资源.md`【分类索引】表追加一行（类别写"原创·<类型名>"｜
   一句话概况｜指向 `04_资源_原创.md` 内对应锚点的链接）。
5. 原创类型不得用于规避 §一【设计原则】的四条红线（禁无来源、禁无限制神物、禁随意定价、
   禁低境高持），红线检查同样适用于原创类型。
