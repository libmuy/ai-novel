# 文风模板 · 天骄崛起流

> 类型：写作规则 · 风格专属层。叠加于 `00_通用写作规则` 之上生效：技艺层（结构/节奏/情感表达/自检框架）以 `00_通用写作规则` 为唯一权威，本模板只定义**风格层差异**。本书是否选用见 `01_规划/00_小说概念.md`【基础定位】『文风』字段；模板清单见 `00_文风索引`。

## 【适用定位】

- **基调方向**：明快热血、天才傲骨、高密度爽感
- **题材适配**：修仙-天才成长（天骄流/打脸流）
- **叙事参考**：《斗破苍穹》式"莫欺少年穷"逆袭打脸
- **一句话特征**：天赋兑现、越级打脸、快节奏爽感，冲突密度高

## 【主角人设红线】

| 要素 | 要求 | 禁止 |
|------|------|------|
| 出身 | 天骄出身或天赋异禀（可为受挫/被轻视的天才） | 禁止开局即巅峰、禁止天赋白给 |
| 心性 | 果决、自信、恩怨分明 | 禁止无脑莽撞、禁止恃才傲物欺压无辜 |
| 行事 | 有底线的傲，先礼后兵 | 禁止无缘无故打脸、禁止仗势欺人 |
| 主修 | 主修体系（各书自定） | 禁止越阶秒杀（越阶须 ≥2 个外部条件支撑，见 `00_通用写作规则` §7） |
| 升级 | 突破须满足三重门槛（见 `00_通用写作规则` §7） | 禁止顿悟升级、禁止闭关速成 |
| 打脸 | 打脸须有前置铺垫（天赋/布局/信息差） | 禁止对手降智、禁止无理由挑衅 |

## 【情绪引擎】

- **反差打脸**：他人轻视主角 → 主角用实力兑现 → 旁观者醒悟。情绪爽点来自"你早该知道"。
- **天赋兑现**：长期隐忍的天赋/努力在关键场合一次释放，让积累可见。
- **守护感**：为宗门/家族/在意之人而战，让每一次越级有情感理由。

## 【爽感循环】

核心循环：**挑衅/轻视 → 受激或忍耐 → 布局/展示 → 打脸/碾压 → 新挑战（更强对手/更高层次目光）**。节奏分配：冲突期3-5章（对手施压、主角蓄力）→ 兑现期1章（实力展示、围观者反应）→ 余波期1章（地位/资源/新敌埋下）。打脸必须提前证明主角的底气来源。

## 【比例微调】

事件:感悟 = **8:2**（打斗/冲突 8 分，感悟 2 分；感悟须更凝练，不拖节奏）。

## 【自检补充项】

在 `00_通用写作规则` 第八章基础上追加：

- [ ] 打脸是否提前铺垫主角底气（天赋/布局/信息差）？
- [ ] 被打脸一方是否按"利益最大化"行动而非降智？
- [ ] 越阶是否满足 `00_通用写作规则` §7 越阶条件（≥2 个外部条件支撑）？
- [ ] 天骄傲骨是否踩线？（无脑莽、欺压无辜、无缘无故打脸）
