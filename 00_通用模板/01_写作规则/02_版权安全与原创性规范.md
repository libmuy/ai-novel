# 版权安全与原创性规范

> 类型：写作规则 · 行为约束/规范，生成与续写时遵循。兼作 `02_数据库/06_书籍/06_书籍.md`（总索引）及下属书籍文件的字段定义源（见 `99_速查手册` S1）。

## 使用范围

定义全书的版权红线、禁词清单、古籍使用规则与原创改写标准。每章生成后必须自动检索并替换违禁内容。

## 一、禁词清单

> 禁词按性质分三类，处理力度不同：
> - **① 法律版权红线**：现代知名作品原词——**硬性禁止**，不可通融。
> - **② 监管红线**：现实宗教原教义表述——**硬性禁止**，不可通融。
> - **③ 原创辨识度规则**：真实古籍原句、历史典故——公有领域文本**本身无版权问题**，禁止是**设计决策**（守住"本小说虚构古籍"的世界观招牌），允许两条中道：**仿古体化用**与**卷首题记例外**。

### 1.1 真实古籍名句（原创辨识度规则，非版权问题）

真实古籍（《道德经》《论语》《易经》《庄子》等）早入公有领域，引用原句**不构成侵权**。本条禁止的是**正文中原句照搬**——与虚构古籍体系同框会"破功"。两条中道：

- **【仿古体化用】**：借用真实古籍的**句式、节奏、意象**铸造新句，句子必须新创，并挂载进虚构古籍之一。技法见 3.1。
- **【卷首题记例外】**：卷首题记/章末铭文可引公有领域古籍原句并**注明出处**（如"卷首题记：《道德经》"）；正文中主角口中的金句仍必须出自虚构典籍。

**正文禁引原句，包括但不限于**："天行健，君子以自强不息"、"道可道，非常道"、"知行合一"（可作理念改写）、"己所不欲，勿施于人"、"大道至简"、"上善若水"，及任何真实古籍原句。

### 1.2 知名仙侠作品原词（法律版权红线·硬性）

**禁引，包括但不限于**："浩然气"、"武夫境"、"剑来"、"我有一剑"、"一剑光寒十九洲"、"天地不仁，以万物为刍狗"（《道德经》句，因高频出现在知名作品中，正文禁引；作卷首题记按 1.1 例外）、"三十年河东，三十年河西"、"莫欺少年穷"，及任何《凡人修仙传》《剑来》《大奉打更人》《一念永恒》《完美世界》《斗破苍穹》等头部作品的高频台词或设定名。

### 1.3 现实宗教原教义表述（监管红线·硬性）

儒家、兵家、佛家、道家等现实宗教思想的原教义表述，如"仁义礼智信"原句、"因果轮回"原句、"空性"原句等。**例外**：可作为"理念"被改写，但禁止直接使用宗教术语作为体系名称或台词。

### 1.4 现实历史典故直接引用（原创辨识度规则）

历史典故公有领域、无版权问题，本条同属**设计决策**：避免读者烂熟的俗套桥段。禁引"荆轲刺秦"、"卧薪尝胆"、"破釜沉舟"、"完璧归赵"等任何现实历史事件。

## 二、虚构古籍使用规则

### 2.1 专属书籍库（全书固定）

> **权威声明**：正文古籍引用只使用该小说**自定的虚构典籍清单**，清单的唯一权威存放于该小说 `02_数据库/06_书籍/06_书籍.md`（总索引）+ `06_书籍_<书名>.md`（每书一文件）书籍库；各书"职能分工"见该小说 `01_设定/05_核心道义.md`；引用红线见 2.2。清单增删只改对应小说的数据文件，本模板不存放具体书名。

**正文书库只使用虚构典籍**（卷首题记/章末铭文可引公有领域古籍原句，见 1.1）。

### 2.2 古籍引用规则

- 每句引用**30字以内**；引用后**立刻回剧情**，不做翻译或解释
- 只在**关键节点**使用，不是每章必用；使用前先铺垫"主角读过这本书"或"偶然想起某句话"
- 每本书的短句数量受 2.4 管理规则约束（种子库 + 生长区），写作时按场景选句
- **例外**：卷首题记/章末铭文不受限（见 1.1）

### 2.3 书籍库文件结构（总索引 + 每书一文件）

本分类为多实体数据，采用「总索引 + 子文件」多文件结构，**每本书一个文件（恒拆分，不设 1KB 阈值）**。全部文件置于分类文件夹 `02_数据库/06_书籍/` 内。

| 文件 | 内容 |
|------|------|
| `02_数据库/06_书籍/06_书籍.md` | 总索引：【书籍索引】表格（书名｜一句话概况｜书籍文件链接） |
| `02_数据库/06_书籍/06_书籍_<书名>.md` | 书籍文件：单个书籍卡全文（含【基础档案】+【种子库】+【生长区】） |

**文件命名规则**：文件名 = 前缀 `06_书籍` + `_<书名>`，书名与书籍卡名称、`@古籍.[书名]` 引用完全一致。

**父子关系规则**：总索引放「书籍索引 + 文件链接」，子文件放「书籍卡全文」；增量追加新书或新句时，须同步在总索引【书籍索引】表追加该书行（书名｜一句话概况｜书籍文件链接），不得只新增书籍文件而遗漏父索引更新。

**按需取分支示例**：某章需引某书短句，只加载 `02_数据库/06_书籍/06_书籍.md`（总索引）+ `02_数据库/06_书籍/06_书籍_<书名>.md`，禁止整目录全量灌入。

**书籍卡字段**（`(必)`=必填，其余选填）：

【基础档案】
| 字段 | 必填 | 说明与示例 |
|------|------|-----------|
| 书名 | (必) | 唯一标识名，与文件名 `_<书名>`、`@古籍.[书名]` 一致 |
| 书籍职能 | (必) | 主攻一类场景职能（人心诡谲/修仙界潜规则/力量代价/强者傲慢/底层烟火/出身地智慧等），与本书 `01_设定/05_核心道义.md` 职能分工对应 |
| 内容概述 | | 一句话概括书的内容与语感风格 |

【种子库】(必) —— 表格：短句 | 适用场景（每书 ≥5 句；启动阶段一次性定稿，进入生长区前不得随意改写）

【生长区】(选) —— 表格：短句 | 适用场景 | 首次使用章节（种子库未覆盖的新情境时追加；与种子句保持同一"风格与职能"）

### 2.4 书籍库管理规则（种子库 + 生长区）

**目标**：既保证启动有"保底弹药"，又允许写作中持续补充，避免"临时现编、风格漂移"。

- **种子库**：小说启动前预设，每本书**至少 5 句**，覆盖常见场景（抉择/失去/坚守/黑暗/底层高光）；由作者或 AI 启动阶段一次性定稿，进入生长区前不得随意改写。
- **生长区**：遇到种子库未覆盖的新情境时追加，每句标注**适用场景**与**首次使用章节**；与种子句保持同一"风格与职能"（见该小说 `01_设定/05_核心道义.md` 的古籍职能分工），禁止一本书跨主题乱用。
- **数量上限**：每本**种子库+生长区合计 ≤12 句**；达到上限后需要新句时优先"改写复用"旧句，避免书籍库无限膨胀。每句 30 字以内、引后不解释（同 2.2）。

> **联动**：所有书籍短句实际存放于该小说 `02_数据库/06_书籍/06_书籍_<书名>.md`（种子库 + 生长区表格），总索引见 `02_数据库/06_书籍/06_书籍.md`；本模板只定义规则与格式。

## 三、原创改写规则

### 3.1 哲理改写标准

想表达常见哲理时（如"修心重于修力"），**禁止直接写原句**。

**改写方法**：① 用主角的**底层视角**重新表达（如："境界是壳，心性是根，壳破根存，尚可再长；根烂壳在，终成空壳"）；② 用**具体比喻**替代抽象概念（如"灯下有鬼"替代"人心险恶"）；③ 用**反讽或悖论**增加深度（如"人守一善，天予一难"替代"善有善报"）。

**古籍智慧采撷与转化**（真实古籍在正文只有两条出口通道——① 采撷改写 本节，② 仿古体化用 见下；原句照搬仅限卷首题记/章末铭文且注明出处）：

- **【采撷许可】**：可参考真实古籍（《道德经》《孙子兵法》《论语》等）的高阶智慧作"思想养分"。正文主角金句一律出自虚构古籍。
- **【去皮留核】**（三步转化法，缺一不可）：① **翻译**：文言文译为主角能听懂的"底层白话"；② **拟态**：抽象哲理转化为主角生活中的具体意象（如用"干农活"比喻"修行"）；③ **挂载**：转化后的金句归入虚构古籍之一，禁止以真实古籍名义出口。
- **【仿古体化用】**：借真实古籍的句式、节奏、意象仿铸新句——拿到文言的精炼上口，但句子必须新创、挂载进虚构古籍。适用：正文想要"古典语感"时。
  - 例一（仿"道可道，非常道"句式）→ "灯可明则室明，心可安则家安"
  - 例二（仿"天行健，君子以自强不息"对仗）→ "路虽远，行者至；地虽瘠，耕者丰"
- **【示例】**：原典"兵者，诡道也。"→ 改写："杀猪和杀人一样，不能让它看清你手里的刀，得先拿把糠逗它。"

### 3.2 体系名称原创标准

修行体系/境界/势力/地理名称必须自创，禁止与现实宗教或知名作品撞名。

### 3.3 角色名称原创标准

主角及重要配角姓名必须自创，禁止与知名作品主角撞名；外号/代号必须体现角色特征，禁止借用知名作品外号。

### 3.4 禁词改写示例对照表（AI 检索与替换参考）

| 禁词/禁句 | 允许的安全改写方式 |
|----------|------------------|
| 天行健，君子以自强不息 | 改写为："天不自健，人自健；天不自强，人自强。" |
| 道可道，非常道 | 改写为："说得清的道，不是真道；能命名的大道，早已偏离。" |
| 知行合一 | 改写为："知而不行，只是半知；行而不知，只是莽行。" |
| 上善若水 | 改写为："最大的善，像枯井里那点水——不争，却救了人命。" |
| 天地不仁，以万物为刍狗 | 改写为："天不偏人，地不怜命——凡人在这里，和杂草一样。" |
| 大道至简 | 改写为："真道理不复杂，复杂的是人心。" |
| 己所不欲，勿施于人 | 改写为："自己不想走的路，别推别人去踩。" |
| 三十年河东，三十年河西 | 改写为："河会改道，人会换命——但改道的水，还是那滩水。" |
| 莫欺少年穷 | 改写为："别因人穷就踩一脚——穷巷里的骨头，比朱门的肉硬。" |
| 我有一剑 | 改写为："我手里这柄短剑，崩了尖，钝了刃，但还能杀人。" |
| 剑来 | 改写为："剑在鞘里，鞘在腰上——拔不拔，看值不值。" |
| 浩然气 | 改写为："胸中那口气，不是天地给的，是自己一口一口攒的。" |
| 武夫境 | 改写为："武道修士不称境界，称背了几条魂。" |
| 香火神道 | 改写为："众生念力凝成神，神散了，念还在——只是没人记得了。" |

> **规则**：改写句必须——① 融入具体意象（天/水/井/路/山等），② 30字以内，③ 自然嵌入主角内心总结，而非强行加塞。

## 四、高风险句式的边界判断

以下句式**本身不是禁词**，但特定语境下可能触雷。Agent 必须按上下文判断：

| 句式类型 | 安全写法（可用） | 危险写法（禁用） | 判断标准 |
|---------|----------------|----------------|---------|
| 家国类 | "村子没了，人还在，就还有根" | "为天地立心，为生民立命" | 是否引用真实古籍原句或名人名言 |
| 修道类 | "境界是壳，心性是根" | "道可道，非常道" | 是否直接引用《道德经》等真实典籍 |
| 人性类 | "修士也是人，是人就有怕的" | "己所不欲，勿施于人" | 是否直接引用《论语》等真实典籍 |
| 善恶类 | "人守一善，天予一难" | "善有善报，恶有恶报" | 是否使用常见宗教/道德教条原句 |
| 力量类 | "背了几条魂，才走到这一步" | "三十年河东，三十年河西" | 是否引用知名作品/俗语原句 |
| 感悟类 | "灯下有鬼，人心里有更鬼的" | "天地不仁，以万物为刍狗" | 是否直接引用真实古籍或知名作品 |

**边界判断三原则**：
1. **来源原则**：句子能否在知名作品、现实宗教经典中找到**一字不差**的原句？→ 是则禁用。真实古籍原句仅**正文**禁用（卷首题记/章末铭文例外）；按 3.1「仿古体化用」新创句子不受限。
2. **长度原则**：超过15字的"常见表达"，若与知名作品/宗教经典原句**高度相似**（替换≤3个字）→ 视为禁用。
3. **语境原则**：同一句话，主角用底层口吻说出（融入具体意象、带个人经历色彩）→ 安全；作为"格言/警句"直接引用 → 危险。

## 五、AI生成后的自动检索流程

每章生成后必须执行：

1. **禁词检索**：扫描全文匹配禁词清单（第一章）。出现即替换或删除。
2. **古籍检索**：确认**正文**所有古籍引用来自虚构典籍；出现真实古籍原句立即替换（卷首题记/章末铭文按 1.1 例外，保留并注明出处）。
3. **金句检索**：扫描是否有"常见网文金句"或"现实名人名言"的影子，有则用主角自己的语言改写。
4. **人设检索**：确认主角行为符合本书所选文风模板的「主角人设红线」。出现无脑爽行为即重写（定义见 `00_通用写作规则` §7）。
5. **比例检索**：按 `00_通用写作规则` §一 的比例基准核对（以所选文风模板微调；逐章自检见其第八章【结构层】）。
6. **边界判断**：对疑似"安全"的哲理表达，用"边界判断三原则"二次校验。
