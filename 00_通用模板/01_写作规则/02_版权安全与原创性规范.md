# 版权安全与原创性规范

> 类型：写作规则 · 行为约束/规范，生成与续写时遵循。本规则兼作 `02_设定/02_版权安全` 的字段定义源（配套产生数据文件，见 `00_使用说明` S1 例外说明）。

## 使用范围
定义全书的版权红线、禁词清单、古籍使用规则与原创改写标准。AI生成每一章后，必须自动检索并替换违禁内容。

---

## 一、禁词清单

> 禁词按**性质分三类**，性质不同、处理力度不同：
> - **① 法律版权红线（1.2）**：现代知名作品原词——**硬性禁止**，不可通融。
> - **② 监管红线（1.3）**：现实宗教原教义表述——**硬性禁止**，不可通融。
> - **③ 原创辨识度规则（1.1、1.4）**：真实古籍原句、历史典故——公有领域文本**本身没有版权问题**，禁止它们是**设计决策**（守住"六本虚构古籍"的世界观招牌与原创辨识度），因此允许两条中道：**仿古体化用**与**卷首题记例外**（见 1.1）。

### 1.1 正文禁引真实古籍名句（原创辨识度规则，非版权问题）

> 真实古籍（《道德经》《论语》《易经》《庄子》等）早已进入公有领域，引用原句**不构成侵权**。本条禁止的是**正文中原句照搬**——它与虚构古籍体系同框会"破功"、架空感破裂。请用以下两条中道：

**【仿古体化用】（推荐，兼顾古籍语感）**：允许借用真实古籍的**句式、节奏、意象**铸造新句，句子必须新创，并挂载进六本虚构古籍之一。技法与示例见 3.1「仿古体化用」。

**【卷首题记例外】**：**卷首题记 / 章末铭文**允许直接引用公有领域古籍原句，并**注明出处**（如"卷首题记：《道德经》"）。题记是体裁惯例、自带出处，不破坏世界观。正文中主角口中的金句**仍必须**出自六本虚构古籍。

正文中仍禁止原句照搬，包括但不限于：
- "天行健，君子以自强不息"
- "道可道，非常道"
- "知行合一"（原句，但可作为理念改写）
- "己所不欲，勿施于人"
- "大道至简"
- "上善若水"
- 任何《道德经》《论语》《易经》《庄子》等真实古籍的原句

### 1.2 严禁出现的知名仙侠作品原词（法律版权红线·硬性）

包括但不限于：
- "浩然气"
- "武夫境"
- "剑来"
- "我有一剑"
- "一剑光寒十九洲"
- "天地不仁，以万物为刍狗"（《道德经》句，因高频出现在知名作品中，正文禁引；作卷首题记按 1.1 例外）
- "三十年河东，三十年河西"
- "莫欺少年穷"
- 任何《凡人修仙传》《剑来》《大奉打更人》《一念永恒》《完美世界》《斗破苍穹》等头部作品的高频台词或设定名

### 1.3 严禁出现的现实宗教原教义表述（监管红线·硬性）

- 儒家、兵家、佛家、道家等现实宗教思想的原教义表述
- 如："仁义礼智信"原句、"因果轮回"原句、"空性"原句等
- **例外**：可以作为"理念"被改写，但禁止直接使用宗教术语作为体系名称或台词

### 1.4 严禁出现的现实历史典故直接引用（原创辨识度规则）

> 历史典故公有领域、无版权问题，本条同属**设计决策**：避免读者烂熟的俗套桥段。

- "荆轲刺秦"
- "卧薪尝胆"
- "破釜沉舟"
- "完璧归赵"
- 任何现实历史事件的直接引用

## 二、虚构古籍使用规则

### 2.1 专属古籍库（全书固定）

> **权威声明**：此处为六本虚构典籍的**唯一权威清单**；各书的"职能分工"见 `03_核心道义体系` §3.3，引用红线见 2.2。清单如需增删，只改本处。

**正文书库只使用以下六本虚构典籍**（卷首题记/章末铭文可引公有领域古籍原句，见 1.1）：

1. 《尘心杂记》
2. 《俗世儒章》
3. 《清虚残篇》
4. 《云山道录》
5. 《人间风物志》
6. 《乡野古训》

### 2.2 古籍引用规则

- 每句引用控制在**30字以内**
- 引用后**立刻回到剧情**，不做翻译或解释
- 只在**关键节点**使用，不是每章必用
- 使用前先铺垫"主角读过这本书"或"偶然想起某句话"
- 每本古籍的短句数量受 2.4 节管理规则约束（种子库 + 生长区），写作时按场景选句
- **例外**：卷首题记 / 章末铭文不受本规则限制，可引公有领域古籍原句并注明出处（见 1.1）

### 2.3 古籍弹药库格式

```markdown
### 古籍弹药库 · [书名]

风格：
主题：

核心短句：
- "……"（适用：面对抉择时）
- "……"（适用：失去重要之物时）
- "……"（适用：坚守底线时）
- "……"（适用：发现黑暗时）
- "……"（适用：底层人物高光时）
```

> 实际落地格式见数据文件 `02_设定/02_版权安全.md`（种子库表格 + 生长区表格）。

### 2.4 古籍弹药库管理规则（种子库 + 生长区）

**目标**：既保证启动时有足够的"保底弹药"，又允许写作中持续补充，避免"临时现编、风格漂移"。

**种子库**：
- 小说启动前预设，每本古籍**至少 5 句**，覆盖最常见场景（抉择/失去/坚守/黑暗/底层高光）。
- 种子句由作者或 AI 在启动阶段一次性定稿，进入生长区前不得随意改写。

**生长区**：
- 写作过程中，遇到种子库未覆盖的新情境时追加，每句必须标注**适用场景**与**首次使用章节**。
- 追加句子与种子句保持同一"风格与职能"（见 03_核心道义体系 第三章的古籍职能分工），禁止一本古籍跨主题乱用。

**数量上限**：
- 每本古籍**种子库 + 生长区合计不超过 12 句**。达到上限后，若仍需要新句，优先"改写复用"旧句（同一古籍中语气最贴近者），避免弹药库无限膨胀。
- 每句 30 字以内，引用后不解释（与 2.2 一致）。

**联动**：所有古籍短句实际存放于数据文件 `02_设定/02_版权安全.md`，本模板只定义规则与格式，不存放具体句子。

## 三、原创改写规则

### 3.1 哲理改写标准

当你想表达一个常见哲理时（如"修心重于修力"），**禁止直接写这个句子**。

**改写方法**：
1. 用主角的**底层视角**重新表达（如："境界是壳，心性是根，壳破根存，尚可再长；根烂壳在，终成空壳"）
2. 用**具体比喻**替代抽象概念（如：用"灯下有鬼"替代"人心险恶"）
3. 用**反讽或悖论**增加深度（如："人守一善，天予一难"替代"善有善报"）

**古籍智慧采撷与转化规则**：

> 按 1.1：真实古籍在**正文**只有两条出口通道——**① 采撷改写**（本节）与 **② 仿古体化用**（见下）；**原句照搬**仅限卷首题记/章末铭文，且须注明出处（见 1.1 例外）。

- **【采撷许可】**：允许参考真实古籍（如《道德经》《孙子兵法》《论语》）中的高阶智慧作为"思想养分"。正文中主角金句一律出自六本虚构古籍，不得以真实古籍原句照搬——如需使用，走下方①或②通道。
- **【去皮留核】**：采撷后必须执行"三步转化法"，缺一不可：
  1. **翻译**：将文言文翻译为主角能听懂的"底层白话"。
  2. **拟态**：将抽象哲理转化为主角生活中的具体意象（如用"干农活"比喻"修行"）。
  3. **挂载**：将转化后的金句归入六本虚构古籍之一，禁止以真实古籍名义出口。
- **【仿古体化用】**：除"思想"外，也可借真实古籍的**句式、节奏、意象**仿铸新句——拿到文言的精炼上口，但句子必须新创、挂载进虚构古籍。适用：正文想要"古典语感"时（与 1.1 中道一致）。
  - 例一（仿"道可道，非常道"句式）：挂载至《清虚残篇》→ "灯可明则室明，心可安则家安"
  - 例二（仿"天行健，君子以自强不息"对仗）：挂载至《乡野古训》→ "路虽远，行者至；地虽瘠，耕者丰"
- **【示例】**：
  - *原典*："兵者，诡道也。"
  - *转化*：挂载至《乡野古训》，改写为："杀猪和杀人一样，不能让它看清你手里的刀，得先拿把糠逗它。"

### 3.2 体系名称原创标准

- 修行体系名称：必须自创，禁止与现实宗教或知名作品撞名
- 境界名称：必须自创，禁止与现实修炼术语或知名作品撞名
- 势力名称：必须自创，禁止与知名作品中的宗门/家族撞名
- 地理名称：必须自创，禁止与知名作品中的地名撞名

### 3.3 角色名称原创标准

- 主角及重要配角姓名：必须自创，禁止与知名作品主角撞名
- 外号/代号：必须体现角色特征，禁止直接借用知名作品外号

### 3.4 禁词改写示例对照表（供AI检索与替换参考）

| 禁词/禁句 | 允许的安全改写方式 |
|----------|------------------|
| 天行健，君子以自强不息 | 改写为："天不自健，人自健；天不自强，人自强。" |
| 道可道，非常道 | 改写为："说得清的道，不是真道；能命名的大道，早已偏离。" |
| 知行合一 | 改写为："知而不行，只是半知；行而不知，只是莽行。" |
| 上善若水 | 改写为："最大的善，像枯井里那点水——不争，却救了人命。" |
| 天地不仁，以万物为刍狗 | 改写为："天不偏人，地不怜命——凡人在这里，和杂草一样。" |
| 大道至简 | 改写为："真道理不复杂，复杂的是人心。" |
| 己所不欲，勿施于人 | 改写为："自己不想走的路，别推别人去踩。" |
| 三十年河东，三十年河西 | 改写为："河会改道，人会换命——但改道的水，还是那滩水。" |
| 莫欺少年穷 | 改写为："别因人穷就踩一脚——穷巷里的骨头，比朱门的肉硬。" |
| 我有一剑 | 改写为："我手里这柄短剑，崩了尖，钝了刃，但还能杀人。" |
| 剑来 | 改写为："剑在鞘里，鞘在腰上——拔不拔，看值不值。" |
| 浩然气 | 改写为："胸中那口气，不是天地给的，是自己一口一口攒的。" |
| 武夫境 | 改写为："武道修士不称境界，称背了几条魂。" |
| 香火神道 | 改写为："众生念力凝成神，神散了，念还在——只是没人记得了。" |

> **规则**：改写后的句子必须满足——① 融入具体意象（天/水/井/路/山等），② 30字以内，③ 自然嵌入主角的内心总结，而非强行加塞。

## 四、高风险句式的边界判断（新增）

以下句式**本身不是禁词**，但在特定语境下可能触雷。Agent 必须根据上下文判断是否安全：

| 句式类型 | 安全写法（可用） | 危险写法（禁用） | 判断标准 |
|---------|----------------|----------------|---------|
| **家国类表达** | "村子没了，人还在，就还有根" | "为天地立心，为生民立命" | 是否引用真实古籍原句或名人名言 |
| **修道类表达** | "境界是壳，心性是根" | "道可道，非常道" | 是否直接引用《道德经》等真实典籍 |
| **人性类表达** | "修士也是人，是人就有怕的" | "己所不欲，勿施于人" | 是否直接引用《论语》等真实典籍 |
| **善恶类表达** | "人守一善，天予一难" | "善有善报，恶有恶报" | 是否使用常见宗教/道德教条原句 |
| **力量类表达** | "背了几条魂，才走到这一步" | "三十年河东，三十年河西" | 是否引用知名作品/俗语原句 |
| **感悟类表达** | "灯下有鬼，人心里有更鬼的" | "天地不仁，以万物为刍狗" | 是否直接引用真实古籍或知名作品 |

**边界判断三原则**：
1. **来源原则**：句子是否能在知名作品、现实宗教经典中找到**一字不差**的原句？→ 是则禁用。真实古籍原句仅在**正文**禁用（卷首题记/章末铭文例外，见 1.1）；按 3.1「仿古体化用」新创的句子不受此限。
2. **长度原则**：超过15字的"常见表达"，若与知名作品/宗教经典原句**高度相似**（替换不超过3个字），→ 视为禁用。
3. **语境原则**：同一句话，主角用自己的底层口吻说出来（融入具体意象、带个人经历色彩）→ 安全；作为"格言"或"警句"直接引用 → 危险

## 六、AI生成后的自动检索流程

每章生成后，必须执行以下检索：

1. **禁词检索**：扫描全文，匹配禁词清单。若出现，立即替换或删除。
2. **古籍检索**：确认**正文**所有古籍引用均来自六本虚构典籍。若出现真实古籍原句，立即替换（卷首题记/章末铭文按 1.1 例外，保留并注明出处）。
3. **金句检索**：扫描是否有"常见网文金句"或"现实名人名言"的影子。若有，用主角自己的语言改写。
4. **人设检索**：确认主角行为符合"谨慎+守底线+懂取舍"（人设红线见 `00_文风与节奏规范` 九「主角人设红线」）。若出现无脑爽行为，重写（定义见其 §7）。
5. **比例检索**：按 `00_文风与节奏规范` §一 的 7:3 规则核对（逐章自检见其第八章【结构层】）。
6. **边界判断**：对疑似"安全"的哲理表达，用"边界判断三原则"二次校验。
