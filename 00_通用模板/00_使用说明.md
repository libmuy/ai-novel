## 使用原则

1. **通用模板只读**：`通用模板/` 目录下的文件仅定义字段、规则与说明，**不得写入任何具体小说数据**。
2. **数据文件独立**：每部小说在 `小说数据/<小说名>/` 下建立自己的数据文件，字段必须与通用模板保持一致。
3. **版本兼容**：若通用模板升级（增加字段），所有历史数据文件应通过追加字段方式兼容，不得删除旧字段。
4. **AI 协作指令**：向 AI 提供创作任务时，应同时提供 `通用模板` 中对应的定义文件 + `小说数据` 中已填写的数据文件，确保 AI 不 hallucinate 字段。

## 文件命名规范

- 通用模板：`NN_对象名称模板.md`（NN 为两位序号，保证文件排序）
- 数据文件：`NN_对象名称数据.md`（序号与对应模板一致，方便检索）
- **主角档案例外**：主角档案使用 `00_主角档案数据.md`，对应模板 `00_主角人设卡模板.md`

## 必填 vs 选填

模板中每个字段后标注：
- `(必填)`：必须填写，否则该卡片视为无效。
- `(选填)`：有则填，无则留空或写"无"。
- `(条件必填)`：满足特定条件时必须填写。

## 引用语法规范（跨模板关联基础设施）

所有模板中的"关联"字段，统一使用以下语法：

| 引用类型 | 语法格式 | 示例 |
|---------|---------|------|
| 关联角色 | `@配角.[姓名]` | `@配角.七指虻` |
| 关联主角 | `@主角` | `@主角`（固定写法，无需姓名） |
| 关联势力 | `@势力.[势力名称]` | `@势力.虻巢` |
| 关联伏笔 | `@伏笔.[伏笔ID]` | `@伏笔.V1-C03-001` |
| 关联资源 | `@资源.[资源名称]` | `@资源.引气玉` |
| 关联区域 | `@区域.[区域名称]` | `@区域.翳岭` |
| 关联道义 | `@道义.[道义ID]` | `@道义.DY-001` |
| 关联古籍 | `@古籍.[书名]` | `@古籍.尘心杂记` |

### 引用规则

1. **Agent 在填写数据时，必须使用此格式**，不得使用纯文本名称或模糊指代。
2. **若引用的对象不存在**，应在数据文件末尾的"待创建条目"列表中登记，格式：
   ```markdown
   ## 待创建条目
   - [ ] @配角.某某某（于第X章出场，需补充配角卡）
   - [ ] @资源.某某某（于第X章获取，需补充资源卡）
   ```
3. **引用校验**：每次加载多个数据文件时，Agent 应自动检查所有引用是否能在已加载文件中找到对应条目。若找不到，标记为"待补全"。
4. **大小写敏感**：引用标识符大小写敏感，必须与目标条目的实际名称完全一致。

## ID 编号规范（跨卡片唯一标识）

不同卡片的 ID 前缀不同（用于区分类型），结构统一为"前缀-卷号[-章节]-序号"。**Agent 填写时必须使用下表格式，不得自创变体**：

| 卡片类型 | 格式 | 示例 | 说明 |
|---------|------|------|------|
| 伏笔登记 | `V卷号-C章节号-序号` | `V1-C03-001` | 章节必填，精确到埋设章 |
| 主角突破 | `BP-卷号-序号` | `BP-V1-001` | 章节信息记在突破卡"突破章节"字段 |
| 战斗结算 | `BT-卷号-序号` | `BT-V1-003` | 章节信息记在战斗卡"发生章节"字段 |
| 资源道具 | `RES-类别-序号` | `RES-DAN-003` | 类别枚举：DAN丹药/FAB法宝/CLI材料/LS灵石/GF功法/FU符箓/LIN灵兽/GJ古籍/OTHER |
| 道义条目 | `DY-序号` | `DY-001` | 全书唯一 |
| 待创建条目 | `TODO-序号` | `TODO-001` | 仅在数据文件"待创建条目"列表中使用 |

**规则**：
1. 序号在同类卡片内连续递增，禁止跳号或复用。
2. 若同一章涉及多张同类型卡片，序号递增（如 `BT-V1-003`、`BT-V1-004`）。
3. 未定章节的事件卡（如突破、战斗）允许暂缺章节信息，但回收/引用时必须补充。
4. 引用卡片时一律使用其 ID（如 `@伏笔.V1-C03-001`），禁止用文字描述替代。

## 跨体系战斗标准流程

当一场战斗涉及两个不同修行体系时，Agent 必须按以下流程执行：

```
Step 1: 战前设计 → 填写 11_跨体系冲突卡（理念碰撞、战斗策略）
Step 2: 正文生成 → 按 15_文风节奏 + 07_战斗结算 规则写战斗过程
Step 3: 战后结算 → 填写 07_战斗结算（代价、战利品、消息传播）
```

**边界说明**：
- `11_跨体系冲突卡` = **战前设计卡**：解决"为什么打""双方理念差异""体系互克如何体现"
- `07_战斗结算` = **战后结算卡**：解决"打完代价是什么""谁死了""消息怎么传"
- 在 `07_战斗结算` 的"外部条件核查"中，应引用 `11_跨体系冲突卡` 中设计的"甲方体系优势/乙方反制手段"

## 单章生成后一站式自检清单

生成任意一章正文后，**必须逐项检查以下所有项目**，方可存档。本清单是唯一的章节校验入口，整合了所有模板的校验要求。

### 【结构层】（对应 14_核心道义 + 15_文风节奏 + 13_开篇三章）

- [ ] 本章是否完成了"事件→古籍→感悟"的闭环？（感悟必须依托于具体事件，禁止先感悟后事件）
- [ ] 本章是否至少落地了 **0.5 条**道义？（允许"埋设"而不"揭示"，但每3-5章必须有一次完整闭环）
- [ ] 本章事件:感悟比例是否在 **7:3 ±15%** 范围内？（感悟/说教段落不得超过30%，打斗/冲突不得超过70%）
- [ ] 本章结尾是否有钩子？（重钩或轻钩，禁止圆满收尾）
- [ ] 开篇300字是否满足"动作或异常入戏"？（禁止天气/环境/心情/背景/回忆入戏）
- [ ] 本章是否有"无脑爽"行为？（越阶秒杀/爆种/敌人降智/白给资源/无条件帮助）
- [ ] 同一性质内容（纯打斗/纯对话/纯感悟）是否连续超过 **1000字**？（开篇三章为800字）
- [ ] 本章新设定是否超过 **3个**？（每个新设定必须在同章或下一章产生叙事效果）
- [ ] 本章感悟段落是否超过 **300字**？（超过需拆分或精简）
- [ ] 对话段落是否控制在 **3-5句** 内并穿插动作/环境描写？

### 【数据层】（对应各数据模板）

- [ ] 本章所有**新出场角色**（有姓名的）是否已登记到配角卡数据？（使用 `@配角.姓名` 格式）
- [ ] 本章所有**新埋设伏笔**是否已登记到伏笔登记表？（使用标准ID格式：V卷号-C章节号-序号）
- [ ] 本章所有**新获取/消耗/损毁资源**是否已登记到资源道具卡？（使用 `@资源.名称` 格式）
- [ ] 本章若有**战斗**，是否填写了战斗结算清单？（07_战斗结算模板）
- [ ] 本章若有**跨体系战斗**，是否先填写了跨体系冲突卡？（11_跨体系冲突模板）
- [ ] 本章若有**突破**，是否填写了突破卡？（06_主角突破卡模板）
- [ ] 本章若有**两难抉择**，是否填写了抉择卡？（08_两难抉择卡模板）
- [ ] 本章若有**感悟闭环**，是否填写了感悟闭环卡？（09_感悟闭环卡模板）

### 【版权层】（对应 16_版权安全）

- [ ] 本章是否出现禁词清单中的任何内容？（真实古籍名句、知名作品原词、现实宗教原教义）
- [ ] 所有古籍引用是否来自六本虚构典籍？（《尘心杂记》《俗世儒章》《清虚残篇》《云山道录》《人间风物志》《乡野古训》）
- [ ] 古籍引用是否控制在 **30字以内**？引用后是否立刻回到剧情、不做解释？
- [ ] 是否有"常见网文金句"或"现实名人名言"的影子？（若有，用主角自己的语言改写）
- [ ] 所有角色名称、势力名称、地名是否与知名作品撞名？

### 【主角人设层】（对应 00_主角人设卡 + 16_版权安全）

- [ ] 主角在本章的行为是否符合"谨慎+守底线+懂取舍"？
- [ ] 主角若做了道义选择，是否承担了**具体且无法立刻化解**的代价？
- [ ] 主角若获得收益，是否伴随**至少一个隐患或代价**？
- [ ] 主角若与人结盟，对方帮助是否有**利益交换或情感铺垫**？（禁止无条件帮助）
- [ ] 主角若杀人夺宝，是否结算了**消息传播路径**和**后续追查**？
- [ ] 情感表达是否用了**动作/环境细节**替代直接写情绪？（禁止"他感到悲伤"）

### 【资源与经济层】（对应 12_资源分级）

- [ ] 本章出现的资源等级是否与主角当前境界匹配？（禁止低境界持有高阶资源无代价）
- [ ] 本章的经济交易是否符合已设定的兑换比例？（禁止随意更改灵石兑换率）
- [ ] 主角的财务状态是否与"主角经济曲线"一致？

**全部勾选通过，本章方可存档。**
