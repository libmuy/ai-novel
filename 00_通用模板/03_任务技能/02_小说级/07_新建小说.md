# 新建小说技能

## 触发条件

用户要求新建小说、创建小说、初始化新书项目时执行。

## 流程

### 1. 脚手架（脚本，纯文件操作，无 LLM）

```
python3 02_工具/00_系统级/new_novel.py <小说名>          # 先 --dry-run 看编号与计划
python3 02_工具/00_系统级/new_novel.py <小说名>
```

脚本会：算目录编号 `NN`（现有最大 +1，两位，从 `00` 起）→ 从
`00_通用模板/05_项目骨架模板/` 复制骨架到 `01_小说数据/<NN>_<小说名>/` →
建相对符号链接 `00_通用模板 -> ../../00_通用模板` → 用
`00_通用模板/00_小说级AGENTS模板.md` 生成本书 `AGENTS.md`（替换 `{{小说名}}`/`{{NN}}`）→
改 `00_进度.md` 标题 → 打印目录树与自检结果。

### 2. 核对脚手架

- 目录树含 6 个顶层目录：`01_设定 02_数据库 03_规划 05_工作区/02_状态/01_最新状态 05_工作区 10_正文`；
- 软链接 `00_通用模板` 能解析、只读；
- `AGENTS.md` 无残留 `{{占位符}}`；
- `05_工作区/02_状态/01_最新状态/00_说明.md`、`05_工作区/02_状态/00_基线状态/00_说明.md`、
  `05_工作区/02_状态/01_最新状态/00_同步状态.md`（`折叠至章: __none__`）就位；
- 无逐章 `03_本章初始状态.md`、无旧的 `05_云端回填/`。
（脚本自检若报错，按提示修复后重跑。）

### 3. 交接云端规划管线

云端规划提示词由 `00_通用模板/04_提示词/00_云端提示词生成器.md` 拼装，按依赖顺序执行、
产物存 `05_工作区/00_提示词/`，云端回填走 `02_云端回填.md` 技能：

```
00 概念+世界基本法则 → 01 修炼体系 → 04 资源 → 02 地理区域 → 03 势力组织
→ 05 主角与核心配角 → 06 道义 / 07 文风爽感 → 08 书籍库 → 09 全书卷大纲
→ 10 第一卷大纲+开篇三章 → 11 单章细纲
```

`01_设定/` 与 `02_数据库/` 全部定稿后、写第 1 章正文前，执行技能
`08_基线状态初始化.md` 生成冻结基线。

## 禁止

- 不手动 `cp -r` 骨架（用 `new_novel.py`，保证编号/软链/占位符一致）。
- 不在设定/数据库定稿前生成基线或写正文。
- 不编辑目标小说目录以外的文件（`00_通用模板/` 只读）。
