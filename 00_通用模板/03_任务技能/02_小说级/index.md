# 共用小说级技能索引

> 适用于单本小说的数据维护和写作流程。技能定义怎么执行，字段和约束仍以 `00_通用模板/00_使用说明.md`、规则和卡片模板为准。

| 技能 | 触发词 | 文件 |
|---|---|---|
| 项目状态审计 | 项目状态、进度审计、成熟度审计、当前阻断 | `01_项目状态审计.md` |
| 云端回填 | 云端回填、分割输出、回填设定、合并输出 | `02_云端回填.md` |
| 章节状态对账 | 状态对账、章后维护、同步台账、更新状态 | `03_章节状态对账.md` |
| 单章质量验收 | 单章验收、章节检查、正文质检、质量检查 | `04_单章质量验收.md` |
| 伏笔回收校验 | 伏笔校验、伏笔回收、检查伏笔 | `05_伏笔回收校验.md` |
| 章节回溯修改 | 回溯修改、改早期章节、重算状态、重折全局状态 | `06_章节回溯修改.md` |
| 新建小说 | 新建小说、创建小说、初始化项目、新书 | `07_新建小说.md` |
| 基线状态初始化 | 基线状态、初始化状态、创世状态、生成基线 | `08_基线状态初始化.md` |

## 任务到技能绑定

| 任务类型 | 主技能 | 回退策略 |
|---|---|---|
| 状态对账维护（章后） | `03_章节状态对账.md` | 无 |
| 回溯修改早期章节 / 重折全局状态 | `06_章节回溯修改.md` | 无 |
| 新建小说 | `07_新建小说.md` | 无 |
| 基线状态初始化（写第 1 章前） | `08_基线状态初始化.md` | 无 |
| 云端回填分割（合并输出回填） | `02_云端回填.md` | 无 |
| 伏笔回收校验 | `05_伏笔回收校验.md` | 无 |
| 写单章正文 | `04_单章质量验收.md`（章后验收） | 生成阶段按路由表直连 |
| 其余任务（卷大纲、战斗、突破、配角、势力、爽感、压抑、古籍、版权、开篇三章） | 暂不绑定主技能 | 按 `00_使用说明.md` 路由表执行 |

## 使用约束

1. 先读取当前小说 `00_进度.md`，只引用「定稿」数据。
2. 再读取匹配技能和本书 `03_任务技能/index.md`、`本书技能配置.md`。
3. 先走主技能，未命中或未绑定任务再走路由回退。
4. 技能不得绕过文件边界、引用、ID、状态和验收规则。
