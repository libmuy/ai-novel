# 规则精简压缩技能

## 触发条件

用户要求精简规则、压缩模板、减少 Token、删除重复说明或压缩 Agent 指令时执行。

## 输入

- 最近一次系统规则审查结果
- `00_通用模板/00_使用说明.md`
- 相关写作规则、卡片模板和提示词生成器

## 流程

1. 确认唯一权威文件和当前规则边界。
2. 标记重复说明、背景解释、示例和不可删除的硬约束。
3. 只删除冗余；合并同义规则；将详细规则改为单一入口引用。
4. 必须保留：字段、格式、路由、引用、ID、前置阻断、禁止覆盖、状态迁移和验收。
5. 检查压缩后是否仍保留任务名称、路径、触发条件和失败处理。
6. 执行差异、空白、关键词和路径回归检查。
7. 输出修改摘要；未经用户要求不自动提交。

## 禁止

- 不删除机器可执行约束。
- 不改变小说设定、数据和成熟度状态。
- 不把多个权威来源重新复制成多份。
- 不以减少字数为理由合并互相冲突的规则。

## 输出

```text
修改文件
保留的硬约束
删除或合并的内容
压缩前后行数或字数
验证结果
遗留风险
```
