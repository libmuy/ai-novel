# 主角突破事件设计卡模板

## 使用范围
每次主角境界突破前填写。三者缺一，禁止写突破。

## 突破卡片字段

### 基础定位

| 字段 | 类型 | 说明 |
|------|------|------|
| `目标境界` | 文本 (必填) | 从X境到Y境 |
| `突破章节` | 文本 (必填) | |
| `突破地点` | 文本 (必填) | 忌安静密室，要有压力或异常 |
| `外部环境` | 文本 (必填) | 突破时正在发生什么？ |

### 三重门槛（缺一不可）

| 字段 | 类型 | 说明 |
|------|------|------|
| `资源条件` | 文本 (必填) | 具体列出，忌“获得机缘” |
| `心境条件` | 文本 (必填) | 对当前境界的什么道理认知到位？必须与前文某次事件挂钩 |
| `代价条件` | 文本 (必填) | 突破过程或突破后，必须失去/付出什么？ |

### 过程设计

| 字段 | 类型 | 说明 |
|------|------|------|
| `突破触发` | 文本 (必填) | 什么具体事件迫使/促使他突破？ |
| `破境时长` | 文本 (必填) | 忌过长，短篇节奏控制在半章以内 |
| `外部干扰` | 文本 (选填) | 是否有人护法？是否有敌人逼近？是否有环境危机？ |

### 古籍与感悟

| 字段 | 类型 | 说明 |
|------|------|------|
| `内心总结` | 文本 (必填) | 主角用大白话总结一句，忌文言 |
| `古籍点题` | 文本 (必填) | 从虚构典籍中选一句，30字以内，引用后不做解释 |
| `转化为行动` | 文本 (必填) | 这个感悟变成他后续什么具体行为准则？ |

### 战后状态

| 字段 | 类型 | 说明 |
|------|------|------|
| `境界稳固度` | 数值 (必填) | 100%为完美，低于80%需后续修补 |
| `遗留隐患` | 文本 (必填) | 受伤/灵气亲和下降/被盯上/某物损毁 |
| `下一步需求` | 文本 (必填) | 为了稳固境界，他接下来必须去做什么？ |
