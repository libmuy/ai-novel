> 本文档为 `05_工作区/` 目录下章级状态（`03_本章初始状态.md` 与 `04_本章状态履历.md`）唯一权威的字段定义规范。

## 一、 字段合并类型与语法规范

章级状态表格统一包含 4 列：`| 对象ID | 字段 | 类型 | 值 |`。

所有字段划分为以下两大类（4 个细分类型）：

### 1. 运算类字段 (Operation Fields)
运算类字段支持精确计算、原子替换或列表增删。在 `04_本章状态履历.md` 中，其"值"列必须遵守固定语法。

| 细分类型 | 说明 | 履历(Changelog)语法规范 | 合并(Merge)计算规则 |
|---|---|---|---|
| **运算-数值** | 可计算的数值 (如内力值、灵石数、耐久度) | `+N` (增加 N) 或 `-N` (减少 N) | 在初始状态值的基础上累加/累减。如初始 `100`，履历 `-30`，合并终态为 `70`。 |
| **运算-枚举** | 有限固定选项 (如境界、状态、终态标记) | `目标枚举值` | 直接替换为目标枚举值。对象终态可写作固定枚举（如 `活跃` / `死亡` / `退场` / `暂离`）。 |
| **运算-列表** | 集合或列表 (如持有物品、人情债) | `+X,-Y` (添加 X，移除 Y) | 对原列表做元素增删。如初始 `锈铁剑,破草鞋`，履历 `+培元丹,-破草鞋`，合并终态为 `锈铁剑,培元丹`。 |

### 2. 描述类字段 (Description Fields)
自由文本描述，不进行语义逻辑合并。

| 细分类型 | 说明 | 履历(Changelog)语法规范 | 合并(Merge)计算规则 |
|---|---|---|---|
| **描述** | 自由文本 (如外貌变化、当前心境、领地动向) | 自由 Markdown 文本 | **整体覆盖**。以本章履历中的最新描述直接替换初始状态中的旧描述。未出现的保持原样。 |

> **描述类字段合并漏洞与复核**：整体覆盖会丢弃旧描述里未被新描述涵盖的信息。
> `merge_chapter_state.py --review-descriptive` 会在描述字段发生实际变更时先打印「旧值 vs 新值」，
> 交互式下询问是否覆盖（选 `n` 则保留旧值，由人工合并两段文本后再更新履历）。
> `rebuild_from_chapter.py` 级联重放时默认开启该模式。
> 选 `n` 保留/人工合并后的最终文本，**必须回写进对应章 `04_本章状态履历.md` 的「值」列**，
> 否则 `audit_consistency.py` 的 `chain_drift` 检查会因「重放结果 ≠ 存盘 03」持续误报。

### 3. 履历元数据列（不参与合并计算）

`04_本章状态履历.md` 在标准 4 列 `| 对象ID | 字段 | 类型 | 值 |` 之后追加 3 个**元数据列**。
它们由 `parse_md_table` 读入但**不参与 `merge_states` 的任何类型合并计算**，仅用于人工检索、
章后审计与「改早期章节」后的级联冲突排查。其他 Agent **不得**把它们当作需要参与类型合并的字段。

- **章节号**：产生该条变更的章节编号，如 `0001`。用于定位变更来源、级联重放时的溯源。
- **变更时间**：该条变更被记录/定稿的日期，如 `2026-08-30`；未知写 `-`。
- **变更类型**：该「对象-字段」在本章的变更性质，枚举 `新建` / `修改` / `移除`。
  - `新建`：该对象-字段本章首次出现；
  - `修改`：在已有值基础上做数值运算、枚举替换、列表增删或描述覆盖；
  - `移除`：该对象-字段在本章后不再追踪（仅标记，合并计算仍按「值」列语法处理）。

`03_本章初始状态.md` 与 `04_全局状态/` 下的分类文件保持标准 4 列，**不带**这 3 个元数据列。

## 二、 官方注册字段表 (Official Registry)

### 1. 角色类对象 (`角色.[姓名]`)

| 字段名 | 细分类型 | 合法枚举值 / 示例说明 | 适用场景 |
|---|---|---|---|
| **境界** | 运算-枚举 | 凡人 / 炼气一层 / 炼气二层 / 筑基初期 ... | 修为阶段追踪 |
| **身体状况** | 描述 | 健康 / 左臂受创 / 内伤未愈 ... | 伤势与生理状态 |
| **内力值** | 运算-数值 | 数值 (如 `+50`, `-30`) | 消耗性数值/真气 |
| **所在地** | 描述 | 灰壤凡域·墨骨巷 / 云璃坊链 ... | 空间位置追踪 |
| **持有物品** | 运算-列表 | `+锈铁剑,-破草鞋` | 装备/随身道具列表 |
| **外貌变化** | 描述 | 眉角多了一道疤 / 穿麻衣黑袍 ... | 形象特征变动 |
| **当前心境** | 描述 | 警惕 / 焦躁 / 坚决 ... | 心理状态变动 |
| **关键关系** | 描述 | 与赵铁柱交恶 / 对陈掌柜怀疑 ... | 临时人际关系动向 |
| **隐患·未解代价** | 描述 | 灰毒入髓(三月内须解) ... | 伏笔与生存威胁 |
| **对象终态** | 运算-枚举 | `活跃` / `死亡` / `退场` / `暂离` | 生命/剧本状态 |
