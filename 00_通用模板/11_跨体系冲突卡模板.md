# 跨体系冲突设计卡模板

## 使用范围
设计每场跨体系战斗或谈判前填写。确保冲突不仅是“谁打谁”，更是“谁信什么”。

## 冲突卡片字段

### 冲突双方

| 字段 | 类型 | 说明 |
|------|------|------|
| `甲方` | 文本 (必填) | 体系/境界/角色 |
| `乙方` | 文本 (必填) | 体系/境界/角色 |
| `冲突场景` | 文本 (必填) | 具体地点与环境 |

### 双层冲突

| 字段 | 类型 | 说明 |
|------|------|------|
| `利益冲突` | 文本 (必填) | 争什么具体资源/位置/秘密？ |
| `理念冲突` | 文本 (必填) | 甲方认为……，乙方认为…… |

### 战前交锋

| 字段 | 类型 | 说明 |
|------|------|------|
| `甲方道理` | 文本 (必填) | 用甲方体系逻辑说话，忌骂人 |
| `乙方道理` | 文本 (必填) | 用乙方体系逻辑反驳 |
| `交锋结果` | 文本 (必填) | 谁也没说服谁，或某方暂时沉默 |

### 战斗策略

| 字段 | 类型 | 说明 |
|------|------|------|
| `甲方体系优势` | 文本 (必填) | 甲方用什么手段克制乙方？ |
| `乙方反制手段` | 文本 (必填) | 乙方如何利用环境/法宝/特点反制？ |
| `外部条件` | 文本 (必填) | 地形/天气/第三方干扰/双方状态 |

### 战后反思

| 字段 | 类型 | 说明 |
|------|------|------|
| `甲方反思` | 文本 (选填) | 对方的道理有没有可取之处？ |
| `乙方反思` | 文本 (选填) | |
| `认知变化` | 文本 (必填) | 主角对某体系的理解发生了什么改变？ |

### 古籍点题

| 字段 | 类型 | 说明 |
|------|------|------|
| `古籍点题` | 文本 (选填) | |
