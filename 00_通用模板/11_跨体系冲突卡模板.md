# 跨体系冲突设计卡模板

## 使用范围

设计每场**跨体系战斗或谈判前**填写。确保冲突不仅是"谁打谁"，更是"谁信什么"。

> **定位**：本模板是**战前设计卡**，解决"为什么打""双方理念差异""体系互克如何体现"。正文生成后的战后结算使用 `07_战斗结算模板`。
>
> **标准流程**：
> ```
> Step 1: 战前设计 → 填写本模板（理念碰撞、战斗策略）
> Step 2: 正文生成 → 按 15_文风节奏 + 07_战斗结算 规则写战斗过程
> Step 3: 战后结算 → 填写 07_战斗结算（代价、战利品、消息传播）
> ```
> 在 `07_战斗结算` 的"外部条件核查"中，应引用本模板中设计的"甲方体系优势/乙方反制手段"。

## 冲突卡片字段

### 冲突双方

| 字段 | 类型 | 说明 |
|------|------|------|
| `甲方` | 文本 (必填) | 体系/境界/角色 |
| `乙方` | 文本 (必填) | 体系/境界/角色 |
| `冲突场景` | 文本 (必填) | 具体地点与环境 |

### 双层冲突

| 字段 | 类型 | 说明 |
|------|------|------|
| `利益冲突` | 文本 (必填) | 争什么具体资源/位置/秘密？ |
| `理念冲突` | 文本 (必填) | 甲方认为……，乙方认为…… |

### 战前交锋

| 字段 | 类型 | 说明 |
|------|------|------|
| `甲方道理` | 文本 (必填) | 用甲方体系逻辑说话，忌骂人 |
| `乙方道理` | 文本 (必填) | 用乙方体系逻辑反驳 |
| `交锋结果` | 文本 (必填) | 谁也没说服谁，或某方暂时沉默 |

### 战斗策略

| 字段 | 类型 | 说明 |
|------|------|------|
| `甲方体系优势` | 文本 (必填) | 甲方用什么手段克制乙方？ |
| `乙方反制手段` | 文本 (必填) | 乙方如何利用环境/法宝/特点反制？ |
| `外部条件` | 文本 (必填) | 地形/天气/第三方干扰/双方状态 |

### 战后反思（战后填写）

| 字段 | 类型 | 说明 |
|------|------|------|
| `甲方反思` | 文本 (选填) | 对方的道理有没有可取之处？ |
| `乙方反思` | 文本 (选填) | |
| `认知变化` | 文本 (必填) | 主角对某体系的理解发生了什么改变？ |

### 古籍点题

| 字段 | 类型 | 选填 |
|------|------|------|
| `古籍点题` | 文本 (选填) | |

## 与07_战斗结算模板的联动

本模板与 `07_战斗结算模板` 的分工：

| 维度 | 本模板（跨体系冲突卡） | 07_战斗结算 |
|------|----------------------|------------|
| 填写时机 | **战前** | **战后** |
| 核心问题 | "为什么打""怎么打" | "打完代价是什么" |
| 关键字段 | 理念冲突、体系优势、反制手段 | 伤亡统计、资源消耗、消息传播 |
| 引用关系 | 被 `07_外部条件核查` 引用 | 引用本模板的"甲方体系优势/乙方反制手段" |

**跨体系战斗的标准执行顺序**：
1. 确定战斗涉及两个不同体系 → 触发本模板
2. 填写本模板全部字段（特别是"双层冲突"和"战斗策略"）
3. 生成正文（战斗过程）
4. 填写 `07_战斗结算`，在"外部条件核查"中引用本模板的策略设计
5. 填写 `09_感悟闭环卡`（如有感悟）
