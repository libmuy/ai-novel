# 卷大纲模板

## 使用范围
生成任意一卷大纲时，必须按此结构输出。禁止跳跃章节或省略字段。

## 输出字段

### 基础定位

| 字段 | 类型 | 说明 |
|------|------|------|
| `卷号` | 文本 (必填) | 如：第一卷 |
| `卷名` | 文本 (必填) | 如：泥腥集 |
| `主角起始境界` | 文本 (必填) | 本卷开始时主角的境界 |
| `主角结束境界` | 文本 (必填) | 本卷结束时主角的境界 |
| `本卷核心矛盾` | 文本 (必填) | 一句话概括本卷要解决的核心问题 |
| `本卷必须落地的道义ID` | 列表 (必填) | 从 `14_核心道义体系模板` 中选至少1条，本卷必须通过具体事件让其自然浮现 |

### 章节节拍表

| 字段 | 类型 | 说明 |
|------|------|------|
| `章节总数` | 数值 (必填) | 通常10-15章 |
| `章节列表` | 表格 (必填) | 每行包含：章节号、一句话剧情摘要、必用模板、核心事件类型、钩子类型 |

章节列表格式：

```markdown
| 章节 | 一句话剧情摘要 | 必用模板 | 核心事件类型 | 钩子类型 |
|------|---------------|---------|------------|---------|
| 第1章 | ... | 13_开篇三章指南 | 入戏/危机 | 重钩 |
| 第2章 | ... | 13_开篇三章指南 | 冲突/吃亏 | 轻钩 |
| ... | ... | ... | ... | ... |
```

核心事件类型枚举：
- 入戏/危机：开篇300字规则
- 冲突/战斗：涉及战斗结算
- 冲突/谈判：涉及跨体系冲突或势力博弈
- 抉择/道义：涉及两难抉择卡
- 突破/晋升：涉及主角突破卡
- 感悟/闭环：涉及感悟闭环卡
- 日常/铺垫：信息释放、关系建立、伏笔埋设
- 收束/回收：伏笔回收、情感释放、阶段性结算

钩子类型枚举：
- 重钩：未解决的危机、突发变故、隐秘伏笔显现、两难困境激化
- 轻钩：伏笔暗现、自我疑惑、未说破的一句话、反常细节
- 无钩：仅用于卷末重大情感释放后的"喘息章"，极其罕见

### 资源与伏笔规划

| 字段 | 类型 | 说明 |
|------|------|------|
| `本卷埋设伏笔列表` | 列表 (必填) | 每个伏笔包含：伏笔名称、类型（短/中/长）、埋设章节、预计回收章节/卷 |
| `本卷回收伏笔列表` | 列表 (必填) | 本卷计划回收的前文伏笔 |
| `本卷新增资源/道具` | 列表 (选填) | 本卷主角获得的重要物品，关联 `10_资源道具卡` |
| `本卷损毁/失去资源` | 列表 (选填) | 本卷主角失去的重要物品或能力 |

### 角色与关系

| 字段 | 类型 | 说明 |
|------|------|------|
| `本卷新出场配角` | 列表 (必填) | 每个配角关联 `04_配角卡` |
| `本卷退场配角` | 列表 (选填) | 死亡/离开/背叛/被遗忘 |
| `本卷关系变化` | 列表 (选填) | 主角与某势力/配角的关系变化 |

### 卷末状态

| 字段 | 类型 | 说明 |
|------|------|------|
| `本卷结束时主角状态` | 文本 (必填) | 资源/关系/隐患/道心/身体五维状态简述 |
| `卷末钩子` | 文本 (必填) | 引出下一卷的核心悬念 |
| `下一卷预告方向` | 文本 (必填) | 下一卷主角将去哪里、面对什么、解决什么问题 |

## 填写示例（格式参考）

```markdown
### 卷大纲 · 第一卷 · 泥腥集

【基础定位】
卷号：第一卷
卷名：泥腥集
主角起始境界：练气一层（玄道）
主角结束境界：练气七层（玄道），开卷境（文道，未正式立言）
本卷核心矛盾：主角如何在修仙界最底层的残酷法则中活下来，同时不丢掉做人的底线
本卷必须落地的道义ID：DY-001（修术易，修心难）、DY-003（仙未必善，凡未必愚）

【章节节拍表】
章节总数：12

| 章节 | 一句话剧情摘要 | 必用模板 | 核心事件类型 | 钩子类型 |
|------|---------------|---------|------------|---------|
| 第1章 | 主角在槐安镇整理祖辈遗物，发现残诀暗纹，母亲病重，决定前往泥腥集寻药 | 13_开篇三章指南 | 入戏/危机 | 重钩 |
| 第2章 | 主角初到泥腥集，目睹劫修杀人夺宝，第一次理解"修士不是仙人" | 13_开篇三章指南 | 冲突/吃亏 | 轻钩 |
| 第3章 | 主角为救母亲购得灵米，路遇孤悬观遗孤，赠米留三分之一，被多方注意 | 08_两难抉择卡, 09_感悟闭环卡 | 抉择/道义 | 重钩 |
| ... | ... | ... | ... | ... |
| 第12章 | 主角在矿洞强行突破练气后期，右手经脉滞涩，被残简阁注意到 | 06_主角突破卡, 09_感悟闭环卡 | 突破/晋升 | 重钩 |

【资源与伏笔规划】
本卷埋设伏笔列表：
- 残诀暗纹（短，第1章埋，第7章回收）
- 灵米的代价（短，第3章埋，第8章回收）
- 蜕壳宗弟子的血（中，第8章埋，第15章回收）
- 磷火粉追踪（短，第8章埋，第10章回收）

本卷回收伏笔列表：
- （第一卷无前文伏笔可收）

本卷新增资源/道具：
- 引气玉（半块，从蜕壳宗弟子尸体拾得）
- 浊灵丹（突破用，品质驳杂）

本卷损毁/失去资源：
- 家传短剑（剑尖崩裂）
- 三分之二灵米（赠予遗孤）

【角色与关系】
本卷新出场配角：
- 七指虻（关联配角卡）
- 泥骨妪（关联配角卡）
- 铁瘢真人（关联配角卡）
- 孤悬观观主（关联配角卡）

本卷退场配角：
- 孤悬观观主（预计第15章战死，但第12章时仍存活）

本卷关系变化：
- 主角与虻巢：中立→敌对
- 主角与残简阁：未知→被关注

【卷末状态】
本卷结束时主角状态：
- 资源：灵石耗尽，右手经脉滞涩，引气玉含怨气
- 关系：被虻巢盯上，被残简阁关注，欠孤悬观观主人情
- 隐患：引气玉怨气、右手经脉滞涩、突破波动被感知
- 道心：初步确立"谨慎+守底线"的行为准则
- 身体：后背灼伤未愈，右手掐诀迟缓

卷末钩子：残简阁掌柜主动接触主角，说"那日矿洞突破的，是你吧？"——主角发现自己一直在被观察

下一卷预告方向：主角进入嘈集城，第一次接触四大体系的碰撞，兼修文道的契机出现
```
