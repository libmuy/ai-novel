## 0. 一句话

关系目前散在「自由文本描述 / 单向指针 / 双向指针」三种互不兼容的形式，同一事实可双重记录且无校验。W5 把它收敛成两类：**非对称关系单边记录、反向派生**；**对称关系升为一等对象 `关系.甲&乙`、规范化无向 ID**。

**时机极好**：苍玄现在是最小基线（7 对象），全书状态数据里**没有任何一条** `关键关系`/`主要关系`/`持有物品` 记录，也没有卡片在「动态字段清单」里声明这三个字段。W5 这一波**零数据迁移**，纯基础设施 + 模板 + 词表改动。真正的关系数据要等正文推进后由履历「新建」引入。

## 1. 现状问题（为什么要改）

```
角色.苏砚   | 关键关系 | 描述      | 与赵铁柱交恶      ← 自由文本，无法查询/校验
势力.黑石会 | 主要关系 | 描述      | 与云璃商会敌对    ← 同上
物品.矿钉   | 持有者   | 运算-枚举 | @角色.[苏砚]      ← 单向指针（这个形式是对的）
角色.苏砚   | 持有物品 | 运算-列表 | 矿钉,古玉「老灰」  ← 与上一行同一事实的双重记录，可各自漂移
```

- 描述类关系字段：LLM 才能读，脚本无法查「苏砚现在跟谁敌对」，无法校验双方记录一致。
- `持有者` ↔ `持有物品`：两处独立可变，没有任何检查保证它们一致。

## 2. 设计方案

### A. 非对称关系 → 记在「从属方」，单边记录，反向派生

**判据**：这个事实变化时只有一方主动改变。

| 事实 | 权威记录处 | 反向查询 |
|---|---|---|
| 物品归属 | `物品.Y \| 持有者`（已有，保留） | 脚本扫 `物品.*.持有者` 反查「某角色持有哪些物品」→ 写进 `01_最新状态/01_角色/` 索引，**派生视图非权威** |
| 师承 | `角色.X \| 师承`（运算-枚举，值 `@角色.[师父]`）——**按需新增，苍玄暂无** | 派生「某人的徒弟列表」 |
| 势力隶属 | `势力.X \| 隶属`（运算-枚举，值 `@势力.[上级]`）——**按需新增** | 派生「某势力的下属」 |

**动作**：
- **废除 `角色.X | 持有物品` 字段**。一个事实只在一处记录。
- `师承` / `隶属` 这两个新枚举字段**不预先铺开**，等剧情真需要追踪时在对应卡片「动态字段清单」里声明、由履历「新建」引入（符合「不要编」）。

> ⚠️ 待定 D1：`财务.X | 人情债·债务`（运算-列表）现在是自由文本条目（`+欠陈掌柜50下品灵石`）。执行计划提议改成"指向债权人的结构化列表"。**建议本波不动**——它不是双重记录（债务只记在欠方），结构化收益小、改造成本高。列为 W5.1 可选后续。

### B. 对称关系 → 一等对象 `关系.甲&乙`

**判据**：没有从属方，记在任何一边都是任意的，且必然双边不一致（敌对/结盟/同门/血亲/竞争…）。

```
文件: 05_工作区/00_全局/01_最新状态/06_关系/06_关系_柳禾&苏砚.md

| 对象ID | 字段 | 类型 | 值 |
| --- | --- | --- | --- |
| 关系.柳禾&苏砚 | 关系性质   | 运算-枚举 | 血亲·母子 |
| 关系.柳禾&苏砚 | 亲疏       | 运算-枚举 | 至亲 |
| 关系.柳禾&苏砚 | 公开程度   | 运算-枚举 | 公开 |
| 关系.柳禾&苏砚 | 甲对乙态度 | 描述      | （柳禾对苏砚）唯一牵挂，怕拖累他 |
| 关系.柳禾&苏砚 | 乙对甲态度 | 描述      | （苏砚对柳禾）活下去的全部理由，情感锚点 |
| 关系.柳禾&苏砚 | 关系概述   | 描述      | 相依为命的矿城母子，母肺痨晚期 |
```

**ID 规范**：
- 分隔符**必须是 ASCII `&`**。不能用 `｜`(NFKC→`|` 会炸表格)、`~`(已是文件名碰撞后缀)、`+`/`-`/`,`(运算-列表语法)。`&` 是 ASCII、文件系统安全、Markdown 无义、不在 `_UNSAFE_NAME_CHARS`。
- 两端名字**按 Unicode 码位排序后**用 `&` 拼接。排序保证同一对关系物理上只有一个文件——**双边不一致从结构上不可能**。
- 「甲」=排序在前者，「乙」=排序在后者。`甲对乙态度` / `乙对甲态度` 两个固定字段承载不对称的那部分。（`柳禾`(U+67F3) < `苏`(U+82CF)，故 `关系.柳禾&苏砚`，甲=柳禾。）

**关系对象字段集（待用户敲定，见 Q1）**——建议：

| 字段 | 类型 | 值域 / 说明 | 必填 |
|---|---|---|---|
| 关系性质 | 运算-枚举 | 见下方值域清单 | ✅ |
| 亲疏 | 运算-枚举 | `死仇/交恶/疏远/中立/友善/亲密/至亲`（7 档粗粒度，不用数字——数字是编造） | ✅ |
| 公开程度 | 运算-枚举 | `公开/半公开/隐秘` | ✅ |
| 甲对乙态度 | 描述 | 不对称的主观视角 A→B | 选填 |
| 乙对甲态度 | 描述 | 不对称的主观视角 B→A | 选填 |
| 关系概述 | 描述 | 一句话来龙去脉 | ✅ |
| 对象终态 | 运算-枚举 | `活跃/终结`（一方死亡或关系彻底了断后标记，供级联检查） | 选填 |

**关系性质值域**（初版，可扩，写进字段词表；见 Q2）：
`血亲·父子` `血亲·母子` `血亲·兄弟` `血亲·其他` `师徒` `同门` `结盟` `友谊` `交易伙伴` `雇佣` `竞争` `敌对` `血仇` `债务纠葛` `利用` `暧昧` `恩义`

### C. 废除 `关键关系`（角色）/ `主要关系`（势力）描述字段

内容迁进关系对象。苍玄无存量数据，纯删词表 + 模板条目。
