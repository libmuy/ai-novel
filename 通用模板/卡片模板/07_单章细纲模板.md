# 单章细纲模板

> 类型：卡片模板 · 定义字段与填写示例，用于生成/维护对应数据文件。

## 使用范围

在生成单章正文前，必须先填写本细纲。本模板将一章拆分为若干**场景**，每个场景定义字数、功能、内容要点和钩子，确保AI写单章时节奏可控、不跑偏。

> **注意**：本模板是"写单章正文"任务的**必读模板**（见00_使用说明任务路由表）。没有细纲，禁止直接生成正文。

---

## 单章细纲字段

### 基础信息

| 字段 | 类型 | 说明 |
|------|------|------|
| `章节号` | 文本 (必填) | 如：第1章、第1卷第3章 |
| `本章类型` | 枚举 (必填) | 推进章/冲突章/转折章/情感章/信息章/压抑章/爽感章 |
| `预计总字数` | 数字 (必填) | 建议范围：2000-4000字 |
| `关联卷大纲节点` | 文本 (必填) | 对应06_卷大纲中的哪个章节节拍？ |

### 场景列表（核心）

每章由 **2-5个场景** 组成。每个场景填写以下字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `场景序号` | 数字 (必填) | 第1场景、第2场景…… |
| `场景地点` | 文本 (必填) | 具体地点，关联地理区域 |
| `场景字数` | 数字 (必填) | 该场景预计字数，所有场景字数之和=本章总字数 |
| `场景功能` | 枚举 (必填) | 推进（推动主线）/ 揭示（释放信息）/ 转折（改变局势）/ 情感（塑造人物）/ 铺垫（埋设伏笔） |
| `场景内容简述` | 文本 (必填) | 100字以内，谁做了什么，结果是什么 |
| `出场角色` | 列表 (必填) | 使用 `@配角.姓名` 或 `@主角` 格式 |
| `涉及资源` | 列表 (选填) | 使用 `@资源.名称` 格式 |
| `涉及伏笔` | 列表 (选填) | 使用 `@伏笔.ID` 格式 |
| `场景钩子` | 文本 (必填) | 场景结束时留下的悬念或牵引，驱动进入下一个场景 |

### 章级钩子

| 字段 | 类型 | 说明 |
|------|------|------|
| `章末钩子类型` | 枚举 (必填) | 重钩（危机/变故/悬念激化）/ 轻钩（疑惑/反常/未说破） |
| `章末钩子内容` | 文本 (必填) | 50字以内，具体写了什么让读者翻页？ |
| `与下章衔接点` | 文本 (必填) | 下一章第一句必须承接什么？ |

### 道义与感悟

| 字段 | 类型 | 说明 |
|------|------|------|
| `本章落地道义` | 文本 (必填) | 对应03_核心道义体系中的哪条道义？（允许写"0.5条——仅埋设"） |
| `古籍引用` | 文本 (选填) | 若使用古籍点题，写清书名和短句 |
| `感悟触发场景` | 文本 (选填) | 在哪个场景中触发感悟？ |

### 自检预检

| 字段 | 类型 | 说明 |
|------|------|------|
| `预估事件:感悟比例` | 文本 (必填) | 如 "7.5:2.5"，必须在 7:3 ±15% 范围内 |
| `预估压抑/爽感` | 枚举 (必填) | 本章整体是压抑章还是爽感章？（连续压抑不得超过3章） |
| `新设定数量` | 数字 (必填) | 本章计划引入的新设定数量（不得超过3个） |

## 场景功能说明

| 功能类型 | 定义 | 占比建议 | 示例 |
|---------|------|---------|------|
| **推进** | 主角向目标前进了一步（获得线索、到达新地点、完成交易） | 40-50% | 主角进入秘境，找到入口机关 |
| **揭示** | 释放新信息（世界观、人物背景、势力关系） | 15-20% | 配角透露某个势力的真实目的 |
| **转折** | 局势突然改变（被发现、被背叛、意外收获） | 10-15% | 主角以为安全，突然遭遇伏击 |
| **情感** | 塑造人物关系或内心变化 | 10-15% | 主角与配角的信任建立/破裂 |
| **铺垫** | 埋设伏笔或制造悬念 | 5-10% | 一个看似无关的细节，实为后续关键 |

**规则**：
- 每章至少包含 **1个推进场景** 和 **1个情感或转折场景**
- 连续两个场景不得同为"推进"（避免流水账）
- "揭示"场景后必须紧跟"推进"或"转折"场景（避免信息堆砌）

## 场景间钩子设计

场景与场景之间必须有**钩子**连接，禁止硬切：

| 钩子类型 | 用法 | 示例 |
|---------|------|------|
| **悬念钩子** | A场景末尾留下未解答的问题，B场景开头回答或深化 | "他打开盒子，里面不是丹药，而是一封信" → 下场景读信 |
| **动作钩子** | A场景末尾主角做出一个动作，B场景展示动作结果 | "他拔出剑，向黑影刺去" → 下场景剑锋所指 |
| **情绪钩子** | A场景末尾主角产生一个情绪，B场景展示情绪如何影响决策 | "他第一次感到恐惧" → 下场景因恐惧而做出反常选择 |
| **信息钩子** | A场景末尾释放一条信息，B场景展示谁对此做出反应 | "消息传到了虻巢" → 下场景虻巢内部的讨论 |
