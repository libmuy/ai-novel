# 地理区域模板

> 类型：卡片模板 · 定义字段与填写示例，用于生成/维护对应数据文件。

## 使用范围
定义小说世界的空间结构、区域属性、势力分布与资源流动。

## 区域层级字段

### 基础信息

| 字段 | 类型 | 说明 |
|------|------|------|
| `区域名称` | 文本 (必填) | 唯一标识名 |
| `区域层级` | 枚举 (必填) | 凡域/坊市带/天域/禁地/其他自定义层级 |
| `地理位置` | 文本 (必填) | 在世界中的相对位置与接壤区域 |
| `灵气浓度` | 文本 (必填) | 对修行的影响，如“稀薄”“中等”“浓郁如液” |

### 生态与资源

| 字段 | 类型 | 说明 |
|------|------|------|
| `主导体系` | 文本 (必填) | 该区域哪种修行体系占主流 |
| `特产资源` | 列表 (必填) | 该区域产出的关键资源 |
| `危险等级` | 文本 (选填) | 进入该区域所需的最低实力或生存难度 |
| `区域特色` | 文本 (必填) | 用于叙事的世界观氛围描述 |

### 势力分布

| 字段 | 类型 | 说明 |
|------|------|------|
| `势力列表` | 列表 (必填) | 该区域内所有重要势力，每项需关联势力卡 |
| `势力关系简述` | 文本 (选填) | 该区域内势力间的局部冲突或合作 |

### 与主角关系

| 字段 | 类型 | 说明 |
|------|------|------|
| `主角活动阶段` | 文本 (选填) | 主角在哪一境界阶段主要在此活动 |
| `核心冲突类型` | 文本 (选填) | 主角在此区域经历的主要冲突类型 |
| `世界观展开层级` | 文本 (选填) | 该区域揭示世界的哪一层真相 |
