# 战斗结算模板

> 类型：卡片模板 · 定义字段与填写示例，用于生成/维护对应数据文件。

## 使用范围

用于记录每一场战斗的完整设计与战后结算。战斗不是"打赢了"就结束，必须清算代价、传播消息、调整势力关系。

> **触发条件**：任何涉及主角的战斗（无论胜负）都必须填写。纯修炼切磋可简化。
>
> **关联模板**：跨体系战斗需先填 `13_跨体系冲突卡`（战前设计），战后填本模板（战后结算）。

---

## 战斗卡字段

### 基础信息

| 字段 | 类型 | 说明 |
|------|------|------|
| `战斗ID` | 文本 (必填) | 格式：`BT-卷号-序号`，如 `BT-V1-003` |
| `发生章节` | 文本 (必填) | 如 `第15章` |
| `战斗类型` | 文本 (必填) | 遭遇战 / 伏击战 / 阵地战 / 追逐战 / 生死战 / 试探性交手 |
| `战斗规模` | 文本 (必填) | 单挑 / 小队（2-5人）/ 群战（5人以上） |

### 参战方

| 字段 | 类型 | 说明 |
|------|------|------|
| `甲方` | 文本 (必填) | `@主角` 或 `@配角.姓名`，注明当前境界 |
| `乙方` | 文本 (必填) | `@配角.姓名` 或 `@势力.名称`，注明当前境界/人数 |
| `甲方战力评估` | 文本 (必填) | 战斗前的客观战力（含装备、状态、环境优势） |
| `乙方战力评估` | 文本 (必填) | 战斗前的客观战力 |
| `战力对比` | 文本 (必填) | 如：甲方弱三成 / 势均力敌 / 甲方强两成。必须诚实 |

### 战斗设计

| 字段 | 类型 | 说明 |
|------|------|------|
| `战斗目标` | 文本 (必填) | 甲方为什么打？（逃命/夺宝/灭口/拖延/试探） |
| `环境条件` | 文本 (必填) | 地形、天气、时间、有无第三方。环境必须影响战斗 |
| `甲方策略` | 文本 (必填) | 主角怎么打？忌"正面硬刚"，要有具体战术 |
| `乙方策略` | 文本 (必填) | 敌人怎么打？敌人必须有脑子，会针对主角弱点 |
| `外部条件` | 文本 (条件必填) | 若引用了 `13_跨体系冲突卡`，此处填写体系互克如何体现 |
| `转折点` | 文本 (必填) | 战斗中最关键的转折是什么？（主角示弱诱敌、环境突变、第三方介入、底牌暴露） |

### 战斗结果

| 字段 | 类型 | 说明 |
|------|------|------|
| `胜负` | 文本 (必填) | 胜 / 负 / 平局 / 逃脱 |
| `击杀名单` | 列表 (选填) | 谁死了？引用 `@配角.姓名`。每个死亡必须有原因 |
| `甲方伤势` | 列表 (必填) | 主角受了什么伤？必须具体（左臂骨折、三根肋骨裂纹、灵气耗尽、神识受损） |
| `甲方消耗` | 列表 (必填) | 消耗了哪些资源？引用 `@资源.名称` |
| `战利品` | 列表 (选填) | 获得什么？引用 `@资源.名称`。必须有来源（从谁身上/哪里获得） |

### 战后结算（重点）

| 字段 | 类型 | 说明 |
|------|------|------|
| `消息传播` | 文本 (必填) | 战斗结果会被谁看到？怎么传出去？传播范围多大？（方圆十里/整个坊市/某个势力） |
| `后续追查` | 文本 (条件必填) | 若有人死亡或有势力受损，谁会追查？追查力度如何？ |
| `势力关系变化` | 文本 (选填) | 哪些势力因此对主角改变态度？ |
| `新敌人/新盟友` | 文本 (选填) | 因这场战斗产生了什么新的敌友关系？ |
| `心理影响` | 文本 (必填) | 主角对这场战斗的心理反应？（第一次杀人的呕吐、险死还生的后怕、对力量的渴望） |
| `断裂伏笔/任务链` | 列表 (条件必填) | 因本次战斗导致的死亡、伤残或势力灭绝，哪些已登记的伏笔（引用 `@伏笔.ID`）已失效或必须强制转向？每个失效伏笔须注明"失效原因"与"转向方案" |
| `消息封锁代价` | 文本 (条件必填) | 若主角试图"杀人灭口且无人知晓"，必须额外结算一项具体的"因果代价"（如：遗落了带气味的碎布、被路过的飞禽目睹、战斗痕迹无法清理等），禁止"完美灭口" |

## 填写示例

```markdown
### 战斗结算 · BT-V1-003

【基础信息】
战斗ID：BT-V1-003
发生章节：第15章
战斗类型：伏击战
战斗规模：单挑

【参战方】
甲方：@主角（练气六层，左肋有旧伤，灵气约七成）
乙方：@配角.黑脸劫修（练气七层，全盛状态，擅长近身缠斗）
甲方战力评估：弱两成（境界低一层+旧伤未愈）
乙方战力评估：正常练气七层，无特殊法宝，但战斗经验丰富
战力对比：甲方弱两成

【战斗设计】
战斗目标：逃命（主角携带灵草返回途中被伏击）
环境条件：翳岭山道，黄昏，两侧灌木丛可藏身，远处有低阶妖兽活动
甲方策略：佯装不敌向山道狭窄处退却，利用神识优势提前感知妖兽位置，诱敌深入后借妖兽干扰脱身
乙方策略：速战速决，近身缠斗不给主角施法空间，意图三招内结束战斗
转折点：主角故意卖出左肋破绽（旧伤位置），诱使劫修全力一击；劫修命中后发现是陷阱——主角用护身玉简硬接，同时引爆预先埋下的炎符，炸塌山道逼退劫修，借烟尘遁入灌木丛

【战斗结果】
胜负：逃脱（未分生死）
击杀名单：无
甲方伤势：
  1. 左肋旧伤崩裂，失血约两成
  2. 护身玉简碎裂，短期内无二次防护
  3. 灵气耗尽八成，需半日恢复
甲方消耗：
  - @资源.护身玉简 × 1（损毁）
  - @资源.炎符 × 2
  - @资源.回春丹 × 1（战后服用）
战利品：无

【战后结算】
消息传播：山道炎符爆炸声引来附近采药人，看到血迹和碎玉，传回坊市后成为"散修斗法"谈资，主角身份未暴露
后续追查：劫修受伤不轻，暂时退走养伤，但记下了主角的功法特征（木系灵气+炎符），准备追查
势力关系变化：无直接影响
新敌人/新盟友：新增潜在敌人——黑脸劫修及其同伙（共3人）
心理影响：主角第一次意识到"修仙界没有公平决斗，只有生死相搏"；对护身玉简的消耗感到心疼，但也明白"活着才能心疼"
```

## 战斗设计红线

| 禁止项 | 说明 |
|--------|------|
| 禁止越阶秒杀 | 甲方战力弱于乙方时，必须通过策略、环境、代价换取胜利/逃脱，禁止"爆种反杀" |
| 禁止敌人降智 | 乙方必须有合理的战术，不能站着等主角放大招 |
| 禁止无伤胜利 | 即使赢了，甲方也必须付出代价（伤势、资源消耗、暴露底牌） |
| 禁止战斗后无传播 | 战斗结果必须有人知道、有传播路径，禁止"无人知晓的秒杀" |
| 禁止杀人无后果 | 只要有人死亡，必须有后续追查，禁止"杀完没人管" |
| 禁止连续战斗无恢复 | 两场战斗之间必须有恢复/准备时间，禁止"打完一场立刻打第二场满血复活" |

## 与13_跨体系冲突卡的联动

若本场战斗涉及两个不同修行体系：

1. **战前**：先填写 `13_跨体系冲突卡`，明确双方体系差异、互克关系、理念碰撞
2. **战后**：填写本模板时，在`外部条件`字段引用跨体系冲突卡中的设计（如："按11_卡设计，甲方体系优势为XX，乙方反制手段为YY，实战中体现为ZZ"）
3. **结算**：跨体系战斗的战利品可能包含"对方体系物品"，需在`战利品`中注明"需研究/无法直接使用"
