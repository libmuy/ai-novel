# 伏笔登记表模板

> 类型：卡片模板 · 定义字段与填写示例，用于生成/维护对应数据文件。

## 使用范围
每埋设一个伏笔必须登记，不登记=不存在，禁止临时现编回收。

## 伏笔登记字段

### 基础信息

| 字段 | 类型 | 说明 |
|------|------|------|
| `伏笔ID` | 文本 (必填) | 格式：V卷号-C章节号-序号，如 V1-C03-001 |
| `伏笔名称` | 文本 (必填) | 一句话概括，方便检索 |
| `类型` | 枚举 (必填) | 短(3-5章)/中(10-30章)/长(全篇或跨卷) |
| `埋设章节` | 文本 (必填) | 精确到章 |
| `计划回收章节` | 文本 (必填) | 精确到章或区间 |

### 埋设设计

| 字段 | 类型 | 说明 |
|------|------|------|
| `埋设内容简述` | 文本 (必填) | 50字以内，具体写了什么？ |
| `埋设方式` | 枚举 (必填) | 对话提及/环境描写/物品出现/主角内心闪念/配角反常行为 |
| `读者可见度` | 枚举 (必填) | 明显/隐约/极隐 |

### 回收设计

| 字段 | 类型 | 说明 |
|------|------|------|
| `回收章节` | 文本 (条件必填) | 实际回收时填写 |
| `回收方式` | 文本 (必填) | 直接揭示/角色口述/主角推理/战斗触发/环境变化 |
| `前置暗示` | 文本 (必填) | 回收前1-3章，安排了什么细节让读者似曾相识？ |
| `回收冲击类型` | 枚举 (必填) | 逻辑冲击/情感冲击/战力冲击/世界观冲击 |

### 关联网络

| 字段 | 类型 | 说明 |
|------|------|------|
| `关联角色` | 列表 (选填) | 使用 `@配角.姓名` 格式 |
| `关联势力` | 列表 (选填) | 使用 `@势力.名称` 格式 |
| `关联主线/支线` | 文本 (选填) | 主线推进/支线展开/世界观揭秘/人物塑造 |

### 状态追踪

| 字段 | 类型 | 说明 |
|------|------|------|
| `当前状态` | 枚举 (必填) | 已埋设/已暗示/已回收/已废弃/待调整 |
| `备注` | 文本 (选填) | 回收时的具体台词或场景草稿，或废弃原因 |
