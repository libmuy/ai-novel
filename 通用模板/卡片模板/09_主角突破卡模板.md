# 主角突破卡模板

> 类型：卡片模板 · 定义字段与填写示例，用于生成/维护对应数据文件。

## 使用范围

用于记录主角每一次境界突破/晋升的完整设计。突破不是"升级"，而是主角与世界规则的一次深层对话——是力量、代价、感悟三者的交汇点。

> **触发条件**：主角每次突破大境界（如练气→筑基）或关键小境界（如练气三层→六层）时必须填写。日常修炼进度无需填写。
>
> **关联模板**：填写前必读 `04_资源分级体系`（确认资源条件），突破后必读 `10_感悟闭环卡`（完成感悟闭环）。

---

## 突破卡字段

### 基础信息

| 字段 | 类型 | 说明 |
|------|------|------|
| `突破ID` | 文本 (必填) | 格式：`BP-卷号-序号`，如 `BP-V1-001` |
| `突破章节` | 文本 (必填) | 发生在第几章，如 `第23章` |
| `当前境界` | 文本 (必填) | 突破前的境界 |
| `目标境界` | 文本 (必填) | 突破后的境界 |
| `突破类型` | 文本 (必填) | 正常晋升 / 强行突破 / 破而后立 / 外力催化 / 双修共鸣 |

### 前置条件（必填，缺一不可）

| 字段 | 类型 | 说明 |
|------|------|------|
| `修为积累` | 文本 (必填) | 突破前经历了多少章的积累？具体做了什么？（如：历经7章，完成3次散修任务，积累灵石47块） |
| `资源消耗` | 列表 (必填) | 使用了哪些资源？引用 `@资源.名称` 格式，并注明数量。必须与 `04_资源分级体系` 中的等级匹配 |
| `外部契机` | 文本 (必填) | 是什么外部事件触发了突破契机？（战斗重伤、古籍启发、生死危机、他人点化） |
| `心境铺垫` | 文本 (必填) | 突破前主角经历了什么心理变化？（如：第一次杀人后的自我怀疑、目睹弱者被欺后的愤怒与无力） |

### 突破过程设计

| 字段 | 类型 | 说明 |
|------|------|------|
| `突破场景` | 文本 (必填) | 在哪里突破？环境特征是什么？（忌"洞府闭关"，要有具体环境压力：瘴气沼泽、敌营腹地、雷暴山巅） |
| `过程描写` | 文本 (必填) | 突破不是"轰的一声"，要写出**身体的具体感受**（经脉撕裂、灵气倒灌、识海震荡、旧伤复发） |
| `干扰因素` | 文本 (选填) | 突破过程中是否有外部干扰？（敌人追杀、环境恶化、心魔侵扰、资源不足） |
| `失败风险` | 文本 (必填) | 如果失败，代价是什么？（境界跌落、经脉受损、寿元削减、被敌人发现） |

### 突破结果

| 字段 | 类型 | 说明 |
|------|------|------|
| `新能力` | 列表 (必填) | 突破后获得的核心能力变化，2-3项，忌多忌杂。必须具体（如：灵气储量翻倍→可持续战斗时间从半时辰延长到一个时辰） |
| `新限制` | 列表 (必填) | 突破后新增的**限制或代价**（如：筑基后需定期服用定基丹，否则境界不稳；新功法与旧功法冲突，需重新磨合） |
| `战力评估` | 文本 (必填) | 突破后能打什么水平的敌人？与同境界普通修士相比如何？（必须诚实，禁止"同阶无敌"） |

### 感悟闭环（突破后必跟）

| 字段 | 类型 | 说明 |
|------|------|------|
| `突破感悟` | 文本 (必填) | 主角对这次突破的领悟，必须**依托于突破过程中的具体痛苦或抉择**。引用 `@古籍.[书名]` 点题 |
| `古籍引用` | 文本 (必填) | 哪句古籍短句对应了这次感悟？控制在30字以内 |
| `认知变化` | 文本 (必填) | 这次突破让主角对修行/世界/自己产生了什么新认知？ |

### 后续影响

| 字段 | 类型 | 说明 |
|------|------|------|
| `势力反应` | 文本 (选填) | 哪些势力会注意到这次突破？他们会怎么做？ |
| `敌人反应` | 文本 (选填) | 主角的敌人得知后会如何调整策略？ |
| `新目标` | 文本 (选填) | 突破后主角的下一个目标是什么？ |

## 填写示例

```markdown
### 突破卡 · BP-V1-001

【基础信息】
突破ID：BP-V1-001
突破章节：第23章
当前境界：练气六层
目标境界：练气七层（后期）
突破类型：强行突破

【前置条件】
修为积累：历经8章，完成5次散修任务，猎杀妖兽3头，积累灵石62块
资源消耗：
  - @资源.引气玉 × 2
  - @资源.回春丹 × 1
  - @资源.低阶灵石 × 47
外部契机：与劫修生死战后，经脉受震，灵气逆流，被迫在逃亡中突破
心境铺垫：第一次杀人后连续三夜失眠，意识到"不杀人就被杀"不是道理，只是无奈

【突破过程设计】
突破场景：翳岭深处毒瘴沼泽，需在三个时辰内完成，否则瘴气入体
过程描写：灵气倒灌如沸水入喉，旧伤（左肋刀伤）在灵气冲击下崩裂，血与汗混合滴落；识海中出现被杀劫修的脸，必须一边压制心魔一边引导灵气
干扰因素：瘴气侵蚀导致视线模糊，远处有妖兽被血腥味吸引
失败风险：经脉寸断，沦为凡人；或被妖兽发现，死于沼泽

【突破结果】
新能力：
  1. 灵气储量增加约40%，可持续战斗时间延长至一炷香
  2. 神识范围从三丈扩展至五丈，可提前感知低阶妖兽靠近
新限制：
  1. 强行突破导致根基略虚，需一个月内每日服用定基丹巩固
  2. 左肋旧伤未愈，剧烈运动时灵气运转会受阻三成
战力评估：可正面击败普通练气七层，但遇练气八层仍需周旋；同境界中属中上，非顶尖

【感悟闭环】
突破感悟：原来突破不是"变强"，是"承受更多"。能承受多少痛苦，才能承载多少力量。
古籍引用：《尘心杂记》"器满则溢，人满则损，知止而后有定。"
认知变化：开始理解为什么高阶修士大多冷漠——不是心性变了，是承载的东西太多，分给旁人的就少了

【后续影响】
势力反应：@势力.虻巢 的眼线注意到沼泽灵气异动，派出探查
敌人反应：劫修同伙得知同伴被杀且凶手突破，开始追查主角身份
新目标：需在一月内凑齐定基丹材料，否则境界倒退
```

## 突破设计红线

| 禁止项 | 说明 |
|--------|------|
| 禁止无代价突破 | 每次突破必须有资源消耗、身体代价或心理代价，至少一项 |
| 禁止"顿悟突破" | 禁止主角因"突然想通了"而突破，必须有具体积累 |
| 禁止越阶秒杀 | 突破后战力评估必须诚实，禁止"同阶无敌""越阶秒杀" |
| 禁止突破即满血 | 突破过程中受的伤、消耗的精力，突破后必须保留 |
| 禁止连续突破 | 两次突破之间至少间隔 **10章** 或 **一个完整事件** |
| 禁止突破后无感悟 | 每次突破必须伴随感悟闭环，否则视为无效突破 |

---

## 与10_感悟闭环卡的联动

突破卡的`感悟闭环`部分，必须在正文生成后，单独填写一张 `10_感悟闭环卡`，将突破感悟扩展为完整的"事件→古籍→感悟"三段式。

联动方式：
- 突破卡负责"突破过程与结果"的设计
- 感悟闭环卡负责"突破后感悟段落"的文学化表达
- 两张卡片的`古籍引用`字段必须一致
