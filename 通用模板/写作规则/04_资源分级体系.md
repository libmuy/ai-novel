# 资源分级体系

> 类型：写作规则 · 行为约束/规范，生成与续写时遵循。本规则兼作 `04_资源分级数据` 的字段定义源（配套产生数据文件，见 `00_使用说明` S1 例外说明）。

## 使用范围
定义小说中所有可获取、交易、消耗的资源的分级标准，防止后期战力崩坏与经济体系混乱。

## 设计原则
1. **分级必须对应境界**：每一级资源都应有明确的"最低使用境界"与"最佳使用境界"。
2. **兑换比例固定**：货币或等价物之间的兑换比例一旦设定，全书不得随意更改。
3. **越级使用有代价**：低境界强行使用高阶资源，必须有明确的副作用或浪费率。
4. **稀缺度与获取难度挂钩**：高阶资源的获取途径必须与其等级匹配，禁止"路边捡到仙器"。

## 一、通用资源分级总表

### 1.1 货币/能量单位分级

| 字段 | 说明 |
|------|------|
| `货币名称` | 通用交易媒介的名称 |
| `分级列表` | 各级名称、对应基准价值、兑换比例 |
| `灵气纯度` | 每一级蕴含的灵气量或能量密度 |
| `外观特征` | 便于在叙事中描述 |
| `主要用途` | 交易/修炼/布阵/驱动法宝 |
| `获取途径` | 矿脉开采/任务报酬/战利品/兑换 |

### 1.2 丹药分级

| 字段 | 说明 |
|------|------|
| `品级体系` | 几品制？每品是否分阶？ |
| `品级名称` | 一品至X品的具体名称 |
| `对应境界` | 每一品建议的使用境界 |
| `炼制难度` | 对应炼丹师境界要求 |
| `主材等级` | 炼制该品级丹药所需材料的最低等级 |
| `药效上限` | 对同阶修士的效果；对高阶修士的衰减率 |
| `丹毒/副作用` | 越级服用或过量服用的后果 |
| `保存期限` | 丹药是否随时间失效？ |

### 1.3 法宝/武器分级

| 字段 | 说明 |
|------|------|
| `等级名称` | 各等级名称（如：法器→灵器→法宝→灵宝→通天灵宝） |
| `对应境界` | 每一级建议的持有境界 |
| `灵性程度` | 是否有器灵？器灵智能等级？ |
| `祭炼要求` | 需要多少时间与灵气才能初步祭炼？ |
| `进阶可能` | 是否可通过温养/吞噬材料升级？ |
| `损毁修复` | 受损后如何修复？修复成本？ |
| `认主机制` | 滴血/神识烙印/因果绑定/其他？ |

### 1.4 功法/典籍分级

| 字段 | 说明 |
|------|------|
| `等级名称` | 各等级名称（如：基础→进阶→核心→秘传→禁术） |
| `对应境界` | 每一级建议的修习境界 |
| `修习难度` | 入门时间/悟性要求/前置功法要求 |
| `威力上限` | 同阶发挥几成威力？跨阶衰减率？ |
| `隐患/代价` | 修习或施展的副作用 |
| `传承限制` | 是否可抄录？是否可外传？是否有传承禁制？ |

### 1.5 材料/天材地宝分级

| 字段 | 说明 |
|------|------|
| `等级名称` | 各等级名称（如：凡品→灵品→地品→天品→仙品） |
| `对应用途` | 每一级通常用于炼制什么等级的丹药/法宝/阵法？ |
| `生长环境` | 生长/产出地点的特征 |
| `采集难度` | 是否有守护妖兽？是否有采集手法要求？ |
| `保存条件` | 离开原生环境后多久失效？需要什么容器保存？ |

### 1.6 妖兽/古裔材料分级

| 字段 | 说明 |
|------|------|
| `等级对应` | 妖兽/古裔等级与修士境界的对照 |
| `材料部位` | 哪些部位有价值？（皮/骨/血/丹/角/魂） |
| `价值差异` | 同一妖兽不同部位的价值比例 |
| `处理要求` | 击杀后多久内必须处理？处理不当的后果？ |

### 1.7 秘境/遗迹/洞天分级

| 字段 | 说明 |
|------|------|
| `危险等级` | 各等级名称与建议进入的最低境界 |
| `收益等级` | 通常可获得的资源等级 |
| `开启条件` | 时间限制/血脉限制/钥匙/修为门槛 |
| `存活率` | 各境界进入后的历史存活率（用于叙事参考） |
| `特殊规则` | 内部是否有禁法/禁空/时间流速差异等？ |

## 二、经济体系设计字段

### 2.1 通货膨胀/稀缺度控制

| 字段 | 说明 |
|------|------|
| `高阶资源流通方式` | 高阶资源是否允许用低阶货币直接购买？还是必须以物易物？ |
| `大宗门垄断项` | 哪些资源被大宗门垄断？散修如何获取？ |
| `黑市定价规则` | 黑市价格与官方/坊市价格的差异比例？ |
| `资源再生速度` | 灵脉/妖兽/草药的再生周期？是否可持续开采？ |

### 2.2 主角经济曲线

| 字段 | 说明 |
|------|------|
| `阶段财富定位` | 主角在每个境界阶段的财富水平（贫困/温饱/小康/富裕/巨富） |
| `收入来源` | 每个阶段的主要收入来源 |
| `支出大头` | 每个阶段的主要支出项 |
| `财务危机设计` | 每个阶段是否安排"缺钱"的困境？ |
