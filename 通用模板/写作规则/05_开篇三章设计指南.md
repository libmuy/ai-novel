# 开篇三章设计指南

> 类型：写作规则 · 行为约束/规范，生成与续写时遵循，不产生独立数据文件。

## 使用范围

定义长篇小说前三个章节（即"开篇三章"）的顶层设计原则、结构规则与禁忌清单。适用于任何修仙/玄幻长篇，需在具体小说数据中适配。

**核心原则**：开篇三章不是"铺垫"，而是"契约"——与读者签订的一份关于"这本书将给你看什么"的契约。三章之内，必须让读者明确：主角是谁、世界有多残酷、这本书和其他修仙文有什么不同。

> **注意**：本模板仅保留"前三章专属规则"。关于开篇300字、中段松紧搭配、结尾钩子、情绪锁死、节奏禁忌等**通用写作规则**，详见 `00_文风与节奏规范`（全书唯一权威来源）。

## 一、三章功能定位（不可互换）

### 第一章：立人——主角是谁？

**功能**：让读者在300字内记住主角，在3000字内理解主角的"独特之处"。

**必须完成的任务**：
1. **底层出身锚定**：主角的出身必须在第一章明确（凡人/散修后裔/小家族/战乱遗孤），且必须是"底层"。忌开局宗门天骄、转世大能、系统加身。
2. **核心性格亮相**：通过一次具体行动，展示主角的"谨慎"与"底线"（见模板11_两难抉择卡）。不是旁白说"他很谨慎"，而是他**做了**一件谨慎的事。
3. **第一次"内心评估"**：主角面对新情况时，必须在第一章出现至少一次"内心评估"（实力/退路/风险/值不值得），这是人设落地的核心动作。
4. **世界的第一层展开**：展示主角所处环境的"日常残酷"（赋税、饥荒、仙凡鸿沟、修士冷漠），但不要解释世界观，只展示现象。

**禁止做的事**：
- 禁止开篇写天气、环境、心情铺垫（详见 `00_文风与节奏规范` §3.1）
- 禁止第一章出现超过两个有名字的角色（防止信息过载）
- 禁止第一章解释修炼体系、境界划分、世界历史
- 禁止第一章出现金手指、系统、老爷爷、神秘声音
- 禁止第一章写主角的"宏大理想"（如"我要成仙"）

---

### 第二章：立界——世界有多残酷？

**功能**：让读者理解这个世界的运行规则，且规则必须是"利益优先，善恶其次"。

**必须完成的任务**：
1. **第一次外部冲突**：主角与外部世界发生第一次实质性冲突（不是与妖兽，而是与"人"——修士、豪强、劫修、坊市规则）。冲突必须围绕"资源"展开。
2. **展示"利益优先"法则**：冲突中的各方（包括看似"好人"的角色）行为动机必须是利益最大化。若有人选择善良，必须给出成本或隐藏目的。
3. **主角的第一次"吃亏"**：主角在冲突中必须吃亏（失去资源、被欺骗、被迫让步），且这个亏不能立刻报复回来。忌开局反杀、开局打脸。
4. **引入第一个"信息差"**：主角发现这个世界有他不知道的规则/秘密/势力，产生"信息饥渴"，驱动读者追读。

**禁止做的事**：
- 禁止第二章出现"纯粹为了坏而坏"的反派
- 禁止主角在第二章获得明显收益（忌"因祸得福"）
- 禁止第二章解释四大体系的完整设定
- 禁止第二章出现跨体系战斗（信息过载）

---

### 第三章：立约——这本书有什么不同？

**功能**：让读者意识到"这本书不是普通的修仙爽文"，建立差异化认知。

**必须完成的任务**：
1. **第一次"道义选择"**：主角面临一个"利益 vs 底线"的两难选择。**执行方式**：直接使用 `11_两难抉择卡模板` 填写此次事件，选择结果必须为B（底线），且代价不可在3章内化解。这是全书灵魂"修心重于修力"的第一次亮相。
2. **世界观第二层展开**：通过主角的遭遇，展示修仙界的一个"反常识"真相（如：修士不是仙人，只是有力量的人；小宗门也有体面；古裔不是妖兽）。
3. **引入第一个"长期悬念"**：埋设一个中/长伏笔（见模板05_伏笔登记表），与主角的身世/未来/世界真相相关，三章内不回收。
4. **建立"七分三感"的节奏契约**：第三章必须包含至少一次"打斗/冲突"与至少一次"感悟/内心活动"的交替，让读者习惯"事件→古籍→感悟"的固定结构。

**禁止做的事**：
- 禁止第三章让主角"顿悟"或"突然变强"
- 禁止第三章圆满收尾（必须有未解决的悬念）
- 禁止第三章出现超过500字的设定解释
- 禁止第三章的感悟是空洞说教（必须依托于具体事件）

## 二、每章黄金结构规则（前三章特化版）

> 通用版规则详见 `00_文风与节奏规范` 第三章。本节仅列出前三章的**额外限制**。

### 2.1 开篇300字规则（前三章加严版）

**通用规则**（第一句动作/异常、前100字、前300字、四选一入戏方式、禁止的入戏方式）详见 `00_文风与节奏规范` §3.1。

**前三章额外限制**：
- 第一章第一句必须是**动作**或**异常**，且必须同时展示主角的**底层出身**和**谨慎性格**（通用规则只要求动作/异常，前三章加严到"一石二鸟"）

### 2.2 中段结构规则（前三章加严版）

**通用规则**（松紧搭配、每章新信息≤3个、信息须在同章或下一章产生效果）详见 `00_文风与节奏规范` §3.2。

**前三章额外限制**：
- 禁止同一性质内容（纯打斗/纯对话/纯感悟）连续超过**800字**（比通用规则的1000字更严）
- 出现的新信息必须与主角当前困境直接相关（禁止"为设定而设定"）

### 2.3 结尾钩子规则（前三章特化版）

**通用规则**（重钩/轻钩定义、使用频率、禁止的结尾）详见 `00_文风与节奏规范` §3.3。

**前三章强制要求**：
- **第一章**：必须用**重钩**（未解决的危机或突发变故）
- **第二章**：必须用**轻钩**（伏笔暗现或自我疑惑）——让读者"喘口气"但保持好奇
- **第三章**：必须用**重钩**（两难困境激化或长期悬念显现）
- **禁止连续两章使用同一种钩子**

## 三、主角人设落地规则（开篇三章专用）

> 主角**固定人设红线**（底层出身、守底线、懂取舍、忌无脑爽）的权威定义见 `02_版权安全与原创性规范` §5.1；本节只定义开篇三章"如何展示"这三项人设。

### 3.1 "谨慎"的展示规则

开篇三章中，主角必须完成以下**至少三项**谨慎行为：

1. **遇事先找退路**：进入新环境时，先观察出口/暗道/逃跑路线
2. **动手前观察**：面对潜在敌人时，先评估对方实力（灵气波动、武器、随从数量）
3. **准备后手**：做任何有风险的事时，预留至少一个备用方案
4. **不轻易相信**：对陌生修士保持距离，不透露真实姓名/来历/目的
5. **能跑就跑**：面对明显强于自己的对手，第一反应是逃而非战
6. **试探陷阱**：得到机缘前，先以最低成本试探是否有诈

**展示方式**：必须通过**动作和内心评估**展示，禁止旁白直接说"他很谨慎"。

### 3.2 "底线"的展示规则

开篇三章中，主角必须完成**一次"吃亏的道义选择"**：

- **选择情境**：主角可以在"利益"和"底线"之间选择利益而不受惩罚，但他选择了底线
- **即时代价**：选择底线后，主角必须在**同一章**内承受具体损失（资源、时间、安全、人情）
- **延迟回报**：这个选择的回报不得在**前五章**内出现（保持"吃亏"的真实感）
- **他人反应**：至少有一个旁观者（配角或路人）对主角的选择表示不解或嘲笑，强化"这个世界不鼓励善良"的氛围

### 3.3 "底层视角"的展示规则

开篇三章中，必须通过**至少两个细节**展示主角的底层出身：

1. **资源计算细节**：主角对每一颗灵石/每一口食物/每一寸布料的价值有精确认知
2. **身体记忆细节**：主角有凡人时期留下的身体习惯（如：走路时避开石板缝隙；吃饭时先舔干净碗边）
3. **语言细节**：主角说话带有底层口音或习惯用语（如：不说"灵气匮乏"，说"这地方喘口气都费劲"）
4. **知识盲区细节**：主角对某些修仙界常识一无所知

## 四、世界观展开节奏（三层冰山）

开篇三章只展示世界的**第一层（水面之上）**，但必须在第三章埋设**第二层（水面之下）**的入口。

### 第一层：水面之上（日常残酷）
- **展示内容**：凡人如何被修士漠视、资源如何稀缺、杀人夺宝如何常见、小人物如何挣扎
- **展示方式**：通过主角的**亲身经历**展示，不是旁白介绍
- **三章分配**：第一章和第二章主要展示第一层

### 第二层：水面之下（规则暗流）
- **展示内容**：修仙界不是"弱肉强食"那么简单，背后有宗门博弈、体系互克、历史遗留、经济垄断
- **展示方式**：通过主角的一次"吃亏"或"被利用"，让他意识到"事情没这么简单"
- **三章分配**：第二章末尾或第三章开始展示第二层的一角

### 第三层：深海（世界真相）
- **展示内容**：四大体系的本源、上古大战的真相、长生的真正代价、苍玄界的终极秘密
- **展示方式**：开篇三章**完全不展示**，只埋设一个**极隐伏笔**
- **三章分配**：第三章埋设一个与第三层相关的长伏笔

## 五、情绪与节奏控制规则（前三章特化版）

> 通用版情绪锁死技巧和节奏禁忌详见 `00_文风与节奏规范` 第四、五章。本节仅列出前三章的**额外限制**。

### 5.1 情绪锁死技巧（开篇三章必用）

通用技巧（反差共情 / 付出回报不对等 / 道理靠事件落地）详见 `00_文风与节奏规范` 第四章。**与通用规则的区别**：通用规则为"推荐使用"，前三章为**必须全部使用**。

### 5.2 节奏禁忌（开篇三章红线）

通用节奏禁忌详见 `00_文风与节奏规范` 第八章「单章一站式自检清单」（其原第五章内容已并入该清单，800字/300字/3个新设定/钩子等通用红线不再复述）。前三章仅两项加严：

- 感悟段落不超过**200字**（通用规则为300字）
- 禁止主角在第三章前获得任何形式的"金手指"或"天降机缘"

## 六、与后续章节的衔接规则

### 6.1 第三章结束时的状态要求

主角在第三章结束时，必须处于以下**至少两项**状态：

1. **有未解决的危机**：一个明确的威胁尚未解除（被追杀、被盯上、欠债、身负隐患）
2. **有未解答的疑问**：主角（和读者）对某个现象/人物/物品产生强烈好奇
3. **有未兑现的代价**：第三章做出的道义选择，其代价将在后续章节持续发酵
4. **有未探索的线索**：一个明确的"下一步该去哪/该做什么"的方向

### 6.2 第四章的启动规则

第四章必须从**第三章的钩子**直接延续，禁止时间跳跃或场景跳跃后重新铺垫。

- 若第三章是重钩（危机），第四章第一句必须是主角面对危机的**即时反应**
- 若第三章是轻钩（疑惑），第四章必须在**前300字**内让这个疑惑产生**实际影响**

## 七、开篇三章自检清单

> 每章级的通用自检（开篇300字、事件→古籍→感悟闭环、7:3比例、字数上限、结尾钩子等）由 `00_文风与节奏规范` 第八章「单章一站式自检清单」逐章执行。本节仅保留**"三章整体契约"**级检查，在确认"可以开始写第四章"之前逐项勾选：

- [ ] 第一章第一句是否是动作或异常？
- [ ] 第一章是否在300字内让读者知道主角是谁、面临什么？
- [ ] 第一章是否展示了主角的"谨慎"（至少三项行为中的一项）？
- [ ] 第一章是否明确了主角的底层出身？
- [ ] 第二章是否展示了"利益优先，善恶其次"的世界规则？
- [ ] 第二章的冲突是否围绕"资源"展开？
- [ ] 第二章主角是否吃亏？
- [ ] 第三章是否有"利益 vs 底线"的两难选择？
- [ ] 第三章主角是否选择了底线并承担了具体代价？
- [ ] 第三章是否埋设了至少一个中/长伏笔？
- [ ] 三章内是否出现了"事件→古籍→感悟"的固定结构至少一次？
- [ ] 三章内是否有"七分打斗/冲突，三分感悟"的节奏交替？
- [ ] 三章内新设定总数是否不超过**9个**（平均每章3个）？
- [ ] 三章内新角色（有名字）总数是否不超过**7个**？
- [ ] 主角是否在第三章结束时处于"有未解决危机/疑问/代价/线索"的状态？
- [ ] 三章内是否完全没有金手指、系统、老爷爷、神秘声音？
- [ ] 三章内是否完全没有"我要成仙"式的宏大理想宣言？
- [ ] 三章内是否完全没有知名仙侠作品原词、现实宗教原教义？真实古籍是否只以"仿古体化用"或卷首题记形式出现（见 02_版权安全 §1.1）？

**全部勾选通过，方可进入第四章。**
