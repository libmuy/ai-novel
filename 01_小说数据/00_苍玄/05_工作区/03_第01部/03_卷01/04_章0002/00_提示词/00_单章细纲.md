```markdown
## 一、固定文风比例（基准）
七分：修仙事件/打斗/冒险/资源争夺/秘境探索；三分：人心取舍/道义感悟/古籍点题/内心成长。

每章（或每连续两章）必须完成闭环：剧情事件 → 古籍短句点题 → 主角心境道理感悟。
禁止变体：纯说教 / 纯打斗流水账 / 空洞讲道理。（允许"每连续两章"完成闭环——本章可不出现显性古籍点题，由第3章承接。）

## 三、每章黄金结构
### 3.1 开篇300字规则
- 第一句：必须是**动作**或**异常**，禁止天气/环境/心情铺垫。
- 前100字：必须出现**主角** + **冲突/危机/异常**。
- 前300字：必须让读者产生"然后呢？"的冲动。
- 可选入戏方式（四选一）：① 危机入戏 ② 悬念入戏 ③ 两难入戏 ④ 伏笔入戏。

### 3.2 中段结构规则
- 松紧搭配：前段打斗/冲突→中段插对话或内心评估；前段日常/对话→中段安排小冲突或危机。同一性质内容连续不得超过 1000 字（**开篇三章 800 字**）。

### 3.3 结尾钩子规则

## 六、情感表达规则
### 6.1 禁止直接写情绪
```

## 模板三：05_开篇三章设计指南（前三章专属规则 · 全文）

```markdown
# 开篇三章设计指南

**核心原则**：开篇三章不是"铺垫"，而是"契约"——与读者签订"这本书将给你看什么"。三章之内必须让读者明确：主角是谁、世界有多残酷、这本书和其他修仙文有什么不同。

## 一、三章功能定位（不可互换）

### 第一章：立人——主角是谁？（已完成 · 章0001）
借身体状态/旁人称呼/白描带出年龄；一次具体行动展示"谨慎"与"底线"；至少一次内心评估；世界第一层展开（只展示现象、不解释世界观，但关键制度/黑话第一次出现须有同章行为锚点）。

### 第二章：立界——世界有多残酷？（★本次任务）
**功能**：让读者理解世界运行规则是"利益优先，善恶其次"。
**必须完成**：
1. **第一次外部冲突**：与"人"（修士、豪强、劫修、坊市规则）发生实质冲突，冲突围绕"资源"展开（不是与妖兽）。
2. **展示"利益优先"法则**：各方行为动机必须是利益最大化；若有人选善良，必须给出成本或隐藏目的。
3. **主角的第一次"吃亏"**：必须吃亏（失去资源、被欺骗、被迫让步），且**不能立刻报复**。忌开局反杀、开局打脸。
4. **引入第一个"信息差"**：主角发现这个世界有他不知道的规则/秘密/势力，产生"信息饥渴"。
**禁止**："纯粹为了坏而坏"的反派；主角获得明显收益（忌"因祸得福"）；解释四大体系完整设定；跨体系战斗（信息过载）。

### 第三章：立约——这本书有什么不同？（下一章，本章须为其铺垫）
第一次"道义选择"（利益 vs 底线，选 B，代价不可 3 章内化解）；世界观第二层展开；引入第一个"长期悬念"（埋中/长伏笔，3 章内不回收）；建立"七分三感"节奏契约。

## 二、前三章额外限制（在 00_通用写作规则 之上加严）
| 维度 | 前三章加严 |
| 开篇300字 | 第一章第一句须一石二鸟（本条只约束第1章）；**第2章第一句须是主角面对第1章重钩的即时反应**（见§五 5.2） |
| 连续同质内容 | 不超过 **800字** |
| 感悟段落 | 不超过 **200字** |
| 结尾钩子 | 第1章重钩、**第2章轻钩**、第3章重钩，禁止连续两章同钩 |
| 金手指 | 第三章前禁止任何"金手指"或"天降机缘" |
| 新设定 | 三章内合计≤**9个**；且必须与主角当前困境直接相关 |
| 新角色 | 三章内有名字角色合计≤**7个** |

> **祖传/开篇前已持有的异宝 ≠「天降机缘」，但三章内仍须「零收益」**：主角家传信物/异宝在开篇三章里**只能留悬念、不能给任何实际好处**——不得内视、开辟空间、加速修炼、预警危险、提供情报、增强战力。它的作用限于"发热/共鸣/异动"这类勾起读者与主角疑问的表现。真正的能力兑现放到第四章及以后。破了这条，等同于金手指提前生效。

## 三、主角人设落地规则（开篇三章专用）
### 3.1 "谨慎"的展示规则
通过**动作和内心评估**展示（禁旁白说"他很谨慎"）：① 遇事先找退路；② 动手前观察；③ 准备后手；④ 不轻易相信；⑤ 能跑就跑；⑥ 试探陷阱。
### 3.2 "底线"的展示规则
第三章完成一次"吃亏的道义选择"；选择后同章内承受具体损失；回报不得在前五章内出现；至少一个旁观者不解或嘲笑。
### 3.3 "底层视角"的展示规则
通过**至少两个细节**展示底层出身：① 资源计算细节；② 身体记忆细节；③ 语言细节（底层口音/习惯用语）；④ 知识盲区细节（对某些修仙常识一无所知）。

## 四、世界观展开节奏（三层冰山）
第一层（日常残酷：凡人被漠视、资源稀缺、杀人夺宝常见）——第1、2章，主角亲身经历，非旁白介绍。
第二层（规则暗流：宗门博弈、体系互克、历史遗留、经济垄断）——**第2章末或第3章**，主角一次"吃亏"或"被利用"后意识到"事情没这么简单"。
第三层（世界真相）——第3章只埋一个极隐伏笔。

## 五、与后续章节的衔接规则
### 5.1 第三章结束时的状态要求
主角必须处于以下至少两项：① 有未解决的危机；② 有未解答的疑问；③ 有未兑现的代价；④ 有未探索的线索。
### 5.2 第四章的启动规则
第四章必须从第三章钩子直接延续，禁止时间跳跃或场景跳跃后重新铺垫。
> **对本章（第2章）的直接约束**：第1章是重钩（危机：黑石会夜巡监工的灵石灯钉在苏砚藏身岩柱前、脚步逼近、怀里私藏两枚废灵石即将暴露）。第2章**第一句必须是苏砚面对这一危机的即时反应**（动作），禁止时间跳跃或重新铺垫。
```

## E. 本章相关道义

### DY-006（力量类·尊严维度）— 卷1必须落地，但**本章仅埋设（≤0.5 条）**
- 道义表述："跪着活是活，站着活也是活；区别是，跪着的人看谁都像膝盖，站着的人看谁都像眼睛。"
- 核心含义：尊严不是反抗的姿态，而是在被践踏时仍保持人的形状；尊严应是在生存缝隙中挤出来的第三选项，而非与生存对立的二选一。
- 禁忌写法：禁止把尊严写成"主角光环"式无脑硬刚；禁止"宁死不屈"的廉价悲壮；尊严的选择必须有具体代价，且主角必须算过这笔账。
- **本章处理**：DY-006 的正式"道义选择"在第 3 章（拒跪指认工友）。本章只让处境**隐含**这条张力——苏砚 挨鞭时不反抗、不哀求、也不折骨下跪；这份"挨着但不趴下"的姿态是他日后拒跪的对照。**不要**在本章让苏砚说尊严相关的金句、做硬刚，或让他"宁死不屈"地激化冲突。可以极轻地带一笔 **DY-002（善恶类：魔修杀人用刀，正道杀人用规矩）** 的影子——监工/马铁秤 拿"会里规矩""矿上的规矩"给"没收 + 克扣 + 立威"穿上合法外衣，别的矿工因此不敢作声——但**不点题、不上古籍**。

苏砚，十六岁凡人矿工，在枯港矿城地下矿道撬废灵石，当日撬得九枚、四两五钱。日头偏西到矿务司征收点交矿，管事马铁秤压秤把四两五钱按"三两、下等"算，本该一枚半只发一枚整，另口头讹三成"护矿费"记账下月扣，又冲书办冷笑"看他跪不跪"。苏砚算清硬顶的代价（被记名、派"鬼见愁"矿层、娘的止咳散断），没跪也没顶，低头谢过，攥着一枚碎灵石回家。棚户里母亲柳禾肺痨咳血，苏砚拿手头两枚碎灵石换回小半包止咳散煎上，谎称在矿上吃过饭、把口粮省给娘。柳禾从枕下取出祖传古玉"老灰"，叫他戴上"去去晦气"，来历不肯多说。子夜等娘睡沉，苏砚揣矿钉摸进弃矿沟捡漏，摸出两枚小指大的废灵石。歇脚时手撑沟壁，蹭到几道像被大火燎烙过的灼烧刻痕；他解下古玉把玩，掌心忽然发烫，玉一靠近刻痕更烫、移开渐凉，前后五息三息，无光无声。他按住恐惧、像记矿下说不清的岩层一样把细节记牢，主动搁下"回头有命再琢磨"，把玉塞回衣领（已凉透）。这时沟口亮起黑石会夜巡的灵石灯，光柱扫过、停在他藏身的岩柱前没有移开，脚步声由远及近——怀里两枚私藏废灵石即将暴露。

> 苏砚没出声，把玉攥在掌心，把刚才那点动静在心里从头到尾过了一遍——热来得没有预兆，是从玉心里透出来的；凑近那几道刻痕就烫得凶，手一移开又慢慢凉回去；前后不过五息、三息；没有光，没有声响，也没有气味。刻痕是什么来路、玉为什么发热，他一样都想不明白。想不明白的先搁着，跟矿下遇上说不清的岩层一个道理——记牢，回头有命再琢磨。
>
> 他把玉塞回衣领，凉意重新贴上胸口。指头在那根玉绳上无意识地蹭了蹭——玉没再动，凉的。
>
> 就在这时，沟口上方忽然亮起一束光。是灵石灯——黑石会夜巡矿丁的家什，凡人矿工谁也点不起。白光雪亮，像一把刀切进黑暗，沿着沟壁扫下来，所过之处每块碎石都被照得惨白。苏砚瞬间贴紧岩柱，把呼吸压到最浅，手指扣住凸起岩石，掌心被粗糙岩面硌得生疼。光柱在沟底缓慢移动，照过他歇脚的岩柱——然后停住了。
>
> 碎石被踩动的脚步声从沟口上方传来，由远及近。那束光钉在他藏身的岩壁上，近得他能看见光晕里浮动的尘粒，看见自己的影子被钉死在岩面上。没有移开。
