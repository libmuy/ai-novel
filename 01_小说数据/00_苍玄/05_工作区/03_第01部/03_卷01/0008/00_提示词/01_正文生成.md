## 一、主角人设红线（苏砚）

> ← `01_设定/00_主角档案.md`【人设红线】 ＋ `01_设定/00_文风.md`【本书文风差异】§2

**五条绝对禁止**：

1. **禁宗门天骄模板** —— 永远不是亲传弟子/天才；即便入宗也是外门/记名/杂役，靠熬和算计往上爬，不靠天赋。
2. **禁圣母** —— 不做无底线牺牲；每次救人必须有代价和选择，「先活自己，再救他人」。
3. **禁冷血无情**（约束对象是底层弱者/同伴，不约束对敌人的手段）—— 哪怕成为高阶修士也保留对底层的共情，记得矿下的味道，不说「凡人如蝼蚁」；但对威胁同伴或底层的敌人，允许狠辣、不留退路，狠劲冲着施暴者去，不冲无辜者和弱者去。
4. **力量使用永远有代价；越阶按实力差分级** ——
   - 对方**高两阶及以上**：不正面硬撼；每次交手须有充分准备（阵法/灵傀/古玉/情报预设至少两项），且自身必受损（经脉受损、神魂眩晕、财物耗尽，至少占一样）。
   - **同阶或高一阶**：可持本卷招牌法宝/功法正面接战、正面取胜（高一阶吃力），不强制提前设局；但每战必付即时代价（灵气大耗 / 神魂震荡 / 法宝耐久或经脉损耗，至少一样）＋ 战后可见虚弱期。
   - 任何情况禁「爆种 / 突然觉醒新能力 / 绝境升级」换胜。
5. **禁成为统治阶级代言人** —— 永远不说「上位者也有苦衷」，永远站中下层立场，不洗白垄断与剥削。

**双重人格结构**（本书核心，改写/新写句子时必须校准）：

- **表层（人前）**：活泼开朗、话多带市井粗口、偶尔冷幽默。功能是降低戒心、收集情报、维系底层关系网。
- **里层（独处/推演）**：冷静、**偏执**、**系统性算计**。
- **「里层」不是「冷静」，是「系统性算计 + 偏执」** —— 苏砚算账像在矿下记岩层：把每个变量拆开、逐条过一遍代价。读者该看见的是「这少年脑子转得飞快、什么都算到了」，**不是**「他很淡定」。这是最容易被写平的一条。
- **标志性细节两项分开，不得混用**：紧张时**转手腕旧绳**；推演/算账时右手食指敲**三短一长**（矿下数岩层的节奏，**不是**信号暗号）。
- **切换红线**：表层可以崩溃（濒临绝望、一蹶不振），但里层必须在崩溃后**重新接管**；禁止表层永久覆盖里层，也禁止里层冷血到泯灭人性。
- **叙事红线（计谋/推演类内心活动，← `00_通用写作规则`§6.3 ＋ `01_设定/00_文风.md`【本书文风差异】§2）**：里层推演默认**不叙述具体思路**，只写"敲食指"动作标记＋随后的事实/行动；**禁止**"如果……就……"式分步陈述内心决策链（如"硬顶→被记名→……；忍了→……"）。计谋兑现后靠对话、旁观者反应、后续细节事后回收（"原来那一步是为了这个"），不得在动作发生前把整个盘算端出来。情绪类内心活动（担忧、恐惧、隐忍）不受本条限制，仍按第四节处理。

**弹性空间**（可写，但必须带代价）：对敌撒谎/设局/反间（须承受自我厌恶，且**绝不对同伴撒谎**）；放弃部分财物机缘换人命安全；极端情况下与邪恶势力交易（须付信誉崩塌/心理创伤/被追杀的代价）。小恶有界：可做小恶，必带代价或一丝不安；大恶不做。

## 三、经济锚点（全书单一基准，不得临场另编数字）

> ← `02_数据库/04_资源/04_资源_经济.md` ＋ 用户裁决（记于 `00_进度.md`）

- 凡人货币 ＝ **碎灵石**（按枚计）。**不叫「铜钱」**。
- **1000 碎灵石 = 1 下品灵石**。
- **废灵石**＝矿里撬的含微量灵气废矿料，交征收点**按重量折算**；暗规约「**三两废灵石 ≈ 一枚碎灵石**」（管事压秤后更低）。
- 一副**止咳散 ≈ 10 枚碎灵石**，够病人吃两日。
- **续命丹 ≈ 300 下品灵石 = 30 万碎灵石** —— 凡人够不着，这是绝望的天花板。
- 苏砚**两个钱袋分开**：十年攒的约 10 枚碎灵石是**压箱底救命钱**；日子靠当天工钱流水。
- **记账纪律**：凡俗货币与修士货币**分列不混算**；工钱/克扣是**流量**，积蓄是**存量**，不得混记。

## 四、文风与情绪引擎

> ← `01_设定/00_文风.md`【本书文风差异】§1、§3、§6.4、§6.6 ＋ `00_通用模板/01_写作规则/00_文风_底层成长流.md`

- **反差共情**：强者做极冷漠的事 ⟷ 弱者做极温热的事，读者自己判断谁更像人，**作者不旁白评判**。
- **表里反差**：读者比对手**更早一步**知道「他在演」。
- **付出回报不对等**：苏砚出力 A、回报远小于 A 甚至为负 —— 底层视角的核心情绪，靠**事实并置**，不靠煽情。
- **感悟依附事件**：任何道理/感触都挂在**具体动作或物件**上；**禁无事件支撑的顿悟金句**；单章至多 1 句缓冲金句。
- **句子**：偏短促；意象从**矿井/岩石/身体劳作**里取；少书面成语堆砌；对白带市井口音，别文绉绉。
- **幽默与崩溃的配比**：压抑期允许苦中作乐/自嘲，但压抑超过 2 章后幽默**逐次递减**；**真实绝望/崩溃只允许出现在压抑周期节点**（短周期第 3 章 / 中周期第 5-6 章 / 长周期第 10 章后），非节点章一律不许崩溃。 <!-- REDLINE-ok: 「第N章」指压抑周期内序数、非小说章号（通则同 00_通用写作规则 §7.1） -->
- **爽感禁忌**：爆种、敌人降智、白给资源、无条件帮助 —— 一律禁；「越阶秒杀」按实力差分级——高两阶及以上禁正面碾压，同阶/高一阶可带即时代价正面打赢（见第一节④）。

## 七、结构与节奏通则

- **开篇 300 字**：第一句是**动作或异常**；禁天气/环境/心情/背景/回忆入戏。
- **场景**：2-5 个；相邻场景功能不重复（推进/揭示/情感/转折），**不连续两个「转折」**。
- **同质内容**：单场纯打斗/纯对话/纯感悟 ≤1000 字（开篇三章 ≤800 字）。
- **事件:感悟 = 7:3 ±15%**；感悟段落 ≤300 字（开篇三章 ≤200 字）。
- **新设定 ≤3 个**，每个须在同章或下章产生叙事效果。
- **对话 3-5 句**内并穿插动作/环境描写。
- **章末必须有钩子**（轻钩起步；「无钩」仅卷末喘息章），禁圆满收尾；钩子强度对齐事件类型，节奏由卷纲统筹（连续同强度 ≤3 章）。
- **禁脑补（硬约束）**：细纲未列出的道具、机制、因果链、场景，一律不得自行添加。**留白处宁可不写，不得脑补。** 新增任何名词性设定须在同章产生叙事效果且可登记。

## I. 本章道义 · DY-002

### 道义条目 · DY-002
**道义类型**：善恶类

**道义表述**：
魔修杀人用的是刀，正道杀人用的是规矩——刀还有躲的时候，规矩躲不了。

**核心含义**：
善恶的边界不在执行者心中，而在制度的字里行间。最危险的恶是穿了"规矩/正义/传统"外衣的恶，因为它让你骂不出口。

**表现范式**：
- 冲突类型：个体良知 vs 制度合理性
- 选择结构：发现制度的恶意后，是服从、反抗还是利用？
- 代价结构：反抗的代价（被边缘化、失去机会）vs 服从的代价（良心磨损）
- 人物关系变化：与制度执行者的关系从理解到质疑
- 价值矛盾：制度的表面正义 vs 实际后果的非正义

**禁忌写法**：
禁止脸谱化反派（如青面獠牙的魔修）；禁止"他忽然明白善恶"的顿悟式写法；善恶必须通过具体规则/制度的运作来呈现，而非人物自白或旁白总结。

**校验问题**：
本章的"恶"是否穿了"规矩/正义/传统"的外衣？主角是否发现了这套外衣下的具体运作机制（如条款细则、执行流程、利益链条）？反派（或制度）是否有自洽的逻辑，而非单纯"坏"？

**深化方向**：
- 初期：善恶是简单的，好人坏人一眼可辨
- 中期：善恶是复杂的，发现"好人"也在作恶
- 后期：善恶是相对的，理解每个人都有自己的"正义"

## 八、单章一站式自检清单（唯一校验入口）

> 生成任意一章正文后，**必须逐项勾选以下所有项目方可存档**。本清单是全书的**唯一章节校验入口**，整合了所有模板的校验要求。**用法**：每章生成后逐项自检；数据层与版权层涉及"登记/填写卡片"的项，须在对应数据文件中实际操作；风格层校验项（情绪引擎、爽感循环、主角人设红线）以所选文风模板为准。

### 【结构层】

- [ ] 本章是否自然体现了道义？（允许"埋设"或"揭示"，不强制固定结构）
- [ ] 道义密度是否合理？（软约束，无硬性配额；过度使用同一道义会削弱叙事张力）
- [ ] 事件:感悟比例是否符合本书所选文风的比例设定（默认 **7:3 ±15%**）？（感悟/说教≤30%，打斗/冲突≤70%，按所选文风微调）
- [ ] 结尾是否有钩子？（重钩或轻钩，禁止圆满收尾）
- [ ] 开篇300字是否满足"动作或异常入戏"？（禁止天气/环境/心情/背景/回忆入戏）
- [ ] 是否有"无脑爽"行为？（越阶秒杀/爆种/敌人降智/白给资源/无条件帮助）
- [ ] 同一性质内容（纯打斗/纯对话/纯感悟）是否连续超过 **1000字**？（开篇三章800字）
- [ ] 新设定是否超过 **3个**？（每个须同章或下章产生叙事效果）
- [ ] 感悟段落是否超过 **300字**？（开篇三章200字）
- [ ] 对话是否控制在 **3-5句** 内并穿插动作/环境描写？
- [ ] 是否连续两章用同一种钩子（重钩/轻钩）？
- [ ] 是否出现连续两个以上的华丽形容词？
- [ ] 专有代价术语是否堆叠？（单章点名≤1个，其余用"代价/损耗/反噬"等通用表达，见 §6.4）

### 【爽感与压抑层】

- [ ] 本章是压抑章还是爽感章？
- [ ] 若为压抑章：已连续压抑多少章？是否超过3章未释放？
- [ ] 若为爽感章：爽感来源是否来自第七章"允许清单"？是否满足前置条件？爽感循环是否符合所选文风模板？
- [ ] 爽感释放后，是否立刻跟进代价结算或新的隐患？
- [ ] 读者预期情绪是否为"爽但担心"或"憋屈但期待"？（禁止"纯憋屈"或"纯爽"）

### 【数据层】

- [ ] 所有**新出场角色**（有姓名）是否已登记到人物卡数据？（`@人物.姓名`）
- [ ] 所有**新埋设伏笔**是否已登记？新号 = `03_规划/00_伏笔总纲.md`（FH 总账，**唯一权威**）已用最大号 +1，并同步登记进总纲；本卷伏笔册 `00_伏笔册_《卷》.md` 补埋设位置与拟回收卷/章（`audit_consistency.py` 的 `FS001`/`FS005` 据此校验）
- [ ] 所有**新获取/消耗/损毁资源**是否已登记到 04_资源 对应类别文件的物品清单？（`@资源.名称`）
- [ ] 若有**战斗**，是否填写了战斗结算卡？（08_战斗结算模板）
- [ ] 若有**跨体系战斗**，是否填写了战斗卡「跨体系冲突」区块？
- [ ] 若有**突破**，是否填写了突破卡？（09_主角突破卡模板）
- [ ] 若有**两难抉择或感悟闭环**，是否填写了事件与感悟卡？（10_事件与感悟卡模板）
- [ ] 涉及对象的**状态变更**是否已登记到章级状态履历？（`05_工作区/《部》/《卷》/《章》/02_状态/01_状态履历.md`，按 `00_通用模板/03_字段词表.md` 语法要求填写）

### 【版权层】

- [ ] 是否出现禁词清单中的内容？（知名作品原词、现实宗教原教义、历史典故——见 `02_版权安全` §1.2/§1.3/§1.4）
- [ ] **正文散文里是否出现了现实书名/作者名？**（现实古籍**文句可用**，只须不具名——见 `02_版权安全` §1.1；虚构书系为可选承载。卷首题记/章末铭文可注明出处，不受此限）
- [ ] 古籍引用是否控制在 **30字以内**？引用后是否立刻回到剧情、不做解释？
- [ ] 是否有"常见网文金句"或"现实名人名言"的影子？（若有，用主角自己的语言改写，或按 `02_版权安全` §3.1「仿古体化用/去皮留核」再造；纯现实古籍原句不在此列，可直接引）
- [ ] 所有角色/势力/地名是否与知名作品撞名？

### 【主角人设层】

- [ ] 主角行为是否符合本书所选文风模板的「主角人设红线」？
- [ ] 若做道义选择，是否承担了**具体且无法立刻化解**的代价？
- [ ] 若获收益，是否伴随**至少一个隐患或代价**？
- [ ] 若与人结盟，对方帮助是否有**利益交换或情感铺垫**？（禁止无条件帮助）
- [ ] 若杀人夺宝，是否结算了**消息传播路径**和**后续追查**？
- [ ] 情感表达是否用**动作/环境细节**替代直接写情绪？（禁止"他感到悲伤"）
- [ ] 计谋/推演过程是否**未实时叙述思考链条**？（只写事实+行动，结果达成后再事后回收，见 §6.3）

### 【资源与经济层】

- [ ] 出现的资源等级是否与主角当前境界匹配？（禁止低境界持高阶资源无代价）
- [ ] 经济交易是否符合已设定的兑换比例？（禁止随意更改灵石兑换率）
- [ ] 主角财务状态是否与 `04_资源_经济.md`【财富分级基准表】对应境界的典型持有量一致？

### 【事件设计层】（战斗/突破/资源三类事件红线的唯一自检执行入口）

**战斗**（08_战斗结算）：
- [ ] 禁止越阶秒杀？（弱于对方时必须靠策略、环境、代价取胜/逃脱，禁"爆种反杀"）
- [ ] 禁止敌人降智？（乙方必须有合理战术）
- [ ] 禁止无伤胜利？（即使赢，甲方也要付出代价：伤势、消耗、暴露底牌）
- [ ] 禁止战斗后无传播？（结果必须有人知道、有传播路径）
- [ ] 禁止杀人无后果？（只要有人死亡，必须有后续追查）
- [ ] 禁止连续战斗无恢复？（两场战斗间必须有恢复/准备时间）

**突破**（09_主角突破卡）：
- [ ] 禁止无代价突破？（三重门槛见 §7：资源+心境+外部，至少一项代价）
- [ ] 禁止"顿悟突破"？（必须有具体积累）
- [ ] 突破后战力评估是否诚实？（禁"同阶无敌""越阶秒杀"）
- [ ] 禁止"突破即满血"？（突破中受的伤、耗的精力必须保留）
- [ ] 禁止连续突破？（两次间隔至少 10 章或一个完整事件）
- [ ] 禁止突破后无感悟？（每次突破必须伴随感悟闭环）

**资源**（04_资源·物品卡）：
- [ ] 禁止无来源资源？（任何资源必须有获取方式）
- [ ] 禁止无限制神物？（高阶资源必须有使用条件或副作用）
- [ ] 禁止随意定价？（价格必须与 `04_资源` 一致）
- [ ] 禁止低境高持？（低境界持高阶资源必须有合理来源和"怀璧其罪"隐患）
- [ ] 禁止资源通胀？（同一资源同期价格波动≤±30%，除非有剧情解释）
- [ ] 禁止一次性道具无交代？（消耗品使用后须交代是否补充，法宝损毁后须交代是否修复）

**全部勾选通过，本章方可存档。**

### 【世界规则层】（正文级世界基本法则一致性自检）

> 对照 `01_设定/00_小说概念.md`【世界基本法则】（WR 规则，硬/软/未知三态）逐项检查。未知规则保持未知，禁止自行补全。冲突时报告并修改剧情/下层设定，**禁止修改世界基本法则**。

- [ ] 本章是否违反世界硬规则？（如：随意复活已死亡角色、无来源/无代价力量、角色全知知晓世界全部设定）
- [ ] 角色的认知是否只包含符合其身份、经历、时代和认知能力的信息？（信息与认知法则；禁止默认角色知道世界全部设定）
- [ ] 本章新引入的设定/能力/事件/资源是否与已定稿世界基本法则冲突？（有冲突时：指出冲突位置 → 修改剧情或下层设定；确为剧情异常现象时登记 `05_工作区/《部》/《卷》/《章》/02_状态/01_状态履历.md` 世界对象状态，不得改动世界基本法则）
- [ ] 涉及死亡/灵魂/复活/夺舍/轮回的内容是否符合生命与死亡法则？
- [ ] 涉及誓言/契约/命运/时间的能力是否符合因果法则与空间与时间法则？
