      → 锚点：「背上刚结痂的鞭伤瞬间崩裂，鲜血淌在冰冷的岩石上」+「血水顺着下巴滴在胸前的古玉上」

## 第4场景

- [x] 涉及资源：周莽留下的缺嘴酒葫芦（内半壶药酒，苏砚用于消毒鞭伤——回收第2场景）；突破结果见【本章突破卡】
      → 锚点：「摸索着抓起地上的那只酒葫芦，拔开塞子，一股浓烈的药酒味冲散了血腥气」

      → 锚点：「他听清了那咳声末尾，带着一种沉重、粘稠的水音。一种他说不清的坏。」

      → 锚点：「脑袋里天旋地转，眼前看什么都是重影」+「拄着当拐杖……扶着石壁走走停停，慢慢朝矿道口的方向挪去」
- [x] 要点：代价要分清两层（供正文与第05章衔接对齐）：① **肉身体力/耐击打是实打实翻倍的**——他能勉强撑着把翻倍定额干完（虽然每一镐下去经脉都刺痛、比往常慢得多、干干停停）；② **新醒的一线灵根细弱、又被经脉隐伤锁着，灵气与神魂这一块是废的**——数息一竭、眩晕未退，接下来约两章打不出刚突破时感到的那个上限，遇战即险。"变强了却用不出全力"是本章代价的核心。（第05章可试出他此后能否自行吐纳——按裁决他有微末灵根、能极缓自行修行，只是这两章废着。）
      → 锚点：「变强了，却根本用不出全力，数息一竭」
- [x] 要点：酒葫芦回收：用第2场景周莽留下的酒葫芦里的药酒擦鞭伤——既回收标志物，也让"周莽护着他"这份情落到具体动作上。
      → 锚点：「他反手将大半药酒浇在自己血肉模糊的后背上」
- [x] 要点：情绪定调：周莽的咳声只带来一种沉重、模糊的不安，**不能写"他撑不了多久""得快点"这类判断句**。
      → 锚点：「一种他说不清的坏」
- [x] 要点：感悟落地：周莽逆着火光走远的背影与"别问哪来的"那句话回上心头，与刚脱胎的肉身剧痛交织——"善良撑不住自己的时候，得有人拿命垫"。不点古籍。
      → 锚点：「周莽逆着火光走远的背影，和那句别问哪来的交代，在脑海里挥之不去。……善良撑不住自己的时候，得有人拿命来垫。」
- [x] 要点：生存压迫感：突破没带来立刻翻盘的轻松——十五枚碎灵石的债、悬欠的护矿费还压在头顶，力量只让他有了"暂时不上砧板"的资格。章末他攥紧手、知道自己得站稳脚跟，但不下"要快"的结论。
      → 锚点：「十五枚碎灵石的债还在账上，护矿费窟窿也没填上。」
