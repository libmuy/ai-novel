### 场景1 · 矿道收工

| 项目 | 内容 |
|------|------|
| 场景功能 | 推进 |
| 字数 | 700 |
| 空间 | @区域.[鬼见愁矿层] 支巷末端 |
| 时间 | 收工前，矿灯将尽未尽 |

**简述**：
苏砚在「鬼见愁」矿层最末一条支巷里撬最后一块废灵石。矿钉入岩的闷响、掌心旧茧的触感、矿灯将熄时视野边缘的黑暗——先以感官细节把读者按进矿道。他撬下一块废灵石，掂在手里约四两五钱，成色中上；按矿里暗规，三两废灵石折一枚碎灵石，这块该折一枚半。他心算：加上昨日没花完的一枚，今日若不被管事刁难，能凑到两枚半——离一副止咳散（十枚碎灵石）还差得远，但够给娘的药钱添一星半点。废灵石交到征收点按重量与成色折算成碎灵石，是凡人流通货币，这是矿上人人知道却没人敢明说的暗规。

收工号子响起时，他无意识转了两圈手腕上那根褪色旧绳——那是紧张或情绪起伏时的老习惯。他把废灵石揣进怀里，矿钉插回腰带，随人流往井口走。路过主巷时，他瞥见岩壁上新刻的监工告示：「仙师巡察，停工三日」——字是朱砂写的，凡人连抬头多看一眼都不敢。

**情绪钩子**：
旧绳在腕上勒出浅痕。他低头看了眼掌心裂口渗出的血珠，没擦，让它自己干——擦了，明天还得裂。

**涉及资源**：
- 废灵石（一块，约四两五钱，成色中上）
- 碎灵石（昨日存量一枚，本章不动）

**出场对象**：
- @人物.[苏砚]（主视角）
- @物品.[矿钉]
- 矿友（群像，无名，不建卡）

**伏笔 / 线索**：
- DY-006 埋设 0.5 条：告示上的「仙师」二字，苏砚只扫了一眼就垂下目光——不是敬畏，是熟练的回避。不点金句，不硬刚。

### 场景2 · 征收点受辱

| 项目 | 内容 |
|------|------|
| 场景功能 | 揭示 |
| 字数 | 800 |
| 空间 | @区域.[矿务司征收点] |
| 时间 | 黄昏，收工后 |

**简述**：
征收点是一间漏风的石屋，马铁秤坐在桌后，两个打手拄着棍靠在门框上。苏砚把废灵石放上台秤——马铁秤眼皮不抬，秤杆一压，四两五钱的料子成了「三两，成色下等」。按暗规本该一枚半碎灵石，按这一称只值一枚。马铁秤又开口：「三成护矿费，规矩你懂。」但他当日没扣，把一枚碎灵石推过来，说了句「三成记在账上，下月一并算」——记账制的威慑，不是当场扣光，是让你知道有一笔债永远悬在头上。

苏砚接了那枚碎灵石，没道谢，也没争辩。马铁秤忽然笑了，冲打手说：「你看他跪不跪。」——不是问句，是当着众人的宣判。苏砚脊背绷直了一瞬，旧绳在腕上转了三圈。他没跪，但也没抬头，攥着那枚碎灵石走出征收点，背后是马铁秤跟打手的笑骂。他没回头，往家的方向走，心里却已经在盘算——今晚等娘睡下，废矿沟那条老路，还得再摸一趟。

出征收点后他心里有笔细账：应得一枚半，到手一枚，这一天硬生生少挣三分之一还多；「看他跪不跪」那句他记下了。

**场景功能说明**：
本场按「揭示」承担世界第一层展开（克扣/工分/仙凡鸿沟的运作），收在强情绪钩子（当众的下跪威胁）上；其后接「情感」场（场景3）由归家探母承接并放大这份压力，是有意为之，节奏不断裂。DY-006 在此仅作处境埋设，不点题、不硬刚。

**情绪钩子**：
苏砚攥着那枚碎灵石走出征收点，背后是马铁秤跟打手的笑骂。他没回头，往家的方向走，心里却已经在盘算——今晚等娘睡下，废矿沟那条老路，还得再摸一趟。

**涉及资源**：
- 废灵石（四两五钱，被压秤为三两）
- 碎灵石（当日实发一枚整；三成护矿费记账下月算）

**出场对象**：

- @人物.[马铁秤]
- @关系.[马铁秤-苏砚]（管事-矿工，克扣/记账关系）

**伏笔 / 线索**：

### 场景3 · 归家探母

| 项目 | 内容 |
|------|------|
| 场景功能 | 情感 |
| 字数 | 700 |
| 空间 | @地名.[苏家破屋] |
| 时间 | 入夜，掌灯时分 |

**简述**：
苏家破屋在矿村最边缘，半间漏风。苏砚推门时先闻见药味——娘又在熬止咳散。苏母半靠在床头，咳得轻了，见他回来，从枕下摸出一块古玉塞给他：「你爹留下的，老灰……你收着，别让人看见。」那是@物品.[古玉「老灰」]，半块，灰扑扑的，苏砚从小见过无数次，从没异样。

他坐下，把今日两枚碎灵石摊在掌心——昨日剩一枚，今日实得一枚，共两枚。他拿这两枚去矿村药摊换了两成一副的止咳散：一副十枚，两枚换两成，够娘吃一天。换完余零枚。他把药包递给娘，看她就着温水服下，才低声说「今日收成不好」。

娘絮叨起他爹：「你爹当年也是矿上的，要是没那回事……」苏砚没接话，起身去灶间。他自己那份口粮又省了半块——不是不饿，是省下来的碎灵石能换半日药钱。他蹲在灶前，右手食指无声敲出「三短一长」的节奏，那是矿下数岩层的习惯，推演盘算时老毛病。心里一笔账越算越沉：娘的药一副要十枚，他一天上工到手也就一枚上下；这月怕是要动那十枚本金——本金一动，续命丹更是想都不敢想。续命丹约三百下品灵石，合三十万碎灵石，那是仙凡鸿沟另一头的事。

本金那十枚碎灵石，本章自始至终没动，只在心算里被「怕是要动」地掂量。

**情绪钩子**：
娘睡着后，苏砚把古玉揣回自己怀里，贴着肋骨。窗外矿务司的方向还亮着灯，他盯着那片光，食指又敲了一遍三短一长。

**涉及资源**：
- 碎灵石（昨日剩一枚 + 今日实得一枚 = 两枚；换止咳散两成后余零枚）
- 止咳散（一副约十枚碎灵石，劣质凡药，够吃两日；本次换得两成，够一日）
- 本金碎灵石（十枚，存量，本章未动用）

**出场对象**：
- @人物.[苏砚]
- @人物.[苏母]
- @关系.[苏砚-苏母]（母子，病中相依）
- @物品.[古玉「老灰」]
- @财务.[苏砚]（个人收支心算）

**伏笔 / 线索**：
- @伏笔.FH-067 第 1 段：古玉「老灰」首次以「爹留下的」身份出场，为后文器灵觉醒埋线。本章只交玉、不异常。

### 场景4 · 弃矿沟夜探

| 项目 | 内容 |
|------|------|
| 场景功能 | 转折·重钩 |
| 字数 | 800 |
| 空间 | @区域.[弃矿沟] 废巷深处 |
| 时间 | 深夜，娘睡下后 |

**简述**：
苏砚习惯夜里去弃矿沟。那是条废巷，监工不巡，矿友不来，偶有私藏的废灵石能捡漏。他揣着半块私藏的废灵石——今日从主巷顺出来的，硌在肋骨上——贴着岩壁往里摸。古玉贴在胸口，忽然发热、微微震颤。越靠近岩壁上一道旧刻痕，玉温越烫。那刻痕他见过无数次，是早年塌方留下的凿印，从没异样。

监工的灯光从巷口扫来。苏砚屏息退进岩柱阴影，离刻痕渐远，玉温随距离缓缓回落，到藏身时已是温的，还没凉透。他贴着岩柱没动，等灯光移走，才低头看了眼怀里——古玉贴着胸口，温吞吞地烫，像揣了块没熄透的炭。

他没慌。先把半块私藏废灵石的重量和位置在心里记了一笔账：若明日征收再被压秤，这块能补半枚碎灵石的缺口。然后他才把注意力放回古玉——反常，但今晚不追究。娘的药钱、马铁秤的账、下月的护矿费，哪一桩都比一块古玉的温度更迫眉睫。他精明地给这桩异常记了笔「待查」，主动搁置。

但灯光又扫回来了。这一次，光柱停在他藏身的岩柱前——监工似乎听见了什么，或者看见了什么。苏砚怀里，那半块废灵石硌着肋骨，古玉温吞吞地烫。他一动不动。

**情绪钩子（章末重钩）**：
怀里半块废灵石硌着肋骨，古玉贴着胸口，温吞吞地烫，像揣了块没熄透的炭。巷口灯光没移开。

**涉及资源**：
- 废灵石（半块，私藏，硌在肋骨上）
- @物品.[古玉「老灰」]（发热异常，渐进降温：近刻痕最烫 → 退后缓缓回落 → 藏身时温的未凉透）

**出场对象**：
- @人物.[苏砚]
- 监工（无名，不建卡，仅灯光/人影存在）

**伏笔 / 线索**：
- @伏笔.FH-067 续埋：古玉近旧刻痕发热，器灵未说话，苏砚精明记账+主动搁置，为后文回收留口。
- 半块私藏废灵石 → 第2章开场回收。

**与第2章衔接点**：
章末灯光锁定怀中鼓囊（私藏废灵石），古玉发热之谜未解，苏砚被困在岩柱阴影中——第2章开场从此刻接续。

## 【开篇300字方案】

**目标**：让读者在300字内进入苏砚的身体，建立「矿道=压迫=生存」的体感。

**节奏**：感官细节（触觉/听觉/嗅觉）→ 动作（撬石）→ 心算（经济压力）→ 情绪锚点（旧绳）。

**标志性细节**：
- **紧张 / 情绪起伏时**：无意识转手腕上那根褪色旧绳。开篇300字保留此细节（此刻是收工、非推演场景）。
- **推演 / 盘算时**：右手食指无声敲出「三短一长」（矿下数岩层的节奏）。开篇300字暂不出现，留到场景3归家后首次展示。

**开篇片段（供正文参考）**：
> 矿钉入岩的闷响，在支巷里撞出三重回音。苏砚掌心抵着钉尾，虎口裂口渗出的血把木柄浸得发黏。他数着呼吸——第七下，废灵石从岩缝里松动了。他把它撬下来，掂在手里：约四两五钱，成色中上，按暗规该折一枚半碎灵石。加上昨日没花完的一枚，今日若不被管事刁难，能凑到两枚半。离一副止咳散还差得远，但够给娘的药钱添一星半点。收工号子从主巷传来，他无意识转了两圈腕上那根褪色旧绳，把废灵石揣进怀里，随人流往井口走。
