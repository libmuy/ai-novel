## 模板二：00_通用写作规则（技艺层唯一权威）

```markdown
# 通用写作规则

## 一、固定文风比例（基准）
七分：修仙事件/打斗/冒险/资源争夺/秘境探索；三分：人心取舍/道义感悟/古籍点题/内心成长。
校验：单章感悟/说教≤30%；单章打斗/冲突≤70%；连续两章"事件:感悟"波动≤±15%。7:3 为基准，文风模板可微调。

## 二、固定写作结构
每章（或每连续两章）必须完成闭环：剧情事件 → 古籍短句点题 → 主角心境道理感悟。
禁止变体：纯说教 / 纯打斗流水账 / 空洞讲道理。

## 三、每章黄金结构
### 3.1 开篇300字规则
- 第一句：必须是**动作**或**异常**，禁止天气/环境/心情铺垫。
- 前100字：必须出现**主角** + **冲突/危机/异常**。
- 前300字：必须让读者产生"然后呢？"的冲动。
- 可选入戏方式（四选一）：① 危机入戏 ② 悬念入戏 ③ 两难入戏 ④ 伏笔入戏。
- 禁止入戏方式：环境描写、心情铺垫、背景介绍（"这个世界分为……"）、回忆入戏（"三年前……"）。
### 3.2 中段结构规则
- 松紧搭配：前段打斗/冲突→中段插对话或内心评估；前段日常/对话→中段安排小冲突或危机。同一性质内容连续不得超过 1000 字（**开篇三章 800 字**）。
- 信息释放：每章新信息（新角色/新设定/新悬念）≤3个；每个必须同章或下一章产生叙事效果。
### 3.3 结尾钩子规则
- 重钩（关键章节/卷末）：未解决的危机、突发变故、隐秘伏笔显现、两难困境激化。
- 轻钩：伏笔暗现、自我疑惑、未说破的一句话、反常细节。
- 频率：每3章至少2重1轻；重大情感释放后必须用轻钩。
- 禁止结尾：圆满收尾、纯说明收尾、时间跳跃收尾、感悟收尾无钩子。

## 六、情感表达规则
### 6.1 禁止直接写情绪
删除"他感到悲伤/愤怒/失落"；替换为：具体动作 / 环境细节 / 物品互动。
### 6.2 情感戏对话控制
每段对话 3-5 句内；必须穿插动作/环境描写；禁止超过 100 字的无打断独白。
### 6.3 代价术语统一简化
正文承接代价描写默认用"代价/损耗/反噬/折寿"等通用词；专名点名仅两处（体系首次登场点题处、代价成为本章转折核心处）；单章点名专有代价术语 ≤1 个。

## 七、爽感释放机制
- **无脑爽禁令**：爽感必须来自"提前布局、合理前置、兑现代价"，禁五类——① 越阶秒杀（越阶须≥2个外部条件）② 绝境"爆种"反杀 ③ 敌人突然降智 ④ 盟友无条件帮助 ⑤ 杀人夺宝后无人追查。
- **突破门槛**：突破必须同时满足 资源条件 + 心境条件 + 外部条件 三重门槛，缺一不可。
### 7.1 压抑周期控制
| 周期 | 连续压抑上限 | 必须释放 |
| 短 | 3章 | 小爽感（脱险/获关键信息/结识可靠盟友） |
| 中 | 8章 | 中爽感（布局反杀/以弱胜强智斗/隐忍后资源获取） |
| 长 | 15章 | 大爽感（绝地反击/伏笔华丽回收/突破后首次碾压） |
压抑定义：资源持续流失 / 关系持续恶化 / 道义选择持续吃亏 / 信息持续匮乏。

## 八、单章一站式自检清单（唯一校验入口）
生成正文后逐项勾选。细纲阶段按此**预检**（下文【验收自检】已提炼本章适用项）。
【结构层】道义自然体现 / 事件:感悟 7:3±15% / 结尾有钩子 / 开篇300字动作或异常入戏 / 无"无脑爽" / 同质内容连续≤800字（开篇三章）/ 新设定≤3 / 感悟段≤200字（开篇三章）/ 对话3-5句 / 不连续两章同钩 / 不连续两个华丽形容词 / 专有代价术语不堆叠。
【爽感与压抑层】压抑章还是爽感章 / 连续压抑≤3章 / 爽感来源在允许清单 / 爽感后立刻跟代价或隐患 / 读者情绪为"爽但担心"或"憋屈但期待"。
【数据层】新角色登记人物卡 / 新伏笔登记伏笔册 / 新资源登记 04_资源 / 战斗填结算卡 / 突破填突破卡 / 抉择填事件卡 / 状态变更登记 01_状态履历.md。
【版权层】无禁词（知名作品原词/现实宗教原教义）/ 古籍引用来自本书虚构典籍 / 引用≤30字且引后立刻回剧情 / 无网文金句现实名言影子 / 角色势力地名不撞名。
【主角人设层】符合文风模板「主角人设红线」/ 道义选择承担具体且无法立刻化解的代价 / 获收益伴随隐患 / 结盟有利益或情感铺垫 / 杀人夺宝结算消息传播与追查 / 情感用动作环境替代直接写情绪。
【资源与经济层】资源等级与境界匹配 / 交易符合兑换比例 / 财务与【财富分级基准表】一致。
【世界规则层】不违反世界硬规则（随意复活/无来源无代价力量/角色全知）/ 角色认知只含符合其身份经历时代的信息 / 新设定不与世界基本法则冲突。

## 九、主角人设红线（底层成长流）
底层出身、坚韧守底线懂取舍、遇事先明理、禁开局即巅峰、突破须三重门槛。
```

## 模板三：05_开篇三章设计指南（前三章专属规则）

```markdown
# 开篇三章设计指南

**核心原则**：开篇三章不是"铺垫"，而是"契约"——与读者签订"这本书将给你看什么"。三章之内必须让读者明确：主角是谁、世界有多残酷、这本书和其他修仙文有什么不同。

## 一、三章功能定位（不可互换）

### 第一章：立人——主角是谁？（★本次任务）
**功能**：让读者 300 字内记住主角，3000 字内理解主角的"独特之处"。
**必须完成**：
1. **底层出身锚定**：明确出身（凡人/散修后裔/小家族/战乱遗孤），必须"底层"。忌宗门天骄、转世大能、系统加身。
2. **核心性格亮相**：通过一次具体行动展示"谨慎"与"底线"——不是旁白说"他很谨慎"，而是他**做了**一件谨慎的事。
3. **第一次"内心评估"**：面对新情况至少一次内心评估（实力/退路/风险/值不值得）。
4. **世界的第一层展开**：展示环境的"日常残酷"（赋税、饥荒、仙凡鸿沟、修士冷漠），只展示现象、不解释世界观。
**禁止**：天气/环境/心情铺垫入戏；超过两个有名字的角色；解释修炼体系/境界划分/世界历史；金手指、系统、老爷爷、神秘声音；宏大理想宣言（"我要成仙"）。

### 第二章：立界——世界有多残酷？（下一章，本章须为其铺垫）
第一次外部冲突（与"人"、围绕"资源"）；展示"利益优先"法则；主角第一次"吃亏"且不立刻报复；引入第一个"信息差"。

### 第三章：立约——这本书有什么不同？
第一次"道义选择"（利益 vs 底线，选 B，代价不可 3 章内化解）；世界观第二层展开；引入第一个"长期悬念"（埋中/长伏笔，3 章内不回收）；建立"七分三感"节奏契约。

## 二、前三章额外限制（在 00_通用写作规则 之上加严）
| 维度 | 前三章加严 |
| 开篇300字 | 第一章第一句必须**同时**展示**底层出身**和**谨慎性格**（一石二鸟） |
| 连续同质内容 | 不超过 **800字** |
| 感悟段落 | 不超过 **200字** |
| 结尾钩子 | 第1章重钩、第2章轻钩、第3章重钩，禁止连续两章同钩 |
| 金手指 | 第三章前禁止任何"金手指"或"天降机缘" |
| 新设定 | 三章内合计≤**9个**；且必须与主角当前困境直接相关 |
| 新角色 | 三章内有名字角色合计≤**7个** |

> **祖传/开篇前已持有的异宝 ≠「天降机缘」，但三章内仍须「零收益」**：主角开篇前就带在身上的家传信物/异宝，不算"第三章前的天降机缘"（不是三章内获得的）。但在开篇三章里，它**只能留悬念、不能给任何实际好处**——不得内视、开辟空间、加速修炼、预警危险、提供情报、增强战力。它的作用限于"发热/共鸣/异动"这类勾起读者与主角疑问的表现。真正的能力兑现（如借它入道）放到第四章及以后。破了这条，等同于金手指提前生效。

## 三、主角人设落地规则（开篇三章专用）
### 3.1 "谨慎"的展示规则
开篇三章必须完成**至少三项**以下行为，且通过**动作和内心评估**展示（禁止旁白说"他很谨慎"）：① 遇事先找退路；② 动手前观察（评估对方实力）；③ 准备后手（留至少一个备用方案）；④ 不轻易相信（不透露真实姓名/来历/目的）；⑤ 能跑就跑（面对明显强者第一反应是逃）；⑥ 试探陷阱（得到机缘前先以最低成本试探）。
### 3.2 "底线"的展示规则
开篇三章必须完成一次"吃亏的道义选择"（第三章）；选择后同章内承受具体损失；回报不得在前五章内出现；至少一个旁观者不解或嘲笑。
### 3.3 "底层视角"的展示规则
开篇三章必须通过**至少两个细节**展示底层出身：① 资源计算细节（对每一颗灵石/每一口食物的价值有精确认知）；② 身体记忆细节（凡人时期习惯：走路避开石板缝隙、吃饭先舔干净碗边）；③ 语言细节（底层口音或习惯用语）；④ 知识盲区细节（对某些修仙界常识一无所知）。

## 四、世界观展开节奏（三层冰山）
开篇三章只展示世界**第一层**（日常残酷：凡人被漠视、资源稀缺、杀人夺宝常见——主角亲身经历，非旁白介绍）。第二层入口在第三章埋；第三层只埋一个极隐伏笔。

## 五、与后续章节的衔接规则
### 5.1 第三章结束时的状态要求
```
