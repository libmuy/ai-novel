# 苍玄 · 云端提示词档案说明

> 本目录存放《苍玄》**全书级**规划任务的云端提示词执行缓存（一任务一文件），供复制到浏览器端云端大模型执行。每次执行前必须依据最新 `00_进度.md` 和定稿数据重新拼装；数据或前置状态变化后，旧缓存不得直接执行。
> 卷级/章级提示词分别存于 `05_工作区/《部》/《卷》/00_提示词/` 与 `.../《章》/00_提示词/`。
> 文件名不带"提示"后缀（`NN_<任务名>.md`）；云端产出回填文件与提示词**同名**、落在同级 `01_模型输出/`。任务 01~04、08 为**合并单文件输出模式**（见下方说明）。

## 合并单文件输出模式（任务 01~04、08）

任务 01~04、08（多文件拆分类：修炼体系/地理区域/势力组织/资源/书籍库）的云端提示词要求云端把一次任务的全部产出**合并为一个 Markdown 文件**整体输出，每个目标文件用 `<!-- FILE: 输出路径 -->` … `<!-- /FILE -->` 区块标记分隔。

执行流程：
1. 按通用提示词生成器基于当前定稿数据重新生成对应缓存（文件头注明"执行前重建"；任务 01~04、08 另注明"合并单文件输出模式"），再复制到云端执行；
2. 云端整体输出一个 Markdown 文件；
3. 保存到 `05_工作区/01_模型输出/<存档同名>`（与本目录对应提示词同名）；
4. 请 OpenCode 执行"云端回填分割"，按 `00_通用模板/01_写作规则/07_云端回填分割规则.md` 分割回填到 `02_数据库/` 对应文件并校验、更新 `00_进度.md`。

任务 00、05~07、09~11 为单文件产出任务，不启用合并模式。

## 固定骨架

提示词由 OpenCode 按 `00_通用模板/04_提示词/00_云端提示词生成器.md` 的固定骨架拼装，六段结构如下：

| 段落 | 内容 |
|------|------|
| 【你的角色】 | 规划师/设定师，严格按给定模板与数据行事，禁止凭空编造；先以多轮问答引导用户补齐必要信息，齐备后再生成 |
| 【必读模板】 | 本任务相关卡片模板/写作规则全文（单次 ≤4 个，以模板文件名为区块标题内联） |
| 【已有数据】 | 本小说已定稿数据（保证一致性） |
| 【任务目标】 | 生成 XX → 对应 01_设定/、02_数据库/ 或 03_规划/（任务00含"未齐备不生成"约束） |
| 【输出格式】 | 严格按上文【必读模板】内联模板的字段 + @引用/ID 规范；冲突以【已有数据】段为准 |
| 【验收自检】 | 字段齐全 / @引用可解析 / 版权道义红线 / 数值符合资源 |

云端大模型直接执行提示词生成规划产出，不会访问仓库；因此模板规则与数据全部内联。存档文件不得残留 `{{占位符}}`。
