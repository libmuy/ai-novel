### 数据2：主角档案（核心摘录）

**苏砚** | 16岁/凡人 | @地名.[枯港矿城]底层矿工

**核心特殊性**：「底层视角的推演执念」——非天赋异禀、非系统加身，而是将矿井下观察岩层裂纹、通风走向、监工巡逻规律的生存本能，升华为对人心、局势、功法的系统性推演。古玉「老灰」仅提供 raw data（原始数据），苏砚负责 pattern recognition（模式识别）。

**双重人格结构**：
- **表层（人前）**：活泼开朗、话多带市井粗口、紧张时转旧绳、偶尔冷幽默。功能：降低敌人戒心、收集情报、维系底层关系网。
- **里层（独处/推演）**：冷静、偏执、系统性算计。功能：敲食指（三短一长）进入推演模式，古玉 raw data + 自主 pattern recognition。

**修行体系**：主修玄元道 + 兼修阵纹道（提前布阵）+ 灵傀道（矿傀/骨傀牵制）

**核心矛盾**：修术 vs 修心——在弱肉强食的修仙界，变强是活下去的唯一手段，但变强的过程处处要求放弃底线。

**本卷状态**：出场时底层少年，对修仙界一无所知，带着"治好母亲"的执念入场。手腕上缠着母亲编的褪色旧绳，紧张时会无意识地转。

**本卷弧线**：第一阶段——学会"修仙界没有公道，只有规则"。从坚信"努力就有回报"转变为明白"弱即是罪，尊严是奢侈品"。

**说话风格**：底层口音 + 市井粗口，紧张时话多且带冷幽默；偶尔蹦出金句，扎心又扎肺。对敌人用"矿下骂人话"；对同伴用"矿上黑话"。

**标志性细节**：① 转旧绳（紧张时）② 敲食指（推演时，三短一长）③ 吐唾沫（杀人或见血后）

### 数据3：本卷必须落地的道义——DY-006（尊严类）

**道义表述**：跪着活是活，站着活也是活；区别是，跪着的人看谁都像膝盖，站着的人看谁都像眼睛。

**核心含义**：尊严不是奢侈品，而是人之所以为人的底线。在极端压迫下，放弃尊严可以换来生存，但失去的东西比命更重。

**表现范式**：
- 冲突类型：生存压力下的屈辱选择——服从压迫换取生存 vs 抵抗压迫付出代价
- 选择结构：主角面临"跪下就能活"的诱惑
- 代价结构：选择尊严的具体损失（资源/安全/人情）vs 选择屈辱的心理代价
- 人物关系变化：旁观者的嘲笑/不解 vs 同类的共鸣
- 价值矛盾：生存的必要性 vs 人格的不可交易性

**禁忌写法**：禁止主角在无具体压迫场景时旁白"悟了"尊严；禁止用"天命如此""大势所趋"来合理化屈服；禁止选择尊严后立刻得到回报。

### 数据4：世界观法则（WR规则·摘录）

- **WR-001**：世界有四大修炼体系（玄元道、灵傀道、阵纹道、命契道），各有独立规则
- **WR-003**：力量有来源——任何能力必须有明确来源（修炼/法宝/丹药），禁止无来源力量

## 【规则约束】

### 开篇三章设计指南（第一卷必读）

**第一章：立人——主角是谁？**
- 必须在300字内让读者知道主角是谁、面临什么
- 第一句必须同时展示底层出身和谨慎性格（一石二鸟）
- 必须展示：底层出身锚定 + 核心性格亮相 + 第一次内心评估 + 世界的第一层展开（日常残酷）
- 禁止：天气/环境/心情铺垫入戏；超过两个有名字的角色；解释修炼体系；金手指、系统、老爷爷；宏大理想宣言

**第二章：立界——世界有多残酷？**
- 让读者理解世界运行规则是"利益优先，善恶其次"
- 必须展示：第一次外部冲突（围绕资源）+ "利益优先"法则 + 主角的第一次"吃亏" + 引入第一个"信息差"
- 禁止："纯粹为了坏而坏"的反派；主角获得明显收益；解释四大体系完整设定

**第三章：立约——这本书有什么不同？**
- 让读者意识到"这不是普通的修仙爽文"
- 必须展示：第一次"道义选择"（DY-006尊严类）+ 世界观第二层展开 + 引入第一个"长期悬念" + 建立"七分三感"节奏契约
- 禁止：主角"顿悟"或"突然变强"；圆满收尾；超过500字的设定解释

**前三章额外限制**：
| 维度 | 通用规则 | 前三章加严 |
|------|---------|-----------|
| 开篇300字 | 第一句动作/异常 | 第一章第一句必须同时展示底层出身和谨慎性格 |
| 连续同质内容 | 不超过1000字 | 不超过800字 |
| 感悟段落 | 不超过300字 | 不超过200字 |
| 结尾钩子 | 每3章至少2重1轻 | 第1章重钩、第2章轻钩、第3章重钩 |
| 金手指 | — | 第三章前禁止任何"金手指"或"天降机缘" |
| 新设定 | 每章≤3个 | 三章内合计≤9个 |
| 新角色 | — | 三章内有名字角色合计≤7个 |

### 通用写作规则（核心约束）

1. **文风比例**：事件:感悟 = 7:3（±15%）
2. **写作结构**：剧情事件 → 古籍短句点题 → 主角心境道理感悟
3. **开篇300字规则**：第一句必须是动作或异常，禁止天气/环境/心情铺垫
4. **中段松紧搭配**：前段打斗/冲突 → 中段必须插对话或内心评估；前段日常/对话 → 中段必须安排小冲突或危机
5. **结尾钩子**：每3章至少2重1轻；重大情感释放后必须用轻钩让读者"喘口气"
6. **爽感循环**：谨慎布局 → 压抑 → 反杀 → 代价结算 → 新的隐患
7. **突破三重门槛**：资源条件 + 心境条件 + 外部条件，缺一不可

### 本书文风·爽感禁忌（摘录）

- **SJ-003**：古玉 ≠ 全知——古玉仅提供 raw data，推演必须由苏砚完成
- **SJ-004**：燃 ≠ 爆种——战斗燃点必须来自布局兑现或绝境极限操作
- **SJ-006**：灵傀 ≠ 无限——第一卷上限约3~5具低阶矿傀/骨傀
- **SJ-008**：代价 ≠ 虚设——每次爽感释放后的代价必须在至少1章内真实结算
