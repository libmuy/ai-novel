# 苍玄 · 小说工作区说明

> 本文档是 OpenCode 在本小说工作区的行为指南。**任务开始前，必须先读取 `00_通用模板/00_使用说明.md`**——路由表、@引用/ID 规范、Token 控制、一站式自检等核心规则全部集中在该文件，本文档仅作总览与范围界定。

- **工作区根目录**：本书文件夹（`01_小说数据/00_苍玄/`），所有路径均相对此目录。
- **`00_通用模板`**：是指向根目录通用模板的符号链接或目录联接（`-> ../../00_通用模板`），**只读**，禁止写入任何本书数据；其下文件仅定义字段、规则与说明。

## 范围隔离（最重要）

1. **数据目录边界**：数据目录即 OpenCode 直接打开的目录——本书文件夹（`01_小说数据/00_苍玄/`，即小说数据的根目录）；**禁止编辑此目录以外的任何文件**。本书目录内的 `00_通用模板` 是符号链接，可经其**参照**通用模板数据，但**只读，禁止编辑**。
2. 本工作区只操作「苍玄」一书的数据；禁止读取或修改其他小说文件夹（`01_小说数据/` 下的兄弟目录）的数据。
3. 只引用 `00_进度.md` 标记为「定稿」的数据；草稿/待校验数据不得作为写作依据。

## 数据位置（相对本书根目录）

| 目录 | 内容 |
|------|------|
| `00_进度.md` | 各文件成熟度状态（草稿/待校验/定稿），任务前必读 |
| `01_设定/` | 设定层：全书级基础设定（小说概念、主角档案、文风、核心道义） |
| `02_数据库/` | 设定卡（资料层，每个分类一个 `NN_分类/` 文件夹：修炼体系、地理、势力、资源、书籍、人物、伏笔等） |
| `03_规划/` | 规划层：全书规划、各部规划、各卷大纲、单章细纲（`规划_卷章0001.md`）及事件卡（`01_事件/` 或平铺） |
| `05_工作区/02_状态/01_最新状态/` | 状态层：全书唯一权威对象状态（每对象一文件，按类目分层，脚本覆盖写入） |
| `05_工作区/` | 动态工作区（全书/部/卷/章 递归结构：提示词/模型输出/状态，含履历与基线） |
| `10_正文/` | 创作层：按部与卷组织的具体章节正文（如 `10_正文/01_第01部/01_卷01/正文_卷章0001.md`） |

## 任务执行约定

1. 任务路由表、@引用语法、ID 编号规范、Token 控制（单次 ≤4 个模板）——一律以 `00_通用模板/00_使用说明.md` 为准，本文件不重复定义，避免规则多源、口径不一。
2. 通用模板只读：`00_通用模板/` 下文件不得写入任何本书数据。

## 技能发现

当前小说目录是工作区根目录。执行任务前：

1. 读取 `00_通用模板/03_任务技能/01_系统级/index.md`。
2. 读取 `00_通用模板/03_任务技能/02_小说级/index.md`。
3. 读取 `05_工作区/02_状态/02_技能/index.md` 和 `05_工作区/02_状态/02_技能/本书技能配置.md`。

技能负责执行流程，模板负责字段，规则负责约束，小说数据负责内容。技能索引不是定稿数据，不参与正文设定引用。

## 动态工作区说明

`05_工作区/` 记录生产任务与每章状态履历。状态的唯一权威存储是 `05_工作区/02_状态/01_最新状态/`
（每对象一文件），冻结基线在 `05_工作区/02_状态/00_基线状态/`。

- `05_工作区/00_提示词/` - 全书级 Prompt 存档
- `05_工作区/01_模型输出/` - 全书级大模型原始输出
- `05_工作区/02_状态/` - 状态层：`00_基线状态/`（冻结基线）、`01_最新状态/`（唯一权威）、`02_技能/`
- `05_工作区/03_第01部/03_卷01/03_章0001/` - 章级工作区
  - `00_提示词/` - 本章 Prompt 存档
  - `01_模型输出/` - 本章大模型原始输出
  - `02_状态/` - 状态层（`00_开篇状态.md`、`01_状态履历.md`、校验记录等）

工作区中的中间提示词与运行归档是生产过程数据，不是正式小说数据。正式小说数据只存在于 `01_设定/`、`02_数据库/`、`03_规划/`、`05_工作区/02_状态/01_最新状态/`、`05_工作区/`（各级 `02_状态/` 中的履历与基线）、`10_正文/`。
