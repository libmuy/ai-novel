# 战斗结算 · BT-V1-001

| 字段 | 值 |
|------|-----|
| 战斗ID | BT-V1-001 |
| 发生章节 | 第2章（章0002） |
| 战斗类型 | 遭遇战 |
| 战斗规模 | 单挑 |
| 是否跨体系 | 否 |

【参战方】
| 甲方 | @主角 苏砚，凡人（尚未开始修炼） |
| 乙方 | 黑石会夜巡监工（无名角色），炼气期 |
| 甲方战力评估 | 凡人少年，无修为、无护体真气；仅两枚淬枯骨藤毒的矿钉（凡兵，对炼气期修士等同废物） |
| 乙方战力评估 | 炼气期修士，气机压制凡人肉身；配灵石灯照明、短鞭（牛皮浸盐水） |
| 战力对比 | 甲方远弱——凡人对炼气期，全无还手可能，唯一变量是"认罚态度能不能换来轻罚" |

【战斗设计】
| 战斗目标 | 甲方：把损失降到最低（保命、保住矿籍、护住藏在颈上的古玉），不是求胜；乙方：按会里规矩执法立威，震慑其他矿工 |
| 环境条件 | 弃矿沟，子夜，仅灵石灯光柱照明，无第三方在场 |
| 甲方策略 | 主动从阴影中现身、暴露在光柱下，先交出赃物、认罚服软，靠"矿上私藏被抓的老规矩"经验判断——硬顶只会升级到断手/发去鬼见愁，软下来顶多挨鞭没收 |
| 乙方策略 | 常规搜身走一遍流程 + 训诫式鞭刑，抽够数（五记）即收手——打残了明日没人下矿，会里划不来的账，乙方也算得清 |
| 转折点 | 监工搜身时手按到苏砚胸口古玉，停了半息——险些搜出，却当作"不值钱的破石头"直接放过 |

【战斗结果】
| 胜负 | 负（凡人对炼气期无胜算；苏砚达成的只是"次优结果"——没升级到断手/发配鬼见愁，古玉未暴露） |
| 击杀名单 | 无 |
| 甲方伤势 | 背部鞭伤五道，皮开渗血，次日仍未愈合（章0002 后段"忍着背上的鞭伤照常上工"、铁妞用草药止血散包扎） |
| 甲方消耗 | 两枚私藏的废灵石被没收（约一两，折算不足三分之一枚碎灵石） |
| 战利品 | 无（乙方没收两枚废灵石，非甲方所得） |

【战后结算】
| 消息传播 | "苏砚私藏被抓"当晚就传遍矿区——监工回黑石会记名入簿，矿工口耳相传比他人跑得还快 |
| 后续追查 | 私藏前科正式记名在案，为章0003"监工借此拿捏苏砚、逼他跪下指认工友"埋因（见章0001【与下章衔接点】） |
| 势力关系变化 | 无新势力对象变化；`势力.黑石会` 对苏砚的关注度提高（记名在册），沿用章0001已建立的敌对关系，不新建关系对象（监工本人无名不建卡） |
| 新敌人/新盟友 | 无新增关系对象——监工无名，不建 `关系.` 对象；本章真正的关系变化在别处（铁妞包扎/石守根夜谈，走人物履历，不走本战斗卡） |
| 心理影响 | 全程没有对抗冲动，只有"止损"的冷静盘算；事后隐忍照常上工，"弱即是罪"的滋味第一次真切硌在牙根上，但仍存"规矩总会讲"的将信将疑 |
| 断裂伏笔/任务链 | 无 |
| 消息封锁代价 | 不适用——苏砚是被当场抓获认罚，不存在"灭口"意图 |
