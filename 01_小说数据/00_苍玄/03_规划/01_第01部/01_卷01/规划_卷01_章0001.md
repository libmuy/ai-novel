## 【开篇 300 字方案】

### 草稿

矿钉尖抵住岩缝时，苏砚先侧耳听了三息。

头顶没有渗水声，左壁没有裂石响，连远处主矿道里监工皮靴碾碎骨渣的动静都还在三十丈开外。他这才手腕一沉，矿钉斜斜楔进页岩缝隙，撬下那块嵌了半月的废灵石。

石料落在掌心，沉甸甸的。苏砚掂了掂，约莫四两五钱，成色中上，按矿上暗规能折一枚半碎灵石。加上昨日没花完的那一枚，今日若管事不刁难，能凑到两枚半——离一副止咳散还差得远，但够给娘的药钱添一星半点。

他把废灵石揣进怀里，贴着肋骨，像贴着一块尚未兑现的药。

收工锣声从主矿道传来，闷闷的，像敲在肺上。苏砚没急着往外走，先贴着左壁站了片刻，让眼睛适应更暗的光线。十年矿工，他知道这条西七巷支洞哪段顶板松、哪侧岩缝藏水，知道什么时候该快、什么时候该停。矿上死的人，一半是塌的，一半是急的。

他摸了摸手腕上那根褪色的旧绳，娘去年编的，已经磨得起毛。紧张时他会无意识地转它。

### 逐项核对

- [x] **第一句是动作/异常**："矿钉尖抵住岩缝时，苏砚先侧耳听了三息"——动作入戏。
- [x] **同时展示底层出身 + 谨慎性格**：底层出身（矿钉、岩缝、废灵石、十年矿工、止咳散、娘的病）；谨慎性格（撬石前先听三息、确认安全才动手、贴着左壁适应光线、知道哪段顶板松）。
- [x] **前100字出现主角 + 冲突/异常**：主角苏砚在首句即出现；冲突/异常隐含——他必须在监工赶来前撬下废灵石，且废灵石直接关联母亲的药钱（生存压力）。
- [x] **无天气/环境/心情/背景/回忆入戏**：无天气描写，无"这个世界分为……"背景，无"三年前……"回忆，无"他感到悲伤"心情铺垫。
- [x] **底层视角细节 ×2**：① 资源计算（"四两五钱……折一枚半碎灵石……离一副止咳散还差得远"）；② 身体记忆（"贴着左壁站""知道哪段顶板松""转手腕旧绳"）。
- [x] **谨慎行为 ×1（动作+事实观察，非独白展开）**：听三息确认安全才动手；贴着左壁适应光线；知道"什么时候该快、什么时候该停"。
- [x] **前300字让读者产生"然后呢？"的冲动**：废灵石已撬下，但能否顺利换成止咳散？监工还在三十丈外，但收工锣已响——读者想知道他能否带着这块"药"安全离开矿道。

### 标志性细节归属（供正文层区分，勿混用）

- **紧张 / 情绪起伏时**：无意识转手腕上那根褪色旧绳（母亲编，磨得起毛）。开篇 300 字保留此项。
- **推演 / 盘算时**：右手食指无声敲出"三短一长"（矿下数岩层的节奏）。首次出现放在场景2 内心记账 / 场景3 灶前盘算，不与"转旧绳"写成同一个动作。
