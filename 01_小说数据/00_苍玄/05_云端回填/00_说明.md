# 苍玄 · 云端回填存档说明

> 本目录存放任务 01~04「合并单文件输出模式」的云端产出存档。

## 使用流程

1. 将对应云端提示词（`04_提示词/` 存档，文件头注明"合并单文件输出模式"）整体复制到云端大模型执行。
2. 云端把一次任务的全部产出合并为一个 Markdown 文件整体输出。
3. 保存到本目录，命名 `<NN>_<任务名>_云端输出.md`（如 `03_势力组织_云端输出.md`）。
4. 请 OpenCode 执行"云端回填分割"，按 `00_通用模板/01_写作规则/07_云端回填分割规则.md` 分割回填到 `02_设定/` 对应文件，校验通过后更新 `00_进度.md`。
5. 本目录文件**保留存档**，分割完成后不删除。
