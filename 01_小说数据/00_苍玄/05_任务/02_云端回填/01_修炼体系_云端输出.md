| 字段 | 内容 |
|------|------|

## 【能力边界】

### 核心能力

| 能力名称 | 上限与限制 |
|----------|-----------|
| 灵气操控 | 同等级内灵气操控精度与储量上限受肉身与神魂强度限制（WR-005），超出则经脉爆裂 |
| 法术施展 | 可施展不高于自身等级三阶的法术，越阶施法需燃烧精血或寿元（WR-004） |
| 神识探查 | 神识外放距离见境界表，探查高阶修士可能被反噬致神魂受损 |
| 御器飞行 | 飞行速度受等级与法器品质双重限制，不可突破音障十倍（WR-015） |
| 法则感悟 | 5级后每级仅可主修一条法则，兼修法则不超过三条，否则法则冲突反噬 |
| 领域掌控 | 8级领域上限百丈，持续不超过一个时辰，过度展开损伤本源 |

### 能力细则（红线划定）

| 高危能力 | 红线规则 |
|----------|----------|
| 因果干预 | 仅7级后可初步干涉，每次须以等阶机缘/寿元/修为偿还；不可抹除因果，只能转移或延缓 |
| 复活术 | 8级后期方可触及，每次复活欠下天道因果，未来以等价机缘、寿元或修为偿还，每次翻倍（WR-007）；神魂湮灭则不可复活（WR-010） |
| 时间停滞 | 9级初期可短暂停滞一瞬（约0.1秒），须提前铺垫"触摸时间法则"剧情，每次使用折寿十年（WR-019软规则） |
| 瞬移/传送 | 不借助外物不可瞬移（WR-015）；6级后可借传送阵/传送符实现（WR-016） |
| 言出法随 | 8级领域范围内可有限实现，仅限领域内且不可违背世界硬规则 |

### 使用代价

- **普遍代价**：施展法术消耗丹田灵气，灵气枯竭后须调息恢复；过度使用损伤经脉（WR-004）。
- **越阶代价**：施展高于自身等级的法术，须燃烧精血或折寿，越一阶折寿十年，越两阶折寿五十年。
- **神识代价**：神识过度外放或探查高阶修士，导致头痛欲裂、短暂失明，严重者神魂受损。
- **法则代价**：法则感悟越深，越易受天道同化风险，长期不突破则逐渐丧失情感，化为"天道傀儡"。

### 致命弱点

1. **灵气依赖**：无灵气环境（如绝灵之地、某些位面）战力暴跌九成，近乎凡人。
2. **肉身脆弱**：同等级下肉身强度远低于金刚道，被近身则危。
3. **心魔易生**：因感悟天道、触及因果，高阶修士心魔滋生概率远高于其他体系。
4. **突破风险**：每次大等级突破失败均有严重后遗症（见【突破风险】）。

> 本区块定义玄元道内部规则，优先级链：世界基本法则（上位）→ 玄元道体系规则 → 具体能力规则 → 剧情行为。

| 修炼原理 | 吐纳→经脉运转→丹田储存→滋养肉身/神魂；每一步须积累足够灵气量方可晋升，拒绝无积累跳级。 |

## 【世界基本法则一致性检查】

1. **是否违反世界硬规则？** 否。力量有来源（WR-003）、有消耗（WR-004）、有上限（WR-005）、不瞬移（WR-015）、不时间回溯（WR-018）、神魂湮灭不可逆（WR-010）。
2. **是否与世界力量法则一致？** 是。力量来源于天地灵气，消耗为灵气/精血/寿元，上限受肉身神魂限制，存在互克与副作用。
3. **是否与生命与死亡法则冲突？** 否。未设计无条件复活；复活须因果偿还（WR-007软规则）；神魂湮灭真死（WR-010）。
4. **是否与因果法则冲突？** 否。因果干预仅在7级后开放，且须付出代价；命运非绝对（WR-012），未设计绝对命运能力。
5. **是否产生无法解释的力量来源？** 否。所有力量来源明确为天地灵气或蕴含灵能之物。
6. **是否存在无代价能力？** 否。即使最低级法术也消耗灵气；越阶/特殊能力均有明确代价。
7. **是否存在能力上限？** 是。每等级能力上限明确，领域/法则/神识均有硬上限。

> 检查结论：玄元道设计通过全部 7 项一致性检查，无冲突，可落位。

## 【能力边界】

### 核心能力

| 能力名称 | 上限与限制 |
|----------|-----------|
| 血气吞噬 | 同等级内可吞噬他人血气恢复自身，上限为自身血池容量的50%；超出则血气暴走 |
| 战魂附身 | 4级后战魂可附身兵器或离体，离体时间不超过一炷香，超时战魂消散 |
| 血魔真身 | 5级后可用，战力三倍但理智下降，持续时间不超过半个时辰，事后虚弱三日 |
| 血域开辟 | 6级后可用，范围上限百丈，持续不超过一日，维持血域持续消耗血气 |
| 血债因果 | 7级后可用，转移因果须以等阶血气或寿元偿还，不可抹除因果 |
| 不死血躯 | 8级后可用，神魂不灭可借血重生，但每次重生消耗血池九成储备，且因果翻倍（WR-007） |

### 能力细则（红线划定）

| 高危能力 | 红线规则 |
|----------|----------|
| 吞噬金丹/元婴 | 可吞噬但不可完全消化，仅能获得对方一项能力的一成威力，持续一炷香；吞噬过多导致怨念缠身 |
| 血裔创造 | 8级后可创造血裔，血裔有独立灵魂（WR-008）但受创造者控制；血裔反叛概率随数量增加而上升 |
| 战神附身 | 9级后可召唤远古战魂附身，战力翻倍但战后须以十年寿元为代价，且战魂可能夺舍（WR-009软规则） |

### 使用代价

- **普遍代价**：战斗消耗血气，血气枯竭后燃烧肉身精血→肉身崩溃；每次吞噬他人血气附带怨念，怨念积累过多导致心魔。
- **战意代价**：长期处于非战斗状态，战意消退，修为倒退；每闲置一月，战力下降1%。
- **理智代价**：频繁使用血魔真身/战魂离体，理智逐渐丧失，最终沦为杀戮傀儡。
- **因果代价**：吞噬他人血气=结下血债，高阶后血债化为因果劫（WR-007/012）。

### 致命弱点

1. **灵气克制**：玄元道精纯灵气可净化血气，同等级被克。
2. **战意依赖**：无战斗则修为倒退，无法像玄元道那样静坐修炼。
3. **怨念反噬**：吞噬的血气中蕴含死者怨念，积累过多必遭反噬。
4. **理智丧失**：越阶使用能力或频繁战斗，理智逐渐丧失，最终失控。

| 修炼原理 | 战斗激发血气→吞噬血气储存于血池→血池满则突破；拒绝静坐，越战越强。 |
| 消耗机制 | 战斗消耗血气，血气枯竭燃烧肉身精血；吞噬附带怨念积累（WR-004）；无战斗则战意消退、修为倒退。 |
| 突破条件 | ①资源：足够血气（吞噬或战场吸收）；②心境：通过血战考验（见【基础定义】）；③外部：需战斗环境或强敌。 |
| 突破风险 | 失败后果：①血池爆裂，修为尽废；②怨念反噬，沦为杀戮傀儡；③血气暴走，肉身崩溃；④杀意失控，敌我不分。 |
| 能力限制 | 同等级内能力上限受血池容量限制（WR-005）；战魂离体/血魔真身/血域均有时间/范围上限；吞噬能力有消化上限。 |
| 克制关系 | 克玄元道（血气破灵气），被金刚道克（肉身强横不惧血气）；互克非绝对。 |
| 体系边界 | ①不可无条件复活（血祖重生须血池储备+因果偿还，WR-007软）；②不可时间回溯（WR-018硬）；③不借外物不可瞬移（WR-015硬）。 |
| 特殊例外 | "以杀证道"：屠戮万人可强行破境，代价为永坠杀道、丧失人性，须提前铺垫角色黑化线。 |
| 上位规则合规声明 | 遵守硬规则：WR-001, WR-003, WR-004, WR-005, WR-008, WR-010, WR-011, WR-013, WR-014, WR-015, WR-017, WR-018。与软规则相关：WR-007（血祖重生因果）、WR-009（战魂夺舍）、WR-012（血债因果）。触碰敏感边界：血裔创造（有灵魂但受控，WR-008/012）、战神附身（夺舍风险，WR-009）。确认无冲突。 |

---

## 【世界基本法则一致性检查】

1. **是否违反世界硬规则？** 否。力量有来源（血气/战意，WR-003）、有消耗（血气/肉身/理智，WR-004）、有上限（血池容量，WR-005）、不瞬移（WR-015）、不时间回溯（WR-018）、神魂湮灭不可逆（WR-010）。
2. **是否与世界力量法则一致？** 是。力量来源于杀伐血气与吞噬，消耗为血气/肉身/理智，上限受血池限制，存在互克与副作用。
3. **是否与生命与死亡法则冲突？** 否。血祖重生须血池储备+因果偿还（WR-007软）；神魂湮灭真死（WR-010）。
4. **是否与因果法则冲突？** 否。血债因果须偿还；未设计绝对命运能力（WR-012）。
5. **是否产生无法解释的力量来源？** 否。所有力量来源明确为血气/战意/吞噬精血。
6. **是否存在无代价能力？** 否。即使血气护体也持续消耗血气；吞噬附带怨念；无战斗则倒退。
7. **是否存在能力上限？** 是。每等级能力上限明确，血池/战魂/血魔/血域均有硬上限。

> 检查结论：血煞道设计通过全部 7 项一致性检查，无冲突，可落位。

|----------|----------|

### 使用代价

- **普遍代价**：施展鬼术消耗阴气，阴气枯竭后燃烧神魂→神魂受损（WR-004/008）。
- **阳光代价**：阳光下战力衰减五成（7级前），须夜间或阴气浓郁处作战。
- **驭鬼代价**：高阶鬼物可能反叛，反叛时反噬神魂；驭鬼过多导致神魂负担过重。
- **冥界代价**：频繁接触冥界，逐渐被冥界同化，情感丧失，最终化为冥界生物。

### 致命弱点

1. **阳气克制**：玄元道精纯灵气可净化阴魂，同等级被克。
2. **阳光削弱**：阳光下战力暴跌，必须依赖环境。
3. **神魂脆弱**：阴神虽强，但被专门的神魂攻击克制；神魂受损恢复极慢。
4. **冥界同化**：高阶后频繁接触冥界，逐渐丧失人性，化为非人存在。

## 【世界基本法则一致性检查】

1. **是否违反世界硬规则？** 否。力量有来源（阴气/阴魂，WR-003）、有消耗（阴气/神魂，WR-004）、有上限（阴泉容量，WR-005）、不瞬移（WR-015）、不时间回溯（WR-018）、神魂湮灭不可逆（WR-010）。
2. **是否与世界力量法则一致？** 是。力量来源于阴气/阴魂，消耗为阴气/神魂/阳光削弱，上限受阴泉限制，存在互克与副作用。
3. **是否与生命与死亡法则冲突？** 否。复活须冥河因果（WR-007软）；神魂湮灭真死（WR-010）；还阳非真正复活。
4. **是否与因果法则冲突？** 否。复活/还阳均有因果代价；轮回感知模糊非绝对（WR-012）。
5. **是否产生无法解释的力量来源？** 否。所有力量来源明确为阴气/阴魂/冥河。
6. **是否存在无代价能力？** 否。即使低级驭鬼也消耗阴气；阳光削弱持续消耗。
7. **是否存在能力上限？** 是。每等级能力上限明确，阴泉/驭鬼/阴神/鬼域均有硬上限。

> 检查结论：幽冥道设计通过全部 7 项一致性检查，无冲突，可落位。

2. **远程弱势**：缺乏远程攻击手段，须近身作战；被放风筝则危。
3. **资源饥渴**：肉身淬炼资源消耗巨大，底层体修极难获得足够资源。
4. **速度瓶颈**：虽肉身强横，但速度同等级下低于玄元道/血煞道，难以追击敌人。

## 【世界基本法则一致性检查】

1. **是否违反世界硬规则？** 否。力量有来源（精血/灵物/锻炼，WR-003）、有消耗（气血/肉身本源，WR-004）、有上限（肉身强度，WR-005）、不瞬移（WR-015）、不时间回溯（WR-018）、神魂湮灭不可逆（WR-010）。
2. **是否与世界力量法则一致？** 是。力量来源于精血/灵物/锻炼，消耗为气血/肉身本源/神魂薄弱，上限受肉身限制，存在互克与副作用。
3. **是否与生命与死亡法则冲突？** 否。复活须精血为引+因果偿还（WR-007软）；神魂湮灭真死（WR-010）。
4. **是否与因果法则冲突？** 否。复活有因果代价；未设计绝对命运能力（WR-012）。
5. **是否产生无法解释的力量来源？** 否。所有力量来源明确为精血/灵物/肉身锻炼。
6. **是否存在无代价能力？** 否。即使肉身防御也持续消耗气血；锻炼伴随极端痛苦。
7. **是否存在能力上限？** 是。每等级能力上限明确，气血/分身/重生均有硬上限。

> 检查结论：金刚道设计通过全部 7 项一致性检查，无冲突，可落位。

## 【能力边界】

### 核心能力

| 能力名称 | 上限与限制 |
|----------|-----------|
| 傀儡操控 | 同等级内操控数量见境界表；超出数量则神魂负担过重，反噬风险剧增 |
| 神魂分念 | 分念数量受神魂强度限制（WR-005）；分念被灭则本体神魂受损 |
| 傀儡炼制 | 炼制高阶傀儡需稀有材料与长时间（数月到数年）；炼制失败材料全毁 |
| 灵傀共鸣 | 6级后可用，与灵傀共鸣可共享感知，但共鸣期间本体无防备 |

| 高危能力 | 红线规则 |
|----------|----------|
| 创造有灵魂傀儡 | 8级后仙傀有灵魂雏形（WR-008），9级后神傀有独立灵魂；独立灵魂可能反叛，反叛概率：仙傀5%/神傀15% |

| 神傀独立渡劫 | 神傀可独立渡劫，失败不影响本体，但神傀毁灭后本体损失大量神魂与资源 |

### 使用代价

- **普遍代价**：操控傀儡持续消耗神魂之力，神魂枯竭后头痛欲裂、昏迷（WR-004）。
- **分念代价**：每道分念被灭，本体神魂受损一成，恢复需数月。
- **材料代价**：高阶傀儡材料稀有且昂贵，底层灵傀师极难获得。
- **反叛代价**：高阶傀儡（仙傀/神傀）可能反叛，反叛时反噬神魂，严重者神魂湮灭（WR-010风险）。

### 致命弱点

1. **本体脆弱**：灵傀师本体通常弱于同等级主修修士，被近身则危。
2. **神魂依赖**：一切能力基于神魂，神魂受创则全线崩溃。
3. **资源黑洞**：高阶傀儡是无底洞，材料/时间/神魂消耗巨大。
4. **反叛风险**：高阶傀儡独立意识越强，反叛风险越高。

## 【世界基本法则一致性检查】

1. **是否违反世界硬规则？** 否。力量有来源（神魂/材料，WR-003）、有消耗（神魂，WR-004）、有上限（神魂强度，WR-005）、不瞬移（WR-015）、不时间回溯（WR-018）、神魂湮灭不可逆（WR-010）。
2. **是否与世界力量法则一致？** 是。力量来源于神魂/材料，消耗为神魂/材料/时间，上限受神魂限制，存在实战优劣。
3. **是否与生命与死亡法则冲突？** 否。未设计复活能力；傀儡替死不涉及真正复活；神魂湮灭真死（WR-010）。
4. **是否与因果法则冲突？** 否。未设计因果能力；神傀受控不涉及命运绝对（WR-012）。
5. **是否产生无法解释的力量来源？** 否。所有力量来源明确为神魂/材料/妖丹。
6. **是否存在无代价能力？** 否。操控持续消耗神魂；分念被灭反噬；炼制消耗资源。
7. **是否存在能力上限？** 是。每等级能力上限明确，操控数量/分念/傀儡等级均有硬上限。

> 检查结论：灵傀道设计通过全部 7 项一致性检查，无冲突，可落位。

| 备注 | — | 优劣非绝对。丹师若有强力护法傀儡/阵法，可弥补本体脆弱；幽冥道若等级不足，阴魂难侵高阶丹火 |

## 【兼修机制】

| 可兼修体系 | 兼修桥梁 | 兼修代价 |
|-----------|----------|----------|
| 玄元道 | 玄元道修士以灵气控火，天然适合炼丹；丹药可反哺修为 | 分神炼丹导致修炼时间减少三成；炼丹失败炸炉可反噬神魂 |
| 阵纹道 | 以阵法辅助炼丹（聚灵阵、控火阵），可提升成丹率 | 阵法与丹火配合难度高，配合失败炸炉风险翻倍 |
| 金刚道 | 以丹药辅助淬体，可加速肉身修炼 | 丹药杂质积累于肉身，长期导致肉身僵化，灵活性下降 |

## 【体系规则】

| 规则项 | 规则内容 |
|--------|----------|
| 力量来源 | 灵草、灵矿、天地精华；丹火来源于修士自身或地火/天火（WR-003）。 |
| 修炼原理 | 采集→辨识→控火→炼制→成丹；以炼丹磨砺神识与控火，丹药反哺修为。 |
| 消耗机制 | 炼丹消耗神魂/灵气/材料；炸炉反噬丹师（WR-004）；长期服用积累丹毒。 |
| 突破条件 | ①资源：足够材料；②心境：通过丹试；③外部：安全炼丹环境+控火条件。 |
| 突破风险 | 失败后果：①材料全毁；②炸炉反噬，经脉烧伤；③丹火失控，修为跌落；④丹毒爆发，根基受损。 |
| 能力限制 | 同等级内能力上限受神魂/控火/辨识限制（WR-005）；越级炼制成丹率暴跌；丹药效果递减。 |
| 克制关系 | 辅助职业无直接互克，实战优劣见【互克关系】。 |
| 体系边界 | ①不可无条件复活（还魂丹须神魂未湮灭+因果偿还，WR-007/010）；②不可无限续命（效果递减，WR-007软）；③低阶无法理解高阶丹方（WR-014硬）。 |
| 特殊例外 | "以丹入道"：吞服禁忌丹药可强行突破，代价为丹毒攻心、寿元锐减五成，须提前铺垫丹药来源与禁忌知识。 |
| 上位规则合规声明 | 遵守硬规则：WR-001, WR-003, WR-004, WR-005, WR-008, WR-010, WR-011, WR-013, WR-014, WR-015, WR-017, WR-018。与软规则相关：WR-007（还魂丹因果/续命递减）、WR-012（命运非绝对）。触碰敏感边界：复活（还魂丹须神魂未湮灭+因果偿还，WR-007/010）、续命（效果递减，WR-007软）。确认无冲突。 |

## 【世界基本法则一致性检查】

1. **是否违反世界硬规则？** 否。力量有来源（灵草/灵矿，WR-003）、有消耗（神魂/灵气/材料，WR-004）、有上限（神魂/控火，WR-005）、不瞬移（WR-015）、不时间回溯（WR-018）、神魂湮灭不可逆（WR-010）。
2. **是否与世界力量法则一致？** 是。力量来源于灵草/灵矿，消耗为神魂/灵气/材料，上限受神魂限制，存在副作用（丹毒/炸炉）。
3. **是否与生命与死亡法则冲突？** 否。还魂丹须神魂未湮灭+因果偿还（WR-007软）；神魂湮灭真死（WR-010）；续命效果递减（WR-007软）。
4. **是否与因果法则冲突？** 否。还魂丹有因果代价；未设计绝对命运能力（WR-012）。
5. **是否产生无法解释的力量来源？** 否。所有力量来源明确为灵草/灵矿/天地精华。
6. **是否存在无代价能力？** 否。炼丹消耗神魂/灵气；炸炉反噬；长期服用丹毒积累。
7. **是否存在能力上限？** 是。每等级能力上限明确，成丹率/丹药效果/辨识数量均有硬上限。

> 检查结论：丹鼎道设计通过全部 7 项一致性检查，无冲突，可落位。

# 体系卡 · 阵纹道（辅助职业）

## 【基础定义】

| 字段 | 内容 |
|------|------|
| 体系名称 | 阵纹道 |
| 体系代号 | 阵纹 |
| 本源描述 | 天地纹路、地势龙脉与法则碎片。力量来源于观察天地自然纹路、借地势龙脉之力、以及法则碎片的排列组合，不可凭空产生（WR-003）。 |
| 修行方式 | 观天地纹路→悟阵理→绘阵纹→布阵法→借天地/地势/法则之力放大效果；阵师以推演阵法磨砺神识与计算能力，阵法可攻防困敌，但主修仍需另修体系。 |
| 代表人群 | 阵法师、风水师、宗门阵堂弟子、散修阵师 |
| 破境考验 | 每升一级须通过"阵试"：在限定条件下布置指定阵法并承受阵法反噬，阵法运转稳定则晋级；失败则阵法崩溃、反噬神魂。 |

---

## 【境界体系】

> 基准对照系：以玄元道为通用参照。结构：1~9 级简表（等级编号｜对应主修等级｜核心能力｜战力标志）。

| 等级编号 | 对应主修等级 | 核心能力 | 战力标志 |
|----------|-------------|----------|----------|
| **1级** | 1级（炼气） | 可布置十种低级阵法（迷踪阵、聚灵阵、警戒阵） | 阵法范围十丈，持续一日，威力等同1级 |
| **2级** | 2级（筑基） | 可布置中级阵法（防御阵、杀阵、困阵） | 阵法范围百丈，持续三日，威力等同2级 |
| **3级** | 3级（金丹） | 可布置复合阵法（杀困一体、防聚一体）；开始推演阵理 | 阵法范围千丈，持续七日，可困3级修士 |
| **4级** | 4级（元婴） | 可布置4级阵法（空间折叠阵、神识屏蔽阵） | 阵法范围十里，持续一月，可困4级修士 |
| **5级** | 5级（化神） | 可布置法则阵法（引动法则碎片加持阵法） | 阵法内可短暂改写小范围规则（非绝对，WR-012） |
| **6级** | 6级（炼虚） | 可布置虚空阵法（传送阵、位面缝隙阵，WR-016） | 传送阵可实现跨域传送（须两端布阵）；位面缝隙阵限时一息 |
| **7级** | 7级（合体） | 可布置因果阵法（因果转移阵、命数遮蔽阵） | 因果转移须以等阶机缘/寿元为代价（WR-012）；命数遮蔽可隐瞒天道感知三日 |
| **8级** | 8级（大乘） | 可布置复活阵法（招魂阵、还阳阵） | 招魂阵可召回未湮灭神魂（WR-010硬）；还阳阵须欠天道因果（WR-007软） |
| **9级** | 9级（渡劫） | 可布置仙阵（渡劫辅助阵、天道屏蔽阵） | 天道屏蔽阵可遮掩天道感知一炷香（WR-002未知规则相关，登记伏笔） |

## 【能力边界】

### 核心能力

| 能力名称 | 上限与限制 |
|----------|-----------|
| 阵法布置 | 同等级内可布置阵法见境界表；越级布置阵法崩溃风险剧增，反噬严重 |
| 阵纹推演 | 推演复杂度受神识与计算能力限制；高阶阵法须数日甚至数月推演 |
| 阵法维持 | 阵法持续消耗灵气/神识/材料；维持时间越长消耗越大，过度维持损伤根基 |
| 借势能力 | 借地势龙脉可放大阵法威力（最高十倍），但须提前勘察地形，不可凭空借势 |
| 法则阵法 | 5级后可引动法则碎片，但法则碎片稀有且难以控制，失控则阵法反噬 |

### 能力细则（红线划定）

| 高危能力 | 红线规则 |
|----------|----------|
| 传送阵 | 6级后可布置，须两端同时布阵方可传送；单方布阵不可传送（WR-016软）；传送过程不可中断，中断则坠入虚空（WR-001） |
| 因果转移阵 | 7级后可布置，转移因果须以等阶机缘/寿元/修为偿还，不可抹除因果（WR-012） |
| 天道屏蔽阵 | 9级后可布置，可遮掩天道感知一炷香；涉及WR-002天道不可证未知规则，登记伏笔，禁止AI补全天道真相 |
| 还阳阵 | 8级后可布置，召回未湮灭神魂并重塑肉身，欠天道因果，每次翻倍（WR-007软）；神魂湮灭不可召回（WR-010硬） |

### 使用代价

- **普遍代价**：布阵消耗神识与灵气，阵法维持持续消耗；过度推演导致神识枯竭、头痛欲裂（WR-004）。
- **材料代价**：高阶阵法需稀有材料（灵石、法则碎片、龙脉石等），底层阵师极难获得。
- **反噬代价**：阵法崩溃/被破时反噬布阵者，轻则神识受损，重则经脉寸断。
- **借势代价**：借龙脉/地势之力须付出代价（如折寿、损功德、结因果），不可无偿借势。

### 致命弱点

1. **布阵时间**：阵法须提前布置，突发战斗中难以即时布阵；被近身则危。
2. **本体脆弱**：阵师本体战力通常弱于同等级主修修士。
3. **资源黑洞**：高阶阵法材料是无底洞，且阵法为一次性消耗（除永久阵法外）。
4. **反噬风险**：阵法越复杂，崩溃反噬越严重；8级仙阵崩溃可灭方圆百里。
