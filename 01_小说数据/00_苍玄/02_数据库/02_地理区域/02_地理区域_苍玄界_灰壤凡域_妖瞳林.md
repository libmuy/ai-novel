# 妖瞳林

## 基础信息

| 字段 | 内容 |
|------|------|
| 地名 | 妖瞳林 |
| 所属区域 | @地名.灰壤凡域 |
| 位置描述 | 位于灰壤凡域西部，腐骨沼林以北十八里；一片密林，林中树木的树干上天然生长着类似眼球的瘤状突起，在月光下会微微转动，中阶妖兽常在此筑巢 |
| 类别 | 险地 |

## 环境与驻留

| 字段 | 内容 |
|------|------|
| 灵气/危险 | 灵气中等，带有诡异的窥视感，修士在林中总感觉被无数眼睛注视；危险来自3~4级瞳类妖兽、妖瞳树瘤释放的致幻孢子、以及林中妖兽的群体猎杀 |
| 地标建筑 | 妖瞳母树（林中最高大的一棵树，树干上长着一颗巨大的树瘤，形似巨眼）、猎妖暗哨（老猎妖人在树冠中搭建的隐蔽观察点）、月光祭台（林中一处空地，妖兽每逢月圆在此聚集） |
| 常驻人物与势力 | 无固定势力 |

## 叙事用途

| 字段 | 内容 |
|------|------|
| 叙事用途 | 主角获取妖兽材料（瞳类妖兽的妖瞳是炼制幻术法器的关键材料）的场所：林中猎妖、与林之子的奇遇、妖瞳母树的秘密；适合安排心理惊悚剧情 |
| 相关事件/伏笔 | @伏笔.FH-021（妖瞳母树是上古某位瞳术大能的化身所化）、@伏笔.FH-022（林中某处隐藏着通往妖兽位面的裂隙） |
