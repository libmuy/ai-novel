# 符皮树林

> 关联：@地名.[灰壤凡域]

---

## 基础信息

| 字段 | 内容 |
|------|------|
| 地名 | 符皮树林 |
| 所属区域 | @地名.[灰壤凡域] |
| 位置描述 | 位于灰壤凡域西北部，黑棘林以东十里；一片奇特的树林，树木的树皮天然生长着类似符纹的纹路，剥下后可作为低阶符箓的载体，中阶妖兽常出没于林间 |
| 类别 | 险地 |

---

## 环境与驻留

| 字段 | 内容 |
|------|------|
| 灵气/危险 | 灵气浓度中等，树皮符纹会随机释放微弱的法术波动；危险来自3~4级树栖妖兽、树皮符纹的意外触发、以及符皮掠夺者之间的冲突 |
| 地标建筑 | 符皮母树（林中最大的一棵树，树皮上生长着完整的低阶符纹，被视为神树）、剥皮人营地（林边缘散修搭建的临时剥皮作坊）、古符碑（林中一块刻有符道的石碑，被藤蔓缠绕） |
| 常驻人物与势力 | 无固定势力 |

---

## 叙事用途

| 字段 | 内容 |
|------|------|
| 叙事用途 | 主角获取符箓载体材料（符树皮是绘制中阶符箓的优良材料）的场所：林间剥皮、与剥皮人的交易或冲突、古符碑的符道领悟；适合安排符箓修行剧情 |
| 相关事件/伏笔 | @伏笔.FH-025（符皮母树的树心中封印着一张上古符箓）、@伏笔.FH-026（古符碑是某位符道宗师悟道之地，碑中藏有符道真意） |
