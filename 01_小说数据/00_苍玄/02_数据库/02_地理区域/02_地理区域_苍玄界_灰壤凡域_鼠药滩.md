# 鼠药滩

> 关联：@地名.灰壤凡域

---

## 基础信息

| 字段 | 内容 |
|------|------|
| 地名 | 鼠药滩 |
| 所属区域 | @地名.灰壤凡域 |
| 位置描述 | 位于灰壤凡域南部边缘，枯港矿城以南三十五里；一片河滩湿地，因盛产一种被噬矿鼠视为毒药的低阶灵草而得名，滩涂泥泞，芦苇丛生 |
| 类别 | 秘境入口 |

---

## 环境与驻留

| 字段 | 内容 |
|------|------|
| 灵气/危险 | 灵气平缓但带有湿毒，长期滞留会关节肿痛；危险来自滩涂陷泥、毒蛇、以及被灵草吸引而来的低阶妖兽，但每逢朔望之日滩涂中央会出现漩涡状空间裂口 |
| 地标建筑 | 无固定建筑，仅有采药散修搭建的芦苇棚；滩涂中央有一块半沉于泥中的石碑，碑上刻有药字 |
| 常驻人物与势力 | 无固定势力 |

---

## 叙事用途

| 字段 | 内容 |
|------|------|
| 叙事用途 | 主角早期采集妖兽相关草药（鼠药草可克制低阶噬矿鼠）的场所：滩涂采药、发现朔望漩涡的秘密；适合安排智慧剧情 |
| 相关事件/伏笔 | @伏笔.FH-019（鼠药滩地下连接着一处上古药园遗迹）、@伏笔.FH-020（石碑药字是某位丹道宗师的亲笔，内含丹道真意） |
