# 腐骨沼林

## 基础信息

| 字段 | 内容 |
|------|------|
| 地名 | 腐骨沼林 |
| 所属区域 | @地名.灰壤凡域 |
| 位置描述 | 位于灰壤凡域西部边缘，黑棘林以南二十里；一片沼泽与密林交织的湿地，林中树木根系浸泡在腐殖泥沼中，常有妖兽骨骼半露于泥面 |
| 类别 | 险地 |

---

## 环境与驻留

| 字段 | 内容 |
|------|------|
| 灵气/危险 | 灵气阴湿腐臭，带有强烈的尸毒属性；危险来自3~4级腐骨妖兽、陷泥沼、沼气爆燃、以及林中游荡的亡灵残念 |
| 地标建筑 | 腐骨祭台（林中一处由妖兽骨骼堆砌的诡异石台）、沼中浮岛（几座由千年腐殖质堆积而成的可移动陆地）、猎人树屋（老猎妖人在巨树上搭建的避难所） |
| 常驻人物与势力 | 无固定势力 |

## 叙事用途

| 字段 | 内容 |
|------|------|
| 叙事用途 | 主角获取法宝炼制材料（腐骨可用于炼制阴属性法器）的场所：沼中寻宝、与邪道散修的交锋、树屋中的情报交换；适合安排灰色地带剧情 |
| 相关事件/伏笔 | @伏笔.FH-013（腐骨祭台是上古某邪宗的献祭遗址）、@伏笔.FH-014（沼林深处有一具保存完好的高阶妖兽完整骨架） |
