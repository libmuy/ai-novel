| 所属世界 | 苍玄界 |

| 地理位置 | 苍玄界中部偏东，西接紫极天域，东连灰壤凡域；由数十座浮空岛屿与悬空栈道相连而成，状若琉璃珠链悬浮于云海之上 |
| 灵气浓度 | 中等浓度，灵气稳定充沛，适合筑基期与金丹期修士日常修行；最高支持境界为金丹期（3级） |

【生态与资源】

| 字段 | 内容 |
|------|------|
| 主导体系 | 玄元道为主流，丹鼎道、阵纹道、灵傀道等辅助职业在此繁荣发展 |
| 特产资源 | 二至三阶灵草、中品灵石、炼器材料、丹方与阵图残卷 |
| 危险等级 | 筑基期可自由活动，金丹期修士为主力；坊市内禁止斗法，但暗巷与黑市危机四伏 |
| 区域特色 | 琉璃瓦覆顶的悬空建筑、云海中的栈道商队、昼夜不息的交易喧嚣；这里是底层修士向上攀爬的第一道门槛，也是高阶势力伸向下层的触手交汇之地 |
