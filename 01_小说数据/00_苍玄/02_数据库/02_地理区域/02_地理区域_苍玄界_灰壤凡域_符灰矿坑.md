# 符灰矿坑

> 关联：@地名.灰壤凡域

---

## 基础信息

| 字段 | 内容 |
|------|------|
| 地名 | 符灰矿坑 |
| 所属区域 | @地名.灰壤凡域 |
| 位置描述 | 位于灰壤凡域中部，碎灵沟以西十二里；一处废弃的露天矿坑，坑壁岩石呈现符箓燃烧后的灰白色，地下仍埋藏着少量可用于绘制低阶符箓的灵石碎屑 |
| 类别 | 险地 |

---

## 环境与驻留

| 字段 | 内容 |
|------|------|
| 灵气/危险 | 灵气稀薄且带有符灰的灼烧属性，吸入过多会损伤肺脉；危险来自坑壁塌落、符灰自燃、以及黑石会在此征收拾荒税的打手 |
| 地标建筑 | 符灰坑底（矿坑最深处，积满符灰，偶见未燃尽的符箓残片）、黑石会税棚（坑口的简易木棚，用于盘查进出者）、废弃符箓作坊（坑边一处坍塌的石屋，曾是低阶符师的居所） |
| 常驻人物与势力 | @势力.黑石会（征收符灰矿坑的拾荒税） |
