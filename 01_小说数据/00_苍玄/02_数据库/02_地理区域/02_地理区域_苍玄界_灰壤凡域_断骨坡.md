| 地名 | 断骨坡 |
| 所属区域 | @区域.[灰壤凡域] |
| 位置描述 | 位于灰壤凡域西部边缘，是通往云璃坊链的必经险道；一段长达三十里的陡峭山脊，乱石嶙峋、罡风呼啸，因早年盗匪与修士冲突中尸骨遍野而得名 |
| 类别 | 险地 |

【环境与驻留】

| 字段 | 内容 |
|------|------|
| 灵气/危险 | 灵气稀薄但罡风凌厉，炼气期修士难以御风而行；危险来自二阶风属性妖兽"裂骨鹫"、盘踞此地的盗匪团伙、以及山体滑坡与迷障 |
| 地标建筑 | 断骨碑（刻有"过此坡者，骨断魂留"的警示石碑）、半崖栈道（前人开凿的狭窄通道，最窄处仅容一人侧身）、避风洞（盗匪与商旅临时歇脚处） |
