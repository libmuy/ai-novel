# 体系卡 · 幽冥道

## 【基础定义】

| 字段 | 内容 |
|------|------|
| 体系名称 | 幽冥道 |
| 体系代号 | 幽冥 |
| 本源描述 | 阴魂死气与幽冥之力。力量来源于阴气浓郁之地（坟场、阴脉、冥河）、吞噬阴魂、以及自身死气转化，不可凭空产生（WR-003）。 |
| 修行方式 | 在阴气浓郁处吐纳阴魂死气，凝练阴丹；吞噬游荡阴魂或驭使鬼物作战；亦可借冥河之水洗炼神魂。 |
| 代表人群 | 鬼道散修、冥宗弟子、守墓人、阴阳先生 |
| 破境考验 | 每级晋升须面对阴魂考验：1级→2级阴风噬魂、2级→3级黄泉引路、3级→4级万鬼噬心、4级→5级阴神出窍劫、5级→6级幽冥叩门、6级→7级万鬼朝宗、7级→8级阴阳合体、8级→9级冥河逆流、9级圆满后鬼神叩天。 |

## 【能力边界】

### 核心能力

| 能力名称 | 上限与限制 |
|----------|-----------|
| 驭鬼术 | 同等级内驭鬼数量上限见境界表；高阶鬼物可能反叛，须以阴气压服 |
| 阴神离体 | 4级后可用，离体时间不超过七日，超时肉身腐朽；阴神受损则本体同步受损（WR-008） |
| 鬼蜮/鬼域 | 3级后可用鬼蜮，6级后升级为鬼域；范围上限百丈，持续不超过一日，维持消耗阴气 |
| 附身术 | 4级后可用，仅可附身同阶或以下，不可读取记忆，附身期间肉身无防备 |
| 冥河召唤 | 5级后可用，须在有冥河投影处；召唤物可能反叛，须持续消耗阴气压制 |
| 还阳术 | 7级后可用，还阳者无自主意识，持续三日，非真正复活（WR-007/010） |

### 能力细则（红线划定）

| 高危能力 | 红线规则 |
|----------|----------|
| 真正复活 | 8级后期方可触及，每次复活欠下冥河因果，未来以等价机缘/寿元/修为偿还，每次翻倍（WR-007软）；神魂湮灭不可复活（WR-010硬） |
| 轮回感知 | 9级后可模糊感知他人前世，信息碎片化且可能错误，不可作为绝对依据 |
| 冥种寄生 | 8级后可创造冥种，寄生者保留自主意识但被控制生死；冥种可被高阶灵气净化 |

### 使用代价

- **普遍代价**：施展鬼术消耗阴气，阴气枯竭后燃烧神魂→神魂受损（WR-004/008）。
- **阳光代价**：阳光下战力衰减五成（7级前），须夜间或阴气浓郁处作战。
- **驭鬼代价**：高阶鬼物可能反叛，反叛时反噬神魂；驭鬼过多导致神魂负担过重。
- **冥界代价**：频繁接触冥界，逐渐被冥界同化，情感丧失，最终化为冥界生物。

### 致命弱点

1. **阳气克制**：玄元道精纯灵气可净化阴魂，同等级被克。
2. **阳光削弱**：阳光下战力暴跌，必须依赖环境。
3. **神魂脆弱**：阴神虽强，但被专门的神魂攻击克制；神魂受损恢复极慢。
4. **冥界同化**：高阶后频繁接触冥界，逐渐丧失人性，化为非人存在。

## 【体系规则】

| 规则项 | 规则内容 |
|--------|----------|
| 力量来源 | 阴魂死气、阴气浓郁之地、吞噬的阴魂、冥河之水（WR-003）。 |
| 修炼原理 | 阴气入体→凝练阴泉→吞噬阴魂→阴丹→阴神；在阴气浓郁处修炼效率翻倍。 |
| 消耗机制 | 施展鬼术消耗阴气，阴气枯竭燃烧神魂；阳光下持续消耗额外阴气（WR-004）。 |
| 突破条件 | ①资源：足够阴气/阴魂；②心境：通过阴魂考验（见【基础定义】）；③外部：阴气环境或冥河投影。 |
| 突破风险 | 失败后果：①神魂受损（WR-008）；②沦为活死人；③被冥界吸入；④阴魂反噬，丧失记忆。 |
| 能力限制 | 同等级内能力上限受阴泉容量限制（WR-005）；驭鬼/阴神/鬼域均有数量/时间/范围上限；阳光削弱。 |
| 克制关系 | 克金刚道（阴魂蚀神魂），被玄元道克（灵气净化阴气）；互克非绝对。 |
| 体系边界 | ①不可无条件复活（须冥河因果，WR-007软）；②不可时间回溯（WR-018硬）；③不借外物不可瞬移（WR-015硬）；④还阳非真正复活。 |
| 特殊例外 | "借尸还魂"：可借他人尸体重生，丧失原肉身修为三成，须提前铺垫尸体来源与契合度剧情。 |
| 上位规则合规声明 | 遵守硬规则：WR-001, WR-003, WR-004, WR-005, WR-008, WR-010, WR-011, WR-013, WR-014, WR-015, WR-017, WR-018。与软规则相关：WR-007（复活因果）、WR-012（命运非绝对）、WR-016（传送外物）。触碰敏感边界：真正复活（8级后期开放，冥河因果偿还）、轮回感知（9级模糊感知，信息碎片化）。确认无冲突。 |

## 【世界基本法则一致性检查】

1. **是否违反世界硬规则？** 否。力量有来源（阴气/阴魂，WR-003）、有消耗（阴气/神魂，WR-004）、有上限（阴泉容量，WR-005）、不瞬移（WR-015）、不时间回溯（WR-018）、神魂湮灭不可逆（WR-010）。
2. **是否与世界力量法则一致？** 是。力量来源于阴气/阴魂，消耗为阴气/神魂/阳光削弱，上限受阴泉限制，存在互克与副作用。
3. **是否与生命与死亡法则冲突？** 否。复活须冥河因果（WR-007软）；神魂湮灭真死（WR-010）；还阳非真正复活。
4. **是否与因果法则冲突？** 否。复活/还阳均有因果代价；轮回感知模糊非绝对（WR-012）。
5. **是否产生无法解释的力量来源？** 否。所有力量来源明确为阴气/阴魂/冥河。
6. **是否存在无代价能力？** 否。即使低级驭鬼也消耗阴气；阳光削弱持续消耗。
7. **是否存在能力上限？** 是。每等级能力上限明确，阴泉/驭鬼/阴神/鬼域均有硬上限。

> 检查结论：幽冥道设计通过全部 7 项一致性检查，无冲突，可落位。
