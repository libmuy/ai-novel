# 体系卡 · 万火凝丹（丹修）

【基础定义】
| 体系名称 | 万火凝丹 |
| 体系代号 | 丹修 |
| 本源描述 | 万物药性纹理，与天地灵力同源异流。丹药内部凝结"丹纹"（灵力固化纹理），是判断品质的核心 |
| 修行方式 | 以火炼药，识别并调和药性纹理，化灵成丹 |
| 代表人群 | 炼丹师、医师、毒师 |
| 破境考验 | 每大境界需独立炼制一炉对应品级丹药 |

【境界体系】
| 等级 | 对应主修境界 | 核心能力 | 战力标志 |
|------|------------|---------|---------|
| 1 级 | 感灵境 | 识别十种凡火，控温±十度 | 可炼 1 品丹药 |
| 2 级 | 拓灵境 | 控焰分化，液化单药材 | 可炼 2 品丹药 |
| 3 级 | 凝灵境 | 九药同炼，丹纹初成 | 可炼 3 品丹药 |
| 4 级 | 化灵境 | 九纹丹成，丹灵萌芽 | 可炼 4 品丹药 |
| 5 级 | 生灵境 | 灵丹自飞，一丹双效 | 可炼 5 品丹药 |
| 6 级 | 玄灵境 | 玄丹择主，药效随机 | 可炼 6 品丹药 |
| 7 级 | 道灵境 | 服丹悟道，道丹破境 | 可炼 7 品丹药 |
| 8 级 | 真灵境 | 丹我合一，替死丹成 | 可炼 8 品丹药 |
| 9 级 | 苍灵境 | 一丹一世界，苍丹生 | 可炼 9 品丹药 |

基准对照系：以玄灵九叠为通用参照。

【能力边界】
| 核心能力 | 上限与限制 |
|---------|-----------|
| 丹纹识别 | 识别丹药内部纹理判断品质；上限：识别高两阶（大境界）丹药；限制：对"无纹丹"（上古遗留）无效 |
| 化纹炼丹 | 以灵纹稳定丹火；上限：提升同小境界炼丹成功率30%；限制：需提前建立"灵火同调"，耗时七日 |

| 使用代价 | 炼丹消耗药材与火焰本源，失败则火焰降级 |

| 致命弱点 | 战斗力极弱，同小境界战力仅为灵修三成 |

【互克关系】
| 克制体系 | 无直接克制，但丹毒可削弱所有体系 |
| 被克体系 | 无直接克制，但依赖灵修稳定火焰 |
| 互克备注 | 丹修为辅助体系，实战中需依附其他体系 |

【兼修机制】
| 可兼修体系 | 玄灵九叠 |
| 兼修桥梁 | 灵火同调 |
| 兼修代价 | 破境时间翻倍；丹毒以灵斑形式积累于灵窍内壁 |
