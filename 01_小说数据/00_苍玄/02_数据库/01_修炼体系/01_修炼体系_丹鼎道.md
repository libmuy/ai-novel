# 体系卡 · 丹鼎道（辅助职业）

## 【基础定义】

| 字段 | 内容 |
|------|------|
| 体系名称 | 丹鼎道 |
| 体系代号 | 丹鼎 |
| 本源描述 | 灵草灵矿与天地精华。力量来源于采集灵草、挖掘灵矿，以丹火炼化其精华于丹丸之中，不可凭空产生（WR-003）。 |
| 修行方式 | 采集灵草→辨识药性→控火炼丹→成丹服饵或外售；丹师以炼丹过程磨砺神识与控火能力，丹药可反哺修为，但主修仍需另修体系。 |
| 代表人群 | 炼丹师、药农、宗门丹堂弟子、散修丹师 |
| 破境考验 | 每升一级须通过"丹试"：在限定条件下炼制指定丹药，成丹品质达标则晋级；失败则材料全毁、丹火反噬。 |

---

## 【境界体系】

> 基准对照系：以玄元道为通用参照。结构：1~9 级简表（等级编号｜对应主修等级｜核心能力｜战力标志）。

| 等级编号 | 对应主修等级 | 核心能力 | 战力标志 |
|----------|-------------|----------|----------|
| **1级** | 1级（炼气） | 可辨识十种常见灵草，炼制低级丹药（回气丹、疗伤散） | 成丹率三成，丹药效果为市售五成 |
| **2级** | 2级（筑基） | 可辨识五十种灵草，炼制中级丹药（筑基丹、清心丸） | 成丹率五成，丹药效果等同市售 |
| **3级** | 3级（金丹） | 可辨识百种灵草，炼制3级丹药（金丹助凝丹、爆灵丹） | 成丹率七成，可炼制带丹纹的精品丹 |
| **4级** | 4级（元婴） | 可辨识三百种灵草/矿，炼制4级丹药（元婴养神丹、化形丹） | 成丹率八成，可炼制"一炉九丹" |
| **5级** | 5级（化神） | 可辨识千种材料，炼制5级丹药（法则感悟丹、破境丹） | 成丹率九成，可炼制"天丹"（引丹劫） |
| **6级** | 6级（炼虚） | 可炼制虚空级丹药（空间稳固丹、位面通行丹） | 可炼制"虚空丹"（内含空间碎片，WR-017） |
| **7级** | 7级（合体） | 可炼制因果级丹药（斩因果丹、续命丹） | 续命丹可延寿五十载（每次服用效果减半，WR-007软） |
| **8级** | 8级（大乘） | 可炼制复活级丹药（还魂丹、逆命丹） | 还魂丹可复活死者（须神魂未湮灭，欠天道因果，WR-007软） |
| **9级** | 9级（渡劫） | 可炼制仙丹（渡劫辅助丹、飞升丹） | 仙丹可助渡劫成功率+10%，但引动丹劫（天雷轰炉） |

## 【能力边界】

### 核心能力

| 能力名称 | 上限与限制 |
|----------|-----------|
| 丹药炼制 | 同等级内可炼制丹药见境界表；越级炼制成丹率暴跌，且炸炉风险剧增 |
| 丹火操控 | 丹火温度/精度受神魂与控火功法限制；丹火失控则炸炉，反噬丹师 |
| 药性辨识 | 辨识数量见境界表；高阶灵草需对应等级方可辨识，低阶无法理解高阶信息（WR-014） |
| 丹药效果 | 同种丹药多次服用效果递减；爆灵丹等激发类丹药有副作用，不可连续服用 |
| 天丹/仙丹 | 5级后天丹引丹劫（小型天雷轰炉）；9级仙丹引丹劫（威力等同4级天劫） |

### 能力细则（红线划定）

| 高危能力 | 红线规则 |
|----------|----------|
| 续命丹 | 7级后可炼制，每次服用延寿五十载，但效果递减（第二次二十五载，第三次十余载…），不可无限续命（WR-007软） |
| 还魂丹 | 8级后可炼制，可复活死者（须神魂未湮灭），每次复活欠天道因果，未来以等价机缘/寿元/修为偿还，每次翻倍（WR-007软）；神魂湮灭不可复活（WR-010硬） |
| 飞升丹 | 9级后可炼制，助渡劫成功率+10%，但引动丹劫（天雷轰炉），丹劫威力等同4级天劫，丹师须自抗 |

### 使用代价

- **普遍代价**：炼丹消耗神魂与灵气，连续炼丹导致神魂枯竭、灵气耗尽（WR-004）。
- **材料代价**：高阶丹药材料稀有且昂贵，一炉失败损失巨大；底层丹师极难获得高阶材料。
- **炸炉代价**：炸炉时丹火反噬，轻则烧伤，重则丹火入体焚毁经脉。
- **丹毒代价**：长期服用丹药积累丹毒，丹毒侵蚀根基，导致突破难度增加。

### 致命弱点

1. **战力薄弱**：丹师本体战力通常弱于同等级主修修士，被近身则危。
2. **资源依赖**：炼丹是烧钱行为，无资源则寸步难行。
3. **炸炉风险**：越高阶丹药炸炉风险越大，8级炼制仙丹炸炉可灭方圆十里。
4. **丹毒积累**：长期服丹者丹毒缠身，根基受损，反而影响主修突破。

## 【互克关系】

> 辅助职业不参与直接互克，但存在实战中的优劣势关系。

| 关系类型 | 目标体系 | 优劣逻辑 |
|----------|----------|----------|
| 优势对 | 血煞道 | 丹药可快速恢复/爆发，克制血煞道的持久战；但血煞道近身可秒杀丹师 |
| 劣势对 | 幽冥道 | 幽冥道阴魂可侵蚀丹火，干扰炼丹；鬼术直接攻击神魂，丹师难以抵御 |
| 备注 | — | 优劣非绝对。丹师若有强力护法傀儡/阵法，可弥补本体脆弱；幽冥道若等级不足，阴魂难侵高阶丹火 |

## 【体系规则】

| 规则项 | 规则内容 |
|--------|----------|
| 力量来源 | 灵草、灵矿、天地精华；丹火来源于修士自身或地火/天火（WR-003）。 |
| 修炼原理 | 采集→辨识→控火→炼制→成丹；以炼丹磨砺神识与控火，丹药反哺修为。 |
| 消耗机制 | 炼丹消耗神魂/灵气/材料；炸炉反噬丹师（WR-004）；长期服用积累丹毒。 |
| 突破条件 | ①资源：足够材料；②心境：通过丹试；③外部：安全炼丹环境+控火条件。 |
| 突破风险 | 失败后果：①材料全毁；②炸炉反噬，经脉烧伤；③丹火失控，修为跌落；④丹毒爆发，根基受损。 |
| 能力限制 | 同等级内能力上限受神魂/控火/辨识限制（WR-005）；越级炼制成丹率暴跌；丹药效果递减。 |
| 克制关系 | 辅助职业无直接互克，实战优劣见【互克关系】。 |
| 体系边界 | ①不可无条件复活（还魂丹须神魂未湮灭+因果偿还，WR-007/010）；②不可无限续命（效果递减，WR-007软）；③低阶无法理解高阶丹方（WR-014硬）。 |
| 特殊例外 | "以丹入道"：吞服禁忌丹药可强行突破，代价为丹毒攻心、寿元锐减五成，须提前铺垫丹药来源与禁忌知识。 |
| 上位规则合规声明 | 遵守硬规则：WR-001, WR-003, WR-004, WR-005, WR-008, WR-010, WR-011, WR-013, WR-014, WR-015, WR-017, WR-018。与软规则相关：WR-007（还魂丹因果/续命递减）、WR-012（命运非绝对）。触碰敏感边界：复活（还魂丹须神魂未湮灭+因果偿还，WR-007/010）、续命（效果递减，WR-007软）。确认无冲突。 |

## 【世界基本法则一致性检查】

1. **是否违反世界硬规则？** 否。力量有来源（灵草/灵矿，WR-003）、有消耗（神魂/灵气/材料，WR-004）、有上限（神魂/控火，WR-005）、不瞬移（WR-015）、不时间回溯（WR-018）、神魂湮灭不可逆（WR-010）。
2. **是否与世界力量法则一致？** 是。力量来源于灵草/灵矿，消耗为神魂/灵气/材料，上限受神魂限制，存在副作用（丹毒/炸炉）。
3. **是否与生命与死亡法则冲突？** 否。还魂丹须神魂未湮灭+因果偿还（WR-007软）；神魂湮灭真死（WR-010）；续命效果递减（WR-007软）。
4. **是否与因果法则冲突？** 否。还魂丹有因果代价；未设计绝对命运能力（WR-012）。
5. **是否产生无法解释的力量来源？** 否。所有力量来源明确为灵草/灵矿/天地精华。
6. **是否存在无代价能力？** 否。炼丹消耗神魂/灵气；炸炉反噬；长期服用丹毒积累。
7. **是否存在能力上限？** 是。每等级能力上限明确，成丹率/丹药效果/辨识数量均有硬上限。

> 检查结论：丹鼎道设计通过全部 7 项一致性检查，无冲突，可落位。
