# 体系卡 · 玄灵九叠

【基础定义】
| 字段 | 内容 |
|------|------|
| 体系名称 | 玄灵九叠 |
| 体系代号 | 灵修 |
| 本源描述 | 天地之间弥漫的原始能量，名为**灵力**。凡人如溺水者，灵力穿体而过却无法留存；修士以**灵纹**为引，将灵力导入体内**灵窍**（365 处储能节点），化为己用 |
| 修行方式 | 感灵→拓灵→凝灵→化灵→生灵→玄灵→道灵→真灵→苍灵。核心在于建设灵纹网络：先天灵纹者生来通道完整，后天灵纹者需以针刺墨、以骨为纸、以血为墨，一寸寸刻出引灵之路 |
| 代表人群 | 宗门弟子、世家贵族（先天骨纹完整）、底层散修（仅靠后天皮纹苦撑） |
| 破境考验 | 每突破一个大境界必须面对"灵窍劫"——天地对"人体窃灵"的排斥 |

【灵纹与灵窍总论】
| 概念 | 说明 |
|------|------|
| 灵力 | 天地本源能量，无处不在。无灵纹者，灵力穿体而过，百年不留痕 |
| 灵窍 | 人体天生 365 处储能节点，分九重天。单窍容量称为"池容"，因人而异：废窍(0.3)→浊窍(0.5)→清窍(1.0)→明窍(1.5)→灵窍(2.0)。扩窍上限为先天基准的 3 倍 |
| 先天灵纹 | 出生自带，分三层：皮纹（体表）、肉纹（肌理筋膜）、骨纹（骨骼内部）。骨纹是灵力直入灵窍的高速公路，效率为皮纹的五倍 |
| 后天灵纹 | 由灵纹师以灵针蘸灵墨刻画，一次刻入永久有效，但仅能模拟皮纹与浅层肉纹，**绝对无法触及骨纹**。灵墨入骨，骨髓沸腾，三日爆体 |
| 阶层铁律 | 贵族因先天骨纹，修炼速度是底层五倍；底层后天灵纹刻得再多，也缺骨纹这一层，永远追不上——除非以九曲十八弯的复杂皮纹网络，以量补质 |

【能力边界】
| 核心能力 | 上限与限制 |
|---------|-----------|
| 灵影投射 | 将铭刻之灵纹投影为实体攻击；上限：同小境界可投射九道，跨一阶（大境界）仅三道，跨两阶无效；限制：每道消耗一年寿元（可修炼回补） |
| 灵觉感知 | 感知范围内所有灵力波动，识破伪装与陷阱；上限：可识破高两阶（大境界）以下伪装；限制：对阵修布置的"无灵阵"无效 |
| 灵御护体 | 灵纹覆盖全身形成护甲；上限：可抵挡同小境界全力三击；限制：纯物理攻击（体修）对其造成150%伤害 |
| 言出灵随 | 仅限小范围（十丈→百丈，视小境界）改变环境纹理，不可直接干涉他人因果，不可逆转已发生事实，不可涉及生死轮回 |
| 灵源共鸣 | 可借用天地之势，但借用量不得超过自身承载极限（超过则神魂同化于天地，即"道化"） |

| 使用代价 | 每次使用玄灵九叠能力，消耗"命灵痕"（命魂上铭纹的磨损度），需以灵力或寿元修复，过度使用将直接折寿 |

| 致命弱点 | 1. 绝灵之地：无天地灵力的区域，灵修能力衰减90%；2. 灵修对阵修时，灵力易被阵法吸收转化为阵法能量 |

【互克关系】
| 克制体系 | 铁骨九铸（体修）——灵力直接攻击命魂， bypass 体修强横肉身，体修肉身越强，命魂相对越脆弱 |
| 被克体系 | 千机锁元（阵修）——阵法可锁定灵力流动路径，将灵修攻击吸收或反弹，灵修在阵中战力衰减30%-70% |
| 互克备注 | 互克非绝对：若体修修有"护魂"功法，或灵修境界高两阶以上，则克制关系逆转；若阵修布阵时间不足，或灵修以"灵爆"自毁式攻击，可破阵 |

【兼修机制】
| 可兼修体系 | 万火凝丹（丹修） |
| 兼修桥梁 | 灵火同调：灵纹可稳定丹火波动，使炼丹成功率提升，且丹纹（丹药内部纹理）与灵纹同源 |
| 兼修代价 | 破境时间翻倍（需同时满足两套体系条件），丹毒会以"灵斑"形式积累于灵窍内壁，需额外消耗"洗窍液"清除，否则该灵窍永久降级为浊窍 |
