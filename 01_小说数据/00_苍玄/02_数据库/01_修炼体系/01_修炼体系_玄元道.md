# 体系卡 · 玄元道

## 【基础定义】

| 字段 | 内容 |
|------|------|
| 体系名称 | 玄元道 |
| 体系代号 | 玄元 |
| 本源描述 | 天地灵气，万物之始。超凡力量来源于天地间的游离灵气，以及灵石、灵草、妖兽内丹等蕴含灵能之物，不可凭空产生。（WR-003） |
| 修行方式 | 吐纳天地灵气入体，经经脉运转淬炼，存于丹田气海；以功法引导灵气滋养肉身、凝练神魂，循序渐进，厚积薄发。拒绝跳级与顿悟，每一步须实打实积累。 |
| 代表人群 | 宗门正统修士、散修、修仙世家子弟、持异宝觉醒灵根的凡人 |
| 破境考验 | 每级晋升须面对一次考验：1级→2级心魔试、2级→3级道基雷劫、3级→4级斩念问心、4级→5级元婴天劫、5级→6级问道心劫、6级→7级虚空劫、7级→8级合魂大劫、8级→9级因果劫、9级圆满后九重天劫。详见【境界体系】。 |

## 【能力边界】

### 核心能力

| 能力名称 | 上限与限制 |
|----------|-----------|
| 灵气操控 | 同等级内灵气操控精度与储量上限受肉身与神魂强度限制（WR-005），超出则经脉爆裂 |
| 法术施展 | 可施展不高于自身等级三阶的法术，越阶施法需燃烧精血或寿元（WR-004） |
| 神识探查 | 神识外放距离见境界表，探查高阶修士可能被反噬致神魂受损 |
| 御器飞行 | 飞行速度受等级与法器品质双重限制，不可突破音障十倍（WR-015） |
| 法则感悟 | 5级后每级仅可主修一条法则，兼修法则不超过三条，否则法则冲突反噬 |
| 领域掌控 | 8级领域上限百丈，持续不超过一个时辰，过度展开损伤本源 |

### 能力细则（红线划定）

| 高危能力 | 红线规则 |
|----------|----------|
| 因果干预 | 仅7级后可初步干涉，每次须以等阶机缘/寿元/修为偿还；不可抹除因果，只能转移或延缓 |
| 复活术 | 8级后期方可触及，每次复活欠下天道因果，未来以等价机缘、寿元或修为偿还，每次翻倍（WR-007）；神魂湮灭则不可复活（WR-010） |
| 时间停滞 | 9级初期可短暂停滞一瞬（约0.1秒），须提前铺垫"触摸时间法则"剧情，每次使用折寿十年（WR-019软规则） |
| 瞬移/传送 | 不借助外物不可瞬移（WR-015）；6级后可借传送阵/传送符实现（WR-016） |
| 言出法随 | 8级领域范围内可有限实现，仅限领域内且不可违背世界硬规则 |

### 使用代价

- **普遍代价**：施展法术消耗丹田灵气，灵气枯竭后须调息恢复；过度使用损伤经脉（WR-004）。
- **越阶代价**：施展高于自身等级的法术，须燃烧精血或折寿，越一阶折寿十年，越两阶折寿五十年。
- **神识代价**：神识过度外放或探查高阶修士，导致头痛欲裂、短暂失明，严重者神魂受损。
- **法则代价**：法则感悟越深，越易受天道同化风险，长期不突破则逐渐丧失情感，化为"天道傀儡"。

### 致命弱点

1. **灵气依赖**：无灵气环境（如绝灵之地、某些位面）战力暴跌九成，近乎凡人。
2. **肉身脆弱**：同等级下肉身强度远低于金刚道，被近身则危。
3. **心魔易生**：因感悟天道、触及因果，高阶修士心魔滋生概率远高于其他体系。
4. **突破风险**：每次大等级突破失败均有严重后遗症（见【突破风险】）。

## 【体系规则】

> 本区块定义玄元道内部规则，优先级链：世界基本法则（上位）→ 玄元道体系规则 → 具体能力规则 → 剧情行为。

| 规则项 | 规则内容 |
|--------|----------|
| 力量来源 | 天地灵气及蕴含灵能之物（灵石、灵草、妖丹等），不可凭空产生（WR-003硬规则）。 |
| 修炼原理 | 吐纳→经脉运转→丹田储存→滋养肉身/神魂；每一步须积累足够灵气量方可晋升，拒绝无积累跳级。 |
| 消耗机制 | 施展力量消耗灵气，灵气枯竭后燃烧精血→折寿→损伤根基（WR-004硬规则）；不存在无代价能力。 |
| 突破条件 | ①资源：足够灵气/丹药/灵石支撑；②心境：通过破境考验（见【基础定义】）；③外部：安全环境或护法。三重门槛缺一不可。 |
| 突破风险 | 失败后果：①等级跌落至下一级圆满或后期；②经脉受损，修炼速度减半（持续半年至十年）；③寿元削减（视等级而定，约十年至百年）；④心魔滋生，下次突破难度翻倍。 |
| 能力限制 | 同等级内能力上限受肉身与神魂限制（WR-005）；越阶施法须燃烧精血/寿元；法则感悟上限三条；领域上限百丈/一时辰。 |
| 克制关系 | 克幽冥道（阳气克阴魂），被血煞道克（血气破灵气）；互克非绝对，取决于等级/环境/功法配合。 |
| 体系边界 | ①不可无条件复活（须因果偿还，WR-007软）；②不可时间回溯（WR-018硬）；③不借外物不可瞬移（WR-015硬）；④低阶无法理解高阶信息（WR-014硬）。 |

## 【世界基本法则一致性检查】

1. **是否违反世界硬规则？** 否。力量有来源（WR-003）、有消耗（WR-004）、有上限（WR-005）、不瞬移（WR-015）、不时间回溯（WR-018）、神魂湮灭不可逆（WR-010）。
2. **是否与世界力量法则一致？** 是。力量来源于天地灵气，消耗为灵气/精血/寿元，上限受肉身神魂限制，存在互克与副作用。
3. **是否与生命与死亡法则冲突？** 否。未设计无条件复活；复活须因果偿还（WR-007软规则）；神魂湮灭真死（WR-010）。
4. **是否与因果法则冲突？** 否。因果干预仅在7级后开放，且须付出代价；命运非绝对（WR-012），未设计绝对命运能力。
5. **是否产生无法解释的力量来源？** 否。所有力量来源明确为天地灵气或蕴含灵能之物。
6. **是否存在无代价能力？** 否。即使最低级法术也消耗灵气；越阶/特殊能力均有明确代价。
7. **是否存在能力上限？** 是。每等级能力上限明确，领域/法则/神识均有硬上限。

> 检查结论：玄元道设计通过全部 7 项一致性检查，无冲突，可落位。
