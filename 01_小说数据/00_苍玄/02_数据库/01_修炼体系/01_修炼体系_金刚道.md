# 体系卡 · 金刚道

## 【基础定义】

| 字段 | 内容 |
|------|------|
| 体系名称 | 金刚道 |
| 体系代号 | 金刚 |
| 本源描述 | 肉身气血与筋骨之力。力量来源于吞噬妖兽精血、天地灵物淬体、以及极限肉身锻炼，不可凭空产生（WR-003）。 |
| 修行方式 | 以极端肉身锻炼（负重、抗击打、极限环境生存）激发肉身潜能；吞噬妖兽精血/天地灵物滋养肉身；以气血冲刷筋骨脏腑，由内而外脱胎换骨。 |
| 代表人群 | 体修、武僧、蛮族战士、妖兽化形者 |
| 破境考验 | 每级晋升须承受肉身极限考验：1级→2级筋骨重铸、2级→3级骨髓换血、3级→4级五脏雷鸣、4级→5级髓海翻涌、5级→6级肉身问道、6级→7级不死身劫、7级→8级万象归一、8级→9级天地淬体、9级圆满后天罚雷躯。 |

## 【能力边界】

### 核心能力

| 能力名称 | 上限与限制 |
|----------|-----------|
| 肉身强度 | 同等级内肉身强度为四体系之首，但神魂相对薄弱（WR-005） |
| 气血化形 | 4级后可用，气血化为战兽/兵器，持本体五成战力，持续不超过一炷香 |
| 断肢重生 | 5级后可用，消耗气血储备，非无限；神魂受损则重生失效 |
| 滴血重生 | 6级后可用，一滴血重生肢体，消耗大量气血储备，每次重生后虚弱一月 |
| 气血分身 | 6级后可用，分身持本体三成战力，上限三道，持续不超过半日 |
| 肉身抗法则 | 9级后可用，同等级法则攻击效果减半，但高阶法则仍可有效伤害 |

### 能力细则（红线划定）

| 高危能力 | 红线规则 |
|----------|----------|
| 肉身复活他人 | 8级后期方可触及，以自身精血为引，每次折寿百年，且被复活者欠下复活因果（WR-007软）；神魂湮灭不可复活（WR-010硬） |
| 肉身破空 | 5级后可肉身突破音障，但不可瞬移（WR-015硬）；横渡虚空须借外物（WR-016软） |
| 位面破碎 | 9级后可一拳打开位面缝隙，限时一息，且肉身承受位面反噬，事后虚弱三日 |

### 使用代价

- **普遍代价**：肉身锻炼消耗气血，气血枯竭后燃烧肉身本源→肉身崩溃（WR-004）。
- **修炼代价**：肉身锻炼痛苦远超灵气修炼，每突破一次大等级须承受极端痛苦，心智不坚者易疯魔。
- **神魂代价**：专注肉身导致神魂相对薄弱，神魂攻击对其伤害+50%。
- **资源代价**：肉身淬炼需吞噬大量妖兽精血/天地灵物，资源消耗为玄元道三倍。

### 致命弱点

1. **神魂薄弱**：同等级下神魂强度远低于其他体系，被神魂攻击/控魂术克制。
2. **远程弱势**：缺乏远程攻击手段，须近身作战；被放风筝则危。
3. **资源饥渴**：肉身淬炼资源消耗巨大，底层体修极难获得足够资源。
4. **速度瓶颈**：虽肉身强横，但速度同等级下低于玄元道/血煞道，难以追击敌人。

## 【体系规则】

| 规则项 | 规则内容 |
|--------|----------|
| 力量来源 | 妖兽精血、天地灵物、极限肉身锻炼激发的肉身潜能（WR-003）。 |
| 修炼原理 | 极限锻炼→吞噬精血/灵物→气血冲刷筋骨脏腑→肉身蜕变；每一步须承受极端痛苦。 |
| 消耗机制 | 肉身锻炼消耗气血，气血枯竭燃烧肉身本源；神魂薄弱导致神魂防御消耗额外气血（WR-004）。 |
| 突破条件 | ①资源：足够妖兽精血/天地灵物；②心境：承受极端痛苦不破心志；③外部：安全环境或护法。 |
| 突破风险 | 失败后果：①肉身崩溃，终身残疾；②气血枯竭，等级跌落；③心志崩溃，沦为疯魔；④暗伤积累，寿元削减。 |
| 能力限制 | 同等级内能力上限受肉身强度限制（WR-005）；气血化形/分身/重生均有数量/时间上限；神魂薄弱。 |
| 克制关系 | 克血煞道（肉身强横不惧血气），被幽冥道克（阴魂蚀神魂）；互克非绝对。 |
| 体系边界 | ①不可无条件复活（须精血为引+因果偿还，WR-007软）；②不可时间回溯（WR-018硬）；③不借外物不可瞬移（WR-015硬）；④神魂薄弱为结构性弱点。 |
| 特殊例外 | "以伤入道"：承受极端伤害后可强行破境，代价为留下永久暗伤，每次动用全力暗伤发作，战力下降一成。 |
| 上位规则合规声明 | 遵守硬规则：WR-001, WR-003, WR-004, WR-005, WR-008, WR-010, WR-011, WR-013, WR-014, WR-015, WR-017, WR-018。与软规则相关：WR-007（复活因果）、WR-012（命运非绝对）、WR-016（传送外物）。触碰敏感边界：肉身复活他人（8级后期开放，折寿百年+因果偿还）、位面破碎（9级限时一息+反噬）。确认无冲突。 |

## 【世界基本法则一致性检查】

1. **是否违反世界硬规则？** 否。力量有来源（精血/灵物/锻炼，WR-003）、有消耗（气血/肉身本源，WR-004）、有上限（肉身强度，WR-005）、不瞬移（WR-015）、不时间回溯（WR-018）、神魂湮灭不可逆（WR-010）。
2. **是否与世界力量法则一致？** 是。力量来源于精血/灵物/锻炼，消耗为气血/肉身本源/神魂薄弱，上限受肉身限制，存在互克与副作用。
3. **是否与生命与死亡法则冲突？** 否。复活须精血为引+因果偿还（WR-007软）；神魂湮灭真死（WR-010）。
4. **是否与因果法则冲突？** 否。复活有因果代价；未设计绝对命运能力（WR-012）。
5. **是否产生无法解释的力量来源？** 否。所有力量来源明确为精血/灵物/肉身锻炼。
6. **是否存在无代价能力？** 否。即使肉身防御也持续消耗气血；锻炼伴随极端痛苦。
7. **是否存在能力上限？** 是。每等级能力上限明确，气血/分身/重生均有硬上限。

> 检查结论：金刚道设计通过全部 7 项一致性检查，无冲突，可落位。
