# 体系卡 · 灵傀道（辅助职业）

## 【基础定义】

| 字段 | 内容 |
|------|------|
| 体系名称 | 灵傀道 |
| 体系代号 | 灵傀 |
| 本源描述 | 神魂分念与材料灵性。力量来源于修士神魂分化注入傀儡，以及特殊材料（灵木、玄铁、妖兽骨骼等）蕴含的灵性，不可凭空产生（WR-003）。 |
| 修行方式 | 以神魂分念控制傀儡；收集材料炼制/强化傀儡；通过操控傀儡战斗积累经验，反哺神魂。不走传统等级体系，以"级"衡量造诣。 |
| 代表人群 | 傀儡师、机关师、散修中的"一人成军"者 |
| 破境考验 | 每升一级须通过"控傀试"：在限定条件下操控傀儡完成指定任务，失败则神魂受创、傀儡损毁。 |

---

## 【境界体系】

> 基准对照系：以玄元道为通用参照。结构：1~9 级简表（等级编号｜对应主修等级｜核心能力｜战力标志）。

| 等级编号 | 对应主修等级 | 核心能力 | 战力标志 |
|----------|-------------|----------|----------|
| **1级** | 1级（炼气） | 可操控1具低级傀儡（木质/石质），神魂分念1道 | 傀儡持本体三成战力，可执行简单指令 |
| **2级** | 2级（筑基） | 可操控3具低级傀儡，神魂分念3道；开始炼制傀儡 | 傀儡持本体四成战力，可协同作战 |
| **3级** | 3级（金丹） | 可操控1具中级傀儡（玄铁/灵木），神魂分念可离体附着 | 中级傀儡持本体六成战力，可施展简单法术 |
| **4级** | 4级（元婴） | 可操控3具中级傀儡或1具高级傀儡（妖兽骨骼/稀有金属） | 高级傀儡持本体八成战力，可自主战斗（预设指令） |
| **5级** | 5级（化神） | 可操控5具中级傀儡或3具高级傀儡；神魂分念可短暂独立 | 分念独立可持续一炷香，各持本体五成战力 |
| **6级** | 6级（炼虚） | 可操控1具灵傀（有初等灵性），神魂与灵傀可共鸣 | 灵傀持本体十成战力，可学习成长（上限低阶法术十种） |
| **7级** | 7级（合体） | 可操控3具灵傀；神魂可与灵傀暂时融合 | 融合后灵傀战力翻倍，持续不超过半日 |
| **8级** | 8级（大乘） | 可操控1具仙傀（有完整灵魂雏形，WR-008）；创造傀儡生命 | 仙傀持本体十二成战力，可自主修炼（速度为本体十分之一） |
| **9级** | 9级（渡劫） | 可操控3具仙傀或1具神傀（有独立灵魂，WR-008）；傀儡即本体 | 神傀持本体十五成战力，可独立渡劫（失败不影响本体） |

## 【能力边界】

### 核心能力

| 能力名称 | 上限与限制 |
|----------|-----------|
| 傀儡操控 | 同等级内操控数量见境界表；超出数量则神魂负担过重，反噬风险剧增 |
| 神魂分念 | 分念数量受神魂强度限制（WR-005）；分念被灭则本体神魂受损 |
| 傀儡炼制 | 炼制高阶傀儡需稀有材料与长时间（数月到数年）；炼制失败材料全毁 |
| 灵傀共鸣 | 6级后可用，与灵傀共鸣可共享感知，但共鸣期间本体无防备 |
| 仙傀创造 | 8级后可创造有灵魂雏形的仙傀（WR-008），但仙傀反叛概率随数量增加 |

### 能力细则（红线划定）

| 高危能力 | 红线规则 |
|----------|----------|
| 创造有灵魂傀儡 | 8级后仙傀有灵魂雏形（WR-008），9级后神傀有独立灵魂；独立灵魂可能反叛，反叛概率：仙傀5%/神傀15% |
| 傀儡替死 | 可令傀儡替本体承受致命一击，但替死傀儡须提前以本命神魂祭炼，替死后神魂受创（WR-008） |
| 神傀独立渡劫 | 神傀可独立渡劫，失败不影响本体，但神傀毁灭后本体损失大量神魂与资源 |

### 使用代价

- **普遍代价**：操控傀儡持续消耗神魂之力，神魂枯竭后头痛欲裂、昏迷（WR-004）。
- **分念代价**：每道分念被灭，本体神魂受损一成，恢复需数月。
- **材料代价**：高阶傀儡材料稀有且昂贵，底层灵傀师极难获得。
- **反叛代价**：高阶傀儡（仙傀/神傀）可能反叛，反叛时反噬神魂，严重者神魂湮灭（WR-010风险）。

### 致命弱点

1. **本体脆弱**：灵傀师本体通常弱于同等级主修修士，被近身则危。
2. **神魂依赖**：一切能力基于神魂，神魂受创则全线崩溃。
3. **资源黑洞**：高阶傀儡是无底洞，材料/时间/神魂消耗巨大。
4. **反叛风险**：高阶傀儡独立意识越强，反叛风险越高。

## 【互克关系】

> 辅助职业不参与直接互克，但存在实战中的优劣势关系。

| 关系类型 | 目标体系 | 优劣逻辑 |
|----------|----------|----------|
| 优势对 | 玄元道 | 灵傀师以多打少，可消耗玄元道修士灵气；但玄元道高阶法则可直接摧毁傀儡核心 |
| 劣势对 | 幽冥道 | 幽冥道阴魂可侵蚀傀儡灵性，直接攻击灵傀师神魂；同等级下灵傀师对幽冥道劣势明显 |
| 备注 | — | 优劣非绝对。灵傀品质/数量/配合可扭转局势；幽冥道若缺乏高阶鬼物，灵傀师可凭数量压制 |

| 阵纹道 | 以阵纹强化傀儡，可布"傀阵" | 傀阵复杂度高，布阵失败傀儡自毁 |

## 【体系规则】

| 规则项 | 规则内容 |
|--------|----------|
| 力量来源 | 神魂分念、材料灵性、傀儡核心（妖丹/灵石等）（WR-003）。 |
| 修炼原理 | 神魂分念→注入傀儡→操控战斗→积累经验→反哺神魂→提升等级。 |
| 消耗机制 | 操控消耗神魂之力，神魂枯竭后昏迷/受损（WR-004）；炼制消耗材料与时间。 |
| 突破条件 | ①资源：足够材料炼制对应等级傀儡；②心境：通过控傀试；③外部：安全环境。 |
| 突破风险 | 失败后果：①神魂受创，操控数量下降；②傀儡损毁，材料全失；③分念反噬，本体昏迷。 |
| 能力限制 | 同等级内能力上限受神魂强度限制（WR-005）；操控数量/分念/傀儡等级均有上限。 |
| 克制关系 | 辅助职业无直接互克，实战优劣见【互克关系】。 |
| 体系边界 | ①不可创造真正独立生命（神傀有独立灵魂但受控，WR-008/012）；②不可时间回溯（WR-018硬）；③不借外物不可瞬移（WR-015硬）。 |
| 特殊例外 | "以傀代身"：可将本体转化为傀儡，丧失血肉之躯但获得傀儡不死特性，须提前铺垫转化仪式与材料。 |
| 上位规则合规声明 | 遵守硬规则：WR-001, WR-003, WR-004, WR-005, WR-008, WR-010, WR-011, WR-013, WR-014, WR-015, WR-017, WR-018。与软规则相关：WR-007（傀儡替死非真正复活）、WR-012（神傀命运受控）。触碰敏感边界：创造灵魂（8级后灵魂雏形，9级后独立灵魂但受控，WR-008/012）。确认无冲突。 |

## 【世界基本法则一致性检查】

1. **是否违反世界硬规则？** 否。力量有来源（神魂/材料，WR-003）、有消耗（神魂，WR-004）、有上限（神魂强度，WR-005）、不瞬移（WR-015）、不时间回溯（WR-018）、神魂湮灭不可逆（WR-010）。
2. **是否与世界力量法则一致？** 是。力量来源于神魂/材料，消耗为神魂/材料/时间，上限受神魂限制，存在实战优劣。
3. **是否与生命与死亡法则冲突？** 否。未设计复活能力；傀儡替死不涉及真正复活；神魂湮灭真死（WR-010）。
4. **是否与因果法则冲突？** 否。未设计因果能力；神傀受控不涉及命运绝对（WR-012）。
5. **是否产生无法解释的力量来源？** 否。所有力量来源明确为神魂/材料/妖丹。
6. **是否存在无代价能力？** 否。操控持续消耗神魂；分念被灭反噬；炼制消耗资源。
7. **是否存在能力上限？** 是。每等级能力上限明确，操控数量/分念/傀儡等级均有硬上限。

> 检查结论：灵傀道设计通过全部 7 项一致性检查，无冲突，可落位。
