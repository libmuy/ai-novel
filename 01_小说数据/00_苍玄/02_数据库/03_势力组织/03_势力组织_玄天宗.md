# 势力卡 · 玄天宗

## 【基础档案】

| 字段 | 内容 |
|------|------|
| 势力名称 | 玄天宗 |
| 体系/境界上限 | 修行"玄天罡气诀"；宗主"玄天上人"为玄元道4级中期（元婴中期），宗内长老多为元婴初期 |
| 地理位置 | 山门设于 @地名.紫极天域 "玄天峰"，控制紫极天域东部三千里灵脉 |
| 核心思想 | "玄天之下，万法归宗；九宗并列，唯我玄天。" |

## 【三要素】

| 立场 | 紫极天域九宗联盟成员，与 @势力.紫极仙宗 存在"表面合作、暗中竞争"的关系；在九宗演武中与紫极仙宗争夺盟主之位 |
|------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 欲望 | 在下一届九宗演武中击败紫极仙宗，夺取九宗联盟盟主之位，获得紫极天域最高话语权 |
| 底线 | 若紫极仙宗试图以武力吞并玄天宗或剥夺其九宗席位，玄天宗将联合其他中小宗门发动"宗门大战" |

## 【生存逻辑】

| 经济来源 | 灵脉开采、弟子供奉、九宗联盟拨款、高阶功法传授费 |
|----------|----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 武力构成 | 核心战力为十二名元婴期长老与三百名金丹期弟子，靠正统功法与阵法；弱点是弟子实战能力不足 |
| 信息渠道 | 九宗联盟情报共享、紫极天域散修网络、云璃坊链商户眼线 |

## 【关系网络】

| 敌对势力 | @势力.紫极仙宗（争夺九宗盟主）、@势力.天璇世家盟（世家与宗门的结构性矛盾） |
|----------|----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 潜在盟友 | @势力.天罡阁（共同对抗紫极仙宗的知识垄断） |

| 当前状态 | 中立。主角在九宗演武中崭露头角，引起玄天宗关注 |
|----------|----------------------------------------------------------------------------------------------------------|
| 关系演变轨迹 | 中立（观察）→ 拉拢（玄天宗试图招揽主角为客卿）→ 博弈（主角拒绝依附，玄天宗转为打压）→ 合作（面对紫极仙宗威胁时，主角与玄天宗暂时联手） |
| 主角价值 | ① 主角的异宝可辅助玄天宗探索远古遗迹；② 主角的"底层金句"在玄天宗年轻弟子中引发思潮，威胁宗门传统权威 |
