### 【角色内核】

| 字段 | 必填 | 内容 |
|------|------|------|
| 立场 | (必) | 站在@势力.[血牙寨]「血子」身份与「保护寨中孤儿」的矛盾之间。表面服从寨主，暗中反抗「炼魂换修为」的极端命令。 |
| 欲望 | (必) | 摆脱@势力.[血牙寨]控制，保护寨中被培养的孤儿不被当作「血食」炼魂。不求自由，只求「那些孩子不用变成我」。 |
| 底线 | (必) | ① 不杀寨中孤儿（哪怕寨主命令，以自残抗命）；② 不背叛唯一的朋友（苏砚，从追杀者变为合作者）；③ 不吸凡人血（只吸修士，且尽量吸该死之人）。 |

| 字段 | 内容 |
|------|------|

| 主角对其的影响 | 因苏砚而看到「另一条路」的可能，从认命转为反抗；因苏砚而第一次相信「血牙寨的人，也可以被当作人看」。 |

### 【独立故事线】

| 字段 | 内容 |
|------|------|
| 人生目标 | 摆脱@势力.[血牙寨]控制，保护寨中孤儿，炸毁寨中「血池」（以孤儿炼魂的禁地）。 |
| 当前进度 | 已成为寨中「血子」，但开始暗中抗命——三次拒绝炼魂任务，被寨主以「血咒」惩罚，修为倒退一层。 |
| 高光时刻设计 | 在@势力.[冥河殿]攻寨时，血罗汉本可独自逃走（血咒已解，自由在望），却选择引爆自身血煞本源，与冥河殿先锋同归于尽，为寨中孤儿争取逃生时间。死前对苏砚说：「你走的路，我下辈子试试……这辈子，就让我当一回人吧。」 |
| 预计退场方式 | 死亡。以自爆血煞本源与敌同归于尽，尸骨无存，唯留血骨爪碎片于苏砚手中。（壮烈收场） |
| 退场情感基调 | 壮烈。他终于从「血子」变成了「人」。 |

### 【创作标签】

| 字段 | 内容 |
|------|------|
| 情绪功能 | 悲剧预警。预示修仙界「弱肉强食」逻辑下，即便强者也是受害者。他的死不是解脱，是控诉——控诉这个让人无法做人的世界。 |
| 说话风格 | 沉默寡言，偶尔一句话很狠，像刀。对敌人不说话，直接砍；对孤儿说话温柔，但结巴；对苏砚说话最短，因为「说多了，怕舍不得死」。 |
| 标志性细节 | 杀人后会在骨片上画一道血痕（最初画在手腕，后来痕太多，改画在随身骨片上）。骨片攒了三百七十二片，每片代表一个该死之人——他记得每一个人的脸。 |
