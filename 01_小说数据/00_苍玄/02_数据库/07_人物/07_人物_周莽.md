### 【独立故事线】

| 字段 | 内容 |
|------|------|
| 人生目标 | 为十年前矿难死的兄弟讨说法，让@势力.[黑石会]承认错误、发放抚恤。次要目标：看着苏砚走出去。 |
| 当前进度 | 攒了半辈子灵石，刚够买一颗低阶丹药续命，被苏砚以古玉灵植所救，省下灵石用于调查矿难真相，已找到黑石会掩盖证据的矿道日志残页。 |
| 高光时刻设计 | 在苏砚被@势力.[黑石会]高手围攻于矿道时，周莽以凡人之躯引爆预先埋下的「火硝矿囊」（矿下违禁品），与敌人同归于尽，炸塌矿道为苏砚争取逃生时间。死前把攒了半辈子的灵石袋塞给苏砚：「走出去，别回头……替老子看看，上面的天是不是蓝的。」 |
| 预计退场方式 | 死亡。以凡人肉身引爆矿道，与@势力.[黑石会]修士同归于尽，尸骨埋于矿下。（苍凉 + 温暖收场） |
| 退场情感基调 | 苍凉而温暖。他这辈子没出过矿城，但他的死为苏砚铺出了第一条路。 |

### 【创作标签】

| 字段 | 内容 |
|------|------|
| 情绪功能 | 温暖担当/悲剧预警。是苏砚的「矿城父亲」，代表底层老一辈的善良与无力。他的死预警读者：在修仙界，善良如果没有力量，只能以命换命。 |
| 说话风格 | 粗俗但心软，爱骂人，护短。骂苏砚时最狠（「你个小兔崽子又偷下危险矿道！」），但骂完会把自己的干粮塞过去。对黑石会高层低声下气，对矿友大声嚷嚷。 |
| 标志性细节 | 腰间永远挂着一个缺嘴的酒葫芦，葫芦里永远有半壶药酒——不是给自己喝的，是给矿友止血用的。他咳血时从不喝，说「老子的血，比药酒值钱」。 |
