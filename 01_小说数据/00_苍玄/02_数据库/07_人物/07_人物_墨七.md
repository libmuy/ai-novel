### 【修行档案】

| 字段 | 必填 | 内容 |
|------|------|------|
| 修行体系 | (必) | 玄元道·炼气七层 + 幽冥道杂修（半吊子，靠偷学阁中禁书，未得真传） |
| 当前境界 | (必) | 玄元道·炼气七层（对应基准炼气后期），幽冥道·鬼眼（可看破低阶幻术与伪装） |
| 功法/神通特色 | | ① **鬼影步**：幽冥道潜行术，可在阴影中隐匿气息三息，用于逃命与伏击，非正统传承，步法别扭像瘸子。② **千面**：低阶易容术，靠人皮面具 + 神魂微调，可模仿声音但模仿不了习惯（常被苏砚识破）。③ **听风**：非战斗神通，情报收集术，可通过灵气波动判断方圆百丈内的人数与大致修为（误差率三成）。 |
| 本命法宝/武器 | | 无。靠暗器（淬毒骨钉）、迷烟、以及「缺角铜钱」（实为低阶储物法器，内藏保命毒粉）。 |
| 战斗风格 | | 不正面战斗。伏击 + 毒 + 情报战 + 逃跑。座右铭：「能打过的不用打，打不过的不能打。」 |

### 【角色内核】

| 字段 | 必填 | 内容 |
|------|------|------|
| 立场 | (必) | 站在「自己」一边。游离于@势力.鬼手阁「红线」（杀人）与「灰线」（情报）之间，靠信息差活着。不信任任何势力，只信任「已经付过钱的人」。 |
| 欲望 | (必) | 查清师父（鬼手阁上一任灰线负责人）被灭口的真相，不想一辈子当别人的刀。次要欲望：攒够钱买一条离开@区域.云璃坊链的路。 |
| 底线 | (必) | ① 不出卖给了钱的人（职业道德，也是唯一的人格锚点）；② 不杀无辜（只杀该死之人，且尽量借刀杀人，不脏自己的手）；③ 不碰小孩买卖（@势力.鬼手阁涉及人口贩卖，墨七绝不接相关单）。 |

### 【与主角关系】

| 字段 | 内容 |
|------|------|
| 初遇地点 | @地名.九曲长街（黑市交易，苏砚买情报，墨七卖黑石会巡逻路线图） |
| 初遇关系定位 | 交易对象 |
| 关系演变轨迹 | 交易对象 → 互相猜忌（苏砚推演墨七，墨七反追踪苏砚） → 利益同盟（共同对抗@势力.云璃商会） → 生死之交（「你死了，这修仙界就彻底没趣了」） |
| 对主角的影响 | 教会苏砚「利益可以计算，但别把自己也算成数字」。苏砚的推演从此多了一条「人性误差」变量——因为墨七证明，人有时候会做亏本买卖。 |
| 主角对其的影响 | 因苏砚而相信「这世上有人值得不计回报地帮」，从纯利益导向转为有底线；因苏砚而第一次觉得「灰线」之外，还有别的活法。 |

### 【独立故事线】

| 字段 | 内容 |
|------|------|
| 人生目标 | 查清师父被@势力.云璃商会灭口的真相，并以此为筹码脱离@势力.鬼手阁。 |
| 当前进度 | 已查到师父之死与@势力.云璃商会「垄断跨区域贸易路线」有关，证据藏在商会密室，尚未得手。 |
| 高光时刻设计 | 在苏砚被全修仙界通缉时，墨七本可出卖苏砚换取@势力.鬼手阁阁主之位，却选择用全部积蓄和人情买通追杀路线，伪造苏砚已死证据。留下一句：「你死了，这界就彻底没趣了——我还等着看你推翻云璃商会呢。」 |
| 预计退场方式 | 离开。查清真相后，以证据要挟@势力.鬼手阁放人，远走他界。（释然收场） |
| 退场情感基调 | 释然。他终于不再是任何人的刀。 |

### 【创作标签】

| 字段 | 内容 |
|------|------|
| 情绪功能 | 黑暗揭示/利益镜子。照出修仙界的灰色地带，让读者明白「不是所有人非黑即白，但灰色地带也要付过路费」。 |
| 说话风格 | 阴阳怪气 + 笑面虎。每一句话都在试探，每一个笑容都在估价。对苏砚说话像谈判（「这条命，你出多少灵石？」），但关键时刻从不讲价。 |
| 标志性细节 | 说话时总爱转一枚缺角的铜钱，转得越快说明越紧张；铜钱停转时，就是他要做决定的时候——而那个决定，往往出人意料。 |
