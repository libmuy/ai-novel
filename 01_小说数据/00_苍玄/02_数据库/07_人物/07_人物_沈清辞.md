### 【与主角关系】

| 字段 | 内容 |
|------|------|
| 初遇地点 | @地名.[天璇圣城]（执法堂，苏砚被当作「异宝持有者嫌疑人」扣押，沈清辞为执法弟子） |
| 初遇关系定位 | 执法者 vs 嫌疑人 |
| 关系演变轨迹 | 执法者vs嫌疑人 → 理念冲突（苏砚的「底层道义」vs 沈清辞的「宗门规矩」） → 互相理解（沈清辞发现规矩之外有人道，苏砚发现规矩之内有空间） → 道不同但相为谋（「你走你的灰线，我守我的规矩，但目标一样」） |
| 对主角的影响 | 教会苏砚「规则可以被利用，也可以被改变」。苏砚从此学会在修仙界的规则缝隙中游走，而非一味对抗。 |
| 主角对其的影响 | 因苏砚而质疑「宗门永远正确」的教条，从盲从规矩转为理解规矩之外的人道；因苏砚而第一次抗命，以规矩对抗命令。 |

### 【独立故事线】

| 字段 | 内容 |
|------|------|
| 人生目标 | 改革@势力.[紫极仙宗]外门制度，建立寒门弟子「功勋晋升制」，打破世家垄断。 |
| 当前进度 | 刚入内门，发现改革阻力极大——世家弟子把控「功勋评定权」，寒门功劳被吞没。已开始暗中收集证据。 |
| 高光时刻设计 | 在@势力.[紫极仙宗]命令其追杀苏砚（因苏砚身怀异宝）时，沈清辞在执法堂上以「宗门规矩」对抗「宗门命令」：「规矩说，未经审判不得定罪；命令说，先杀后审。我选规矩。」自断一臂谢罪，以废人之躯护住苏砚三日逃亡时间。 |
| 预计退场方式 | 未退场。于@势力.[紫极仙宗]内持续改革，成为寒门派领袖，以「断臂剑仙」之名留于宗门史册。（坚守收场） |
| 退场情感基调 | 温暖。他证明了规矩之内，也可以有人道。 |

### 【创作标签】

| 字段 | 内容 |
|------|------|
| 情绪功能 | 道义对照。与苏砚形成「体制外道义」vs「体制内规矩」的对照，让读者看到：改变可以从内部发生，也可以从外部施压，两者缺一不可。 |
| 说话风格 | 文言腔 + 寡言 + 认死理。说话像背书（「宗门戒律第三十七条……」），但背完会补一句自己的理解（「……但此条之意，在护弱，非护强」）。 |
| 标志性细节 | 紧张时会反复整理袖口，越紧张整理得越频繁；断臂后改用左手整理左袖，动作笨拙但固执，像是对失去右臂的无声抗议。 |
