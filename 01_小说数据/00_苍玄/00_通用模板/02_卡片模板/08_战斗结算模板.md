# 战斗结算模板

> 类型：卡片模板 · 定义字段与填写示例，用于生成/维护战斗结算数据。数据落位：`正文卷N/00_事件卡/<BT-卷号-序号>_战斗结算.md`。
>
> 任何涉及主角的战斗（无论胜负）都必须填写；纯修炼切磋可简化。战斗不是"打赢了"就结束，必须清算代价、传播消息、调整势力关系。**战前设计与战后结算共用本卡**，不另设跨体系冲突卡。

## 字段与示例

`(必)`=必填、`(条)`=条件必填，其余选填；示例值为格式参考，勿照抄。

### 战斗结算 · [BT-卷号-序号]

【基础信息】
| 字段 | 必填 | 说明与示例 |
|------|------|-----------|
| 战斗ID | (必) | 格式：`BT-卷号-序号`，如 `BT-V1-003` |
| 发生章节 | (必) | 如 `第15章` |
| 战斗类型 | (必) | 遭遇战/伏击战/阵地战/追逐战/生死战/试探性交手 |
| 战斗规模 | (必) | 单挑/小队（2-5人）/群战（5人以上） |
| 是否跨体系 | (必) | 是/否。为"是"时必须填写「跨体系冲突」区块 |

【参战方】
| 甲方 | (必) | `@主角` 或 `@配角.姓名`，注明当前境界 |
| 乙方 | (必) | `@配角.姓名` 或 `@势力.名称`，注明当前境界/人数 |
| 甲方战力评估 | (必) | 战前客观战力（含装备、状态、环境优势） |
| 乙方战力评估 | (必) | 战前客观战力 |
| 战力对比 | (必) | 如：甲方弱三成/势均力敌/甲方强两成。必须诚实 |

【战斗设计】
| 战斗目标 | (必) | 甲方为什么打？（逃命/夺宝/灭口/拖延/试探） |
| 环境条件 | (必) | 地形、天气、时间、有无第三方。环境必须影响战斗 |
| 甲方策略 | (必) | 主角怎么打？忌"正面硬刚"，要有具体战术 |
| 乙方策略 | (必) | 敌人怎么打？敌人必须有脑子，会针对主角弱点 |
| 外部条件 | (条) | 若为跨体系战斗，此处填写体系互克如何体现（见「跨体系冲突」） |
| 转折点 | (必) | 战斗最关键转折（主角示弱诱敌/环境突变/第三方介入/底牌暴露） |

【跨体系冲突】（条件必填：`是否跨体系` = 是）
| 利益冲突 | (必) | 争什么具体资源/位置/秘密？ |
| 理念冲突 | (必) | 甲方认为……，乙方认为……（"谁信什么"的分歧） |
| 甲方道理 | (必) | 用甲方体系逻辑说话，忌骂人 |
| 乙方道理 | (必) | 用乙方体系逻辑反驳 |
| 甲方体系优势 | (必) | 甲方用什么手段克制乙方？ |
| 乙方反制手段 | (必) | 乙方如何利用环境/法宝/特点反制？ |
| 甲方反思 | | 战后：对方的道理有没有可取之处？ |
| 认知变化 | (必) | 战后：主角对某体系的理解发生什么改变？ |

【战斗结果】
| 胜负 | (必) | 胜/负/平局/逃脱 |
| 击杀名单 | | 谁死了？引用 `@配角.姓名`。每个死亡必须有原因 |
| 甲方伤势 | (必) | 必须具体（左臂骨折、三根肋骨裂纹、灵气耗尽、神识受损） |
| 甲方消耗 | (必) | 消耗了哪些资源？引用 `@资源.名称` |
| 战利品 | | 引用 `@资源.名称`，必须有来源。跨体系战利品注明"需研究/无法直接使用" |

【战后结算】（重点）
| 消息传播 | (必) | 战斗结果被谁看到？怎么传出去？范围多大？（方圆十里/整个坊市/某个势力） |
| 后续追查 | (条) | 若有人死亡或势力受损，谁会追查？力度如何？ |
| 势力关系变化 | | 哪些势力因此改变对主角态度？ |
| 新敌人/新盟友 | | 产生了什么新的敌友关系？ |
| 心理影响 | (必) | 主角对战斗的心理反应？（第一次杀人的呕吐、险死还生的后怕、对力量的渴望） |
| 断裂伏笔/任务链 | (条) | 因本次战斗导致的死亡/伤残/势力灭绝，哪些已登记伏笔（引用 `@伏笔.ID`）失效或必须强制转向？各注明"失效原因"与"转向方案" |
| 消息封锁代价 | (条) | 若主角试图"杀人灭口且无人知晓"，必须结算一项具体的"因果代价"（遗落带气味的碎布、被飞禽目睹、战斗痕迹无法清理等），禁止"完美灭口" |

## 跨体系战斗标准流程

战斗/突破/资源的通用红线见 `00_通用写作规则` §7（无脑爽禁令、突破门槛），逐项自检见其第八章【事件设计层】。本卡只定义流程：

```
Step 1: 战前设计 → 填写「跨体系冲突」区块（理念碰撞、体系优势/反制）
Step 2: 正文生成 → 按 00_通用写作规则 + 本书所选文风模板 + 本卡规则写战斗过程
Step 3: 战后结算 → 填写「战后结算」区块（代价、战利品、消息传播）
```

- 「跨体系冲突」= 战前设计：解决"为什么打""双方理念差异""体系互克如何体现"
- 「战后结算」= 战后结算：解决"打完代价是什么""谁死了""消息怎么传"
- 「战斗设计」的 `外部条件` 字段应引用「跨体系冲突」设计的"甲方体系优势/乙方反制手段"
