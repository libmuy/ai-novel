# 小说概念 · 苍玄

## 【基础定位】

| 字段 | 内容 |
|------|------|
| **题材类型** | 修仙-底层成长（叙事参考《凡人修仙传》《剑来》） |
| **一句话简介** | 凡人少年持异宝步步积累，以底层金句破幻象，求长生亦守底线。 |

## 【核心定位】

| 字段 | 内容 |
|------|------|
| **卖点** | ① **底层金句视角**：主角以底层身份行走修仙界，时不时以金句刺破阶层幻象与社会荒诞，让读者在爽感中获得对现实社会的深层共鸣。<br>② **渐进式全能成长**：主角最终趋近全能，但每一步都是实打实的积累结果，拒绝跳级与顿悟，完整呈现"凡人如何一步步走到巅峰"的扎实路径。<br>③ **异宝爽感驱动**：异宝机制设计带来强烈的阅读爽感，与渐进式成长形成"爽而不飘"的节奏张力。 |
| **核心矛盾** | 在弱肉强食的修仙界，主角以善良为刃、以智为盾，在求长生与守底线之间反复撕扯。 |
| **基调** | 热血加幽默 |
| **受众** | 喜欢《凡人修仙传》《剑来》式扎实叙事，同时希望有轻松幽默调剂的读者 |
