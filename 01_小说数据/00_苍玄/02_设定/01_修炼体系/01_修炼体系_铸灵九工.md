# 体系卡 · 铸灵九工（器修）

【基础定义】
| 体系名称 | 铸灵九工 |
| 体系代号 | 器修/铸师 |
| 本源描述 | 天地灵力在器物中的固化。铸器师以灵纹为骨、以材料为肉，将灵力通道铸入器物 |
| 修行方式 | 观器→摹纹→铸纹→养纹，以双手为媒介、以神识为锤，极度依赖材料积累与反复实践 |
| 代表人群 | 宗门器堂弟子、坊市铸匠、遗迹发掘者、专精修补古器的"缝器人" |
| 破境考验 | 每大境界需独立铸造一件对应等级法宝，并通过"器劫"——法宝成型瞬间引动的天地灵压，铸师需以神识硬抗器物反噬 |

【境界体系】
| 等级 | 对应主修境界 | 核心能力 | 战力标志 |
|------|------------|---------|---------|
| 1 级 | 感灵境 | 辨材质真伪 | 可铸凡纹器 |
| 2 级 | 拓灵境 | 摹纹无误，锻灵萌芽 | 可铸灵纹器雏形 |
| 3 级 | 凝灵境 | 锻灵醒，器鸣如钟 | 可铸标准灵纹器 |
| 4 级 | 化灵境 | 器三变，生灵咿呀 | 可铸玄纹器雏形 |
| 5 级 | 生灵境 | 器灵学语，通玄自修 | 可铸标准玄纹器 |
| 6 级 | 玄灵境 | 器择主，遇强则强 | 可铸道纹器 |
| 7 级 | 道灵境 | 载三道纹，真铸感应 | 可铸真纹器 |
| 8 级 | 真灵境 | 器替死，真铸不灭 | 可铸苍纹器雏形 |
| 9 级 | 苍灵境 | 天工开物，无中生有 | 可铸完整苍纹器 |

基准对照系：以玄灵九叠为通用参照。

【能力边界】
| 核心能力 | 上限与限制 |
|---------|-----------|
| 铸纹 | 将灵纹固化于器物；上限：同等级可铸造对应等级法宝，跨一阶（大境界）成功率降至30%，跨两阶必败；限制：必须在灵气稳定环境进行，灵气狂暴成功率归零 |
| 养纹 | 温养提升器物品质；上限：可将法宝提升一小阶，不可跨大阶；限制：需持续以自身神识与灵气喂养，耗时同境界修炼时间的三倍 |
| 识纹 | 识别器物内部纹理与隐患；上限：识别高两阶（大境界）器物；限制：对"无纹器"（上古遗留）无效 |

| 使用代价 | 每次铸造消耗"铸纹痕"（双手神识磨损），过度使用则双手颤抖、神识枯竭，终生无法再铸 |

| 致命弱点 | 1. 战斗力极弱：同小境界战力仅为灵修两成；2. 铸火依赖：铸火被压制则能力衰减80%；3. 材料依赖：无材料即无能力 |

【互克关系】
| 克制体系 | 无直接克制，高品质法宝可弥补任何体系短板 |
| 被克体系 | 玄灵九叠（灵修可复制铸造纹理）、万火凝丹（丹火干扰铸火） |
| 互克备注 | 若铸师以"纹锁"封死器纹路径，灵修难以复制；若丹修未修至化液境以上，丹火不足以干扰锻灵境以上铸师 |

【兼修机制】
| 可兼修体系 | 玄灵九叠、万火凝丹 |
| 兼修桥梁 | 纹铸同源、火纹同调 |
| 兼修代价 | 破境时间翻倍；铸造时若使用丹火，丹毒会以"铸斑"形式积累于双手，需"洗纹液"清除，否则双手报废 |
