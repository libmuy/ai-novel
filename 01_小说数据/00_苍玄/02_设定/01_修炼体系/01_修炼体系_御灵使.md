# 体系卡 · 御灵使（契修）

【基础定义】
| 体系名称 | 御灵使 |
| 体系代号 | 契修 |
| 本源描述 | 妖兽命魂之上生有"兽纹"，是野性与天地共鸣的纹理。御灵使以灵力为桥，寻找人与兽纹理的共振频率，缔结"灵契" |
| 修行方式 | 观兽→感灵→缔灵契→共命→通灵，每一步需与妖兽共同生活、共同战斗、共同挨饿，无法闭门造车 |
| 代表人群 | 底层散修（买不起法宝丹药，只能与妖兽抱团取暖）、边疆猎户、遗迹探索者、被宗门抛弃的"废物" |
| 破境考验 | 每大境界需与契约妖兽共同通过"兽纹劫"——天地对"非自然共生"的排斥 |

【境界体系】
| 等级 | 对应主修境界 | 核心能力 | 战力标志 |
|------|------------|---------|---------|
| 1 级 | 感灵境 | 辨种属，感情绪 | 可契约 1 阶妖兽 |
| 2 级 | 拓灵境 | 感灵心，五感全通 | 可契约 2 阶妖兽 |
| 3 级 | 凝灵境 | 缔灵契，心语传递 | 可契约 3 阶妖兽 |
| 4 级 | 化灵境 | 通灵语，情绪同步 | 可契约 4 阶妖兽 |
| 5 级 | 生灵境 | 契纹大成，兽借我纹 | 可契约 5 阶妖兽 |
| 6 级 | 玄灵境 | 三兽化形，纹理互换 | 可契约 6 阶妖兽 |
| 7 级 | 道灵境 | 兽可悟道，道契择 | 可契约 7 阶妖兽 |
| 8 级 | 真灵境 | 瞬移五兽，真身不灭 | 可契约 8 阶妖兽 |
| 9 级 | 苍灵境 | 万兽来朝，天契同归 | 可契约 9 阶妖兽 |

基准对照系：以玄灵九叠为通用参照。

【能力边界】
| 核心能力 | 上限与限制 |
|---------|-----------|
| 灵契缔结 | 与妖兽建立命魂链接；上限：同等级可契约对应阶数妖兽，跨一阶（大境界）成功率30%，跨两阶5%，跨三阶必遭反噬；限制：每只妖兽占用一部分命魂容量，强行超量契约将导致自身兽化 |
| 唤灵共鸣 | 远距离召唤契约妖兽或共享其视野；上限：同等级可瞬间召唤，跨一阶延迟三息，跨两阶延迟一刻钟；限制：若妖兽正处于战斗、睡眠或"闹脾气"状态，可能抗命不来 |
| 灵愈共生 | 以自身灵纹治愈妖兽伤势，或借用妖兽生命力自愈；上限：可治愈同等级妖兽致命伤一次/日；限制：治愈代价为双方共同承受痛苦，且过度借用妖兽生命力会导致妖兽提前衰老 |
| 兽纹拟态 | 临时借用契约妖兽的种族天赋；上限：同等级可完全拟态，跨一阶拟态七成，跨两阶拟态三成；限制：每次拟态后需休息三日，连续拟态将导致自身出现妖兽特征，需以"洗纹液"消除 |

| 使用代价 | 每次使用消耗"契痕"（命魂上契约印记磨损），过度使用将导致"兽化症"——行为逐渐兽化、语言退化为兽语、最终彻底成为失去神智的妖兽；妖兽死亡时，御灵使神魂受创程度与契约等级成正比 |

| 致命弱点 | 1. 契约断裂：若妖兽被强行击杀或契约被灵修篡改，神魂受创，短时间内战力归零；2. 兽性侵蚀：长期与凶暴妖兽共生，自身性格会向妖兽靠拢；3. 纯物理陷阱：妖兽无法进入的狭小空间，御灵使失去最大依仗 |

【互克关系】
| 克制体系 | 千机锁元（阵修）——妖兽蛮力与本能可精准摧毁阵基；铁骨九铸（体修）——妖兽远程牵制与空中打击让体修难以近身 |
| 被克体系 | 玄灵九叠（灵修可绕过妖兽直击御灵使本人，甚至篡改灵契使妖兽反噬其主）；万火凝丹（丹毒可污染灵契，使妖兽狂暴或契约断裂） |
| 互克备注 | 若御灵使与妖兽缔结"共生契"而非"主仆契"，灵修难以找到契约薄弱点篡改；若丹修未修至生灵境以上，丹毒不足以影响生灵境以上御灵使 |

【兼修机制】
| 可兼修体系 | 玄灵九叠、万火凝丹 |
| 兼修桥梁 | 灵契同源、丹兽同养 |
| 兼修代价 | 破境时间翻倍；以丹药喂养妖兽会导致妖兽体内积累"丹毒纹"，需额外消耗资源清除，否则妖兽在战斗中可能突然狂暴 |
