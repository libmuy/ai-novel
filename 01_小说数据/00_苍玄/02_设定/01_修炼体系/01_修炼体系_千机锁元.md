# 体系卡 · 千机锁元

【基础定义】
| 体系名称 | 千机锁元 |
| 体系代号 | 阵修 |
| 本源描述 | 天地灵力节点与流动轨迹 |
| 修行方式 | 观测节点，以灵纹锁定并编织，借天地之力，布阵耗时但威力巨大。阵法师往往也是高阶灵纹师，因为阵法即大型地纹 |
| 代表人群 | 阵法师、建筑师、盗墓贼、擅长埋伏的散修 |
| 破境考验 | 每大境界需独立布置并激活一个对应等级阵法 |

【能力边界】
| 核心能力 | 上限与限制 |
|---------|-----------|
| 锁元阵 | 锁定区域内灵力流动；上限：同小境界锁定对应节点数；限制：需提前布阵，瞬发阵法威力减半 |
| 化阵 | 将阵法刻于器物随身携带；上限：同时携带三座；限制：阵器损毁则阵法反噬 |

| 使用代价 | 布阵消耗阵材与神识，阵法被破则神识受损 |

| 致命弱点 | 阵基被毁则全阵崩溃，体修近身后难以布阵 |

【互克关系】
| 克制体系 | 玄灵九叠（灵修）——吸收灵力为阵法能量 |
| 被克体系 | 铁骨九铸（体修）——阵基易被蛮力摧毁 |
| 互克备注 | 若灵修以"灵爆"自毁攻击，可破阵；若体修无远程手段，阵修以困阵可胜 |
