# 体系卡 · 灵纹师（辅助职业）

【基础定义】
| 字段 | 内容 |
|------|------|
| 职业名称 | 灵纹师 |
| 职业代号 | 纹师/刻师 |
| 本源描述 | 不修境界，专精**灵纹刻画**。以灵针为笔、以灵墨为墨、以人体为纸，为修士铺设引灵通道。是修仙界最古老的手艺人，也是最赤裸的阶层分割线——富人买骨，穷人画皮 |
| 修行方式 | 识图→摹纹→下针→养墨。需极端稳定的手感与神识精度，手抖一毫，灵纹崩解，客人爆体 |
| 代表人群 | 宗门供奉（服务贵族）、坊市摆摊者（服务散修）、黑市"鬼手"（非法改纹） |
| 等级划分 | 1 级（凡纹师）→ 2 级（灵纹师）→ 3 级（玄纹师）→ 4 级（道纹师）→ 5 级（天纹师/传说） |

【等级体系】
| 等级 | 对应主修境界 | 可刻画灵纹 | 业务范围 |
|------|------------|-----------|---------|
| 1 级 | 感灵-拓灵 | 聚灵纹、导灵纹、封灵纹 | 坊市摆摊，5-50 杂灵石/道 |
| 2 级 | 凝灵-化灵 | 化形纹、分灵纹、固灵纹 | 小型店铺，100-1000 清灵石/道 |
| 3 级 | 生灵-玄灵 | 生灵纹、玄阵纹、转灵纹 | 可接宗门外包，一城之主级 |
| 4 级 | 道灵-真灵 | 载道纹、真我纹、不朽纹 | 有价无市，以物易物 |
| 5 级 | 苍灵 | 苍玄纹、造化纹 | 传说，现世不存在 |

【核心规则：先天骨纹不可触及】
| 规则 | 说明 |
|------|------|
| 骨纹禁区 | 灵纹师**绝对不可**将灵针刺入骨骼。灵墨入骨，骨髓沸腾，三日之内骨骼从内部炸裂，必死无疑。这是灵纹师行会的绝对铁律，也是阶层的绝对铁壁 |
| 肉纹边界 | 可刻画于肌肉筋膜，但越深越痛，且易随肌肉拉伸而崩解。优质肉纹需配合"定肌散"使用 |
| 皮纹极限 | 最安全但效率最低。底层散修全身刻满皮纹，密密麻麻如电路板，是坊市最常见的"穷鬼套餐" |

【业务细分】
| 业务 | 说明 | 风险 |
|------|------|------|
| 刻纹 | 在空白皮肤/肌肉上刻画新灵纹 | 低（皮纹）/ 中（肉纹） |
| 洗纹 | 老旧灵纹堵塞或褪色，需以灵墨冲洗疏通 | 中（可能冲毁相邻灵纹） |
| 改纹 | 将低效灵纹改为高效灵纹，需先擦除旧纹 | 高（擦除过程剧痛，且会损伤灵窍） |
| 阵纹 | 在地面/建筑/大型器物上刻画阵法，即大型地纹 | 极高（阵法反噬） |
| 鬼纹（黑市） | 非法刻画"噬灵纹""爆灵纹"等禁纹，或给非修士刻画强行引灵 | 极高（一经发现，灵纹师行会追杀至死） |

【与主角关系】
| 字段 | 内容 |
|------|------|
| 主角身份 | **顶级灵纹设计师，三流灵纹工匠**。异宝"缺页灵鉴"能照见人体最优灵纹路径，生成最高效的后天灵纹图；但主角薄识手抖，只能给自己刻最简单的针纹，复杂图案必须找灵纹师代刻 |
| 核心矛盾 | 主角的设计图价值连城（4 级水准），但手残只能干 1 级的活。他不得不把设计图卖给灵纹师，再花钱请对方刻在自己身上——中间商赚差价，主角永远被剥削 |
| 幽默点 | 主角身上灵纹密密麻麻如电路板，来自十几个不同灵纹师的手笔，风格各异：左肩是王师傅的"粗犷风"，右肩是李师傅的"婉约风"，后背是黑市鬼手的"抽象风"。主角自嘲："我这身子不是修炼圣地，是坊市纹身大赛的展台。" |
