## 04_资源分级体系

> 类型：写作规则 · 行为约束/规范，生成与续写时遵循。兼作 `02_设定/04_资源分级/` 文件夹的字段定义源（见 `99_速查手册` S1）。

### 使用范围

定义小说中所有可获取、交易、消耗的资源的分级标准，防止后期战力崩坏与经济体系混乱。

### 层级结构与文件拆分

本分类为多类别查表型数据，采用「总索引 + 子文件」多文件结构，**产出合计 >1KB 时按每类别一文件拆分**（≤1KB 保持单文件、全部写入总索引）。全部文件置于分类文件夹 `02_设定/04_资源分级/` 内。

| 文件 | 内容 |
|------|------|
| `02_设定/04_资源分级/04_资源分级.md` | 总索引：【分类索引】表格（类别｜一句话概况｜文件链接）；≤1KB 时承载全部区块 |
| `02_设定/04_资源分级/04_资源分级_<类别>.md` | 类别文件：单个类别区块全文 |

**拆分粒度**：货币 / 丹药 / 法宝 / 功法 / 材料 / 妖兽 / 秘境 / 经济（经济体系 + 主角经济曲线合一），共 8 个类别文件。

**文件命名规则**：文件名 = 前缀 `04_资源分级` + `_<类别>`，类别名固定为上述 8 项之一。

**父子关系规则**：总索引放「分类索引 + 文件链接」，子文件放「类别区块全文」（区块标题见 §三）。

**按需取分支示例**：某章主角炼丹，只加载 `02_设定/04_资源分级/04_资源分级.md`（总索引）+ `02_设定/04_资源分级/04_资源分级_丹药.md`；需配平经济时再加载 `04_资源分级_经济.md`，禁止整目录全量灌入。

### 设计原则

1. **分级必须对应境界**：每一级资源都有明确的"最低使用境界"与"最佳使用境界"。
2. **兑换比例固定**：货币或等价物的兑换比例一旦设定，全书不得随意更改。
3. **越级使用有代价**：低境界强行使用高阶资源，必须有明确的副作用或浪费率。
4. **稀缺度与获取难度挂钩**：高阶资源的获取途径必须与等级匹配，禁止"路边捡到仙器"。

### 一、通用资源分级总表

以下各表即 `02_设定/04_资源分级/` 下各类别文件的数据格式，字段均须按表填写。

#### 1.1 货币/能量单位分级

| 字段 | 说明 |
|------|------|
| `货币名称` | 通用交易媒介的名称 |
| `分级列表` | 各级名称、对应基准价值、兑换比例 |
| `灵气纯度` | 每一级蕴含的灵气量或能量密度 |
| `外观特征` | 便于在叙事中描述 |
| `主要用途` | 交易/修炼/布阵/驱动法宝 |
| `获取途径` | 矿脉开采/任务报酬/战利品/兑换 |

#### 1.2 丹药分级

| 字段 | 说明 |
|------|------|
| `品级体系` | 几品制？每品是否分阶？ |
| `品级名称` | 一品至X品的具体名称 |
| `对应境界` | 每一品建议的使用境界 |
| `炼制难度` | 对应炼丹师境界要求 |
| `主材等级` | 炼制所需材料的最低等级 |
| `药效上限` | 对同阶修士的效果；对高阶修士的衰减率 |
| `丹毒/副作用` | 越级服用或过量服用的后果 |
| `保存期限` | 丹药是否随时间失效？ |

#### 1.3 法宝/武器分级

| 字段 | 说明 |
|------|------|
| `等级名称` | 如：法器→灵器→法宝→灵宝→通天灵宝 |
| `对应境界` | 每一级建议的持有境界 |
| `灵性程度` | 是否有器灵？器灵智能等级？ |
| `祭炼要求` | 需要多少时间与灵气才能初步祭炼？ |
| `进阶可能` | 是否可通过温养/吞噬材料升级？ |
| `损毁修复` | 受损后如何修复？修复成本？ |
| `认主机制` | 滴血/神识烙印/因果绑定/其他？ |

#### 1.4 功法/典籍分级

| 字段 | 说明 |
|------|------|
| `等级名称` | 如：基础→进阶→核心→秘传→禁术 |
| `对应境界` | 每一级建议的修习境界 |
| `修习难度` | 入门时间/悟性要求/前置功法要求 |
| `威力上限` | 同阶发挥几成威力？跨阶衰减率？ |
| `隐患/代价` | 修习或施展的副作用 |
| `传承限制` | 是否可抄录？是否可外传？是否有传承禁制？ |

#### 1.5 材料/天材地宝分级

| 字段 | 说明 |
|------|------|
| `等级名称` | 如：凡品→灵品→地品→天品→仙品 |
| `对应用途` | 每一级通常用于炼制什么等级的丹药/法宝/阵法？ |
| `生长环境` | 生长/产出地点的特征 |
| `采集难度` | 是否有守护妖兽？是否有采集手法要求？ |
| `保存条件` | 离开原生环境后多久失效？需要什么容器保存？ |

#### 1.6 妖兽/异族材料分级

| 字段 | 说明 |
|------|------|
| `等级对应` | 妖兽/异族等级与修士境界的对照 |
| `材料部位` | 哪些部位有价值？（皮/骨/血/丹/角/魂） |
| `价值差异` | 同一妖兽不同部位的价值比例 |
| `处理要求` | 击杀后多久内必须处理？处理不当的后果？ |

#### 1.7 秘境/遗迹/洞天分级

| 字段 | 说明 |
|------|------|
| `危险等级` | 各等级名称与建议进入的最低境界 |
| `收益等级` | 通常可获得的资源等级 |
| `开启条件` | 时间限制/血脉限制/钥匙/修为门槛 |
| `存活率` | 各境界进入后的历史存活率（用于叙事参考） |
| `特殊规则` | 内部是否有禁法/禁空/时间流速差异等？ |
