## 【本书文风差异】（对底层成长流模板的覆盖与补充）

### 1. 情绪引擎补充

| 模板原定义 | 本书覆盖 |
|-----------|---------|
| 反差共情：强大修士冷漠 + 弱小凡人温热 | **保留**，但增加一层：@主角 以**人前活泼开朗**的外壳包裹**内心冷静算计**的内核，形成"表里反差"，读者比对手更早一步知道"他在演" |
| 付出回报不对等 | **保留**，但压抑期允许苏砚以**冷幽默/自嘲/金句**进行情绪缓冲，形成"苦中作乐"的底层韧性，而非全程沉重 |
| 道理靠事件落地 | **保留**，金句必须在压抑期或释放后依附具体事件蹦出，禁止无事件支撑的"顿悟式金句" |

### 2. 主角双重人格结构（新增）

- **表层（人前）**：活泼开朗、话多带市井粗口、紧张时转旧绳、偶尔冷幽默。功能：降低敌人戒心、收集情报、维系底层关系网。
- **里层（独处/推演）**：冷静、偏执、系统性算计。功能：敲食指（三短一长）进入推演模式，古玉 raw data + 自主 pattern recognition。
- **切换红线**：表层可以崩溃（濒临绝望、一蹶不振），但里层必须在崩溃后**重新接管**——禁止表层永久覆盖里层，也禁止里层冷血到泯灭人性。
- **叙事红线**（对齐 `00_通用写作规则` §6.3）：进入推演模式默认**只写"敲食指"这个动作标记 + 随后的行动/结果**，不展开具体推演思路（禁止"他想：如果……那么……"式分步陈述）；推演内容事后通过结果、对话或旁观者反应回收，让读者"原来那一步是为了这个"，而非在动作发生前把整个盘算端出来。

### 3. 幽默与压抑的配比（新增）

| 阶段 | 幽默规则 | 崩溃规则 |
|------|---------|---------|
| 布局期 | 允许轻松调侃、金句缓冲，但每3章必须有一次"里层闪现"（读者意识到他在算计） | 不允许崩溃 |
| 压抑期 | 允许苦中作乐式金句，但压抑超过2章后幽默必须**逐次递减** | 短周期第3章、中周期第5-6章、长周期第10章后，必须出现**真实绝望感**（濒临崩溃/一蹶不振） |
| 释放期 | 允许燃+幽默并存，但反杀/收获瞬间必须严肃 | 不允许崩溃 |
| 结算期 | 允许自嘲式幽默消化代价 | 允许"后怕式"虚弱，但不允许再次崩溃 |

### 4. 战斗燃点规则（新增）

- **燃的来源**：必须是"布局兑现"的瞬间（"原来那一步是为了这个"）或"绝境极限操作"的生死一刹。
- **燃的禁区**：禁止靠"爆种""觉醒""突然突破"来燃。燃感来自**读者提前知道底牌但对手不知道**的信息差张力。
- **燃后必虚**：燃点章节结束后，下一章必须进入代价结算，禁止燃完就满血。

### 5. 比例微调

事件:感悟 = **7:3**（沿用通用规则基准，无额外调整）。

## 【爽感规则】

### 一、压抑与爽感周期范式（抽象解耦版）

> 本文件仅定义苍玄选用的【底层成长流】抽象节奏范式，不硬编码任何具体卷号、章次或具体剧情。
> 规划层与创作层（《卷大纲》【章节节拍表】与《单章细纲》）根据本范式在具体卷/章中动态匹配与编排。

| 周期范式 | 压抑长度基准 | 压抑要素推荐组合 | 爽感释放门槛与类型 | 典型释放范式 |
|---------|------------|----------------|-------------------|------------|
| **范式 A：短周期缓冲** | 2 - 3 章 | 资源见底 / 坏人盘剥 / 局地困局 / 信息差蒙蔽 | 小爽感（脱险 / 获得关键线索 / 解锁基础资源） | **提前布局伏击**：提前至少1章布置阵纹/道具，利用环境/规则漏洞以弱胜强脱险或突破盘剥 |
| **范式 B：中周期积蓄** | 5 - 7 章 | 荒野逃亡 / 身受伤患 / 强敌追杀 / 资源耗竭 / 武器灵傀损毁 | 中爽感（布局反杀 / 击退强敌 / 解决重大生存危机） | **地形/环境反杀**：提前2-3章布置复合陷阱/阵纹/灵傀，利用古玉 raw data 分析敌人功法缺陷，借环境克制反杀 |
| **范式 C：短周期破障** | 2 - 3 章 | 阶层排挤 / 被分配劣等资源 / 人格贬损 / 规则构陷 | 小爽感（金句破障 / 结识可靠盟友 / 打破信息壁垒） | **金句/信息破障**：以底层金句刺破虚伪规则，或利用市井智慧抓住规则漏洞，引起关键人物共鸣或反向制衡 |
| **范式 D：长周期爆发** | 10 - 15 章 | 长期被体制针对 / 资源被截留 / 遭受构陷 / 道义选择持续吃亏 | 大爽感（绝地反击 / 长期伏笔华丽回收 / 破境碾压） | **破境/伏笔大回收**：此前多章布置的后手与伏笔全部兑现，满足资源+心境+外部三重门槛后突破，首次同阶正面碾压对手 |

**压抑定义落地**：
- 资源持续流失：灵石耗尽、法宝损毁、灵傀损毁、受伤未愈、神魂损伤
- 关系持续恶化：被追杀、被排挤、被构陷、被误解
- 道义选择持续吃亏：选底线则代价发酵（如拒绝杀人夺宝反被截留资源）
- 信息持续匮乏：被蒙在鼓里、被动挨打、古玉因神魂伤受限

**爽感释放定义落地**：
- 主角通过自身能力（阵纹道/灵傀道/古玉推演/底层智慧）获得正向反馈，非天降机缘。

| 项目 | 内容 |

| **本书专属前置** | ① 信息优势来源可追溯：古玉 raw data（灵气波动/物品特性）+ 苏砚底层观察（人心/规律/习惯）② 反制过程中必须明确展示"他知道，对手不知道"（**通过动作细节/对话潜台词/事后结果呈现，禁止内心独白直接点破判断依据**，见 §6.3）③ 信息优势必须在**至少1章前**建立，禁止临时获得 ④ 禁止"全知视角""对手突然说出关键信息" |

|------|------|

### 三、爽感禁忌（本书专属落地细则）

基于 `00_通用写作规则` §7 无脑爽禁令 + `00_文风_底层成长流` 人设红线，细化如下：

| 禁忌编号 | 细则 | 违反示例 |
|---------|------|---------|
| **SJ-001** | **人前活泼 ≠ 无脑乐观**：@主角 表层可以搞笑，但里层算计必须始终在线。禁止为制造笑点而让苏砚在生死关头"忘乎所以"或"嘴瓢坏事"。 | 禁止：敌人刀架脖子上了还在讲段子导致错过最佳反击时机 |
| **SJ-002** | **小恶有界**：苏砚性格跳脱，可做小恶（偷换资源标签、说谎蒙混、占小便宜、顺手牵羊），但**大恶不做**（杀人夺宝后灭口、背叛同伴、以凡人为耗材、趁人之危夺人根基）。小恶必须有代价（被发现风险、内心撕扯、信誉受损）。 | 禁止：为爽感而"黑吃黑"后毫无心理负担；禁止：以"不拘小节"为借口突破底线 |
| **SJ-003** | **古玉 ≠ 全知**：古玉「老灰」仅提供 raw data（灵气波动、物品/功法特性），**推演必须由苏砚完成**。禁止古玉直接给出"敌人下一步会走左边""此功法弱点在第三周天"等结论。 | 禁止：古玉弹出提示框"检测到敌人弱点，建议攻击左翼" |
| **SJ-004** | **燃 ≠ 爆种**：战斗燃点必须来自布局兑现或绝境极限操作。禁止突然觉醒新能力、禁止越阶秒杀（越阶须至少2个外部条件支撑）、禁止绝境中升级。 | 禁止：被揍到濒死突然突破境界反杀；禁止：以筑基期实力正面秒杀金丹期 |
| **SJ-005** | **幽默 ≠ 轻佻**：压抑期金句可以是苦中作乐或自嘲，但濒临崩溃时（短周期第3章、中周期第5-6章、长周期第10章后）必须写出**真实的绝望感**。禁止用幽默消解所有痛苦，禁止"笑着面对一切"。 | 禁止：矿友全死后苏砚讲个段子就"释然了"；禁止：神魂撕裂时还保持"乐观心态" |
| **SJ-006** | **灵傀 ≠ 无限**：灵傀数量/质量有明确上限（第一卷上限约3-5具低阶矿傀/骨傀，战斗力相当于同阶修士的30%-50%），且损毁后需资源修复。禁止灵傀突然变强、禁止无限召唤、禁止灵傀自主觉醒意识。 | 禁止：危急时刻"突然领悟"召唤出10具灵傀；禁止：灵傀替死一次后满血复活 |
| **SJ-007** | **盟友 ≠ 工具**：任何盟友帮助必须符合"利益最大化"逻辑，禁止因"欣赏主角""觉得有趣"等模糊理由出手。盟友必须有独立动机。 | 禁止：某长老"看你顺眼"就送你功法；禁止：敌对势力高手"惺惺相惜"而放水 |
| **SJ-008** | **代价 ≠ 虚设**：每次爽感释放后的代价必须在**至少1章内**真实结算，禁止"下一章满血复活"。代价包括：伤势、资源耗尽、神魂损伤、暴露风险、新增敌人。 | 禁止：第12章惨胜后神魂枯竭，第13章开篇"经过一夜调息已恢复七成" |

### 四、双重校验流程

每次爽感释放事件完成后，必须同时通过以下两项校验：

#### 爽感校验（防止无脑爽）

- [ ] **来源校验**：爽感是否来自"提前布局、合理前置、兑现代价"？若非，阻断并重新设计。
- [ ] **禁令校验**：是否违反五类无脑爽禁令（越阶秒杀/绝境爆种/敌人降智/盟友无条件/杀人夺宝无追查）？若违反，阻断。
- [ ] **周期校验**：当前压抑长度是否超过对应周期上限（短≤3章、中≤8章、长≤15章）？若超过，必须在下一章强制释放或拆分周期。
- [ ] **信息校验**：信息差优势是否在至少1章前建立？古玉是否仅提供 raw data 而非直接结论？
- [ ] **代价校验**：爽感释放后是否有真实代价在1章内结算？代价是否影响后续剧情（非一次性）？

#### 道义校验（防止人设崩塌）

- [ ] **底线校验**：本次事件中 @主角 是否做了"大恶"（杀人夺宝灭口/背叛同伴/以凡人为耗材/趁人之危夺人根基）？若做了，必须有**至少3章前置的底线撕扯铺垫**和**后续长期的良心代价**，否则阻断。
- [ ] **小恶校验**：若涉及小恶（偷摸拐骗/说谎蒙混），是否有明确代价（被发现风险/内心撕扯/信誉受损）？是否在下文有回收？
- [ ] **表里校验**：人前活泼是否覆盖了里层算计？若表层行为导致里层逻辑断裂（如为搞笑而错过战机），阻断。
- [ ] **崩溃校验**：若当前处于压抑期后半段，是否写出了真实的绝望感？是否用幽默不当消解了痛苦？
- [ ] **盟友校验**：盟友帮助是否符合"利益最大化"逻辑？是否有独立动机？是否在未来章节有回报铺垫？

**校验结果处理**：
- 两项均通过 → 事件定稿，进入代价结算章节设计。
- 爽感校验未通过 → 返回事件设计层，重新规划布局/前置/代价。
- 道义校验未通过 → 返回人设层，重新评估底线边界或增加撕扯铺垫。
- 均未通过 → 废弃该事件，从爽感事件库中选取替代方案重新设计。

## 6. 文学化&生活化东方文学质感补充

### 6.1 文学化使用范围

- **高浓度文学表达**仅限以下场景：里层独处、压抑环境、神魂感知、羁绊细节。
- **普通剧情**允许自然出现具有余味的语言，不强求朴素。
- **禁止**形成"进入某个场景就自动开启文学模式"的机械文风切换。

### 6.2 章节配额废除

- 文学表达由**情绪节点驱动**，而非章节数量驱动。
- 无必要时，允许整章没有明显文学描写。
- **禁止**为了完成配额而强行加入写景或抒情。
- **不出现固定数量限制**（如"每章1-3处"等）。

### 6.3 景物描写原则

景物优先服务以下三者之一：

1. **场景真实感**
2. **叙事氛围**
3. **人物感受**

允许出现：
- 心境映照
- 强烈反差
- 冷漠自然
- 无象征意义的真实环境

**禁止**每次悲伤都下雨、每次压抑都阴天这种套路化映射。

### 6.4 金句概念弱化

- 不把"金句"作为主动创作目标。
- 改用"具有余味的语言"或"自然生长的句子"。
- **禁止**角色说出超越自身年龄、身份、经历、认知层级的作者式哲理。
  - 尤其 @主角 在第一卷仍是底层矿修，其语言必须来自生活经验，而非俯瞰人生。

### 6.5 去除具体作品模仿倾向

- 本节标题定为：**生活化东方文学质感补充**。
- **新增原则**：借鉴成熟东方长篇小说"道理生于生活、情感藏于细节、克制留白"的叙事机制，**但禁止模仿任何具体作品的句式、词汇、对白腔调与叙述声音**。
- 避免模型主动模仿《剑来》或其他特定作品——**本条限定的是文字腔调/句式/叙述声音，不限定叙事技法**：§6.3「计谋/推演类内心活动限制」这类悬念保留机制（先摆事实、后揭算计）属于通用叙事技法，不算"模仿具体作品"，须照常执行。

### 6.6 留白原则（新增）

- 情绪优先通过**行动、物件、停顿、反常行为**表达。
- 作者**不重复解释**读者已经能够理解的情绪。
- 一个细节往往胜过一段抒情。
- 允许结尾留下余味，**不强行总结道理**。

### 6.7 人物语言个体化（新增）

- 不同阶层、年龄、身份的人，**说话方式必须不同**。
- 作者叙述语言可以统一，**人物对白不能统一**。
- 凡人、小商贩、矿工、宗门弟子、长老，应有不同语言纹理。
- **禁止**所有角色共享同一种哲理化表达。

### 6.8 意象规则优化

- 保留古玉自然喻体。
- **新增限制**：
  - 核心意象避免高频重复。
  - 优先使用人物当下真实接触的具体事物作为喻体。
  - 少用固定的风、月、雪、星、深渊等万能意象。
  - 例如矿城更多来自煤灰、铁锈、矿脉、潮气、碎石等环境。

### 6.9 事件:感悟说明补充

- 保留 **7:3** 宏观比例。
- 补充说明：**7:3 为全卷长期倾向，不作为逐章比例；文学感优先融入事件本身，而非增加独立感悟段落。**

### 6.10 自检项更新

在文学自检中新增：

- [ ] 是否存在作者主动解释人物情绪？
- [ ] 是否出现所有角色说同一种话？
- [ ] 是否出现固定意象重复？
- [ ] 是否为了文学而牺牲剧情推进？
- [ ] 是否存在刻意制造"金句"的痕迹？
- [ ] 是否保留了必要留白，而非每次都总结道理？
