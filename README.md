# AI 小说生成系统 (AI Novel Generation System)

这是一个专为**长篇网文（支持百万字至千万字级）**打造的高效、严谨且模块化的 AI 小说创作与工程化支撑基础设施。系统采用“通用模板全局复用 + 单本小说数据隔离”的架构设计，结合强类型 `@引用` 解析与三层职责解耦，解决长篇 AI 创作中的设定幻觉、剧情越权及 Token 爆栈等痛点。

---

## 🌟 核心架构特色

1. **三层职责解耦**
   - **设定层（`01_设定/`、`02_数据库/`）**：定义世界规则、实体卡（体系/地理/势力/资源），回答“是什么/谁是谁”；
   - **规划层（`03_规划/`）**：定义剧情时间线、部/卷/章三级大纲与伏笔追踪，回答“什么时候发生”；
   - **创作层（`10_正文/`）**：仅存放最终定稿的正文章节，与生产中间过程完全隔离。

2. **强类型引用与自动一致性审查**
   - 采用标准 `@引用` 语法（如 `@人物.[姓名]`、`@势力.[名称]`、`DY-001`、`FH-001`）构建强链接网络；
   - 内置 `02_工具/audit_consistency.py` 自动化审查工具，实现占位符（`TODO-xxx`）检测与一致性闭环校验。

3. **千万字级 Context Token 优化与分片继承架构**
   - 路由表精准限制单次任务上下文，实现查表型数据离散化（≤1KB 分片）；
   - 支持部/卷/章三级树状分片与作用域继承，将单章生成状态 Token 消耗控制在 <2,000 Tokens。

## 🚀 快速开始与实用工具

### 1. 运行一致性审查脚本
检查小说项目的目录完整性、总索引一致性及残留占位符状态：
```bash
python3 02_工具/audit_consistency.py 01_小说数据/00_苍玄 --format text
```

### 2. 运行架构 Token 效率与规模评估
量化评估路由表加载策略及千万字长篇（3,300+ 章）下的上下文 Token 开销：
```bash
python3 02_工具/eval_architecture.py
```

### 3. 新建小说项目
复制骨架模板创建新小说项目目录（`NN` 为递增编号）：
```bash
cp -r 00_通用模板/05_项目骨架模板/ 01_小说数据/01_新小说名/
```
