# 03_提示词 · 云端大模型提示词存档

本目录存放 OpenCode 拼装的**自包含**提示词存档，供复制粘贴到云端大模型生成规划产出。

## 生成方式

提示词由**共享生成器** `通用模板/03_提示词/00_云端提示词生成器.md` 产出，本目录**不手工维护骨架**。用法：在 OpenCode 中说"加载生成器，为《苍玄》生成『XX 任务』的云端提示词"，生成器会按 `通用模板/00_使用说明.md` 的路由表拼装并**每个任务产出一个存档文件**。

## 拼装结构（每个提示词固定）

```
【你的角色】规划师/设定师，严格按给定模板与数据行事，禁止凭空编造
【必读模板】……（相关卡片模板/写作规则全文）
【已有数据】……（本小说已定稿数据，保证一致性）
【任务目标】生成 XX → 对应 01_规划/、02_设定/ 或 正文卷N/00_规划/
【输出格式】严格按 NN_xxx模板 字段 + @引用/ID 规范；冲突以已有数据为准
【验收自检】字段齐全 / @引用可解析 / 版权道义红线 / 数值符合资源分级
```
